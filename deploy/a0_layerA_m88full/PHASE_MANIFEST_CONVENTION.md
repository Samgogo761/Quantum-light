# GH 节点相位的边界约定

现有部分 GH manifest 在理论上为零的负虚部处，把相位以 8 位小数写成：

```text
6.28318531
```

它只是文本舍入后的 \(2\pi\)，与相位 `0` 完全等价。加固探索脚本按文件原样归档和求 SHA-256，不会因为该边界值拒绝任务。后续严格 ±N 配对及生产验收必须遵守：

1. ±N 共享节点首先以 manifest 的**字节 SHA-256 完全相同**为硬门；
2. 若还需逐列比较相位，应先计算 \(\phi\bmod 2\pi\)，再比较圆周距离；
3. 相位文本的允许舍入误差取约 \(10^{-6}\) rad；
4. `6.28318531` 与 `0` 不得被判为不同或越界节点；
5. 新生成 manifest 时，应提高 `phi` 与复振幅的输出精度，并把足够接近 \(2\pi\) 的相位规范化为 `0`。

约定的严格配对工具 `tools/analysis/combine_pmN_nodes_strict.py` 应实现上述圆周相位比较，而不是直接使用普通绝对差 `abs(phi_plus-phi_minus)`。
