## 1. 静态数学对象：向量丛、厄米映射和反线性结构

设二维倒格环面 `T_BZ² = R²/Λ*`，基底纤维 `V ≅ C²_layer ⊗ C²_sublattice ⊗ C²_spin ≅ C⁸`。在 embedded Bloch 规范中，哈密顿量并非普通周期函数，而是满足 transition/sewing 关系的纤维厄米映射 `h_N(k)`。M0 的基底为 `(tA↑,tA↓,tB↑,tB↓,bA↑,bA↓,bB↑,bB↓)`。

已有 M0 的模型是

```
h_{ℓ,N}(k) = t_h [Re f σ_x − Im f σ_y] ⊗ s_0
              + λ_SO g σ_z ⊗ s_z + N η_ℓ Δ σ_0 ⊗ s_z,
T_0(k) = exp(ik·q) [[u, v exp(ik·(d+a₂))],
                    [v exp(−ik·d), u]],
h_{8,N}(k) = [[h_{top,N}, T_0 ⊗ s_0],
                [T_0† ⊗ s_0, h_{bottom,N}]].
```

这里 `f(k)=exp(ik·d)[1+exp(−ik·a₁)+exp(ik·a₂)]`，`g(k)=2{sin[k·(a₁+a₂)]−sin(k·a₁)−sin(k·a₂)}`。`η_top=1,η_bottom=−1`，`N=±1`，`h†=h`。`h(k+G)=U_G† h(k) U_G`，`U_G=diag(exp(iG·τ_j))`。这些是已有生产 M0 数学定义，不能为了使某种量子相关非零而改动。

在反演中心为原点的基底下，`P=τ_x⊗σ_x⊗s_0`，`Θ=(τ_0⊗σ_0⊗ i s_y) K`。先前已经数值验收

```
P h_N(k) P⁻¹ = h_{−N}(−k),
Θ h_N(k) Θ⁻¹ = h_{−N}(−k),
Ξ h_N(k) Ξ⁻¹ = h_N(k),   Ξ=PΘ,   Ξ²=−I.
```

**定理 1（Kramers 对）**：若 `h=h†`、`Ξ h Ξ⁻¹=h`，`Ξ` 反幺正且 `Ξ²=−I`，则每个本征值的复几何重数为偶数。证明：由 `h u=Eu` 得 `h Ξu=EΞu`，又 `〈u,Ξu〉=0`，可递推配对。此结论只涉及固定 k 的静态谱，不推出同一磁畴下强场 HHG 输出的奇偶性。`PT` 的反幺正性也不能被当成普通酉对称直接施加到前向演化和探测端口。

在适当 quaternionic 基底下，满足 `Ξ²=−I` 的厄米 `8×8` 矩阵具有块形 `[[A,B],[-B*,A*]]`，其中 `A=A†`、`Bᵀ=−B`；自由实参数为 `16+12=28`，少于任意 `8×8` 厄米矩阵的 64。这里的 `B` **不是**物理层间块 `T_0`。

## 2. 电子多体空间：外代数而不是先引入算符

对一个固定 k 扇区定义 `V_k=C⁸`，四个全同费米子的 Hilbert 空间为 `∧⁴V_k`，维数 `C(8,4)=70`。单粒子映射的自然提升为

```
dΓ(h)(v₁∧v₂∧v₃∧v₄)
 = Σ_{j=1}⁴ v₁∧…∧(h v_j)∧…∧v₄.
```

该构造无须把 `c_j† c_k` 当作公理。设 `s_z` 保守、`V=V_↑⊕V_↓`，每一块维数 4；当初态位于 `n_↑=n_↓=2` 扇区并且耦合仍保自旋时，

```
H_{e,k}^{(2,2)} = (∧²C⁴_↑) ⊗ (∧²C⁴_↓),
            dim = 6×6 = 36.
```

真实宏观样品的多个 k 模式通过**同一量子泵浦和自由辐射场**耦合，不能把独立 k 的量子输出强度求平均后视为精确全局光态。非相互作用+外加经典场下，每 k 的 Slater 态由单粒子幺正演化得到；**量子光回作用**一般打破电子边缘态的 Gaussian 闭合。

## 3. 光子 Hilbert 空间：Bargmann 全纯函数

一个量子光模对应

```
B = {f(z) entire : ||f||² = ∫_C |f(z)|² exp(−|z|²) d²z / π <∞ }.
```

其中 `|n〉 ↔ zⁿ/√(n!)`；在全纯表示下，`a ↔ ∂_z`、`a† ↔ z`。这里产生湮灭算符**是由函数空间几何导出的表示，而非起始假设**。光场真空为常数函数 `1`，相干态 `|α〉` 对应 `e^{−|α|²/2} e^{α z}`。多模时取 Hilbert 张量积 Bargmann 空间。

以单模均匀量子矢势为例，某一条 real-space hopping 的 Peierls 因子为

```
exp[i k·δ] exp[i η_δ (a+a†)],
η_δ = e A_zpf (e_pol·δ)/ℏ.
```

由于 BCH 恒等式 `[z, ∂_z]=−1`，得到严格映射

```
exp[iη(z+∂_z)] f(z)
    = exp(−η²/2+iη z) f(z+iη).
```

它是一个作用于整个 Bargmann 空间的**单位平移算子**（相位空间的 Weyl 位移表示）。对于电子外代数值全纯函数 `Ψ(z,t)∈∧⁴C⁸`，原始非微扰问题可写成

```
iℏ ∂_t Ψ(z,t) = [ℏω z∂_z + dΓ(h_N(k; A_zpf(z+∂_z)))] Ψ(z,t).
```

注意这是一种简洁记法：矩阵函数 `h_N` 必须通过**实空间每条键的 Peierls 指数及其有序算子表示**定义，不能将非交换算子草率塞入任意既有数值插值函数。正确 Peierls 耦合包含各阶电流接触项；有限动量辐射需要 real-space 模式结构，不能全部套用均匀场 k-shift。

多模和宏观多 k 问题仍无限维；该表示改变了数学语言，并**不神奇消除维数灾难**。

## 4. 联合态、动力学和“完整量子图像”

完整观察对象是 `A = CAR(V_e) ⊗ CCR(V_γ)` 的态 `ω(A)`。状态是规范化正线性泛函：`ω(1)=1`、`ω(A†A)≥0`。演化由自同构 `α_{t,s}` 给出：`ω_t(A)=ω_s(α_{t,s}(A))`。有限截断下等价于 `ρ(t)=U(t,s)ρ(s)U†(t,s)`，但无限场的数学定义要认真处理 Weyl 代数、生成元定义域、开关及散射极限。

给定**真实正交的自由输出波包** `b_μ`，可用 Weyl 特征函数定义整份辐射量子态

```
χ_out(ξ) = ω_out[exp(Σ_μ ξ_μ b_μ† − ξ_μ* b_μ)].
```

由 χ 的导数可得到输出各阶矩；其傅里叶变换给 Wigner 准概率。二阶信息为

```
β_μ = ω_out(b_μ),
n_{μν} = ω_out(δb_μ† δb_ν),
m_{μν} = ω_out(δb_μ δb_ν).
```

均值和二阶矩一般**不足以重构非 Gaussian 态**。若预测两个正交模式的 Gaussian 态，正则玻色对易与不确定性条件 `V+iΩ/2 ⪰0` 必须成立；满足辛关系与正性也不等于已证明材料生成非经典辐射。

对于项目已固定的薄电流片输出关系，频域场算符形式为

```
a_src(ω) = i sqrt[Z₀/(4πℏω S)] I~(ω),
a_R,out = a_L,in + a_src,
a_L,out = a_R,in + a_src.
```

必须理解为**完整耦合的 Heisenberg 电流** `I(t)`，包含电磁反馈，不能直接用纯经典期望 `〈I〉` 代替。对于探测模式，`b_out = b_free + ∫ K(t) I(t) dt`，于是 `n,m` 都含 JJ 的**连通多时间关联**和 `free–current` 交叉项。源场自身不需服从正则 CCR，`b_out` 才需要。因此不能把一个普通经典 `J(t)` 的傅里叶谱称为“完整量子辐射图像”。

本项目 2026-10-20 的 G1 仍未通过：混合 `U₀ + driven − undriven` 的有限窗口输入—输出不是经证明的渐近 canonical 输出；无驱动边界数值衔接亦未通过。不得把不合规的 `U,V` 投影或重标定后宣称获得真实 `n,m`。

## 5. 对称性：严格能推出什么，不能推出什么

在保留所有输入、端口、探测波包和初态变换的条件下，反演给出

```
P: (N, A(t)) ↦ (−N, −A(t)),
J_N[A](t) = −J_{−N}[−A](t),
C^>_{N,ab}[A](t,t') = C^>_{−N,ab}[−A](t,t').
```

若 `J_N[A]` 在零场附近可展开为齐次 `r` 阶响应张量，必有

```
J_{−N}^{(r)} = (−1)^{r+1} J_N^{(r)}.
```

因而**相同偏振/几何的理想偶数阶电流非线性系数**在畴翻转下为奇，奇数阶为偶。该陈述严格依赖 P 关联的是 `(N,A)` 与 `(−N,−A)` 两个实验；不能把“固定 A 下所有量子输出 m 必然畴奇”当成结果。光场的 P 还要交换 L/R 端口；时间反演 T 会交换 in/out 和初终边界，不能直接用 PT 静态简并推导动态量子统计选择律。生产 metric 下镜面/C₂ 只有近似精度，不能未经误差控制就赋予其零关联定理。

## 6. 一条可解的弱转换数学实验

为了隔离“输入光统计能否传递给谐波”这个问题，构建一个**不是完整八带 HHG**的、旋波近似的有效模型。令 `a` 是泵浦光模，`b_q` 是第 q 次谐波输出模式（先不处理辐射端口或电子响应），取

```
H_eff/ℏ = Σ_q [g_{q,N} b_q† a^q + (g_{q,N} b_q† a^q)†].
```

`λ_{q,N}=g_{q,N}T` 为小转换幅度。初始谐波模式真空且与泵浦不相关。在 `|λ|≪1`、谐波耗尽可忽略的一级算符展开下

```
b_q,out = b_q,in − i λ_q a^q + O(λ²).
```

该近似仅用于计算低阶物理量；不要把它强制当作**严格**输入输出变换：在 `O(λ²)` 它尚未满足完整的 canonical CCR。对于用完整 `H_eff` 计算到首个非零阶的协方差，结论为

```
β_q = −i λ_q 〈a^q〉 + O(λ³),
n_{q r} = λ_q* λ_r [〈a†q a^r〉 − 〈a†q〉〈a^r〉] + O(λ⁴),
m_{q r} = −λ_q λ_r [〈a^{q+r}〉 − 〈a^q〉〈a^r〉] + O(λ⁴).
```

这里 `O(λ^s)` 仅表示各转换耦合共同以小参数缩放时的阶数；具体初态和波形可能引入更特殊的消零。`n` 的公式假定对应自由谐波输入真空且没有额外有损、散射或真实电子涨落通道。它不是所有 HHG 的通用公式。

### 6.1 压缩真空如何让 H2 发出压缩光？

令泵浦为**零位移单模压缩真空** `S(ζ)|0〉`，其

```
〈a〉=0, n̄=〈a†a〉=sinh² r,
s=〈a²〉=−exp(iφ) sinh r cosh r,
|s|²=n̄(n̄+1).
```

Wick 定理立即给出

```
〈a†² a²〉=3 n̄²+n̄,
〈a⁴〉=3s².
```

带入 H2 公式：

```
β₂=−iλ₂ s + O(λ₂³),
n₂₂=2|λ₂|² n̄² + O(|λ₂|⁴),
m₂₂=−2λ₂² s² + O(|λ₂|⁴).
```

以 `X_θ=(e^(−iθ)δb₂+e^(iθ)δb₂†)/√2`，则

```
min_θ Var(X_θ) = 1/2+n₂₂−|m₂₂|
                  = 1/2−2|λ₂|² n̄ + O(|λ₂|⁴).
```

因此，对任何固定 `n̄>0`，足够小但非零的 `λ₂` 在这个**封闭理想有效模型**里使 H2 有输出正交分量压缩。效应可能很弱、实验损耗会削弱它，且**未证明八带 M0 中 g₂ 非零或可用该 H_eff 逼近**。

同样，在等平均泵浦光子数的比较中，H2 生成通量的首阶比例为

```
〈b₂†b₂〉_sq / 〈b₂†b₂〉_coh
 = (3n̄²+n̄)/n̄² = 3 + 1/n̄.
```

这仅对相同 `g₂,T`、微扰弱转换、定义清晰的单模压缩真空和相干态成立；不是实际强场 HHG 的普适增强律。

### 6.2 对 H2–H3 交叉关联的严格禁止定理

只考虑上述 q=2,3 两个转换通道。定义加权激发数

```
Q = a†a + 2 b₂†b₂ + 3 b₃†b₃.
```

由 `[Q,b_q†a^q]=0` 得 `[Q,H_eff]=0`。特别地 `Π=exp(iπQ)` 是守恒的宇称算子。当泵浦输入具有**偶数光子宇称**（例如纯零位移压缩真空）并且两个谐波初始真空，初态对 `Π` 为 +1 本征态，任何时刻均保持这个性质。

`Π b₂ Π†=+b₂`，`Π b₃ Π†=−b₃`，从而

```
〈b₃〉 = 〈b₂ b₃〉 = 〈b₂† b₃〉 = 0
```

**严格成立，不仅仅在最低阶成立**。中心化后的 `m₂₃` 与 `n₂₃` 同样为零。这个结论对所有满足上述 `Q` 守恒、初态宇称条件的参数成立。

其局限非常关键：真实短脉冲、辐射连续谱、电子内部能量变化、反旋转项以及其他和频/差频耦合都可能破坏**该特定加权激发数**守恒。固定一个 Néel 磁畴的 M0 也不具有单独的电子空间反演，所以不能把该禁止定理直接当成 M0 的最终选择律。它只是一个清晰的可证伪基准：若 M0 计算在无位移压缩输入下看到 `m(H2,H3)≠0`，首先要查明它属于何种已明确建模的额外过程，而不是立刻宣称新量子磁性。

### 6.3 两种候选之间的差异

H2∥–H2⊥ 属于 `q+r=4` 的**偶宇称通道**：中心化压缩输入可让 `m` 非零。但若两种偏振都只由相同二阶转换系数产生，在理想全反演协变的源模型下，两个 `g₂` 在畴翻转时同时变号，乘积 `g₂,∥ g₂,⊥` 反而是**磁畴偶**的。必须另找干涉项或混合阶机制才会得到磁畴奇的同频 `m`。

H3∥–H2⊥ 若要看到固定两探测器下磁畴奇的 `m`，理想转换系数一个属于奇阶、一个属于偶阶，乘积的确具有反号的可能；但是零位移的压缩真空输入正好使所需的**奇数阶泵浦关联** `〈a⁵〉` 消失。这暴露出两条物理要求之间的张力，值得检验：

- 在同一数学范式下，要有磁畴奇的跨阶相干信号，可能需要**有位移的压缩输入**，或者另一个破缺宇称的物理通道；
- 若坚持纯 BSV，应优先检查强场电子响应、额外模式和实际脉冲是否打破理想 `Q` 守恒，而不是先假定 H2–H3 相关必然可观测。

这是对之前方案 C 观测候选的**条件性理论筛选**，不是宣告以前的提案错误。特别地，项目探测协议有两侧入射/出射、固定 +z 接收、局域参考相位，完整反演会交换端口，不能省去这一层映射。

## 7. 如何判别真正非经典，而不把 Q 采样当成量子证明

对单模的量子噪声压缩，检验 `min Var(X)<1/2`；对任意多模状态，定义正常相关 `n` 和异常相关 `m`。若输出可写成具有正 Glauber–Sudarshan P 分布的**经典相干态混合**，其中心化随机复幅度满足

```
|m_{μν}|² ≤ n_{μμ} n_{νν}.
```

因此 `|m_{μν}|²>n_{μμ}n_{νν}` 是针对非经典 P 的一个充分见证（前提是模式真正 canonical，所有相位、噪声和中心化一致）。它**本身不等同于已证明双模纠缠**。

若把输入态的 Husimi Q（永远非负）当普通经典概率，并直接平均 classical-SBE 谱，这是一个可研究的半经典近似，但**不是量子光精确映射的普遍恒等式**；即使它与部分量子统计观测吻合，也不表示所有输出关联已由经典随机场重构。真实等能量/等模式/等带宽/等样品条件要逐项冻结。

## 8. 从已有 G1 框架出发，需要的数学—数值验收门

## 10. 更适合多 k 的精确数学重构：外代数行列式影响泛函

本节可能是比“直接把 36 维电子态与全部光子态张量积”更有价值的扩展路线。**重要前提**：M0 电子哈密顿量对电子算符是二次型，即对于任意给定的经典矢势历史 `A(t)`，电子是非相互作用的；电子初态为确定占据投影的 Slater 态。它不假定量子电磁场一定是经典随机场。

### 10.1 两条场历史的多体重叠可以化成一个 8×8 行列式

选固定 k 的八维单粒子空间，令 `V₀` 为由四个占据正交轨道组成的 `8×4` 矩阵，`P₀=V₀V₀†`。给定一条**数值场历史** `A(t)`，令

```
iℏ ∂ₜ U_N[A](t,t₀) = h_N(k+e A(t)/ℏ) U_N[A](t,t₀),
U_N[A](t₀,t₀)=I₈.
```

多体电子终态是 `∧⁴ U_N[A]` 作用于 `v₁∧v₂∧v₃∧v₄`。给定两条场历史 `A_+` 和 `A_-`，它们所生成的两个四电子态的重叠为

```
F_{N,k}[A_+,A_-]
 = 〈Ψ₀, (∧⁴ U_N[A_-])†(∧⁴ U_N[A_+]) Ψ₀〉
 = det₄(V₀† U_N[A_-]† U_N[A_+] V₀)
 = det₈(I₈−P₀+P₀ U_N[A_-]† U_N[A_+]).
```

第二个等号是外幂内积的 Gram 行列式定义，第三个等号是把空间分成占据/未占据正交直和后的块三角行列式恒等式。**这是精确的，不是电子线性响应近似或低阶光场展开**。它说明在给定两条电磁场历史下，电子对量子电磁场的回馈只需对有限维单粒子矩阵做时间演化、取行列式。

更一般的含多 k、初态因子化的体系有

```
F_N[A_+,A_-] = ∏_{k∈K} F_{N,k}[A_+,A_-],
log F_N = Σ_k log F_{N,k},
```

这里各个 k **看到同一对量子场历史**。因此这是电子部分的因子化，并不是把每个 k 的光输出独立计算后相加。`log` 在数值实现时需连续跟踪复相位分支，不能任意选主值。

因 M0 对 `s_z` 的守恒，`U` 和 `P₀` 在合适的自旋重排基底中各分为两个 `4×4` 块，`F_{N,k}` 还可以写成两个占据数为 2 的小行列式的乘积：

```
F_{N,k}=det₂(V_↑† U_{-,↑}† U_{+,↑} V_↑)
         × det₂(V_↓† U_{-,↓}† U_{+,↓} V_↓).
```

这是结构性的约化，但**未积分掉量子光场**。

### 10.2 非交换概率中的“影响核”具有严格正性

任选有限条场历史 `A₁,…,A_m`，定义

```
K_{ij}=F_N[A_i,A_j].
```

对应电子纯态 `Ψ_i=(∧⁴U[A_i]) Ψ₀`，因此 `K_{ij}=〈Ψ_j|Ψ_i〉`。它是一族向量的 Gram 核，满足

```
K = K†,  K ⪰ 0,  K_ii=1,  |K_ij|≤1.
```

因此我们不仅知道形式上的“理论应保持幺正”，而有了一个**可以机器检验的数值约束**。若一个电子影响泛函的离散近似不满足这些条件，就不能直接把它当作合法的量子电子环境影响。

独立数值测试：用 M0 结构与近似几何在单个 k 点传播四种经典光场历史；比较 `4×4 occupied-overlap` 与 `8×8 determinant` 的两种构造，最大差 `1.05×10^-15`；影响核厄米残差 `8.57×10^-16`，最小本征值 `2.52×10^-4>0`，对角元偏离 1 为 `6.66×10^-15`。这是**数学实现检验**，非真实量子输出。

### 10.3 对光场作剩余的、真正量子的泛函积分

在 Schwinger–Keldysh 双时间支路表示中，量子光场有两个待积分历史 `A_+,A_-`，总生成泛函形式上写作

```
Z_N[ξ_+,ξ_-] = ∫ D A_+ D A_- 
    exp{i[S_γ[A_+]−S_γ[A_-]]/ℏ}
    × ρ_{γ,in}[A_+(t₀),A_-(t₀)]
    × F_N[A_+,A_-]
    × exp{i[ξ_+·A_+−ξ_-·A_-]/ℏ} × (边界/规范因子).
```

这里 `S_γ` 为相应规范和辐射边界下的电磁场作用量，`ρ_{γ,in}` 必须对应输入相干态、压缩态或多模量子态；`ξ` 用于生成输出场相关函数。此式是**明确的数学研究框架**，不是声称已给出可直接调用的收敛积分程序。现实问题还要指定场测度、规范固定、状态边界及 UV/IR 处理。

**特别值得注意**：当 `A_+=A_-=A` 时，`F_N[A,A]=1`，而有意义的电子光场涨落信息恰恰包含在两条历史**不相同**时 `F_N[A_+,A_-]` 的结构中。直接把“正定的 Husimi Q 分布”作为随机经典驱动并对 SBE 光谱做平均，通常会丢失这些支路间量子相干，不能从数学上声称与上述积分等价。

定义 `A_c=(A_++A_-)/2`、`A_Δ=A_+−A_-`，在 `A_Δ=0` 附近对 `log F_N[A_c+A_Δ/2,A_c−A_Δ/2]` 作泛函 Taylor 展开：

```
log F = O(A_Δ) + O(A_Δ²) + O(A_Δ³) + …
```

一阶导数由平均电流控制，二阶导数联系电子电流的量子噪声，更高阶导数产生高阶连通电流关联；对 `A_c` 的混合变分还给出响应与接触贡献。这里的**精确系数**应从完整 `h_N[A]` 的矩阵指数和 determinant 求导，而不能将接触项或 Keldysh 时间排序静默省略。

这样我们能够在同一个数学母体里研究三种方案：

1. 保留一阶：恢复经典强场电流与 HHG 平均辐射基线；
2. 保留一阶及二阶：Gaussian 量子涨落、可供 G1 正则性校验的响应/噪声核；
3. 保留三阶及以上：研究非 Gaussian 输出、反聚束和跨谐波高阶关联的候选贡献（需控制截断、收敛与初态）。

这是一条在电子部分**精确**、在光场部分可以分层近似的方案。它不会自动绕过 G1 已发现的辐射端口和散射边界问题，但能把电子响应问题从巨大联合 Hilbert 空间中独立出来，也为检查 G1 的近似带来新的独立基准。

## 13. 新的可证伪候选：用很弱的相干种子解锁 H2–H3 关联

考虑输入为**位移压缩真空** `|ψ〉=D(α)S(ζ)|0〉`，其中 `α=〈a〉`，定义中心化压缩异常矩 `s=〈(a−α)²〉`。在第 6 节的同一个纯量子转换模型里，泵浦的五次阶**连接矩**精确为

```
C₂₃ := 〈a⁵〉−〈a²〉〈a³〉
     = 6 α³ s + 12 α s²
     = 6 α s (α² + 2s).
```

证明仅用到中心化 Gaussian 态的 Wick 规则：`〈d〉=0`、`〈d²〉=s`、`〈d⁴〉=3s²`，其中 `d=a−α`。因

```
〈a²〉=α²+s,
〈a³〉=α³+3αs,
〈a⁵〉=α⁵+10α³s+15αs²,
```

相减立即得到上述式子。于是跨谐波异常相关

```
m₂₃ = −6 λ₂ λ₃ α s (α²+2s) + O(λ⁴).
```

这里 λ 统一表示小转换强度，且输出所有自由谐波初态仍为真空。一个自然的**条件性实验预测**是：

- 纯零位移压缩真空 `α=0` 时 `m₂₃=0`（第 6.2 节的严格禁止定理）；
- 对固定 `s≠0` 加入小相干种子，`m₂₃≈−12 λ₂λ₃ α s²`，信号在 `α` 上**一阶开启**；
- 改变种子和压缩相位使 `α²+2s=0` 时，一阶转换贡献还会出现**相消零点**；这不是总实际 HHG 关联必须严格消零的定理。

若进一步在**明确满足反演交换磁畴、且已处理端口/偏振变换的有效源模型**里可以证明 `λ₂(−N)=−λ₂(N)`、`λ₃(−N)=+λ₃(N)`，那么对同一量子输入和相位参考，首阶的 `m₂₃` 将具有**磁畴奇**响应。上述 λ 的变换规则只是候选有效模型的额外物理条件，**不是已由完整 M0 的固定 +z 端口量子输出推导得到**。它给我们一个明确的待证伪目标：计算八带 M0 是否产生足够强的复数连接关联及与 Néel 反转一致的端口变换。

在单独的 30×4×4 截断模型中（`r=0.45`,`α=0.2`），输入五阶连接矩数值为 `0.60760552297`，Wick 公式为 `0.60760555141`（高数光子截断误差约 `2.84×10⁻⁸`）。取 `λ₂=λ₃=0.005`，完整酉演化得到 `m₂₃=−1.51808903×10⁻⁵`，最低阶预测 `−1.51901381×10⁻⁵`，差 `9.25×10⁻⁹`，与预期的高阶修正相符。这个例子也支持**可计算、可复现**这一目标，但尚非材料研究数据。

新的优先问题由此非常具体：**在已确认的方案 C 和真实 M0 中，什么样的电子非线性响应与输出端口结构，能把这种纯数学连接矩转化为真正的磁畴敏感辐射？**
