# Q-MATH-16.15 研究接续说明

## 可信的研究状态

- 原生产源码来自 Q-MATH-16.7，经 Q-MATH-16.14 归档，存放在 `sources/QMATH_16_14/Q16_13_original/src_0/`。这套 M0 是**现象学八带机制模型**，不是实际 CrI3 Wannier。
- 已证明：空间反演 P + 自旋 π 旋转 R_x 构成 `λ_SO ↔ -λ_SO` 的协变。合适的均匀电偶极和反演匹配端口中，奇数总电磁场插入的响应是 SOC 奇函数，Néel 反向也翻号。
- 对纯 BSV 与 H2 真空，联合偶宇称入态给出（指定奇宇称电偶极出射模）`beta(-λ)=-beta(λ)`，`n(-λ)=n(λ)`；`beta(0)=0` 不蕴含 `n(0)=0`。严格的计数亮/相干暗玩具反例已做完整酉传播，但 **M0 SOC=0 时 n>0 尚未认证**。
- 120 个 0–7 阶解析 Peierls 顶点检查通过；生产 T3 BZ 与原五阶裸 T 的 SOC 反号通过；`T3/λ` 在 35² BZ 仍显著漂移，所有绝对数值仍未物理收敛。
- 已证明：严格单色泵浦+弹性返回+固定 H2 端口的谱秩最高为 1；跨不同单色入射实验扫频得到的表观谱秩不是固定宽带 BSV 模的输出秩。生产裸核跨输入扫频获得表观 `sin(angle)≈0.194365`，不属于材料内禀多模的证据。
- 核心高阶量子矩来自 Q16.14：`M0=<a²>`, `M1=<a†a³>`, `M2=<(a†)²a⁴>`；它们和已知经典矩界可用于**有谱正交投影、带资源匹配**的磁性量子见证，但目前没有输出物理谱分离证明。

## 运行指令

在解压目录、安装 NumPy/SciPy/Matplotlib 后，按顺序：

```
python qmath_16_15_vertices_symmetry.py
python qmath_16_15_soc_symmetry.py
python qmath_16_15_five_soc_check.py
python qmath_16_15_soc_derivative.py
```

## Q-MATH-16.16 的焦点

1. 在冻结的 M0 键表下研究**同一个**输入纯 BSV 波包 `u(ω)`；用真正的 S 矩阵/连通约化而不是人工 `iγ` 裸 T 的巨大数值。
2. 对比指定反演协变输出模式的 `beta_H` 与输出计数 `n_H`，尤其 SOC=0 限制、电子最终态正频能量壳与因果两时电流 Gram。
3. 如果希望提取高阶异常矩 `M1/M2`，先构建真正宽带输出谱 `S0(Ω;u),S1(Ω;u),S2(Ω;u)`；确认独立谱方向、错误条款、BZ/γ/探测器负控与归一化；再同 `E,F₂,F₃` 最优正 P 经典光比较。
4. 所有新发现必须排除普适 BSV 幅度增益、普通 SOC 触发磁性 SHG、非弹性能量壳伪秩和输出检测窗多模伪象。
