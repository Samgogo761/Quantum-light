# Q-MATH-16.28｜最小独立复算说明

**定位：** 使用用户此前提供的 M0 生产源码（由 Q16.7 → Q16.26 → Q16.27 的可复算接口），在已验证的经典 *retarded* χ² 上完成两个实际占据压缩波包的“异常矩线性响应代理”检验。**不是物理量子 HHG 输出 S 矩阵。**

## 环境
Python 3.10+、NumPy、Matplotlib（只有图表/报告生成脚本才需要）、Pandoc（只有 Word 再生成时需要）。

## 运行方式
从 ZIP 解压后进入包目录，顺序执行：

```bash
python qmath_16_28_multimode_screen.py
python qmath_16_28_photon_weighting.py
python qmath_16_28_classical_dual_audit.py
```

第一步优先读取同目录 `kernel_cache.json` 作为原有 k 网格与频率核缓存；删除这个文件会调用 `q16_27_reference` 下的完整 M0 retarded kernel 重新计算约 90 个频率点，其中部分可直接复用 `qmath_16_27_shape_scan.json`。已保存的缓存来自本轮真实运行，不是合成材料数据。

## 基本验收
- 两个波包正交，内积绝对值 < 1e-12；两个压缩占据严格 > 0。
- parity 导致的交叉输入核 < 1e-11；正确光子 `1/sqrt(w1*w2)` 权重下常数材料核校准后暗输出 < 1e-11。
- Δ=.4 与 .8 的 M0 双频材料核读出矩阵在 eta=.08,.03 下有非零行列式；在 L=161→201 时检验结果稳定。
- 经典 P 紧界采用完整两模自由光子能量矩阵 W（**不能**把它简单近似成 0.18 I），并由显式 ±α 混合达到。
- `classical_dual_audit` 中的随机噪声只是理想化算法单元测试，不是实际实验误差预算。

## 证据分级
**严格数学：** 正 P 能量界、紧性、宇称交叉核的消失、常数核校准后暗输出的消失、代理线性读出的对偶超平面。

**M0 实算：** 因果经典 χ² 的双频频率分配曲率、BZ 与人工展宽依赖；对应的经典响应核可以正交波包投影。
