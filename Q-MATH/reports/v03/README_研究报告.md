# Q-MATH-03：生产 M0 八带 × 完全量子化有限泵浦与 H2 模式（阶段性研究报告）

日期：2026-10-21。计算地点：ChatGPT 当前本地 Python 容器。**这些结果是单动量、有限模式、有限开关时间的理论基准，不是完整晶体的远场 HHG 光子输出预测。**

## 一、可重现模型及严格数学结构

源为用户交付并在此前通过 Mathematica 双验证的三个文件：`q8_m0_model.py`、`q8_tperp_static_audit.py`、`CrI3_scf_soc_a1h_clean.in`。不修改 M0 的 hopping、SOC、层间耦合、反铁磁交换场、轨道嵌入或 Peierls 规范。

只取分数动量 `k=(0.4158,0.1683)`，四电子占据空间选择严格守恒的两个自旋向上、两个自旋向下扇区

\[
\mathcal H_e=\bigwedge^2\mathbb C^4_\uparrow\otimes\bigwedge^2\mathbb C^4_\downarrow,\qquad \dim\mathcal H_e=6\times6=36.
\]

采用有限光子空间 `N_p=25`、`N_{H2}=5`，总维度 \(36\times25\times5=4500\)。光子坐标 \(X_p=a+a^\dagger\)，\(X_2=b+b^\dagger\)，有限截断后它们是有界自伴矩阵。Hamiltonian 定义为

\[
H_N(t)=d\Gamma_{2\uparrow+2\downarrow}\left[h_{8,N}\left(\mathbf k+g(t)\big(A_pX_p\hat{\mathbf e}_{a_2}+A_2X_2\hat{\mathbf e}_{\mathrm{det}}\big)\right)\right]+\hbar\omega_0 a^\dagger a + 2\hbar\omega_0 b^\dagger b.
\]

此式的 \(h_{8,N}(\mathbf k+\hat{\mathbf A})\) 用联合光子坐标矩阵的谱分解（函数演算）定义，不对光场作 Taylor 截断。由于 \(X_p\) 与 \(X_2\) 是不同模式，它们对易。利用 \(X\) 本征基，电子多体 Hamiltonian 可对每个光子坐标本征值通过生产 M0 计算，而无须显式生成整个大矩阵。

\[
g(t)=\sin^2(\pi t/T),\quad 0\le t\le T,\quad T=2\frac{2\pi}{\omega_0},\quad \hbar\omega_0=0.18\,\mathrm{eV},\quad A_p=0.05\,\AA^{-1},\ A_2=0.005\,\AA^{-1}.
\]

初始电子为该 \(k\) 点半填充 Slater 基态，H2 初始真空，泵浦分别取真空、\(|\alpha|^2=0.7\) 的相干态、平均光子数 \(\bar n=0.7\) 的单模压缩真空（squeeze phase 0），以及同 \(\bar n\) 的热态。**本实验不是冻结的八周期 P1，也没有电磁连续谱、辐射片反馈和输入输出端口。**

时间传播使用：半步自由光子相位 + 一整步随中点时间取值的量子化 Peierls 电子演化 + 半步自由光子相位。每小步严格保持截断空间的范数（实测最大偏离 \(10^{-13}\) 量级），时间离散存在二阶误差。完成后由电子和泵浦的约化迹得到 \(\rho_{H2}\)；直接计算 \(P_n\)、\(\langle n\rangle\) 和 \(g^{(2)}=\langle n(n-1)\rangle/\langle n\rangle^2\)。

## 二、实际量子输出数值

基准 N=+1，探测偏振平行于 a2：

| 泵浦输入 | H2 光子数 | g2(0) | 注 |
|---|---:|---:|---|
| 真空 | 0.0006530736 | 10.657 | 时变耦合开关造成的背景，不可视作受激 HHG |
| 相干态，nbar=0.7 | 0.0038191185 | 1.482 | 相位取 alpha>0 |
| 热态，nbar=0.7 | 0.0086078315 | 约5.19 | 11 个 Fock 权重近似（保留总概率0.9999423）；正 P、经典随机光输入 |
| 压缩真空，nbar=0.7 | 0.0118935047 | 约7.82 | 零位移单模压缩真空 |

按绝对平均光子数，BSV/相干约3.114、BSV/热态约1.382。因为真空背景非零，不能把这些比值说成纯驱动的谐波转换效率。与真空同协议差分，净光子数依次约为0.003166、0.007955、0.011240，减背景不等价于测量非经典性的证明。

**这是一种统计与相干相位敏感的非线性响应，不是量子优势证明**：单一相干态对照不足以排除正 P 经典统计效应；热态已经产生比相干态大得多的光子数。所有被列出的 g2>1，不能宣称反聚束。BSV 的 g2 对高光子数尾部更敏感，仍应视为探索性读数。

单 k 双磁畴，平行偏振（绝对值）：

| 输入 | N=+1 | N=-1 | 差 |
|---|---:|---:|---:|
| 相干态 | 0.00381911846 | 0.00381957285 | -4.54e-7 |
| 压缩真空 | 0.01189350469 | 0.01189323065 | +2.74e-7 |

这些微小差异**未通过时间离散/截断误差的磁畴差值收敛门**，不可称为已预测磁畴效应。同一 k 对比也不能代表 BZ 积分或远场端口。

交叉偏振以单模式分别运行（尚不是同一运行中两个偏振的光子关联）：相干态0.000101853、BSV0.000717310、真空0.0000712496。这里 g2 的信号小而数值大，不能直接据此推导偏振纠缠。

## 三、严格的对称性限制（研究路线的新重点）

记 \(\Pi_\gamma=(-1)^{n_p+n_{H2}}\) 为两个光子模式的光子数宇称，\(P_e\) 为真实 M0 的电子反演。M0 严格满足

\[
P_e h_N(\mathbf k+\mathbf A)P_e^{-1}=h_{-N}(-\mathbf k-\mathbf A).
\]

由于 \(\Pi_\gamma X_j\Pi_\gamma^{-1}=-X_j\)，对**本报告的对称、均匀 Peierls 光学环境**，有限模式全 Hamiltonian 严格满足

\[
\boxed{(P_e\otimes\Pi_\gamma)H_{N,\mathbf k}(t)(P_e\otimes\Pi_\gamma)^{-1}=H_{-N,-\mathbf k}(t).}
\]

对宇称不变的输入光态（真空、压缩真空、热态；H2 真空）和由反演相关的电子初态，末态相关；因此任何在光子宇称变换下不变的探测量，特别是 \(n_{H2},P_n,g^{(2)}\)，必须满足

\[
\boxed{\langle O_\mathrm{even}\rangle_{N,\mathbf k}=\langle O_\mathrm{even}\rangle_{-N,-\mathbf k}.}
\]

**独立数值验证**：\(N=+1,\mathbf k\) 的 BSV 输出光子数 `0.011893504692565298`，\(N=-1,-\mathbf k\) 的光子数 `0.011893504692564161`；整个 H2 概率分布的最大元素差为 `2.42e-13`。这比同 k 两磁畴结果更具理论意义。在反演成对的整个 BZ，若实验输入和检测也在反演操作下保持不变，所有这类宇称偶观测量的 Néel-odd 部分严格为零。

**重要边界**：真实远场反演会交换 +z/-z 出射端口，单侧收光的实验算符不一定对反演封闭；BSV 若叠加相干种子则不再是宇称本征态。因此不应将此有限模式的 no-go 不加约束地移植给真实单侧探测的 CrI3。对于有固定相位相干种子的实验，反演映射还会将 \(\alpha\to-\alpha\)，所以在固定同一 \(\alpha\) 的双畴实验中不强制相同。

## 四、数值资格与不足

- 输入 squeezed 态在泵浦 cutoff25 下初态总概率缺损1.93e-6，时间演化中最高占据泵浦 Fock 层的概率约5.61e-4。与 cutoff21,29 的均值差低于约0.5%（光子数尾部统计 g2 仍未充分收敛）。
- 时间步80,160,320时 BSV nH2分别为0.012016597、0.011893505、0.011863809；相干态分别0.003876161、0.003819118、0.003805430。主要均值的差异趋势与二阶时间传播一致，但比磁畴原始差值大很多。不能宣称微小磁性差异。
- H2 cutoff 4,5,6 下 squeezed nH2分别0.01188724、0.01189350、0.01189455，平均光子数变化较小；其 g2 仍对截止尾部较敏感。
- 因为有时变耦合，未给出泵浦为真空时应完全零辐射的假设；开关向系统注入能量。没有该背景的正确物理解读，就不能用此模型直接证明 HHG 由量子泵浦产生。
- 有限截断上的 Fock 操作符不会全空间满足精确 CCR，须在扩大 cutoff 下检查物理结果；此时传播酉性并不等于连续谱光子输入输出正则性已通过。
- 无 BZ 全体 k、无多电子集体辐射相位匹配、无 +z/-z 自由场端口、无真实测量波包、未验证 G1 连续谱输入输出模型。不可用这个数值结果声称输出 squeezing/entanglement。

## 五、科学结论与下一步

当前最牢靠的发现不是3.11倍增强，而是 **反演对称性 + 光子宇称不变泵浦 + 对称检测的 Néel-odd 光子数 no-go 条件**。要产生真正的 Néel-odd 量子光学预测，需要明确哪个条件被打破：例如受控相干种子使泵浦不再宇称不变、实验只收一侧因反演换端口、或测量宇称奇的有相位参考的观测量。与此同时，需要比单一热态更严格的正 P 类对照才能讨论非经典独有优势。

建议 Q-MATH-04：先用同一个精确有限酉模型加入位移压缩输入，并在一次演化中保留 H2 的两偏振、同一个固定的本振参考，明确两个畴和两出射端口的映射；再升级到 full-BZ 和连续模式，不绕过此前尚未通过的 G1。
