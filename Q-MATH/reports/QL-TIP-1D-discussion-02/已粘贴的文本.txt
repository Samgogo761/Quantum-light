我建议就按导师的意见来：只做一个一维模型，不做三维 COMSOL，不做真实金属能带，也不做完整的光—电子联合 QED。

而且我们可以把第一篇论文的目标进一步收紧：

> 研究不同光子统计的入射光，如何影响一维金属纳米尖端的多光子电子发射，以及这种影响如何随入射波长和局域场增强而变化。

暂定英文题目：

Photon-Statistics-Dependent Multiphoton Photoemission from a Metallic Nanotip: A One-Dimensional Model Study

这是一个比较适合初步理论论文的选题。它有明确的物理问题、成熟的计算方法，也不需要投入大量算力。

不过，我核对了原始文献，有一点必须提前说清楚：Heimerl 等人在 2025 年的 Nature Physics 论文中，已经采用一维单电子含时薛定谔方程（1D-TDSE），再结合 BSV 的光强统计，计算金属针尖电子能谱。因此，只复现相干光和 BSV 的发射差异，不能作为我们的主要创新点。&#x20;

## 一、正式确定：只采用一个一维 TDSE 模型

这不是我们自己临时创造的简化模型，而是金属纳米针尖光电子发射文献中已经使用的方法。

例如，2025 年的 ACS Photonics 论文 Quenching Strong-Field Rescattering of Photoemitted Electrons from Metallic Nanotapers by Using Moderate Bias Fields 就采用一维有限深势阱，计算钨针尖电子在激光和静电场下的运动。

### 1. 金属尖端怎样简化成一维？

一维模型示意：只保留沿尖端轴线的电子运动；并非真正的三维针尖形貌或计算结果。

设金属表面位于 \\(x=0\\)，电子向 \\(x>0\\) 的真空区域发射。使用：

\\[ i\hbar\frac{\partial\psi(x,t)}{\partial t} = \left[-\frac{\hbar^2}{2m_e}\partial_x^2+V_s(x)+V_L(x,t)\right]\psi(x,t) \\]

其中，\\(V_s(x)\\) 表示金属表面势阱，\\(V_L(x,t)\\) 表示激光与电子的相互作用。

最简单的表面势阱可取：

\\[ V_s(x)= \begin{cases} -V_0,&-a\leq x\leq0,\\\ 0,&\text{其他位置}. \end{cases} \\]

我们直接采用文献中已经使用的有效参数：

\\[ a=0.135\\,\mathrm{nm},\qquad V_0=10.8\\,\mathrm{eV} \\]

其束缚态能量约为 \\(-5.6\\) eV。注意这是一维有效势阱，不是钨的真实电子能带，也不意味着要计算所有金属电子。

### 2. 近场增强也不需要单独算 Maxwell 方程

写成：

\\[ E\_{\mathrm{loc}}(x,t) =\left[1+(\beta-1)e^{-x/\ell}\right]E\_{\mathrm{in}}(t), \qquad x\geq0 \\]

其中 \\(\beta\\) 是表面场增强因子，\\(\ell\\) 是近场衰减长度。金属内部的光场第一轮近似为零。

激光脉冲则取：

\\[ E\_{\mathrm{in}}(t)=E_0f(t)\cos(\omega t+\phi). \\]

因此，整个计算只需要一个沿 \\(x\\) 方向的电子波函数。

## 二、第一轮计算参数：只固定一套

| 物理量               | 采用值                                                |
| ----------------- | -------------------------------------------------- |
| 材料                | 钨（W）有效表面模型                                         |
| 势阱宽度 \\(a\\)      | 0.135 nm                                           |
| 势阱深度 \\(V_0\\)    | 10.8 eV                                            |
| 有效束缚能             | 约 5.6 eV                                           |
| 激光波长              | 800 nm                                             |
| 脉冲持续时间            | 15 fs（初始测试值）                                       |
| 场增强因子 \\(\beta\\) | 3                                                  |
| 衰减长度 \\(\ell\\)   | 20 nm                                              |
| 入射峰值强度            | 初步扫描 \\(10^{10}\\)–\\(10^{12}\\,\mathrm{W/cm^2}\\) |
| 静态偏压              | 第一轮设为 0                                            |

我特意建议首先用 800 nm，而不是完全照搬实验的 1600 nm。

因为在 800 nm 下：

\\[ \hbar\omega\approx1.55\\,\mathrm{eV},\qquad 4\hbar\omega\approx6.20\\,\mathrm{eV} \\]

对于 5.6 eV 的束缚电子，最低主要多光子发射通道是四光子过程。这让我们更容易理解和检查结果。

这套参数是初始数值测试配置，不是已经证实具有理想发射效率的实验方案。

## 三、量子光部分如何简化？

我建议第一篇只比较三种统计模型：相干光、热光和明亮压缩真空（BSV）。

关键是：我们不把 Fock 态直接替换成一个确定振幅的经典电场，也不在 TDSE 中额外加入量子光子的 Hilbert 空间。

我们先对一组确定强度的经典光场求解相同的一维 TDSE，得到发射概率或电子能谱 \\(Y(I)\\)、\\(S(E;I)\\)，再用不同的入射统计分布进行平均。

例如：

\\[ \overline{Y}\_{j}(\bar I) = \int_0^\infty p_j(I;\bar I)Y(I)\\,dI \\]

其中 \\(j\\) 表示光源类别，\\(\bar I\\) 是相同的平均入射强度。

在明亮、近似单模且强压缩的条件下，可以采用 Heimerl 等人使用的 BSV 强度权重：

\\[ p\_{\rm BSV}(I;\bar I) = \frac{e^{-I/(2\bar I)}}{\sqrt{2\pi\bar I I}}. \\]

热光对应指数强度分布，相干光在忽略相对强度噪声时对应固定强度。这样只需要求解一次模型得到各强度的响应库，随后不同输入统计的计算都是数值积分。

### 一个现在就可以确定的数学检验

在弱场四光子微扰区，电子发射概率近似正比于：

\\[ Y\propto\langle(\hat a^\dagger)^4\hat a^4\rangle. \\]

所以，对于固定平均光子数 \\(\bar n\\)：

| 输入态      | 四阶阶乘矩除以 \\(\bar n^4\\)         |
| -------- | ------------------------------ |
| 相干态      | 1                              |
| 单模热态     | 24                             |
| 单模压缩真空   | \\(105+90/\bar n+9/\bar n^2\\) |
| 明亮压缩真空极限 | 105                            |

这意味着在理想微扰区，明亮 BSV 的四光子吸收响应可以出现很大的统计增强。

但这不是我们发现的新结果，而是程序必须通过的解析基准测试。尤其要明确，105 的增强因子并不单独证明量子优势；具有足够强强度涨落的经典随机光也可能产生相同的高阶强度矩。

真正值得计算的是：当一维尖端进入非微扰响应、电子能谱不再简单服从四光子幂律时，这种统计差异会怎样变化。

## 四、第一篇论文的具体计算任务

我建议只分四个阶段，每个阶段都能独立验收。

任务 1：建立一维表面势阱

求解无光场 Hamiltonian 的初始束缚态，验证束缚能约为 5.6 eV，并确保归一化正确。

交付：势阱图、束缚态波函数和基态能量。

任务 2：只用相干光求解 TDSE

使用 split-operator FFT 或 Crank–Nicolson 方法传播波函数，在真空侧使用吸收边界，计算发射概率。先确认弱场区域的发射产额是否近似满足 \\(Y\propto I^4\\)。

交付：电子发射概率与入射光强的双对数关系图。

任务 3：加入不同光统计

对同一批 TDSE 结果，分别用相干光、热光和 BSV 强度分布进行统计平均。先比较电子发射概率，再计算平均电子能谱。

交付：不同统计下的发射产额、能谱及相对增强因子。

任务 4：增加一个有限的参数扫描

固定一维势阱和光源模型，只改变波长（例如 620、800、1000 nm）以及少量场增强因子。

交付：多光子阶数变化、统计增强偏离微扰预测的条件，以及对应的电子能谱。

最后一项是我们相对于现有工作的主要候选增量：研究统计响应与多光子阶数、局域场强之间的关系，而不是单纯证明 BSV 也能产生光电子。

如果第一轮已经出现足够明确的、超过常规阶乘矩缩放的非微扰趋势，就没有必要再增加模型复杂度。

## 五、怎样判断计算是否可信？

这个工作虽然简单，我仍然建议设置几个硬性验收条件。

| 检查项目    | 必须达到的要求              |
| ------- | -------------------- |
| 无场传播    | 束缚态稳定，无明显虚假发射        |
| 波函数范数   | 仅由规定的吸收边界损失范数        |
| 网格与时间步长 | 主要结果收敛，目标误差约 5% 以内   |
| 弱场幂律    | 800 nm 下验证四光子标度的适用区域 |
| BSV 权重  | 归一化为 1，平均强度等于指定值     |
| 解析基准    | 微扰区恢复热光与 BSV 的四阶矩预测  |
| 电子能谱    | 与发射总概率在归一化上相容        |

电子能谱建议在光脉冲结束后、无静态提取场的条件下，通过真空侧出射波包或连续态投影提取；不能直接把束缚态的动量分布当作发射电子能谱。

还要区分两个概念：这个一维 TDSE 描述的是一个有效束缚电子的发射概率，不是整根针尖包含许多电子时的绝对电子计数。只有经过额外的占据态和发射区域校准，才能连接实验的绝对产额。
