原始 Downloads ZIP、`Documents/8带数学` 及仓库已有资料均未覆盖、移动或删除。Word/PDF 的同文版本、ZIP 嵌套副本、缓存、日志和大型运行轨迹不新增进 Git；原包哈希及排除原因保存在 manifest。原始 Word 仍在原资料位置，仓库优先保留可比较的 Markdown。

**归档目录不是可直接运行的包布局。** 同字节文件只保存一次，例如新版依赖可引用原 `tools/` 或另一版本文件；`manifest.packages` 保留每个历史包的原相对路径。`prepare` 按清单还原到被忽略的临时复现目录，避免维护第二套活跃源码。新版本若修改了依赖，须保留旧冻结字节并使用新版本文件，不能覆盖历史依赖。

## 每轮更新

后续 Q-MATH 工作自动按根目录 [AGENTS.md](../AGENTS.md) 收尾：新增报告/程序/结果后登记，更新本 README 的科学结论与继承关系，再执行：

```powershell
python tools/qmath/manage.py finish --message "qmath: 本轮具体成果"
```

脚本核验原件、刷新 INDEX、检查明确文件清单并创建本地提交。它不判断数学证明是否正确，不执行科研程序，不推送远程；原始归档被改动、已有他人暂存文件或凭据检查命中时停止。普通编辑器不会自行触发提交；这里通过每轮任务收尾约定自动执行，无需后台轮询服务。
