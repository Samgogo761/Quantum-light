## 4. 未闭合项（不计入上表）

1. 步长控制 `.05→.025`：2 条传播 + 匹配准备态 + 读出；只给 `.05` 设置提供收敛证据，不能替代
   `.1` 四相位生产谱的误差。
2. 中区逐节点 η / 盒 / CAP 直接控制（目前仍是 4μ 与 32μ 转用）。
3. 热光严格验收（建议暂缓，但保留未验收标记）。
4. 按任务类型的失败重试与准备开销。
5. 新增强度节点的相位与数值覆盖。

## 5. 插值的层级，不是「八个节点」

- 25.8% 是已有粗细积分差，**不是已知的真实残余误差**。
- 若仅按「每层误差除以四」的情景演算：25.8% → 6.45% → 1.61% → 0.40%；第二层仍高于 1%。
- 节点层级按 4–12μ 的四个 2μ 区间逐层二分：第 1 层 +4（5/7/9/11），第 2 层累计 +12，
  第 3 层累计 +28。这只是层级与累计数量的对应，不是建议实际执行，也不能由它推出「必须八个节点」。
- 收敛是否真按四分之一下降无法预先保证；若响应有阈值结构或非光滑段，层级可能更多。

## 6. 结论（收窄）

**目前尚未找到在现有预算内、证据覆盖完整且成本可信的续算方案。** 暂停本轮自动补算合理；
但这不证明课题不可行，也不证明追加约 40 小时是唯一解决办法。管理上限（112 次、每 F 12 节点、
56 h、72 h）可以另行讨论，但放宽额度不等于解决误差收敛。
