## 2. 项目与物理模型

- 目标：在金属针尖电子发射的简化模型下，比较**亮度压缩真空（BSV）**、**热光**与**相干光**的
  偏压响应差异，核心量 `D = Q_BSV / Q_C`，其中 `Q` 为两偏压产额比。
- 模型：一维单活性电子含时薛定谔方程（TDSE），有效方阱 0.135 nm / 10.8 eV，激光 1600 nm、25 fs，
  直流偏压 `F ∈ {0, 1} V/nm`，单代表初态。势阱参数有 Hergert/Heimerl 钨针尖文献背景，但**不宣称**
  是真实钨的第一性原理计算。
- 明确不做：多电子、温度、态密度、费米能级修正、DFT、三维 Maxwell/QED。
- 材料敏感性：−5.6 eV 参数检查仍为 `DEFERRED_PRIORITY`，未进入本轮主线。

## 3. 冻结协议与观测量

- 共同读出：η = 0.05 eV、ΔE = 0.0125 eV、mask 2–4 nm、100 fs 保存态；
  三个固定阈值 0.5170816 / 0.7170816 / 0.9170816 eV。
- 强度节点（I/μ）：0, 0.25, 0.5, 1, 2, 4, 6, 8, 10, 12, 20, 32；其中 6、10 为后加的插值中点。
- 统计权重：BSV `p(I)=exp[-I/(2μ)]/sqrt(2πμI)`，热光 `p(I)=exp[-I/μ]/μ`，相干点为 `I=μ`；
  用分段线性权重在 `[0, Imax]` 积分，`Imax=32μ`，尾部按解析上界单列。
- 验收门：加权总误差 ≤5%、尾部 ≤ 正产额下限的 1%、节点项 ≤1%、求积 ≤0.1%。

- **节点项**（插值残余证据）：25.82 / 25.76 / 41.64 / 45.71%。它是「加入 6/10μ 后相对无中点
  情形的积分变化」，属一阶粗→细修正，不是已证实的残余；按原规则不能置零。
- **极限诊断**（保持产额与权重不变，仅假设目标项为零）：
  - 全部 CEP 归零后：4.52 / 6.22 / 4.29 / 5.53% —— BSV/F1 仍超 5%。
  - 20μ CEP 与 8μ dt 同时归零后：9.92 / 9.13 / 10.72 / 7.97% —— 四通道仍超 5%。
- 结论：**只补相位或只补中点都不够**；步长、中区逐节点 η/盒、插值细化同时是瓶颈。
