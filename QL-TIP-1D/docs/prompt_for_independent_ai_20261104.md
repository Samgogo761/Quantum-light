# 给另一位 AI 的独立选题审查提示词

我们准备做一篇普通专业期刊的一维金属针尖光电子发射理论补充研究。请独立判断选题，不顺着我的假设预设结果，也不要以 Nature/PRL 级突破作为验收条件。

已有本地 Python/NumPy/SciPy 一维单电子 TDSE 求解器；有限方阱宽0.135 nm、深10.8 eV，解析束缚能−5.5087344341 eV，初态、无场与800 nm单强度收敛已验证。计划固定1600 nm、25 fs、光场增强3、衰减长度20 nm，比较相同平均尖端光强下相干光与明亮近单模BSV。光统计沿用文献的强压缩Husimi强度近似，用确定性积分加权同一个经典驱动响应库。只在本地电脑计算；GPU仅在实际测速有利时使用。

候选唯一主变量是静态提取场F_dc，目标问题：偏压对高能电子贡献的抑制，是否随输入光统计而改变？不预设BSV保留平台、不预设增强比非单调。首轮重点观察绝对高能窗产额Y_H、总产额、高能比例和各光源对零偏压的归一化响应Q_j(F)。若Y_H(I,F)只是光强与偏压的乘积分离，光源的偏压归一化曲线不会不同；我们要查的是是否有可靠偏离。

请核实原始来源并区分已知事实、推测及检索空缺：Heimerl2024 DOI10.1038/s41567-024-02472-6；Heimerl2025 DOI10.1038/s41567-025-03087-1；Hergert2025 DOI10.1021/acsphotonics.5c00207；NILES DOI10.1038/s41567-025-03093-3；BSV能量/动量分辨涨落 DOI10.1103/pgkx-8t5c。不要伪造未读的全文或SI。

请回答：

1. 这个交叉问题是否值得做，最可能与哪篇现有工作重复？给可核查来源；查不到不等于没有。
2. 给出一个最小可证伪命题和最少计算矩阵，区分便宜的想法检查与足够形成论文的验证。
