# QL-TIP-1D 模型规范 v0

日期：2026-11-03。本项目采用一个零偏压一维单电子有限方势阱；与 Q-MATH 的八带 M0 模型没有 Hamiltonian 或结果继承关系。仅共用现有仓库和归档工具。

## Hamiltonian 与方向

表面 x=0，真空发射方向为 +x。势阱为 [-a,0]，a=0.135 nm，阱内 V=-10.8 eV，两侧阱外 V=0。采用电子质量 m_e，真空阈值为能量零点。左侧开放空间是有效有限阱模型的一部分；左侧概率流必须单独记账，不能算真空发射。

内部使用原子单位（e=m_e=ℏ=1）：

\[
i\partial_t\psi=[-\tfrac12\partial_x^2+V_s(x)+E_{\rm in}(t)G(x)-iW_L(x)-iW_R(x)]\psi.
\]

\[
G(x)=\begin{cases}0&x<0\\x+(\beta-1)\ell[1-e^{-x/\ell}]&x\ge0.\end{cases}
\]

因此 G 连续、G(0)=0，而 G'=ξ=1+(β−1)e^(−x/ℓ) 在真空侧，金属侧屏蔽场设为零。长度规范相互作用能为 **+e∫E dx**；电子受力是 −eE。不能用 xE(x,t) 代替空间积分。表面处导数跳跃是本模型的主动简化。

\[
E_{\rm in}(t)=E_0\exp[-2\ln2(t/\tau_I)^2]\cos(\omega t+\phi),\quad
E_0=\sqrt{2I_{\rm inc}/(c\epsilon_0)}.
\]

I_inc 表示脉冲峰值的周期平均入射强度，单位 W/cm²，转 SI 时乘 10⁴。τ_I 是周期平均**强度包络**的 FWHM。首轮 λ=800 nm、τ_I=15 fs、β=3、ℓ=20 nm、E_dc=0；CEP=0 与 π 均须标记。I_apex=β²I_inc，驱动中只乘一次增强因子。λ、脉宽和零偏压属于本项目参数，不是完整复现任一原始实验。

常数从 scipy.constants 读取；每次运行 metadata 保存 a0（nm）、Eh（eV）、原子时间（fs）及软件版本。800 nm 光子约1.5498 eV；连续方阱束缚能5.5087344341 eV对应最低四光子能量门槛。这只是弱场阈值估计，不预设拟合斜率。

## 初态与独立解析检查

令 y=x+a/2、d=a/2、z=kd、z0=d√(2V0)，偶宇称方阱基态满足

\[
z\tan z=\sqrt{z_0^2-z^2},\quad
E_b=-\kappa^2/2,\quad k=z/d,\quad\kappa=\sqrt{z_0^2-z^2}/d.
\]

\[
\psi(y)=A\begin{cases}\cos(ky)&|y|\le d\\\cos(kd)e^{-\kappa(|y|-d)}&|y|>d,\end{cases}\quad
A^{-2}=d+\frac{\sin(2kd)}{2k}+\frac{\cos^2(kd)}\kappa.
\]

z0=1.13646<π/2，故只有一个束缚态。实际连续模型 E_b=−5.5087344341 eV；与文献近似 −5.6 eV 相差约0.0913 eV，不调整参数强行凑数。独立 SI 常数二分求根与 Python 根求解一致。

初态 ∫_(0,∞)|ψ|²dx≈0.135217146，为倏逝尾部而非发射。离开束缚子空间的总概率也不是单独的右侧产额。

## 概率、通量与 CAP

波函数归一化为 ∫|ψ|²dx=1，离散形式为 Σ|ψ_i|²Δx=1；NPZ 的 ψ 单位为 bohr^(-1/2)，CSV 密度为 nm^(-1)。传播中不重新归一化。

在远离表面、早于右 CAP 的探测面 x_d，定义

\[
Y_R(t;x_d)=P_{x>x_d}(t)-P_{x>x_d}(t_0)+A_R(t),\qquad
A_R=\int 2W_R|\psi|^2\,dx\,dt.
\]

使用带符号的净通量，负向回流不能取绝对值或裁剪。无左、右边界泄漏时 Y_R=∫j(x_d,t)dt，并有 N+A_L+A_R=1。数值负值若落在误差内也原样保存，不能悄悄改为零。

对当前有限差分/CN，ψ_mid=(ψ_(n+1)+ψ_n)/2；准确的离散面通量为 j_(i+1/2)=Im(ψ_mid,i* ψ_mid,i+1)/Δx，吸收增量为2ΔtΔxΣW|ψ_mid|²。这一离散连续性恒等式可区分实现误差与物理收敛误差。预算闭合本身不能证明 CAP 无反射，也不能证明有限时间产额已经成为渐近值。

只有通过无场噪声、网格、时间步、盒长、CAP、读出时间检查的产额才能用于斜率拟合。谱提取、统计平均和相位采样均需后续独立验收；本轮没有把束缚态动量谱当作电子能谱。

## 结论边界

该模型给出一个有效电子的概率，不给出整根针尖绝对电子数、真实 W 能带或多电子效应。将来用正强度权重平均 TDSE 结果，只能检验有效随机场统计映射，不能证明不可经典模拟的量子优势、联合光电子相干性或纠缠。暂不开展 Au/Ag SPP、COMSOL、两色驱动或完整 QED。
