# 数值方法与数据约定

当前实现采用双精度 NumPy/SciPy，在本地 CPU 执行。未复制 qmsolve 源码，未安装 CuPy，未报告 GPU 加速比。

## 为什么采用有限差分与 Crank–Nicolson

狭窄方阱的两个跳变界面必须随网格保持固定几何。采用 a/n_w 的均匀网格、单元中心采样，使 −a 和0恰在单元面；所有网格的有效井宽均为0.135 nm。动能是三点二阶差分，矩阵对角1/Δx²，邻对角−1/(2Δx²)。边界为零 ghost 节点，位置随网格记录。

初态使用 SciPy 的实对称三对角本征求解器，仅选负能本征值，避免构造稠密矩阵。这是任务书允许的可靠定态求解方法。[SciPy 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.linalg.eigh_tridiagonal.html)

有场与无场均使用同一个离散 Hamiltonian，时间演化为

\[
[1+i\Delta tH(t+\Delta t/2)/2]\psi_{n+1}
=[1-i\Delta tH(t+\Delta t/2)/2]\psi_n.
\]

LAPACK 三对角分解/求解每步 O(N)。静态 H 只分解一次；有场按中点势重新分解。没有传播后范数修正。

这是对任务书“优先 Strang FFT”的明确算法选择，不是更换物理模型。窄不连续势阱下，不能将有限差分本征态直接交给谱动能传播器，再把初态不匹配造成的泄漏称为发射。FFT 当前只独立验证自由高斯波包；未声称已通过含方阱的 FFT 传播验证。

CN 和 Strang 分裂在适用光滑性条件下均为全局二阶时间方法。qmsolve README 混用了局部/全局误差阶，其措辞不作为精度证明；本实现以实际 Δt 对照为准。[qmsolve 原仓库](https://github.com/quantum-visualizations/qmsolve)

## Stage 1 验收

固定几何扫描 n_w=12、24、48、96、192，比较解析能量和态重叠；另保存“界面节点全纳入”和“半权重界面”作为端点偏差反例。它们不进入生产初态。

无场20 fs分别用约0.2、0.1、0.05 a.u.步长。对于离散本征能 E，CN 的每步相位为−2 arctan(EΔt/2)，不是−EΔt。日志同时保存对精确演化的相位误差与 CN 公式残差；范数精确不等于时间精确。

自由高斯波包初始概率标准差σ，动量p0：平均位置x0+p0t，概率方差σ²+t²/(4σ²)。FFT 使用k=2π·fftfreq(N,Δx)和 exp(−ik²Δt/2)，检查传播方向、动量和展宽；另以 CN 作自由传播及分别加密Δx、Δt的测试。

## 数据与可复现性

每次运行以独立 run_id 创建输出，已存在则拒绝覆盖。metadata 保存完整配置、配置SHA-256、实际源码SHA-256、运行前Git提交、软件版本、设备、单位与时间。运行前提交并不包含当时新增代码，故**源码哈希**用于明确实际运行版本；本轮最终提交由收尾报告给出。

CSV 采用 UTF-8、逗号分隔、单行英文列名，单位写在列名；NPZ 保存复数波函数和坐标。manifest 逐文件记录 SHA-256。日志、失败记录和未通过的曲线均保留；禁止只保留 PNG 或把归一化形状冒充绝对产额。

Stage1 首次运行 r1 在 JSON 序列化 NumPy bool 时失败，科学数组已经生成。修复输出序列化后使用新 run_id r2 重新运行；r1 不作为验收依据。重复字节的归档由项目文件清单映射至一个保存位置。

正式能谱、光统计积分、GPU比较和批量扫描仍需各自的后续数据与关卡。
