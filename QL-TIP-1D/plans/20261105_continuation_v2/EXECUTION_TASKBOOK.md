所有比较均使用新共同η=.05的谱，不能新谱除以旧η=.1产额。默认只到100fs、`full_spectrum_controls=false`，额外读出由新后处理显式安排。每run保存完整100fs态和账本，不归一化、不扣去DC后裁负。

如果四条中任一失败，保留完整现场。只允许第7.2节规定的一轮有原因修正；不要自动把所有dx和dt一起减半。

## 7. 明确误差账本，不能再用“各项<5%”替代总量

### 7.1 每个物理条件建立一行代表误差预算

四条件为(F,I/μ)=(0,1),(1,1),(0,4),(1,4)。令共同读出下的四相位均值为Y，CEP0参考为Y0，各项先在匹配的同CEP下计算绝对/相对变化。

| 类别 | 取值方法 |
|---|---|
| 空间dx、时间dt | 分别用新共同读出下的单参数控制差；两者绝对值相加 |
| 展宽η | 共同四相位均值的η=.05与.025差 |
| 能量积分ΔE | 固定η的网格减半差；与η变化分列 |
| 能量范围 | 增E_max后的Y_H差；全谱归一化仅作另一个诊断 |
| CAP/盒 | 两项变化绝对值相加；记录右CAP损失预警而非把损失直接当谱误差 |
| mask/时间 | 各自变化；只有代表点的项目必须标`representative`，不写全矩阵已直接测试 |
| 准备 | F1/μ两种替代准备的laser主量与默认差的较大值；DC-only占比单独列，不替代此项 |
| CEP | 新η下的2→4变化及代表4→8检查；未做八相位的条件明确标证据覆盖范围 |

最简单的可审阅规则是：在每个代表条件，将上述相对变化保守相加得到`estimated_total_rel_error`；未经直接检验，不假设符号抵消或平方和缩小。若同一误差被两个指标重复诊断，必须写出归类关系，而非任意删掉较大的一个。

CEP0的数值控制是代表抽检；把相对变化用于四相位均值时，报告中注明是经验误差估计，不是所有相位的数学上界。未直接测试的强度不能凭复制一个误差数字自动认证。

为了让R1能有限收尾，以下经验转用是本计划明确允许的规则，记录为`transferred_estimate`，禁止填0或默认为直接测试：

- F0/4μ的盒与CAP项，各取已有F0/μ、F1/μ、F1/4μ对应控制的最大相对变化；两类仍分列。
- 两个4μ条件的mask与时间项，各取F0/μ、F1/μ新共同读出下的最大相对变化。
- F1/4μ的准备项转用F1/μ两种准备变化中的较大者；F0的DC准备变化记`not_applicable`，理由是DC为零且同一本征态仅改变全局相位，不把它记作做过激光控制。
- 未直接做八相位的条件使用当前代表八相位误差与本条件2→4差的较大值，注明覆盖范围。

若任一转用项>1%，或该项使总预算越过5%而必须依赖更准确估计才能判定，则在一次修复额度内补该条件直接控制；不足以完成就INCOMPLETE。否则不自动补齐全矩阵。这是用于有限先导的经验估计，不是对整个强度轴的严格保证；R2/R3仍须检查最高强度和主要贡献区。

### 7.2 门槛及失败处理

- 修复门槛：四个条件的代表性总误差估计≤5%，独立能量积分网格变化≤0.2%，主量高于已验证的绝对误差底，概率账本≤1e−8，准备和DC筛选合格。
- 准备筛选继承预激光损失<1%；同F的DC-only主高能产额<激光μ点的1%。绝对误差底必须引用谱算法测试、背景和实际读出对照，不能凭空填写；也不能把全空间概率账本的1e−8容限直接当成高能窗口的绝对误差——该容限与目前约1e−9的主量不是同一观测量。若信号可信度依赖尚未量化的读出伪差，标INCOMPLETE。
- 候选谱η=.05只有在这些检查完成后才冻结。η=.025目前是对照，不因曲线更好看就改为生产。
- 旧2.21%无需变成显著差异；将q及其误差区间重新计算即可。即使q差仍未分辨，只要响应足够可靠，可以继续统计库。
- 若某项主导而总量>5%，只允许**一轮**针对最大来源的修正，先生成明确任务和成本清单，最多额外8条TDSE，并且R0/R1新增科学时间总计仍≤8h。
- 修改网格/步长后若要作为新中心值，必须有相同新设置的相位平均与必要准备数据，不能只用一个更细CEP0点替换四相位均值。全部所需重算超出额度时，交INCOMPLETE；不靠单点Richardson外推冒充新生产谱。
- 既有盒/mask/准备的代表性证据可复用，但需在误差表注明适用范围；高强度扩展另外验收。

输出新的`R1_gate_<revision>.json`，至少含每项值、参考/控制readout_id、source/config哈希、缺件列表、总量和PASS/FAIL/INCOMPLETE。新runner只认与当前执行配置匹配的这个门槛，不认旧P1_gate的PASS。

## 8. P3先检查高强度成本，再铺库（R2）

只有R1通过才进行。先依次执行以下四个将被最终库复用的点：

1. F0、I=8μ、CEP0；
2. F1、I=8μ、CEP0；
3. 前两点可用后，F0、I=32μ、CEP0；
4. F1、I=32μ、CEP0。

这些是性能与高强度风险检查，不是BSV结论。8μ/32μ的q相近也不能单独宣告统计效应不存在。

初始沿用通过R1的传播数值设置。每点检查：右CAP损失、谱范围、概率账本、耗时/内存；读出前右CAP损失/Y_H<1e−4只是预警线，必须配合大盒对照。发生超线时，不补回CAP标量损失，扩大盒/CAP并新建run，最多两个扩大尝试、最大x=2000nm。

对最高32μ在两个F下分别做dx、dt控制，并在CEP0保存态上补η=.025及固定η的能量网格/范围检查；至少一个风险最大点分别做大盒和CAP减半对照。相应准备缓存存在且完全匹配时复用，否则新准备也计条数/机时。不可把4μ的误差原样用于32μ。

完成后计算预计最低全库成本，纳入后处理、相位补点、插值验证与必要控制。预计超本轮40h、全局72h或新传播112条中的任一项，就交付INCOMPLETE，不因为“已经算了一半”继续超额。

R2门槛不要求最大强度单项机械套用μ的百分比；但必须有足够准确的绝对Y_H、可解释的数值控制和可实现的最终加权误差预算。高强度仍有未量化的CAP/谱损失或>5%的主要数值不稳定，不能铺库掩盖问题。只允许在预算内确定一个更合适的数值设置并按规则重新验证。

## 9. 两偏压经典响应库（R3a）

### 9.1 节点与复用清单

固定F={0,1}、四CEP。初始强度节点：

`I/μ = 0, .25, .5, 1, 2, 4, 8, 12, 20, 32`。

0只用每F一个DC-only，不重复四相位。其余9个非零节点共72条生产响应；旧μ/4μ的16条通过R1且重新统一读出后复用，因此**新增56条生产传播**，包括R2的4条，不是再加56条。

R2通过后的建议顺序：补8μ与32μ其余CEP；然后12μ、20μ；再补.25μ、.5μ、2μ。每批最多8条。先解决强尾成本，弱光节点不成为不必要的开场消耗。

每个F最多12个不同非零I：初始9点之外，最多3点用于真实插值中点和必要尾端扩展。两个F使用共同的节点集合便于审计。不能删除已算点的记录来伪装满足限额。

所有响应使用同一物理协议、共同η和三阈值。传播dx/dt/盒若按强度调整，应有明确`numerical_regime_id`、过渡区同点对照和已验证的误差，不能让不同F恰好采用未经比较的不同数值偏差。没有必要时不要引入自适应网格程序。

### 9.2 相位与主要贡献区检查

保持四相位生产，不因旧4μ的平均稳定就全库降为两相位。

- 最高实际强度（若后来扩到48/64，则以新最高为准）在相位跨度较大的F补45/135/225/315度，检验4→8。
- 得到初步权重贡献后，在主要贡献强度区选择一个代表节点，同样核对CEP和必要dx/dt；若它已经是最高强度测试点则复用。
- 相位平均变化目标≤2%，并纳入最终5%总预算。若四相位不足，不自动把全库翻倍；先核算新成本，预算内不能完成则停止。
- 不能只对两个光源使用不同的相位平均规则来制造差别。

弱光节点即使相对误差大，也不需要无限计算到很小的相对误差。保存其绝对数值和误差估计，检查它对加权结果的**绝对贡献误差**；缺依据时不得设为0或任意给一个上界。

## 10. 统计积分与误差（R3b）

### 10.1 权重与数学单元测试

设Y(I,F)为四CEP平均的绝对正高能产额，0≤Y≤1。主模型为明亮近单模强压缩极限、整体相位随机化后的标量强度平均：

`p_BSV(I)=exp(−I/(2μ))/sqrt(2πμI)`，`p_thermal(I)=exp(−I/μ)/μ`。

相干光固定I=μ；不做10000次独立TDSE，不在I=0添加所谓真空光发射。

这里采用的是Husimi处理在明亮、强压缩条件下的有效强度统计近似，并另行规定整体CEP随机化；上述标量分布不是任意有限光子数压缩态的精确二维Q函数。本文不新引入有限光子数/模式体积标定，也不声称该平均重现完整量子光—电子动力学。论文方法中必须写出此近似范围；不把相位锁定压缩态或一般量子态自动归入同一强度库。

令u=sqrt(I/μ)：

`Y_BSV=sqrt(2/π)∫ exp(−u²/2)Y(μu²,F)du`；

`Y_thermal=2∫u exp(−u²)Y(μu²,F)du`。

对解析函数测试归一化、均值、(I/μ)的2/3/4阶矩：BSV为3/15/105，热光为2/6/24；相对误差<1e−8。这只是权重实现测试，不追加弱场m光子理论推导。

### 10.2 默认分段线性，减少插值歧义

本版明确选**I/μ坐标上的分段线性插值**作为生产默认，PCHIP仅可作为廉价诊断。理由是非负节点保持非负、权重可明确保存、同一网格上的谱与产额积分可保持线性一致；不需要设计复杂拟合器。

对线性帽函数b_i(I)，计算 `w_i=∫_0^Imax p(I)b_i(I)dI`，得到 `Y_trunc=Σw_i Y_i`。w_i≥0，`Σw_i=1−tail_mass`，**不重新归一化w**。在u坐标用自适应求积求权重，检查更紧容差；普通求积误差与响应节点误差分开。

至少在贡献最大的两个**不同强度区间**各补一个真实TDSE中点（两个F、四CEP），比较补点前后的加权产额。建议中点取I的算术中点，与当前分段线性坐标一致。没有真实中点检验，不得用“两种插值器相近”宣布节点收敛。

将两次新增中点导致的加权变化分别保存，以绝对变化的保守合计作为节点收敛估计。若误差仍>1%或导致总预算不达标，可在剩余节点额度内再补；额度耗尽则INCOMPLETE。不把此经验估计称严格插值误差上界。

区分`history_correction`和`current_grid_error_estimate`：历史粗网格的大修正保留在记录中，不永久累加到后续每次误差。当前估计来自当前网格与有真实补点的相邻加密网格之差；每个独立区间用最新有依据的变化，保守合计。仅把中点纳入网格不能将该区间误差设0；没有后续加密证据时保留最新一次差值。节点额度不足以验证改进后的网格时如实INCOMPLETE。

### 10.3 高强度尾部，不外推

I>Imax的缺失**绝对概率上界**：

`B_BSV=erfc(sqrt(Imax/(2μ)))`，`B_thermal=exp(−Imax/μ)`。

要求对每个F、每种统计，B≤已算Y_trunc的1%。若Y_trunc扣除其误差后仍为正，更保守地用此下限判断。不能只要求光脉冲遗漏概率小于某个固定数；目标产额很小时仍可能不可忽略。

32μ不够时，先用当前结果计算48μ与64μ对应的上界，选择足够的最小一个尾端节点，默认不先后盲试两个节点。这样给两个插值中点保留额度。若64μ的界仍不足，或必须超过每F12个非零节点，停止并报告尾部未收敛。

尾端新强度也要检查CAP、dx/dt、η/能区和CEP，不能仅计算φ0再复制四相位。Imax不能超过64μ。遇单次产额显著耗尽，记录其对平均结果的份额，并限制单电子模型的材料解释，不自动增加多电子模型。

### 10.4 总误差不能漏掉新增统计项

节点有已检查的绝对响应误差估计e_i时，线性加权的数值误差估计为`Σw_i e_i`；相位、准备、展宽若已包含在e_i，不重复加入。

对未直接控制的节点，只能在有代表性控制覆盖的强度区间内采用明确标注的经验误差包络，不能无记录填0。主要贡献区与最高强度必须有直接检查；若判断依赖未经检查的区间，则补检查或标INCOMPLETE。

最后汇总：

`δ_non_tail = δ_response + δ_nodes + δ_quadrature + 其他未包含的已量化项`。

统计产额区间记录为`[max(0,Y_trunc−δ_non_tail), min(1,Y_trunc+δ_non_tail+B_tail)]`。这是包含经验收敛估计的保守审计区间，不是严格数学置信区间；其中只有使用Y≤1得到的未知尾部项是严格上界。

正式两偏压统计比较目标：每个加权Y_H的总误差估计≤5%，尾部≤1%、节点变化≤1%，求积误差≤0.1%，各项同时受总5%限制。不能把每项单独5%作为通过标准。相干基准也使用R1的误差区间。

分母信号小于其误差约10倍或区间含0时，不报告增强比。若共用误差可能抵消，除非实际用匹配加密库验证，否则仍按保守区间。

### 10.5 输出D、热光和来源分解

对j=coherent、BSV、thermal保存绝对Y_H,j(F)，并算：

`Q_j=Y_j(1)/Y_j(0)`，`R(F)=Y_BSV(F)/Y_coh(F)`，`D(1)=Q_BSV/Q_coh`。

区间传播：`D_lo=l_B1*l_C0/(u_B0*u_C1)`，`D_hi=u_B1*u_C0/(l_B0*l_C1)`，仅在分母下界>0时计算。也给出thermal相对coherent的对应比较，不称它为BSV独有机制。

复用库输出各I区间贡献和累计贡献；默认分组I/μ<1、1–4、4–12、>12。横轴用I时注意BSV原点奇性，优先给区间贡献而非绘制无限高的单点密度。

若 `Y(I,F)=A(F)B(I)`，D=1；实际检验的是偏压是否对不同强度贡献产生不同作用。q(μ)与q(4μ)只是两个样本，不能替代D。

本轮主任务是可靠Y_H及贡献积分，不要求完整低能渐近总谱。平均谱只能在所有参与节点都有合格能量覆盖的区间生成；未计算能区不能默默补0，partial spectrum不能冒充其积分等于完整Y_H。若全谱统一读出成本高，先交高能产额与强度来源，不增加大盒低能工程。

2. 新建独立用户Python3.12环境，安装与本地相容的NumPy/SciPy，固定实际版本；不修改QE/Wannier用的Python环境。若兼容依赖无法取得，返回本地方案，不发展软件安装项目。
3. 仅传明确运行依赖、配置和需要的准备态，核对SHA。远端是同一版本的执行副本，不是另一个活跃源码仓库；不git init、不clone、不推public origin。
4. 在计算节点做一个已完成条件的同配置CPU对照，比较Y_H/谱、概率账本、实际机时与内存；该重复计算计入本轮限额。远端相对差目标<0.1%，极小量采用明确绝对尺度，超出先查版本/单位/输出。
5. 通过后用Slurm数组处理独立(F,I,CEP)条件，每task先1CPU、按实测峰值加余量申请内存；从最多4并发开始。NumPy/BLAS线程限制为每task的CPU额度，避免每任务都启动整个节点的线程。
6. 不在登录节点跑TDSE。每task≤90分钟；全局预算为各task时间相加，提交前须原子预留额度。避免并发写同一个CSV/JSON：各任务独立目录，由一个汇总器合并。
7. 先把新代码/config冻结并传输后再计算，不在两端分别编辑不同版本。回收小型结果、日志和数据哈希；长期保留所需完整态，不为省传输删除原始结果。

Slurm作业数组的`%4`可限制同时运行任务数，见[官方说明](https://slurm.schedmd.com/job_array.html)。本文没有提供或调用当前不存在的提交脚本；执行Agent应在上述同点验证通过后生成明确任务映射，不能照抄旧SBE/QED的deploy脚本。

统一新runner建议支持：

```powershell
./QL-TIP-1D/.venv/Scripts/python.exe QL-TIP-1D/scripts/run_continuation_v2.py --stage inventory --dry-run
./QL-TIP-1D/.venv/Scripts/python.exe QL-TIP-1D/scripts/run_continuation_v2.py --stage repair-readouts --dry-run
./QL-TIP-1D/.venv/Scripts/python.exe QL-TIP-1D/scripts/run_continuation_v2.py --stage repair-tdse --dry-run

./QL-TIP-1D/.venv/Scripts/python.exe QL-TIP-1D/scripts/run_continuation_v2.py --stage repair-gate --dry-run

```

实现后先dry-run列出具体run_id、复用/新增、依赖、预算与输出，检查无越级。真正执行同命令去掉`--dry-run`并加`--max-new-runs`和`--resume`；后者只复用完整、哈希匹配任务，**不承诺中断时刻的波函数续传**。一次最多8条。

第一次`repair-readouts`处理旧态，`repair-tdse`完成后再次`repair-readouts --resume`补新态、复用已完成读出；两批齐全后才执行`repair-gate`。没有匹配的新R1 PASS时`high-intensity-check/library/statistics`中需要真实响应的阶段必须拒绝。权重解析小测试可在R0完成，不依赖真实统计库。

通用readout至少支持：`--state-path --config-path --eta --step --mask-start --mask-end --energy-min --energy-max --output-dir --label`。不允许输出指向旧run目录。必须检查实际态时刻，必要时额外`--expected-readout-fs`。

## 15. 归档、版本及最终验收清单

原始旧报告/代码/结果不可覆盖。新文件使用新版本、新run_id、新revision；同字节引用同一保存位置。源码完成阶段性工作后再登记冻结，后续确需修改用新版本并保留原依赖关系。

同目录计划清单是说明材料，不自动启动作业。新科研运行的实际清单由执行Agent按通过的协议生成，不把本计划manifest的`planned`字段改成`completed`来冒充执行。

大复数态、完整谱汇总和运行缓存保留本地或已授权服务器，并保存逐文件SHA与位置；不批量加入Git。原文件超过2MiB并不表示可以丢弃。只登记明确的小型关键结果、配置、报告和依赖；文件清单用脚本生成。

每轮先检查暂存区，按根AGENTS约定使用`manage.py register <明确路径>`与`manage.py finish --message "qmath: 具体成果"`。有用户已暂存文件时保留并停止自动提交。更新Q-MATH README当前入口，不覆盖冻结的历史QL-TIP README；不push public origin。

最终交付必须能逐项回答：

- [ ] 四条补验证激光传播是否真实完成？用了哪份准备态？
- [ ] 三阈值是否固定？四条件是否使用共同η/能量积分协议？
- [ ] R1总误差是否合计，而非只逐项判断？代表抽检范围是否写明？
- [ ] 高强度最高点和主要贡献区是否有真正控制？
- [ ] 统计权重、真实中点和未知尾部是否都验收？
- [ ] D的误差区间是否来自正的可信分母？热光是否同步输出？
- [ ] 所有失败、否定结果和未完成项是否保存？
- [ ] 总条数与时间是否含旧任务、失败、后处理，并避免重复计时？
- [ ] 本轮是否停在两偏压，不自动开P4或新研究线？

这份计划允许得到“可信差异”“有限范围内未检出”“预算内无法判断”三种结局。执行质量由可追溯性和如实判断衡量，不由是否出现漂亮曲线衡量。
