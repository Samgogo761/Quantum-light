## 1. 双层 AFM-CrI₃ 的物理特点（为何不是“随便一块磁二维材料”）

### 1.1 层间反铁磁 + 面内晶格

- 原胞含 **上下两层 Cr**（代码里 `Cr1`/`Cr2`），Néel 型层间反平行磁化。  
- 单层铁磁 CrI₃ 已有大量 HHG/磁光工作；**双层 AFM** 多了：**层间相对磁序 N（Néel 矢量）** 作为可翻转的内禀“开关”。  
- SOC + Hubbard U 打开绝缘隙（本计算 Γ gap ≈ **0.667 eV**），强场下可做固体 HHG。

### 1.2 对称性：P 破缺、T 破缺、PT 近似守恒

这是本课题区别于普通半导体 HHG 的关键：

| 对称性 | 状态 | 物理后果 |
|--------|------|----------|
| 空间反演 P | 破缺（层间 AFM + 结构） | 允许偶次谐波、非互易响应通道 |
| 时间反演 T | 破缺（有序磁矩） | 磁性选择定则、自旋/谷相关矩阵元 |
| PT | 近似守恒（理想 AFM） | 净 Berry 曲率在占据流形上被压制；异常霍尔型贡献弱，**量子几何更多进入 quantum metric / 层间相位** |

因此：经典 HHG 谱上会出现 **N 宇称选择定则**（已用 P 共轭 −N TB 验证）；量子光阶段则要把同一对称性印到 **出射谐波的统计**（协方差、压缩、纠缠）上，而不仅是平均强度。

### 1.3 轨道化学：Cr-d 与 I-p

- 近隙光学与低阶 HHG 大量权重在 **Cr-3d** 流形。  
- **I-5p** 提供深价带、p–d 杂化、SOC 增强通道，并影响超交换/磁性。  
- 112-WF = d+p 母模型；40-WF = 以 Cr-d 为初猜的 disentangled 近隙有效模型（**不是**纯原子 d³ 计数）。

## 2. 双层结构与“量子纠缠 / 光子统计”有没有说法？

**有，而且说法应落在“输出谐波光的多模量子态”，不是材料里电子的 Bell 对本身。**

### 2.1 三条可区分的层次（与既有 L1/L2/L3 对齐）

1. **L1 经典驱动**：非线性电流 → 相干谐波；统计接近相干态/经典混合。双层 AFM 的贡献是 **选择定则与非互易谱形**。  
2. **L2 量子驱动、互易介质**：驱动光的强度/相位涨落经非线性映射到谐波平均谱增强——可被经典强度分布复现（González-Monge/Feist 边界）。  
3. **L3（本课题目标）**：量子驱动 + **非互易 / N 分辨** → 双时关联 $C_{\mathrm{conn}}(t,t')$ 的 N-奇通道进入谐波模协方差 $\Sigma$ → **压缩、对数负性、QFI(N)**，并要求相对一切经典混合的优势判据。

双层 AFM 的独特之处：Néel 矢量 **N** 提供一个**离散/连续可控的内禀参数**，把磁群表示论里的奇/偶通道写进 $\Sigma(N)$。单层铁磁没有同等的“层间相对序”旋钮；普通无磁二维材料没有 N 宇称四通道。

### 2.2 纠缠从哪来？

在 Gaussian 光场近似下：

- 谐波模（如 H_q 与 H_{q'}，或 ±N 配对通道）的协方差矩阵 $\Sigma$ 经 symplectic 对角化 / Takagi 分解 → **双模压缩** ↔ Bogoliubov 配对。  
- **对数负性 / PPT** 给出模间纠缠；**QFI** 给出对 N 的传感精度。  
- 电子侧：PT 下 Berry 曲率被压，但 **层间相位、quantum metric、N-奇 Berry 联络** 仍可进入电流关联核——这是“双层”相对单层的理论把手。

### 2.3 诚实边界（写论文必须保留）

- 现有生产数据主要是 **经典 lg_cov HHG + BSV 强度平均（R1）**；**尚未**把 $C_{\mathrm{conn}}\to\Sigma\to$ 纠缠的生产接口跑通。  
- 因此：双层结构**在理论上**为纠缠/光子统计提供对称性与 N 通道；**在数值上**目前仍停留在“为 L3 准备可靠的电子结构 + 经典基准”。  
- 40-WF 若只在 H1–H9 可靠，则只适合做 **近隙/低阶通道的快速原型**；涉及高阶谐波进入 $\Sigma$ 的模，必须回到 112 / full CB。

## 3. 40-WF d-only vs full 112-WF：详细对照

### 3.1 模型定义

| | **40-WF d-only** | **112-WF d+p（母模型）** |
|--|--|--|
| 投影 | 仅 `Cr:d`（4×5×2 spinor） | Cr-d + I-p |
| 外窗（试点） | [−2,3] → opt1 [−1.8,3.5] | [−6,8] |
| $N_{\mathrm{occ}}$ | **22**（disentangled 有效价带数） | **84** |
| SBE 生产用法 | 试点：全 40 带，nv=22 | **nb1–104** 生产 H1–H9；full112 看高阶 |
| Ω_total | ~427 Å²（opt1 待更新） | ~202 Å² |
| 墙时（同 lg_cov k40 T2=0.5） | **~12 min** | nb104 ~**115 min** 量级 |

### 3.2 能带层面

- **近隙**：40 与 112、QE(148) 的 Γ/K gap 一致到 ~1 meV；分栏图显示低导带/价带顶大体同构。  
- **深价带**：40 系统性缺失 I-p；与 QE/112 差是**设计结果**。  
- **高导带（E≳1.5–2 eV）**：Wannier 有、旧 QE bands 无 → 正在补 **nbnd=200 path bands**（Job 26518/26519）以便公平对照；量子光若纳入更高虚跃迁/高阶平台，这一段必须验。

### 3.3 HHG 数值（已有试跑，同激光）

**工作定义（建议写入以后所有文档）**：

- 40-WF：**加速器 / 近隙原型**（调试规范、T2、选择定则流程、快速扫参）。

### 3.4 对纠缠/光子统计议题的含义

| 问题 | 40-WF | 112 / nb104 |
|------|-------|-------------|
| 低阶模（H1–H3）协方差原型 | 可试 | 应用 |
| N 宇称四通道是否定性正确 | 需 ±N 专跑验证 | 已有经典选择定则基准 |
| 高阶模进入 $\Sigma$ | **否** | 视阶数选 nb104/full112 |
| 声称“量子光结果” | **不可**单独基于 40 | 可以谈 R1；L3 仍待代码 |

## 5. 一句话结论

双层 AFM-CrI₃ 的价值在于：**PT 下仍保留的 N 宇称非互易通道**，把磁序写进出射光的统计与纠缠可观测量；40-WF 能加速近隙经典基准，但**不能替代 112 族成为量子光/高阶结论的电子结构**；当前工作应并行推进——高导带 QE 补齐、opt1 局域化、以及 L3 代码接口——而不是把减带试点误当成最终物理模型。
