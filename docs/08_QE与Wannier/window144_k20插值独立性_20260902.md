## 5. A1-O（MMN/Berry \(r\)；用户已批准主线）

独立光学真值 **不是** \(\partial_k H_{\mathrm{TB}}\)。SOC + PAW/非局域赝势下，速度算符有增广修正，不能把 TB 的 \(\partial_k H\) 叫「QE 真值」。

\(v_{mn}\leftrightarrow(\varepsilon_m-\varepsilon_n)r_{mn}\) 只在适用条件下作交叉检查，不是关门公式。

SBE 是长度规范，进方程的是 \(r_{mn}(k)\)。用户批准（2026-09-07）：

\[
\boxed{\text{A1-O 主线 = MMN/Berry 的 }r\text{；不先编译速度矩阵元。}}
\]

只盯 \(k_\eta,k_{H5},k_{H7}\) 的 \(\Pi\leftrightarrow Q\)，外加占据 \(\Pi\)–\(\Pi\) 控制，并用 \(\Gamma\) 做方法控制。孤立带比 \(\lvert r_{mn}\rvert\)；近简并比子空间块 Frobenius / 奇异值。至少三个晶体 \(\delta k\)（0.002, 0.005, 0.010）和 \(\pm\delta k\) 对称差分。相位用 SVD/极分解对齐。

### 5.1 QE 7.2 `compute_mmn` 源码核证（工程，已过）

公开 INPUT 只能说明 `.mmn` 是 spinor Bloch overlap。对本仓库实际二进制 `q-e-qe-7.2`：

- `any_uspp = any(upf%tvanp)`（2036）。Cr/I 的 `*.rel-pbe.upf` 是 PAW（`tvanp` 为真），走增广。
- 平面波项：noncolin 下两分量 `zdotc`（2233–2242）。
