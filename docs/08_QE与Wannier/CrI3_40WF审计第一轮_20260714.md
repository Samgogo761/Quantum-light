## 4. 第一轮交付 4：QE 能带 Cr-d projectability（A5，**决定性证据**）

来源：服务器 3 月 `projwfc.out`（160 带 × 666 k 样本，40 个 Cr-d 态）。  
数据：`analysis/40wf_audit/qe_crd_projectability.csv`；图 [figures/CrI3_qe_crd_projectability.png](figures/CrI3_qe_crd_projectability.png)

| QE 带组（E−E_F, eV） | 物理身份 | **Cr-d projectability（k 均值）** |
|----------------------|----------|----------------------------------:|
| 133–140（−1.16 ~ −0.32，**价带顶**） | VBM 流形 | **0.035–0.056** |
| 121–132（−1.78 ~ −1.01） | 中价带 | 0.06–0.075 |
| 103–120（−2.54 ~ −1.69） | 深价带 | 0.10–0.18 |
| 141–148（+0.35 ~ +0.97，**导带底**） | 第一导带簇 | **0.40–0.47** |
| 149–160（+2.39 ~ +2.94） | 第二导带簇 | **0.81–0.86** |

**这回答了方案的核心问题 1 与 3**：

1. **价带偏差的根因**：CrI₃ 的**价带顶本质上是 I-5p 主导**（Cr-d 权重 <6%）。40 个 Cr-d 初猜投影根本没有这些态的天然载体；disentanglement 只能二选一——pilot 窗把它们硬塞进来（WF 长出大 I-p 尾巴，spread 10–14 Å²），opt1 窗把它们丢掉（N_occ 12，近隙价带覆盖变差）。**调 outer/frozen window 无法同时解决**，因为这是投影基不足，不是窗口选错。
2. **40-WF 是什么**：即便 opt1，被冻结的 VBM 态 pd<0.06，最终 40 个 WF 必然是 **Cr-d-centered + 大量 I-p 杂化尾部** 的有效轨道，绝非原子 Cr-d（回答问题 1；实空间等值面可后续补做定量 I-p 权重）。
3. **对 HHG 的含义**：价带→导带偶极的初末态都强烈依赖 I-p；第一导带簇也只有 ~45% d。**纯 d-40 模型的光学矩阵元不可信区间比能带图暗示的更大**。

**推论（对应方案 Phase B/C）**：显式加入关键 I-p（M52/M64/M88 路线）不是可选项，而是**修正价带物理的唯一途径**；40-WF 定位降级为「算法/流程调试器」。

## 6. 理论补充（用户要求"从理论上还有什么要补"）

方案已很完整；建议**追加四项**：

1. **占据一致性评分 \(\mathcal L_{\rm charge}\)**：模型占据带数 × 每带电荷 vs DFT 占据投影权重；并要求 SBE 侧 `nv_orig` 由 **bands.dat 全网格计数自动生成**而非手填。本次 nv=22/12 事故正是缺这道闸。
2. **磁群/选择定则泄漏评分 \(\mathcal L_{\rm sym}\)**：对每个候选模型跑 ±N（P 共轭 TB）短 HHG 或直接检验 \(H(k)\) 与磁群操作的残差。112 已验证过 N-odd 定则；**缩带模型可能通过 disentanglement 噪声破坏它**——这是 HHG 上岗的必要条件，成本低（k20 即可）。
3. **光学早筛 \(\mathcal L_{\rm opt}\) 提前**：不必等完整 HHG——用现成 JDOS+f-sum 代理工具对每个候选模型跑 \([-2,3.5]\) eV 窗的 f-sum 覆盖率与 \(|r_{vc}|\) 分布（vs 112 基准）。比能带 RMS 更贴近 HHG 灵敏度，纯本地、分钟级。
4. **T2 定位澄清**：退相干扫描是**物理选择**不是收敛参数（T2=0.5 cycle 为生产锚点）；真正的数值收敛变量是 k、dt、`n_dt_deph`（注意约束 dt·n_dt_deph ≪ T2）。写进收敛报告的口径里，避免"T2 收敛"误述。

另一个跨阶段提醒：Löwdin downfolding 的 \(r_{\rm eff}\neq P_A r P_A\)（方案 D2）同样适用于 **Wannier 窗内截断**——40-WF 模型的 r(R) 是自洽的（wannier90 同一变换产出），但任何"从 112 tb.dat 手工挑子块"的捷径都会破坏这一点，此前已在 Bloch 截断答复中确认，保持不越线。
