## 4. 后续怎么走（结论：暂停收敛扫描，转模型构造）

原计划「收敛→量子光 pilot」的前提是「HHG 结果比较好」。**现在两个 40-WF 都没达标**（评分 FAIL + H1 偏差 3 倍），在失败模型上花 ~10 h 做 k80/k120 收敛没有意义。建议顺序：

| 优先 | 任务 | 位置/成本 |
|------|------|-----------|
| **P1** | 方案 Phase B：112 `tb.dat` 的 d–p hopping **按 I 原子/方向分组排名** → SVD 选每个 I 的 \(p_{\rm opt}\)（评分器已产出 WF 分类与流式解析器，可复用） | 本地，~1 天 |
| **P2** | 起草 **M52-interface / M64-all-I-1p** 的 `.win`（窗口按 projectability 设计：VBM 流形必须落入 frozen 窗且有 p 载体） | 本地 |
| **P3** | wannier90 跑 M52/M64（不动 112 链） | part_2，每个 ~1–2 h |
| **P4** | 新模型过评分器四级检验 + nv 自动计数 + 短 HHG vs nb104 | part_2 |
| **P5** | 达标后才回到：k/T2/dt 收敛 → ±N 选择定则 → 量子光 pilot | part_1/2 |
| 暂缓 | opt1-nv12 的 k80/k120 扫描 | 除非你想要「d³ 极限模型」的专门研究 |

**Phase D（Löwdin downfolding）**提醒：`tb.dat` 流式解析器已就绪，可扩展读 r(R)；但 downfold 模型只做能带诊断，**不做 HHG**（\(r_{\rm eff}\neq P_A r P_A\)）。
