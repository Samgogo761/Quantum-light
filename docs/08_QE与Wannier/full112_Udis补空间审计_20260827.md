## 1. 测量对象与定义

Wannier90 3.1 checkpoint 中的 `u_matrix_opt` 是压紧存储：外窗内的行位于
`1:ndimwin`，必须用 `lwindow` 映射回原 QE 带号。解析器逐个核验 Fortran
sequential record 的首尾 marker，并在 \(U_{\mathrm{dis}}\) 后停止，不读取后面的
大 `M_matrix`。

定义

\[
P(\mathbf k)=U_{\mathrm{dis}}(\mathbf k)U_{\mathrm{dis}}^\dagger(\mathbf k),
\qquad
Q(\mathbf k)=I_{W(\mathbf k)}-P(\mathbf k).
\]

对 QE169–200 的坐标子空间 \(S\)，报告

\[
f_Q(\mathbf k)=\frac{\operatorname{Tr}[S Q(\mathbf k)]}{\dim Q}.
\]

它是子空间重叠，不是轨道成分百分比，也没有为结果事后拟合 PASS 阈值。

## 4. 能说明什么，不能说明什么

**已经关闭：**

- 144→112 的补空间维数确为 32；
- QE169–200 不是任意 trial-overlap 假象，而是高质量补空间代理。

**仍未关闭：**

- QE169–200 的正轨道身份；归档 `projwfc` 没有 I-\(d\) 原子投影通道；
- \(P r Q\)、\(P v Q\) 或强场跨空间耦合的大小；
- 缺失补空间是否导致顶部 occupation 或 HHG 偏差，以及偏差量级；
- expanded parent 应加入哪个完整化学壳层。

所以下一步不再是“继续猜 32 条带”，而是：先做少数热点 k 的算符耦合/轨道身份
审计；只有某个完整壳层在 3.5–8 eV 主导，才设计 reference parent。
