## 2. K 点「能带交叉」是否合理？

### 2.1 数值事实（同一 Γ-VBM 对齐后，K 点近隙能级）

在 K 点，**价带顶几条与导带底几条**：QE、112、40 **高度一致**（例：W40 与 QE/112 同为  
VBM 附近 −0.409/−0.402 eV，CBM 附近 +0.723/+0.732 eV）。

三套计算在 K 点都出现若干 **|ΔE| ≲ 5 meV** 的近简并对（例如导带 ~0.825/0.829 eV）。  
这类分裂来自 **SOC + 层间 AFM 磁结构**，在 QE 里同样存在，**不是 40-WF 独有的假交叉**。

### 2.2 图上看起来像「交叉」的两类情况

| 类型 | 含义 | 是否合理 |
|------|------|----------|
| **高对称点近简并** | K 上两条带几乎贴在一起（几 meV） | **合理**；与 QE 同型 |
| **路径上的交叉/反交叉** | 沿 M′–K–Γ 等路径，不同轨道特征的带相遇 | **固体能带中常见**；有对称性保护时可真交叉，否则为 avoided crossing |
| **插值伪交叉 / 带序错乱** | 仅出现在 Wannier、且与 QE 带形明显不符 | **需警惕**；多与 spread 大、子空间不全有关 |

对本 40-WF：**近隙（约 −1~+1.5 eV）带形与 QE 大体同构**，K 点近简并与 QE 对齐 → 你看到的交叉**多数是物理近简并 + 路径上的正常带交叉可视化**，不宜直接判为局域化失败。  
若你指的是某一条蓝线在 K 附近「对穿」且左边 QE 没有对应结构，请指出能量大致范围，可再逐带追踪。

### 2.3 额外注意：高导带（≳1.5 eV）不要跟这套 QE 硬比

现有 QE `bands.x`（`nbnd=148`）在 \(E-E_{\mathrm{VBM}}\) 上大约只到 **~1.29 eV**。  
右图 / 第三列里 **~2–3 eV** 的 Wannier 带，以及那里的交叉，**当前没有 QE 对照**；要验证需加大 `nbnd` 重跑 path bands。

### 2.4 深价带为何对不好？

当前窗：`dis_win = [-2, 3]` eV，`dis_froz = [-1, 1]` eV，投影仅 `Cr:d`。

- **−1.5 eV 以下**大量 QE 价带是 **I-5p 主导**，根本不在 40 维 Cr-d 初猜子空间内。  
- 外窗边界附近（~−2 eV）即便有少量 Wannier 带，也是 **disentanglement 硬切**出来的，形状不必等于 QE。  
- 因此：**深价带吻合差是预期现象，不是画图错误**；若要深价带也对上，必须加回 I-p（回到接近 112）或扩大投影，那就不再是「减带」目标。

## 3. Spread 大：是不是已经最优？还能不能压？

### 3.1 结论先说

**不是参数最优化后的最终结果。**  
当前 40-WF 是 **第一轮试点**（固定窗 + 仅 Cr:d），收敛了，但**没有做过系统窗扫描 / 投影试验**。

| 量 | 40-WF d-only | 112-WF d+p |
|----|-------------:|-----------:|
| Ω_I（Å²） | **354.1** | 197.3 |
| Ω_D | 2.22 | 0.005 |
| Ω_total | **427.0** | 202.3 |
| 最终单 WF spread | 约 **7–14** Å² | 明显更紧 |

说明：

1. **Ω_I 是规范不变的**，主要由 **disentanglement 选出的子空间**决定；再多跑 `num_iter` 也压不下去。  
2. MLWF 阶段已把初始很大的 spread（中间态曾到数十 Å²）收到 **7–14 Å²**；再抠 `num_iter` 收益有限。  
3. **Ω_total 约为 112 的 2× 是结构性的**：缺 I-p、用窄窗硬凑 40 带 → 子空间更「拧」，局域性天然更差。  
4. 因此：**可以再优化，但不应期望 40-WF 的 spread 降到与 112 同级**，除非改回含 p 的更大模型。

### 3.2 可尝试的优化（不动 112 链；仅重跑 wannier90 / 必要时重做 amn）

按优先级：

| 优先级 | 动作 | 目的 |
|--------|------|------|
| A | 收紧 `dis_froz` 更贴隙区（例：−0.6~0.9），略调 `dis_win` | 强迫近隙 DFT 带进入冻结子空间，常能降 Ω_I、改善近隙带形 |
| B | 外窗略扩深价侧或缩深价侧做对比（如 −1.5~3.0 vs −2.5~3.5） | 看深价伪带是否减少、spread 是否改善 |
| C | 检查是否有个别 WF spread ≫ 其余（本 run 最高约 14 Å²，尚可） | 若出现 >30 Å² 的「飞掉」WF，优先改窗/投影 |
| D | 试验性加入少量 I:p（或只加一层 I）→ `num_wann` 升到 ~52–70 | 用少量 p 换更好杂化与更低 Ω_I；仍远小于 112 |
| E | `dis_mix_ratio`、`num_iter` 微调 | 次要；本 run 已收敛 |

**不建议**：为降 spread 盲目把外窗开到与 112 一样宽却仍只用 40 个 d——会强迫子空间吞下过多 I-p 特征，往往 **Ω_I 更大、插值更烂**。

### 3.3 优化判据（建议）

不要只盯 Ω_total。试点是否「更好」应同时看：

1. 分栏图：近隙带形 vs QE  
2. Γ/K gap 是否仍锁在 ~0.667 / 1.124 eV  
3. Ω_I 是否下降、有无异常大 spread WF  
4. （以后）再谈 HHG；现在仍只做局域化

## 4. 当前建议

1. **先用分栏图审阅**；叠图仅作对齐参考。
