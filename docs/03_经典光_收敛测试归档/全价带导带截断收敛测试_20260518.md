## 6. 收敛判断

### H1-H11

`nb1-104` 是目前最好的截断候选。相对 full112：

```text
H1  : -4.2%
H2  : +1.5%
H3  : -0.2%
H4  : -0.2%
H5  : +0.8%
H6  : -0.2%
H7  : +0.1%
H8  : +1.3%
H9  : -2.7%
H10 : -2.6%
H11 : -1.4%
```

这说明在无退相干、40x40、当前场强下，`lg_cov/nb1-104` 已经可以很好复现 full112 的 H1-H11。

### H12-H15

H12 以后仍不稳定，尤其 H13/H15。这里 full112 的绝对强度已经很小：

```text
H11 ~ 3.7e-9
H15 ~ 2.3e-11
```

因此相对误差会被数值地板、窗口函数和有限网格放大。当前不建议用 H12-H15 作为判断截断可用性的主判据，除非后续研究目标明确需要 cutoff 区域。

## 8. 当前总状态

```text
1. k 网格：
   lg_cov/full112 从 30x30 到 40x40 已经很好，H1-H15 基本只变 0%-2%。

2. Peierls VG 截断：
   对称 20-60 bands 失败，有巨大低阶虚假背景电流，不作为生产路径。

   比 Peierls 好很多，但 30-60 bands 仍不能作为绝对谱生产。

4. lg_cov 固定 nb_end=112、补回深价带：
   nb30-112 对 H1-H8 不错，但初始电流和偶次 H2/H6/H8 有明显偏差。

5. lg_cov 保留全部价带、截导带：
   nb1-104 是当前最好的截断候选。H1-H11 接近 full112，初始电流也干净。
```
