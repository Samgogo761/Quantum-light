## 1. 当前谱使用的规范

当前用于经典光生产判断的谱不是 velocity gauge / Peierls substitution，而是 gauge-covariant length gauge SBE，代码中为：

```text
gauge_method = 'lg_cov'
d rho/dt = -i[H0 + E.D, rho] + E.D_k rho
D_k rho uses parallel-transported finite differences.
```

这里包含：

- `D(k)`：Berry connection / dipole matrix；
- `P(k)`：length-gauge current matrix；
- 协变有限差分的 `E · D_k rho` 项。

Peierls velocity gauge 和 `matrix_vg` 之前只作为诊断分支使用。Peierls 对称截断会产生严重伪低阶电流，因此已不作为生产路径。

## 6. 谱比较对象：复振幅、峰值还是积分

目前 `HHG.dat` 输出的是 Hann-window FFT 后的强度谱：

```text
# harmonic_order  omega(a.u.)  HHG_x  HHG_y  HHG_total
HHG_x   = dt^2 * |J_x(omega)|^2
HHG_y   = dt^2 * |J_y(omega)|^2
HHG_tot = HHG_x + HHG_y
```

当前图和表主要比较的是每个整数谐波附近窗口内的 `HHG_total` 峰值强度，不是复振幅，也不是频窗积分强度。若后续要做相位、N 奇偶通道或纠缠相关分析，需要输出或重构复数 Fourier 分量。

## 11. 一句话结论

当前经典光生产谱是 `lg_cov` 长度规范结果，不是 Peierls VG。`nb1-104` 是“全 84 价带 + 最低 20 导带”，对 H1-H9/H11 的低中阶经典谱和 P 共轭选择定则已经足够接近 full112；H13 以后进入弱信号/cutoff/数值地板区域，截去的最高 8 条导带会明显影响相对强度。因此论文中若讨论 H1-H11，可用 nb1-104 作为经济配置并以 full112 对照；若要讨论 H12+ 或 BSV 是否显著延展 cutoff，则必须保留 full112 或至少对高阶区域另做收敛验证。
