## 1. 当前 112-band Wannier 模型的含义

CrI3 双层结构中，本轮模型包含：

```text
4 个 Cr 原子
12 个 I 原子
```

若考虑主要化学轨道：

```text
Cr: 5 个 d 轨道 / 原子 -> 4 * 5 = 20
I : 3 个 p 轨道 / 原子 -> 12 * 3 = 36
spin/SOC: 2
总数 = (20 + 36) * 2 = 112
```

因此当前 112-band Wannier 模型不是随便选的“大窗口”，而是一个化学上比较完整的 Cr-d + I-p spinor 母模型。它保留了：

- Cr-d 与 I-p 杂化；
- SOC 下的自旋混合；
- 深价带对 Berry connection / dipole / velocity 矩阵元的贡献；
- 完整 84 条占据价带和 28 条导带。

所以当前 112-band 模型应当被视为 reference model，而不是“过度冗余”的模型。

## 2. 重做少带 Wannier 不是第一解

重做 20-40 band Wannier 模型不是不可以，但它不是自动更正确。

少带 Wannier 的本质是构造一个有效模型：

```text
把很多深价带、高能导带、杂化通道的影响压缩进较少的 Wannier 函数。
```

这可能带来计算加速，但也会带来风险：

- 丢失部分 Cr-d/I-p 杂化信息；
- Berry connection / dipole 矩阵元不一定复现 112-band 模型；
- HHG 对相位和带间矩阵元很敏感，能带看起来对不代表 HHG 谱就对；
- 少带模型必须重新验证，而不能直接作为生产模型。

因此当前策略应是：

```text
先用现有 112-band 模型测试哪些截断近似可靠；
若现有模型的合理截断仍不够便宜，再考虑重做少带 Wannier；
重做后的少带 Wannier 也必须对比 lg_cov/full112 的经典光谱。
```

## 3. 截断为什么必须谨慎

### 3.1 Peierls 速度规范对称截断已经失败

已测试：

```text
Peierls vg, T2 off
20 bands: 75-94
30 bands: 70-99
40 bands: 65-104
50 bands: 60-109
60 bands: 53-112
112 bands: 1-112
```

结果：

```text
H1:
20 bands  = 4.819e+1
40 bands  = 1.097e+2
60 bands  = 1.681e+2
112 bands = 8.230e-2
```

结论：

```text
Peierls 速度规范 + 对称带窗截断不可用于生产。
```

原因不是简单“带数不够”，而是截掉深价带后破坏了速度规范中的背景电流抵消。

### 3.2 lg_cov 对称截断好很多，但仍未收敛

已测试：

```text
lg_cov, 40x40, T2 off
30 bands: 70-99
40 bands: 65-104
50 bands: 60-109
60 bands: 53-112
112 bands: 1-112
```

结果：

```text
H1 随带数增加逐步接近 full112；
但 H7、H9、H11、H15 仍有明显偏差。
```

结论：

```text
lg_cov 受截断影响小得多，但对称 30-60 bands 仍不能作为绝对谱生产配置。
```

## 4. 目前已经做过哪些“非对称截断”？

这里需要非常明确地区分两类非对称截断。

### 4.1 已经做过：固定导带顶部，逐步补回深价带

已完成：

```text
lg_cov, 40x40, T2 off, nb_end=112

nb=70-112: 15 valence + 28 conduction = 43 bands
nb=60-112: 25 valence + 28 conduction = 53 bands
nb=50-112: 35 valence + 28 conduction = 63 bands
nb=30-112: 55 valence + 28 conduction = 83 bands
nb=1-112 : 84 valence + 28 conduction = 112 bands
```

关键结果，`nb=30-112` 相对 full112：

```text
H1  = 0.999
H3  = 1.055
H4  = 0.955
H5  = 0.969
H6  = 0.857
H7  = 1.027
H8  = 1.186
H9  = 2.006
H11 = 2.685
```

结论：

```text
nb=30-112 是目前最有希望的便宜窗口。
它对 H1-H8 已经很接近 full112，但 H9-H11 仍不够稳定。
```

这类截断保留了全部当前导带，但没有保留全部价带。

### 4.2 还没有做过：保留全部价带，只截高能导带

用户提出的方案是：

```text
nb_start = 1
nb_end   = 94 或 104
```

也就是：

```text
nb=1-94 : 84 valence + 10 conduction = 94 bands
nb=1-104: 84 valence + 20 conduction = 104 bands
nb=1-112: 84 valence + 28 conduction = 112 bands
```

这个测试目前还没有完成。

它的物理意义是：

```text
完整保留所有占据价带；
只截掉当前 112-band 模型顶部的高能导带。
```

这正是“价带要全考虑，导带有限截断”的方案。

它比 `nb=30-112` 更接近“占据态完整”的原则，但带数也更大：

```text
nb=1-94  : 94 bands
nb=1-104 : 104 bands
full112  : 112 bands
```

因此它可能比 `nb=30-112` 更准，但节省时间有限。

## 5. 当前对“价带要全考虑，导带有限截断”的回答

从物理原则上，这个想法是合理的，尤其对长度规范：

```text
保留全部价带可以避免初始占据态不完整；
截掉最高导带主要影响高能虚跃迁；
lg_cov 比速度规范更适合做这种截断收敛测试。
```

但它还没有被实际数据验证。

所以当前不能说：

```text
nb_start=1, nb_end=94/104 已经可用。
```

只能说：

```text
这是下一组最值得补的截断测试之一。
```

## 6. 目前最清楚的决策

### 已经可以确定

```text
1. 当前 112-band Wannier 模型是合理的 reference model。
2. 不应直接放弃 112-band 模型去重做少带 Wannier。
3. Peierls vg 的对称截断不可用。
4. lg_cov 是当前最合理的传播规范。
5. lg_cov/full112/40x40 是当前经典光绝对谱基准。
6. lg_cov/nb30-112/40x40 是目前最有希望的便宜候选，但只在 H1-H8 比较稳。
```

```text

2. 选定 T2 后，nb30-112 是否会更接近 full112。
3. BSV 是否真的需要 H9-H20 的 cutoff 区域。
4. 是否必须重做少带 Wannier。
```
