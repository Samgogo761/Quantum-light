## 8. 与无退相干的区别

相对无退相干 full112，`T2_cycles=0.5` 对谱形影响很大：

```text

H3  : 0.449
```

因此 T2 不是一个无关紧要的数值阻尼参数，而是会显著改变偶次和高阶谐波的物理输入。后续论文计算必须明确说明所采用的 T2 语义，并最好给出 T2 敏感性扫描。

## 10. 当前结论

1. `T2_cycles=0.5` 功能已经在服务器作业中正确生效，有效 T2 为 `5.337 fs`。
2. 在有退相干时，`lg_cov / nb1-104 / 40x40` 仍然很好地复现 `lg_cov / full112 / 40x40` 的 H1-H9。
3. 低阶偶次谐波 H2/H4/H6/H8 的截断误差约在 2.3% 以内，足以作为磁性偶次信号分析的经济配置候选。
4. H10 以后绝对强度很低，比例会被数值地板、窗函数、有限时间和有限 k 网格放大，不应作为当前截断路线的主判据。
5. 经典光绝对基准仍建议保留 `lg_cov / full112 / 40x40`；参数扫描和后续 BSV pilot 可优先考虑 `lg_cov / nb1-104 / 40x40`。
