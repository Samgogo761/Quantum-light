## 9. 结论

当前带窗选择建议：

```text
经典光绝对基准：
lg_cov / full112 / 40x40 / T2_cycles=0.5

最稳经济候选：
lg_cov / nb1-104 / 40x40 / T2_cycles=0.5

更便宜但有 H1 偏差的候选：
lg_cov / nb1-94 / 40x40 / T2_cycles=0.5

不建议继续推进：
nb10-104 / nb20-104
```

具体理由：

```text
nb1-104 保留全部价带，初始电流干净，H1-H9 和偶次 H2/H4/H6/H8 最接近 full112。
nb1-94 同样保留全部价带，初始电流干净，但 H1 低约 18%，H2 低约 7%；可用于便宜试算或 BSV pilot 的探索性配置。
nb10-104 / nb20-104 截掉深价带，初始电流不为零，偶次谐波和 Jy 时间域电流偏差明显，不应作为生产配置。
```
