# 经典光机制树：已有数据 vs 缺失数据（2026-09-02）

```text
LINE               = M
AFTER              = WINDOW144 31678 COMPLETED
IMPACT_ON_HHG      = BASELINE_JQ_CHANGED_K20
FULL112_VERIFIED_FINAL_IP_REF = LOST
FULL112_QUANTITATIVELY_WRONG  = NOT_SHOWN
NOT                = GH7 / k40 / k50 / chemical 144 / Husimi-Q production
A0_CLOSES_INTERP   = false
A1H_CLOSES         = Hamiltonian interp only
A1O_CLOSES         = HHG optical interp
A1H_PASS_NE_HHG_TRUSTED = true
```

场外判断可以收成一句：

\[
\boxed{
\text{材料相与对称性}
\rightarrow
\text{经典 HHG 微观机制}
\rightarrow
\text{找特异点并提出假设}
\rightarrow
\text{量子光验证假设}
}
\]

这不是新课题，而是把 2026-07-16 地图里「模块 1 材料档案 + 模块 3 磁性 HHG 基线」放到「模块 4 量子光输入」前面，并且 **拒绝**「先把所有 Husimi-\(Q\) 节点跑完再解释」。

WINDOW144 的数字让这件事更硬：112→144 的空间处理已经极大改变当前 HHG。正确的说法是 full112 **失去「已验证最终独立粒子参考」资格**，还不是「已被定量证明 H5 错 4.76 倍」（插值与真漏空间尚未分开）。在这种状态下继续堆量子光节点，最后多半只得到「某个峰变大了多少」，说不出为什么。

## 1. 当前母模型到底考虑了什么

问题不是「有没有 stacking」，而是 **只取了一个 stacking，当成了整个材料**。

| 已经在 DFT/Wannier 母模型里 | 没有当成变量扫 |
|---|---|
| 双层 **HT-AFM**、单斜 \(C2/m\) | 菱面体 / AB vs 当前单斜 |
| SOC、DFT+\(U\)、vdW | FM-z；AFM 自旋躺到面内 |
| 层间 AFM 与该单斜堆叠绑在一起 | 连续温度、连续 \(B\)、栅压 \(E_z\) |
| 选择定则用 \(P\) 破、\(T\) 破、\(PT\) 保 解释 \(J_e/J_o\) | 每种结构先写磁空间群再预测谐波 |

第一阶段材料控制矩阵（一次只动一列）：

| 变量 | 第一阶段 | 优先级 |
|---|---|---:|
| 堆叠 | 当前 \(C2/m\) vs 一种 rhombohedral/AB | 最高，但 **不是下一步作业** |
| 磁序 | AFM-z vs FM-z | 最高，同样在机制树之后 |
| 自旋方向 | AFM-z vs 一个 AFM-x/y | 高 |
| 磁群 / 点群 | 每种结构剩下的 \(P,T,PT,C_2,C_3,M\) | 最高，且 **多数是纸面+spglib** |
| \(E_z\) | 层间势差，看 H2 | 中高 |
| \(B_z\) | 先比较 AFM/FM 两端，不连续扫 B | 中高 |
| 温度 | 物相端点，不当成 SBE 里填一个 \(T\) | 后面 |
| 应变/压力 | stacking/磁物理清楚后 | 后面 |

温度不能在 SBE 里填 \(T\) 就算有限温度：它同时改磁序、晶格、声子和 \(T_2\)。

## 2. 机制树：已有 vs 缺失

| 层 | 要回答的问题 | 已有 | 缺 |
|---|---|---|---|
| ① 结构 + 磁群 | 当前 HT-AFM \(C2/m\) 还剩哪些操作 | 结构摘要、\(U_P\)/\(\varepsilon_P\) 闸门、±N 选择定则 | **正式磁空间群页**；stacking 对照 |
| ② 能带组成 | Cr-\(d\) / I-\(p\) / 层 / 自旋 | full112 = Cr-\(d\) 40 + I-\(p\) 72；物种/层/I-site **已核证**（`wf_labels_certified.json`） | \(p_x/p_y/p_z\) 仍是 nnkp 初始投影；无 SOC-off 对照 |
| ③ 静态跃迁地图 | \(\lvert d_{mn}^x(k)\rvert^2\)、\(\lvert v_{mn}\rvert^2\)、JDOS | `transition_jdos_fsum.py` 已在 tb.dat 上跑过；f-sum 代理 | 针对 H2/H5/H7 的 **带对 + \(k\) 热图**（JDOS ≠ 谐波来源） |
| ④ 含时 \(\rho,J\) | 哪些带获得 population、哪些建立相干 | 29458/29452 有 band-resolved occupation（极大文件）；`Jt_decomposed.dat` intra/inter | **求解器还没有** \(\rho_{mn}(k,t)\)、\(J_{mn}(k,t)\)。现有占据只能当候选，不能当「H7 的来源」 |
| ⑤ 谐波路径 | H2/H5/H7/H9 在哪个半周期、哪块 BZ、哪几条带 | 偶次 intra/inter：inter 主导（0.78–0.98）；总谱 \(J(\omega)\) | 总 \(J(t)\) 时频 **现在就能做**（候选时间窗）。带–\(k\) 路径要等 \(\rho_{mn},J_{mn}\) |
| ⑥ 相图对照 | stacking / AFM–FM / 自旋方向 | **只有当前一个相** | 全部 |
| ⑦ 特异点 | 哪一个机制对场强/CEP 敏感 | 未定义 | 必须先有 ①–⑤ |
| ⑧ 量子光假设 | Husimi-\(Q\) 会不会反复推过该点 | GH5 求积未关；A1 不能当 \(g^{(2)}\) | 有假设之前 **不** 投 GH7 |

静态 JDOS 只能筛「哪些跃迁有可能重要」：

\[
H7 = 7\hbar\omega_0
\quad\not\Rightarrow\quad
\text{H7 是某条 }\Delta E=7\hbar\omega_0\text{ 的静态跃迁。}
\]

导带人口大也不等于该带辐射强。虚跃迁的判据应是含时的

\[
\eta_{mn}(\mathbf k(t),t)
=
\frac{e\lvert E(t)\rvert\,\lvert r_{mn}[\mathbf k(t)]\rvert}
{\lvert\varepsilon_m[\mathbf k(t)]-\varepsilon_n[\mathbf k(t)]\rvert},
\]

不能按静态能量差把远带全部删掉，也 **不必** 把所有虚通道显式传播。WINDOW144 碰到的就是这件事；动态子空间 / Löwdin 是算法题，不是「再加 32 带然后 GH7」。

## 3. 激子：不能再只写在「论文局限」里，但现在也不做完整 GW+BSE+强场

双层 CrI\(_3\) 吸收峰约 1.51 / 1.96 / 2.68 eV，与 3200 nm 的 H4 / H5 / H7（约 1.55 / 1.94 / 2.71 eV）几乎撞上。独立粒子基线仍然必须先有（否则激子动力学没有对照）。顺序：

\[
\text{IP 经典 HHG 基线}
\rightarrow
\text{静态 GW/BSE 看清激子结构}
\rightarrow
\text{只对 H4/H5/H7 做 excitonic dynamics}
\]

现在 IP 基线还被 Hilbert 空间摇过，所以 **更不能** 立刻上完整 BSE-HHG。

---

## 4. 量子光何时回来

不是等经典问题 100% 解决。是等到一个 **可证伪的特异点假设**，例如：

- 某种 stacking 允许 H2、另一种压制；
- H5 卡在近共振 / 激子能区；
- H7 是两条路径相消后的弱残余，高场尾会打破相消。

然后才问：Husimi-\(Q\) 的场强/CEP 涨落会不会反复推过这一点。GH5 已经证明求积未关；在假设写出来之前，再投 GH7 仍然是盲算。

---

## 5. 服务器：按三种负载，不要按「CPU 核数」买

现有 SBE：**CPU OpenMP + MKL，无 CUDA**。现在买 GPU **不会**让 29175 二进制变快。GPU-SBE 重写（按 \(k\) batch 的 112×112 复 FP64）排在「先上机器学习」前面。

| 负载 | 最缺什么 |
|---|---|
| QE / Wannier / 普通 DFT | CPU、内存、MPI |
| SBE / HHG | FP64 GPU、HBM 带宽、大量并行 \(k\)（**重写之后**） |
| GW/BSE / 激子 | 大显存 + FP64 + 多 GPU 通信 |

采购看 **FP64 + HBM 容量 + HBM 带宽 + GPU 互联**，不要看训练卡的 FP8。机器学习有用的是主动采样、降阶、动态带选择、SBE surrogate，不是端到端猜谱。

前四五步机制树 **不需要** 先等新机器：大量是对已有 full112 / WINDOW144 / M88 数据加诊断。新算力真正用在后面的多结构对照、激子、以及 **有假设之后** 的 quantum-light ensemble。

### B — 机制树 ①–⑤（现在就可以）

现有数据能做的是 **候选机制**：

\[
\varepsilon_n(k),\quad d_{mn}(k),\quad v_{mn}(k),\quad
\text{轨道/层标签},\quad
\text{总 }J(t)\text{ 的时频}.
\]

这只能说到「这条跃迁容易被激发 / 这个半周期总电流强」。

真正回答「H7 是哪几条带、哪个 \(k\)、哪个半周期产生的」还要求解器增加选择性的

\[
\rho_{mn}(k,t),\qquad J_{mn}(k,t).
\]

那是 B 的后半，不是现在的 SBE 生产扫描。
