## Slide 4：为什么是 112-band 母模型

讲什么：

```text
112 带不是随意大窗口，而是双层 CrI3 的 d+p spinor 完备母模型：
4 Cr x 5 d + 12 I x 3 p = 56 orbitals
SOC spinor x 2 = 112 bands
```

要回应的问题：

```text
为什么不直接重做 30-band Wannier？
因为 Cr-d/I-p 杂化、SOC 自旋混合和深价带对 dipole/Berry connection/velocity 矩阵元都有贡献。
少带模型可以是未来加速模型，但不能在未验证前取代 112-band 母模型。
```

结论：

```text
当前路线是：先用 112-band 建立可靠基准，再在 SBE 内做受控截断。
```

## Slide 10：AFM 选择定则闭环

配图：

```text
figures/report/figB_selrule.png
```

讲什么：

```text
选择定则 J_n(-N) = (-1)^(n+1) J_n(N) 要求 +N/-N 是严格 P 共轭对。
独立做两套 DFT/Wannier 得到的 +N/-N 并不会天然严格配对。
```

失败诊断：

```text
SCF 总能差 2.18 mRy ≈ 0.03 eV
Wannier Omega_I 差约 0.13 Ang^2
Gamma/K/M 本征值差 50-110 meV
H2 leakage ≈ 13，落在错误 evenN 通道
```

解决：

```text
从 +N TB 后处理构造严格 P 共轭 -N TB。
H2 leakage: 13.1 -> 0.32
H1/H3/H5 leakage 大幅下降。
```

结论：

```text
H2 异常来自 DFT/Wannier 配对误差，不是 SBE 求解器错误。
```

## Slide 18：物理定位与利弊权衡

核心表述：

```text
当前 BSV 结果属于 R1：强度分布平均。
```

```text

R3：严格量子优势，证明任意经典分布无法复现某观测量，是长线理论目标。
```

导师汇报要诚实：

```text
不把 R1 夸成量子优势；
```

## Slide 19：Tier 2/R2 具体路线

讲什么：

```text
下一阶段不再只看平均谱，而是看输出谐波光本身的量子统计。
```

核心对象：

```text
C^{ab}(t,t') = <delta J^a(t) delta J^b(t')>
```

数值路线：

```text
1. 用 QRT 或等效线性化传播计算二阶电流关联。
2. 频域变换得到 C(omega_q, omega_q')。
3. 构造谐波模式协方差矩阵。
4. 计算 squeezing, g2, logarithmic negativity, inter-harmonic correlation。
5. 对 AFM 进行 even/odd Néel 通道分解，寻找 C_oo 磁性光子关联。
```

## 附：导师可能问的问题与简短回答

### Q1：40x40 会不会太粗？

回答：

```text
不是只跑了 40x40。full112 的 30x30 -> 40x40 已经显示 H1-H15 变化约 0%-2%，并且补了 60x60/full112/T2=0.5 cycle 确认。对当前 H1-H13 和有能隙 2D 体系，40x40 可作为主网格；极高阶或最强 BSV 节点可做局部 60x60 复查。
```

### Q2：nb1-104 的 H12+ 和 full112 差异较大，能不能用？

回答：

```text
nb1-104 对 H1-H11 和主要偶次磁性谐波是可靠经济配置。H12+ 已靠近当前经典 cutoff/数值地板，差异变大不影响低阶结论；如果论文最终主打 H12+ 或 BSV 高阶尾部，需要用 full112 做局部复查。
```

### Q3：BSV 增强是不是量子优势？

回答：

```text
当前不是严格量子优势，而是 BSV 强度涨落的平均谱增强，可由经典强度分布复现。它仍然是双层 CrI3 + BSV HHG 的可发表 R1 结果。真正量子签名要看输出光二阶关联、压缩、谐波间纠缠或 Néel-odd 光子关联，这是 Tier 2/R2 路线。
```

### Q4：为什么不用旧求解器？

回答：

```text
旧求解器可作为历史参考，但当前双层 CrI3/SOC/完整 d+p spinor 模型需要清楚处理规范、带窗、T2、可观测量和 BSV 多样本复用。新 lg_cov 求解器已经通过选择定则与多项数值验证，并且更适合后续 Tier 2 扩展。
```
