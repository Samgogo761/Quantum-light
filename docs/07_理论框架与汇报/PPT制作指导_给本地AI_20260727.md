## 0. 制作原则（必须遵守）

1. **先图后式**：每页最多 1–2 个关键公式；推导留给附录或口播。
2. **口径冻结**：生产模型写死为 **M88-c20@40×40 + lg_cov**；H10 / H11+ 必须分栏写清。
3. **不夸大**：禁止“已证明量子优势”；BSV 平均谱 ≠ 输出纠缠。
4. **分工可见**：至少 1 页写清 A/B/C/D 组并行任务（不是一个人做完全部）。
5. **放图优先**：能用谱图 / 能带叠图 / 流程图，就不要用大段文字。
6. **中英术语一致**：Néel $\mathbf N$，$J_e/J_o$，BSV，QRT，QFI，`lg_cov`。

### 视觉建议（对齐「量子光CrI3理论.pptx」）

- 深色或干净浅底均可，但全稿统一；避免默认紫渐变 AI 风。
- 每页一个主视觉：流程图 / 对比谱 / 模型金字塔 / 四象限表。
- 标题短；副标题一句“我们证明了什么 / 下一步算什么”。
- 页脚：日期 + “CrI₃ AFM HHG / Quantum light”。
