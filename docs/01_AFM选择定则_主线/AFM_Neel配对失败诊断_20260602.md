因此，H2 的 N-even 主导不能简单归因于“晶格本身非中心对称允许普通 SHG”。

## 4. Wannier 中心反演配对

脚本：

```text
C:\Users\26507\Documents\New_SBEs\Quantum-light\tools\analysis\map_wannier_inversion_pairs.py
```

运行结果：

```text

mean_pair_distance_fractional = 7.79089777e-05
duplicate_targets = 0
non_involutive_pairs_count = 0
```

这说明 `+N` 的 112 个 Wannier 中心可以被几何反演一一配对，而且配对关系是互逆的。这是“从 +N TB 构造严格反演共轭 -N TB”的必要条件之一。

但这还不是充分条件。原因：

```text
1. 同一个原子上有多个 d/p 自旋 Wannier 函数，中心配对不能唯一确定局域轨道/自旋基底的完整酉变换。
2. 反演下 spin 是轴矢量，不应额外做 sigma_x 自旋翻转；-N 来自层交换，而不是显式翻转自旋指标。
3. 反演下 d 轨道为偶宇称，p 轨道为奇宇称，p-like Wannier 函数可能需要额外负号；这会影响 d-p 交叉矩阵元。
4. 反演中心不在原胞原点时，除了 R -> -R，还需要处理每个 Wannier 函数反演后落入的晶胞平移 shift。
5. 若 Wannier 函数不是纯原子轨道，而有局域混合，则简单置换 + 奇偶号可能仍不够，需要局域酉矩阵或 overlap 校准。
```

因此，外部 AI 提出的“从 +N TB 后处理构造 -N TB”方向是合理的，但不能只用中心最近邻置换和 `R -> -R` 做一个过于简化的版本。

## 5. 当前判断

更可靠的根因链条是：

```text
1. 单套 +N 或 -N 的 lg_cov SBE 本身是干净的：|J(0)| 为机器零。
2. +N/-N 选择定则的 H2 异常不是带窗截断造成的，因为 nb1-104 与 full112 图样相同。
3. 几何结构近似有反演中心，因此不能简单归因于普通晶格 SHG。
4. 独立生成的 +N 和 -N SCF 总能不同，Wannier gauge-invariant spread 不同，TB 本征值也不同。
5. 所以当前 +N/-N TB 不是严格反演共轭对，选择定则检查被 DFT/Wannier 配对误差污染。
```

结论：

```text
当前 H2 evenN 主导不能作为真实物理选择定则结论。
它也不是 SBE 求解器已经出错的直接证据。
最可能的问题层级在 DFT/Wannier 配对，而不是 lg_cov 传播。
```

## 6. 后续路线

### 6.1 立刻建议

```text
1. 暂停 BSV 大样本。
2. 不再使用独立 SCF+Wannier 得到的 -N TB 作为严格选择定则验证对象。
3. 下载并归档 -N 的 SCF/nSCF 输入输出文件，至少包括：
   CrI3_scf_soc_mN.in
   CrI3_scf_soc_mN.out
   CrI3_nscf_soc_mN.in
   CrI3_nscf_soc_mN.out
4. 保留当前 -N SBE 数据作为“独立 SCF/Wannier 失败示例”，但不要用于最终选择定则证明。
```

### 6.2 严格路线

目标：从 `+N` 的 `CrI3_tb.dat` 构造一个算符意义上严格反演共轭的 `-N` TB。

需要分三步做：

```text
Step 1: 建立 Wannier 函数的反演映射
        已完成中心层面的配对检查，但还需补充 orbital/spin/parity/translation 信息。

Step 2: 构造 P 共轭 TB
        不是简单的 H^-(R)=H^+(-R) 置换；需要包含每个 Wannier 函数的晶胞平移 shift 和 orbital parity/local unitary。

Step 3: 验证构造结果
        在跑 SBE 前必须先检查：
        E_+N(k) = E_constructed_-N(-k) 到浮点精度；
        H(k) 厄米性正常；
        tb.dat 格式和 nrpts/ndegen 保持一致。
```

只有 Step 3 通过后，才上服务器跑：

```text
lg_cov / T2_cycles=0.5 / k40 / nb1-104
lg_cov / T2_cycles=0.5 / k40 / full112
```

然后重新做 AFM 选择定则分析。
