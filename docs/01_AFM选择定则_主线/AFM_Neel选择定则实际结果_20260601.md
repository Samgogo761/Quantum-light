每个目录包含：

```text
afm_neel_symmetry_harmonics.csv
Jt_evenN.dat
Jt_oddN.dat
```

其中：

```text
J_evenN(t) = [J(t;N) + J(t;-N)] / 2
J_oddN(t)  = [J(t;N) - J(t;-N)] / 2
```

若理想关系

```text
J_n(-N) = (-1)^(n+1) J_n(N)
```

严格成立，则奇次谐波应主要在 `evenN` 通道，偶次谐波应主要在 `oddN` 通道。CSV 中 `leakage_ratio = forbidden / allowed`，越小越干净。

## 5. 当前结论

这次检查不能简单记为“选择定则完全通过”。

可以确认的部分：

```text
1. +N/-N 两套 SBE 的初始电流都在机器零量级。
2. H1 和 H3 的奇次选择定则非常干净。
3. H4 和 H8 的偶次谐波有 oddN 主通道趋势，但存在 10%-20% 量级泄漏。
4. nb1-104 与 full112 给出的选择定则图样一致，说明经济带窗不是主要问题。
```

需要重点解释的部分：

```text
1. H2 没有出现在预期的 oddN 主通道，反而主要在 evenN 通道。
2. H6 混合明显。
3. H10 以后信号很弱，不应作为选择定则核心判据。
```

这意味着目前还不能把“偶次谐波完全是 AFM 序参量奇函数”作为已经数值验证的结论。更稳妥的说法是：奇次谐波的 N-even 结构通过了检查，但偶次谐波的 N-odd 结构只在部分阶数上成立，H2 是关键异常点。

## 6. 可能原因

优先考虑以下方向：

```text
1. 理论关系 J_n(-N)=(-1)^(n+1)J_n(N) 是否遗漏了把 +N 映到 -N 时伴随的空间操作，例如层交换、反演、平移或电流分量变换。
2. +N 和 -N TB 来自两次独立 SCF+Wannier，Wannier gauge/disentanglement 没有被强制成对称配对。
3. 旧 +N SBE 数据和新 -N SBE 数据不是同一天同一代码版本跑出的配对数据。虽然目前改动大多不该影响物理，但 H2 异常值得用同一代码版本重跑 +N 来排除。
4. 实际结构、外场方向或磁构型可能允许一部分 N-even 的二阶响应背景。
5. H2 对相位、CEP、退相干和窗口函数非常敏感，需要确认分析脚本的 Fourier 相位约定是否与论文中定义一致。
```

## 8. 外部反馈后的对称性核对（2026-06-01）

外部 AI 提醒：关系

```text
J_n(-N) = (-1)^(n+1) J_n(N)
```

不是普适关系，它要求存在把 `+N` 映到 `-N` 的空间操作，最常见是反演 `P`。这个提醒在理论上是对的；但不能直接用 QE 输出的 `no inversion` 一句话判断几何结构是否非中心对称，因为当前 QE 输入把 Cr 分成了 `Cr1/Cr2` 两个原子种类来设置 AFM 初态，这会人为降低 QE 的空间群识别。

本地 `+N` SCF 输出显示：

```text
C:\Users\26507\Documents\量子光研究\inputs\CrI3_scf_soc.out
2 Sym. Ops. (no inversion) found
```

但对 `CrI3_scf_soc.in` 的 `ATOMIC_POSITIONS` 直接做几何反演匹配，并把 `Cr1/Cr2` 都视为同一种 Cr 后，可以找到反演中心：

```text
fractional inversion center ≈ (0.499998583, 0.333333067, 0.372004766)
max fractional mismatch ≈ 2.6e-5
```

因此，当前更准确的判断是：

```text
1. 非磁几何结构本身近似有反演中心。
2. QE 的 “no inversion” 很可能主要来自 Cr1/Cr2 标签、非共线 SOC、AFM 初态以及对称性设置，而不是几何堆叠真的非中心对称。
3. 所以 H2 的 evenN 主导目前还不能简单解释为“晶格非中心对称允许普通 SHG”。
```

外部 AI 还建议分别看 `Jx/Jy` 的 H2 通道。当前 CSV 已经输出了每个分量的复数振幅。以 `full112` 为例：

```text
H2:
Jx evenN / oddN ≈ 10.5
Jy evenN / oddN ≈ 16.0
```

也就是说，在当前数据中 `Jy` 的 H2 也主要落在 `evenN`，并没有显示出更纯的 `oddN` 磁性通道。这一点需要反馈给外部 AI。

目前更合理的待检验假设：

```text
1. +N 和 -N 两套独立 SCF+Wannier TB 没有成为严格的 P 相关伙伴。
2. 选择定则推导可能遗漏了从 +N 到 -N 时需要同时施加的具体空间操作、原胞选择或坐标变换。
3. 旧 +N SBE 数据与新 -N SBE 数据不是同一代码版本成对跑出的，需要用当前代码重跑 +N 来排除技术差异。
```

下一步仍建议先重跑当前代码版本的 `+N nb1-104/full112`，然后复用同一个分析脚本重新做成对比较。
