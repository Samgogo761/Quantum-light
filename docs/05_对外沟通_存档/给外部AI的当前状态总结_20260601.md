## 7. 选择定则判据

理论关系：

```text
J_n(-N) = (-1)^(n+1) J_n(N)
```

因此：

```text
奇次谐波 H1/H3/H5/... 应主要在 evenN = [J(N)+J(-N)]/2 通道
偶次谐波 H2/H4/H6/... 应主要在 oddN  = [J(N)-J(-N)]/2 通道
```

脚本中 `leakage_ratio` 定义为 forbidden/allowed：

```text
奇次谐波：yield_oddN  / yield_evenN
偶次谐波：yield_evenN / yield_oddN
```

数值越小，选择定则越干净。优先判断 H1-H10，因为当前 CrI3 经典光谱在 H11 以后已经接近 cutoff/数值地板。

外部 AI 需要帮忙判断：

3. 如果 nb1-104 通过而 full112 略差，是否说明 full112 的两套 Wannier gauge 不够配对？

## 11. 外部反馈后的补充信息：结构反演与 H2 分量

```text

```

但直接检查 `ATOMIC_POSITIONS`，并把 `Cr1/Cr2` 都视为 Cr 后，几何结构存在近似反演中心：

```text
fractional inversion center ≈ (0.499998583, 0.333333067, 0.372004766)
max fractional mismatch ≈ 2.6e-5
```

因此，H2 的 evenN 主导不能简单归因于“结构本身非中心对称”。

同时，按 `Jx/Jy` 分量拆开看 `full112` 的 H2：

```text

Jy evenN / oddN ≈ 16.0
```

所以“只看 Jy 可能得到纯 oddN 磁性 H2”的判断，在当前数据里没有成立。当前最需要判断的是：`+N/-N` 两套独立 SCF+Wannier TB 是否没有成为严格的 P 相关伙伴，或者选择定则推导是否遗漏了原胞/坐标/空间操作。
