## 一、先回答你最担心的问题：不需要重写 SBEs 求解器

**SBE 求解器做的事情是：** 给定哈密顿量 H 和电场 E(t)，输出 J(t; H, E)。这本身是物理可观测量，不依赖于选择定则。求解器正确性的检查是：弱场极化标度（已通过 H1）、规范不变性、初态电流接近零（已通过）等。

**选择定则 `J_n(-N) = (-1)^(n+1) J_n(N)`** 是两次独立计算之间的**外部一致性关系**，它检查的是：

1. TB(+N) 和 TB(-N) 这两个 Wannier 哈密顿量是否真的是 P 相关的伙伴
2. 如果是，那么用同一个 E(t) 跑两次 SBE 后的电流应该满足上述关系

**所以选择定则不通过 ≠ 求解器有错。** 如果通过了，是对求解器+TB+整个流程的强一致性证明；不通过，问题往往在 **TB 构造侧（Wannier gauge）**，而不是 SBE 解算器侧。

## 三、关于"假设 B 需要翻转 E"的澄清

本地 AI 在文档中曾怀疑：从 +N 到 -N 是否需要同时翻转电场 E→-E。外部 AI 重做了严格推导，结论如下：

设 `U_E(t; N)` 是 `H(N) + r·E(t)` 下的时间演化算符。由于：
- `P H(N) P^(-1) = H(-N)`
- `P r P^(-1) = -r`
- `P J P^(-1) = -J`
- `P ρ_0(+N) P^(-1) = ρ_0(-N)`

有：
```
P U_E(t; +N) P^(-1) = U_(-E)(t; -N)
```

代入电流期望值：
```
J(t; +N, E) = -J(t; -N, -E)
```

对 E 做微扰展开，第 n 阶有 `J^(n) ∝ E^n`：
```
J^(n)(t; +N) / E^n = -J^(n)(t; -N) / (-E)^n = -(-1)^n J^(n)(t; -N) / E^n

=> J^(n)(-N) = (-1)^(n+1) J^(n)(+N)
```

**关键：这个关系本身就是用同一个 E(t) 比较的，不需要在 -N 系统中翻转电场。**

所以"假设 B"（之前怀疑要补一个 E→-E）是**错的**，原始关系在严格 P 配对的情况下就是对的。

## 四、H2 evenN 异常的可能来源（按优先级排序）

排除"理论关系本身错"之后，可能性收窄到：

### 1. Wannier gauge 配对问题（最可能）

+N 和 -N 用了两次独立的 SCF→nscf→Wannier90 流程：
- disentanglement 窗口取舍可能不对称
- Wannier90 的 maximally-localized 收敛到不同的局域 gauge
- 初猜（initial projections）即使输入文件一样，迭代路径不同

结果是：`H_TB(-N) ≠ P H_TB(+N) P^(-1)` 在精确算符意义上。两者描述同一个物理（带结构相同，Spread 差异 202.149 vs 202.291 也很小），但作为算符不是 P 共轭对。这对线性响应（H1）影响很小，但非线性响应对 gauge 细节敏感得多，尤其是 H2。

### 2. SOC 投影/磁矩定义的细节差异

SCF 阶段如何定义 +N 和 -N 的初始磁矩方向、SOC 投影到 Wannier 时的 spin 轴选择，都可能让两套 TB 在 spin 部分有除全局反号外的额外相位差异。

### 3. 代码版本

如果确实 +N 也是新版跑的，那这个变量基本可以排除。但还是值得用同一份代码、同一份 input.nml、同一天重跑一次，确保 OMP 调度、随机种子（如有）、并行化细节完全一致。

## 五、为什么 H1/H3 干净但 H2/H6 不干净？

这是关键的诊断信号。

- **线性响应 `χ^(1)`** 对 Wannier gauge 的依赖最弱（在共变规范下规范不变性最强）。
- **`χ^(2)`** 涉及两个 dipole 矩阵元的乘积，对 gauge 相位特别敏感：
  ```
  χ^(2) ~ Σ <u|r|u'><u'|r|u''><u''|...>...
  ```
  任何 spin 子空间内的额外相位 `e^(iφ)` 都会在 `|χ^(2)|` 里活下来。
- **`χ^(3)`** 涉及三个矩阵元乘积，某种程度上相位会再次抵消，所以 H3 又变干净。

这种**"奇阶干净、偶阶肮脏"**的图案非常符合 **gauge 配对失配**的特征。

## 六、建议的工作流（外部 AI 建议）

1. **先检查：**
   - (a) 两套 Wannier90 输入文件的 `initial projections / dis_win / num_iter` 是否完全对称（已确认是）
   - (b) 是否可以从 +N 的 `wannier90.amn/.mmn` 通过自旋翻转直接构造 -N 的版本，而不是独立跑一次 Wannier90

2. **用当前代码重跑 +N**（即使本来就是新版），获得严格成对的数据，排除任何调度/数值细节差异。

3. **如果重跑后 H2 仍然 evenN 主导**，那就几乎可以肯定是 Wannier gauge 配对问题。修复方向是：
   - 从 +N 的 Wannier 函数显式构造 -N 的 Wannier 函数（通过对自旋指标做 σ_x 或自旋翻转操作）
   - **而不是独立再跑一次 Wannier90**
   - 这是 **TB 构造侧的修复**，不需要动 SBE 求解器
