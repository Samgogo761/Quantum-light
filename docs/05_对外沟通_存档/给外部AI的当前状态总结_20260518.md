# 给外部 AI 的当前状态总结（2026-05-18）

本文是当前最适合发给外部 AI 判断路线的精简版。它只记录截至 2026-05-18 晚上的最新结论，不按完整历史展开。

## 1. 当前总原则

BSV 暂时不进入生产计算。原因是经典光求解器路径、带窗截断和退相干参数还需要最后确认。BSV 每个样本都要重复一次经典光传播，在经典光还没有定型前直接上 BSV 会浪费大量计算资源。

当前只讨论经典光：

```text
CrI3
classical light
gauge_method = lg_cov
T2_fs = 1.0e30
即近似无退相干
```

## 2. 退相干参数语义

旧求解器中：

```text
deph_t2 = 0.5
```

不是 0.5 fs，而是 0.5 个光周期。对 3200 nm 驱动光：

```text
T_cycle ≈ 10.674 fs
0.5 cycle ≈ 5.337 fs
```

新求解器现在已经加入：

```fortran
&dephasing
  T2_cycles = 0.5
/
```

用于复现旧代码语义。`T2_fs` 仍然表示显式 fs。若 `T2_cycles > 0`，它会覆盖 `T2_fs`。

## 3. 规范路线判断

### matrix_vg

`matrix_vg` 与旧 VG 在时间域主电流上高度一致，说明新求解器核心动力学没有明显重写错误。但它本质上是：

```text
H(t) = H0(k) + A(t) · P(k)
```

也就是速度规范 Peierls 替换 `H(k + A)` 的一阶近似。当前不把它作为生产路径。

### Peierls vg

Peierls 速度规范全带是理论上更完整的速度规范路径，但对称带窗截断已经失败：

```text
Peierls vg symmetric 20/30/40/50/60 bands:
低阶 H1/H3 出现巨大虚假背景
不向 full112 收敛
```

解释：截掉深价带破坏了速度规范中背景电流抵消。Peierls VG 的截断路径不作为生产路径。

### lg_cov

当前最可靠生产路径是协变长度规范：

```text
gauge_method = lg_cov
```

它没有 Peierls 速度规范截断中的灾难性低阶虚假背景。带窗截断仍然有误差，但表现为逐步精度问题，而不是完全失效。

## 4. k 网格收敛

## 5. 带窗截断测试

### 对称 active-window 截断

测试过：

```text
30 bands: 70-99
40 bands: 65-104
50 bands: 60-109
60 bands: 53-112
```

结论：`lg_cov` 下比 Peierls 好很多，但对称 30-60 bands 仍不能作为绝对谱生产配置。

### 固定导带顶部、逐步补回深价带

测试过：

```text
nb30-112: 55 valence + 28 conduction = 83 bands
```

它对 H1-H8 不错，但初始电流和偶次谐波仍有偏差：

```text
|J(0)| nb30-112 ≈ 4.07e-8
|J(0)| full112  ≈ 4.40e-18
```

偶次相对 full112：

```text
H2  = 1.612
H4  = 0.955
H6  = 0.857
H8  = 1.186
```

所以 `nb30-112` 可作为便宜诊断候选，但不是当前最好的生产候选。

### 保留全部价带，只截高导带

这是目前最重要的新结果。测试过：

```text
nb1-94  : 84 valence + 10 conduction = 94 bands
nb1-104 : 84 valence + 20 conduction = 104 bands
full112 : 84 valence + 28 conduction = 112 bands
```

运行时间：

```text

nb1-104  : 115.48 min
```

## 7. Wannier90 是否需要重做少带模型

当前 112-band Wannier 模型对应：

```text
4 Cr * 5 d = 20
12 I * 3 p = 36
spin/SOC factor = 2
total = 112
```

因此它是一个化学上完整的 Cr-d / I-p spinor 母模型，不是任意过大的模型。

重做 20-40 band Wannier 不是绝对禁止，但它是新的有效模型，不会自动解决规范或截断问题。若重做少带模型，必须再与：

```text
lg_cov / full112 / 40x40
```

比较经典光谱，尤其 H1-H11 和偶次 H2/H4/H6/H8。

当前更合理路线是：

```text
先用现有 112-band 母模型确定可靠截断；
若 BSV 大样本仍太贵，再考虑重做少带 Wannier 作为加速模型。
```
