## 6. 与旧求解器语义的关系

旧求解器的：

```text
deph_t2 = 0.5
```

对应的是：

```text
T2_cycles = 0.5
T2 ≈ 5.337 fs
```

而不是 `T2_fs=0.5 fs`。

本次扫描直接显示：

```text
T2_fs = 0.5 fs
```

会把 H3 及以上谐波压低几个数量级，同时显著放大 H1/H2。它与旧求解器的 `deph_t2=0.5` 不是同一个物理设置，不能混用。

`T2_fs=5 fs` 与 `T2_cycles=0.5` 定性一致；低阶 H1/H2/H3 最接近，高阶由于 `5 fs` 比 `5.337 fs` 更短，仍有 10%-25% 左右的差别。

## 7. 物理判断

1. T2 是强敏感参数，不是无关紧要的数值阻尼。
2. 短 T2 会强烈压低 H3 以上的谐波，尤其偶次 H4/H6/H8/H10。
3. H1 和 H2 对短 T2 的响应不是简单单调抑制；在 `0.5 fs` 下反而比无退相干更强。这说明低频响应和高阶 HHG 受退相干影响的机制不同。
4. 若要与旧求解器历史结果一致，应使用 `T2_cycles=0.5` 或显式 `T2_fs≈5.337`。
5. 若参考文献使用 `T2=5 fs`，它与旧代码等价值接近，但不完全相同。论文中最好给出 T2 敏感性图，而不是只报一个固定值。
