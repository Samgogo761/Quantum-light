# 可视化导出接口更新（2026-06-11）

本文记录为 HHG-XR/科研可视化项目新增或确认的 solver-side 输出接口。目标是提供真实计算数据，而不是让可视化端重建或猜测物理量。

## 1. 已确认已有接口：occupation

`src/mod_sbe.f90` 已有 `occupation_kt.dat` 导出逻辑，通过 `&output` 控制：

```fortran
&output
  save_occupation = .true.
  occ_stride = 100
  occ_band_resolved = .false.
/
```

输出：

```text
occupation_kt.dat
# it  time_fs  ikx iky  kx(1/bohr) ky(1/bohr)  n_val  n_cond
```

其中 `n_val` 和 `n_cond` 是每个 k 点的价带总占据与导带总占据，适合作为第一版 k-space occupation 可视化数据。

`occupation_band_kt.dat` 由 `occ_band_resolved=.true.` 控制。该文件很大，`112 bands / 40x40 / ~50 snapshots` 会达到数百 MB 到 GB 级，默认不建议打开。

## 2. 新增接口：Et.dat

新增位置：

```text
src/mod_laser.f90 :: write_field(filename)
src/main.f90      :: classical path after generate_field()
```

经典单轨迹运行会输出：

```text
Et.dat
# it  time_fs  Ex(a.u.)  Ey(a.u.)  Ax(a.u.)  Ay(a.u.)
```

这是 solver 原生输出，包含 `generate_field_sample()` 中梯形积分得到的 `A(t)` 以及 residual-DC correction 后的最终 `At_vec`。可视化项目应优先使用它，而不是从 `input.nml` 重建场。

当前只在 classical single-trajectory path 输出一个 `Et.dat`。BSV ensemble 暂不逐样本输出场，避免生成大量小文件。

## 3. 新增接口：coherence_kt.dat

新增参数：

```fortran
&output
  save_coherence = .true.
/
```

输出：

```text
coherence_kt.dat
# it  time_fs  ikx iky  kx(1/bohr) ky(1/bohr)  coherence_norm
```

定义：

```text
coherence_norm(k,t) = sqrt(sum_{m != n} |rho_mn(k,t)|^2)
```

用途：作为 interband coherence 的 k-space 标量热图，不导出完整复数密度矩阵。

注意：计算量随 `n_trunc^2 * nk * snapshots` 增长。默认关闭；建议只在 `verify_obs` 或可视化专用小样本 classical run 中打开。

## 4. verify_obs 已更新

`deploy/run_verify_observables.sh` 的 `&output` 已改为：

```fortran
&output
  save_geometry   = .true.
  save_occupation = .true.
  occ_stride = 100
  occ_band_resolved = .false.
  save_coherence = .true.
/
```

因此重跑 `verify_obs` 后应生成：

```text
Et.dat
occupation_kt.dat
coherence_kt.dat
quantum_geometry.dat
Jt.dat
HHG.dat
Jt_spin.dat
HHG_spin.dat
```

## 5. 是否需要重跑 verify_obs

需要。理由：

```text
1. 旧 verify_obs 没有打开 save_occupation。
2. 旧 solver 没有 Et.dat 和 coherence_kt.dat。
3. 可视化项目要把 field source 从 reconstructed_from_input_nml_not_raw_output 升级为 raw_solver_output。
```

推荐命令：

```bash
cd /public/home/wangjs/project/New_SBEs/Quantum-light
sbatch deploy/run_verify_observables.sh
```

若需要避免覆盖旧结果，可指定：

```bash
OUTDIR=/public/home/wangjs/project/New_SBEs/Quantum-light/output_verify_obs_exports_20260611 \
  sbatch deploy/run_verify_observables.sh
```
