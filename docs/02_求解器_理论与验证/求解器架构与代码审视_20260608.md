# SBE 求解器架构与代码逻辑审视（2026-06-08）

对当前 `Quantum-light` Fortran 求解器做的一次整体审视:模块依赖、物理数据流、数值方法、
强项、风险/技术债,以及性能模型(供 BSV 估时用)。基于通读全部源码。

## 1. 模块依赖图(DAG)

```text
mod_params      常数 + 所有输入 namelist(crystal/kgrid/bands/laser/timestep/
                dephasing/bsv/method/diagnostics/output/spin)
mod_wannier     读 tb.dat/hr.dat/r.dat;Fourier 得 H(k),D(k),v(k)
mod_crystal     k 网格、能带对角化 -> Ek + U_trunc(能带基)、谷分配、project_to_trunc
mod_laser       E(t)/A(t) 场(cos^2 包络、CEP、双色、外部 A 可选)
mod_current     写电流
mod_hhg         Hann 窗 + FFTW 谱
mod_quantum_light  BSV 随机相位强度采样(指数分布)
mod_spin        ★新:S_z 算符(名义/可读.spn)+ 自旋流
mod_sbe         ★核心:预计算各规范矩阵、propagate、退相干  [use mod_spin]
mod_geometry    ★新:Berry 曲率 + 量子度规           [use mod_sbe]
mod_berry       旧 vg 路径 Berry                      [use mod_sbe]
mod_ensemble    BSV 蒙特卡洛包装                       [use mod_sbe, mod_quantum_light]
main            串起整个流程
```
依赖是干净的有向无环图,无循环依赖(mod_spin 不 use mod_sbe,靠把 Pk_eq 作参数传入)。

## 2. 物理数据流(lg_cov 生产路径)

```text
1. 读 TB: H(R), r(R)(偶极)
2. 对每个 k 对角化 H(k) -> Ek, U_trunc(截断到 [nb_start,nb_end] 的能带基)
3. 预计算(只算一次,BSV 多样本复用):
     Hk_eq = U†HU(对角=Ek)
     Dk_eq = U†D U(Berry 联络/偶极)
     Pk_eq = U†(dH/dk - i[D,H])U(规范协变速度 = 电流算符)
4. 初始化 ρ:价带填满(n=1..nv 对角=1)
5. 时间演化(RK4, dt=0.35 a.u.):
     dρ/dt = -i[H0 + E·D, ρ] + E·∇_k ρ
     其中 E·∇_k ρ 用平行输运的 5 点有限差分(规范协变导数)
     每 n_dt_deph 步在"瞬时缀饰能带基"里对非对角 ρ 乘 exp(-dt·n_dt_deph/T2)(T2 退相干)
6. 电流 J(t) = -1/(Nk·A) Re Tr[Pk_eq ρ];decompose=.true. 时每步对角化瞬时 H 拆 intra/inter
7. Hann 窗 FFT -> HHG.dat
```

## 3. 数值方法

| 环节 | 方法 |
|------|------|
| 时间积分 | RK4(每步 4 次 RHS) |
| 协变 k 导数 | 5 点(k 少时 3 点)平行输运有限差分 |
| 对角化 | LAPACK zheevd(分治厄米) |
| 谱 | FFTW + Hann 窗,功率谱 \|J(ω)\|² |
| 并行 | OpenMP over k 点(COLLAPSE(2),dynamic),贯穿所有热循环 |

## 4. 强项

```text
1. lg_cov 是物理正确、已多重验证的生产规范;协变导数用平行输运,处理规范相位正确。
2. 截断基 = 本征基(U_trunc 来自对角化),所以 intra/inter、Berry、量子度规、自旋
   都在良定义的能带基里,语义清晰。
3. 预计算提到循环外、只算一次 -> BSV 多样本天然复用,省大量重复。
4. OpenMP over k 是 embarrassingly parallel 的正确切法。
5. 模块化 + namelist 输入,扩展(几何/占据/自旋)是加法式、互不干扰。
```

## 5. 风险 / 技术债 / 注意点

```text
R1 decompose=.true. 的每步对角化是经典 run 的主要额外开销(~30-40%);
   纯 HHG(不需要 intra/inter)用 decompose=.false. 明显更快。BSV 已用 .false.。
R2 退相干是"瞬时缀饰基 + 算符分裂"近似,要求 dt·n_dt_deph << T2。
   现配置 dt·n_dt_deph=1.75 a.u.,T2(0.1 cycle)=44 a.u. -> OK;但若 T2 再缩短需复核。
R3 几何/Berry 的 Kubo 求和只在截断窗口内 -> j_anom/PT 验证必须用 full nb1-112(已记)。
R4 自旋算符默认名义 diag(±1/2),SOC 下近似 -> 严格需 .spn(已提供转换脚本)。
R5 内存:预计算阵 ~ n_trunc²×nk×(若干份)。46×46/full112 估算:
      单份 112²×2116×16B ≈ 0.42 GB;Hk(1)+Dk(3)+Pk(3)+vk(2)+ρ/k1-4/stage/new(~7)
      ≈ 16 份 ≈ 6.7 GB,加 1.1 GB TB -> ~7-8 GB。本地紧张,服务器无碍。
      开 spin_current 再 +SzVk_eq(2 份)≈ +0.8 GB。
R6 编译告警(均无害):tr_intra/tr_inter/tr_spin 的 -Wmaybe-uninitialized、
   BSV 分支 hhg_accum 未初始化告警。可将来加初始化清理。
R7 matrix_vg / Peierls vg 路径保留但非生产(已知截断破坏 f-sum)。
```

## 6. 性能模型(供 BSV 估时)

实测(服务器 36 核,decompose=.true.):
```text
nb104 / 40×40 / nt=5045 : 1.93 h
full112/ 40×40           : 2.35 h
```
分析(每步每 k 的 n³ 操作占比):RK4 RHS 主导(~24-40 n³),decompose 额外 ~15 n³。
故 **BSV 单样本(decompose=.false.)≈ 0.7-1.0 × 经典 run**:
```text
BSV/样本 nb104/40×40 ≈ 1.4-1.9 h   (中值取 1.6 h)
BSV/样本 full112/40×40 ≈ 1.7-2.3 h
k 网格标度: × (nk/1600);  46×46 ≈ × 1.32
```
预计算(每个 array task 一次)≈ 0.1-0.2 h,大 N_per_task 下可忽略。
