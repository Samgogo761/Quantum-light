```bash
       --file output_verify_obs_*/quantum_geometry.dat
```


## 2.（可选,为严格自旋流）生成 .spn

当前自旋流用名义 S_z(SOC 下近似)。要严格版,在服务器重跑 pw2wannier90 + wannier90:

```text
pw2wannier90 输入加:  write_spn = .true.   write_spn_formatted = .true.
wannier90    输入加:  write_u_matrices = .true.
=> 得到 seedname.spn(formatted), seedname_u.mat, seedname_u_dis.mat
```
下载这三个文件到本地,转换成 Wannier 基 S_z:
```bash
python tools/analysis/spn_to_sz_wannier.py \
  --spn CrI3.spn --umat CrI3_u.mat --udis CrI3_u_dis.mat --half \
  --out Sz_wannier.dat
# 自检: Hermiticity ~0, 对角 in [-0.5,0.5]
```
再在 SBE 输入里设 `&spin spin_sz_file = "Sz_wannier.dat" /`,跑出的 `HHG_spin.dat`
即严格自旋 HHG。验证标准 = 求解器打印的"Equilibrium spin check"价带和 ≈ 0(AFM)。

> 注:spn_to_sz_wannier.py 尚未用真实 .spn 实测(本地无此文件),首次使用请看自检输出;
> 格式若不符,对照脚本顶部的格式假设微调。

## 3. BSV pilot 估时（≤3 节点）

### 成本模型
BSV = 蒙特卡洛,每样本 1 次 `run_single_trajectory`(decompose=.false.,比经典 run 快 ~30%);
预计算每个 array task 只算一次。单样本估:
```text
nb104 / 40×40 : ~1.4-1.9 h  (取中值 1.6 h)
full112/ 40×40: ~1.7-2.3 h
46×46 = × 1.32
```

### 墙钟估算（3 节点并发，每节点 36 核）
| 配置 | 单样本 | N=50 | N=100 |
|------|-------|------|-------|
| **nb104 / 40×40**(推荐 pilot) | 1.6 h | **~27 h（约 1.1 天）** | ~54 h（约 2.3 天） |
| full112 / 40×40 | 2.0 h | ~34 h（约 1.4 天） | ~67 h（约 2.8 天） |
| nb104 / 46×46 | 2.1 h | ~35 h（约 1.5 天） | ~70 h（约 2.9 天） |

> 推荐 pilot 用 **nb104 / 40×40 / N=50**:约 1 天出结果。文档已确认 40×40 对 pilot 足够;
> 46×46 留给后续生产。先 N=50 测方差,再用方差反推生产所需 N(误差 ∝ 1/√N)。

### BSV pilot:已经替你改好了 run_bsv.sh
`deploy/run_bsv.sh` 现在默认 **`--array=0-2%3`、N_TOTAL=51、N_JOBS=3**(17 样本/task,
一波占满 3 节点),`WORKDIR` 自动取提交目录,task 0 强制 clean 重编。直接:
```bash
cd <仓库根目录>
sbatch deploy/run_bsv.sh
# TB 不在默认位置时:  BSV_TB_FILE=/你的路径/CrI3_tb.dat sbatch deploy/run_bsv.sh
# 全部完成后合并:
bash deploy/combine_bsv.sh           # 默认扫 3 个 task,出 output_bsv/HHG_bsv_combined.dat
```
BSV 用 `deploy/input_bsv.nml`(lg_cov / 40×40 / nb1-104 / T2_cycles=0.5),
与 `input/input.nml`(你改的 T2=0.1/k46)互不影响。
> 方差/定 N:每个 task 的 `output_bsv/task_*/HHG_bsv.dat` 自带 17 样本的 stderr,
> 用它(而非 combine 的跨 task stderr)反推生产所需 N(误差 ∝ 1/√N)。

### pilot 跑完看什么
```text
1. HHG_bsv.dat 自带 stderr(每频点) -> 估样本噪声,反推生产 N。
2. BSV 平均谱 vs 经典谱:cutoff 是否延展 / 偶次是否增强 / 谱峰是否展宽。
3. 若 pilot 无明显新物理,不必烧大样本。
```

## 4. 顺序建议

```text
A. git 同步 + 服务器编译                              (分钟级)
B. 回归 + 几何验证(nb1-112,确认 j_anom~0、Jt 不变)  (一次经典 run, ~2-3 h)
C.（可选）生成 .spn -> 严格自旋流                      (服务器重跑 pw2wan/wan90)
D. BSV pilot nb104/40×40/N=50,3 节点                  (~1 天)
E. 看 stderr 与新物理,决定是否扩到 N=100-200 或进生产
```
