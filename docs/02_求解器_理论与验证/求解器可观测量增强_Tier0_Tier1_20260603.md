## 3. 输出文件

### 3.1 `quantum_geometry.dat`(默认产出,lg_cov 路径)

```text
# ikx iky band  kx ky  E(eV)  Omega(a.u.)  gxx  gyy  gxy  valley
```
- `Omega` = Berry 曲率 Ω_n(k) = −2 Im Q^{xy}_n
- `gxx,gyy,gxy` = 量子度规 g^{ab}_n = Re Q^{ab}_n
- 几何张量 `Q^{ab}_n(k) = Σ_{m≠n} v^a_{nm} v^b_{mn} / (E_m−E_n)²`,
  其中 `v^a = Pk_eq(:,:,a)` 是已投影到能带基的协变速度,`E_n = Ek`。

分析:
```powershell
& <python> tools/analysis/analyze_quantum_geometry.py --file <outdir>/quantum_geometry.dat
```
会报告 `max|Ω|`、`max|Ω|/中位 Tr g` 比值(PT 判据)、量子度规量级、各能带几何热点。

### 3.2 `occupation_kt.dat`(需 save_occupation=.true.)

```text
# it  time_fs  ikx iky  kx ky  n_val  n_cond
```
`n_cond(k,t)=Σ_{n>nv} ρ_nn(k,t)` 是导带占据(平衡能带基),即真实 k 空间占据图,
适合做激发态动力学/HHG-XR 可视化。分析:
```powershell
& <python> tools/analysis/read_occupation_snapshots.py --file <outdir>/occupation_kt.dat --dump-maps maps.npz
```

## 4. j_anom 的处理(捷径)与"待注意问题"标记

**采用的捷径**:体系 PT 对称(P 破缺 + T 破缺 + PT 守恒)。PT 把 k→k 且 Ω 在 PT 下
为奇 ⟹ **Ω_n(k)=0 逐点成立** ⟹ 反常(Berry)电流 `j_anom ≡ 0` 在所有时刻。因此:
```
(i)  quantum_geometry.dat 展示 max|Ω| ~ 数值地板（相对量子度规可忽略）
(ii) 偶次谐波落在 j_inter（已由 intra/inter 分解证明，见 01_ 主线）
=> j_inter 全为 j_pol => 偶次谐波来自带间极化电流。
```

> ⚠️ **待注意问题(记此备忘)**:这是"用对称性论证 j_anom=0",**不是**在求解器里把
> j_inter 显式拆成 j_pol + j_anom 两路算符并展示后者数值为零。两点风险需将来确认:
> 1. 简并子空间(Kramers 对)里 abelian Kubo 公式跳过了 |ΔE|<1e-8 的项,非阿贝尔
>    Berry 曲率未被这张表捕捉;PT 仍保证总和为零,但严格论文级证据最好再做
>    **时间分辨 j_anom(t)** 的显式四路拆分(Tier 1 热循环改动,见第 5 节)。
> 2. 若将来体系不再严格 PT(例如加面内 canting、外磁场),Ω≠0,此捷径失效,
>    必须回到显式四路电流分解。
> 该问题登记在 `01_AFM选择定则_主线/偶次谐波intra_inter分解_20260603.md` 第 5 节,
> 与本节互为引用。

## 5. 量子度规是什么(回答提问)+ 为什么值得算

**量子度规** `g^{ab}_n(k)` 是量子几何张量 `Q = g − (i/2)Ω` 的对称(实)部;Berry 曲率
`Ω` 是反对称(虚)部。直观上 `g` 度量相邻 k 的 Bloch 态有多"不同"(量子距离),是
Wannier 局域化展宽、超流权重、以及近年非线性光学/HHG 的几何驱动量。

关键点:在 PT 对称体系里 **Ω→0 而 g 存活**。因此"偶次谐波的几何起源是量子度规、而非
Berry 曲率"是一个干净且新颖的叙事——这正是把它和 Ω 一起算出来的原因。现代 HHG/非线性
光学文献(平带、量子几何驱动的高次谐波,2022–2024)确有研究这些量,故纳入正式计算目标。

## 6. Tier 2 架构草案:量子光多时关联(待你审阅理论后再实现)

**战略前提**:当前 BSV MC(`mod_quantum_light` 随机相位强度采样)只能给 BSV **平均谱**,
落在 González-Monge/Feist "无量子优势"区。要拿到驱动光光子统计 ↔ 谐波光子统计的关联
(你强调的二阶关联),必须实现**多时电流关联 + 量子回归定理(QRT)**。

核心新对象(理论文档核心):
```
C^{ab}(t,t') = ⟨Ĵ^a(t) Ĵ^b(t')⟩
            = Σ_k Tr[ v̂^a U(t,t') ( v̂^b ρ(t') ) ]     (量子回归定理)
```

**代码改动的最小架构**(不改物理框架,只多演化辅助算符):
```
现状:  时间循环演化 1 个 ρ(k,t)，每步算 ⟨J(t)⟩ = Tr[v ρ]
Tier2: 对选定的"源时刻" t' ∈ {t'_1,...,t'_M}:
        1. 在 t' 处构造辅助算符 χ_b(k,t') = v̂^b(k) ρ(k,t')   (b=x,y,z)
        2. 用同一个 lg_cov 传播子 U(t,t') 把 χ_b 演化到 t > t'
        3. 每步累计 C^{ab}(t,t') = Σ_k Tr[ v̂^a(k) χ_b(k,t) ]
        => 复用现有 propagate_lg_covariant 的 RHS / RK4，
           把 rho 换成辅助算符 χ_b 再跑一遍(每个 t' 一次)。
```

**数值代价**:存储 O(N_t × M)、计算 ~ M × (单次传播)。M = 源时刻数。
- 廉价版:只取少量 t'(如脉冲峰附近 M~10–20),先验证 ⟨J(t)J(t')⟩ 结构与对称性。
- 完整版:M ~ N_t(双时全谱),配合频域 C^{ab}(ω,ω') → 二阶相干/压缩/纠缠。

**产出链**(都从 C^{ab} 后处理):
```
⟨n_q⟩ 谐波强度       ←  ∫∫ e^{iω_q(t−t')} C(t,t')
g^{(2)}(q,q')         ←  四点关联(先用 Gaussian 近似从 C 拼)
压缩谱 ⟨δX_q²⟩        ←  二阶电流协方差
谐波间纠缠            ←  C^{ab}(ω_q,ω_q') 的非对角(q≠q')
Gaussian QFI(N,J_ex) ←  均值=一阶电流, 协方差=C^{ab}
ee/oo 通道分解        ←  按 Néel 宇称拆 C = C_ee + |N|² C_oo（C_oo 为 AFM 独有）
```

**与 BSV MC 的关系**:两者互补。MC 给"经典统计平均"基线;QRT 给"真实量子关联"。
量子优势判据 = QRT 的 QFI 是否超过任何经典强度分布能达到的上界。

**独立轻量线(强信号、低成本)**:JC 崩塌-复苏 T_R(BSV)=½ T_R(相干),Δn=2 的代数指纹。
可在简化两能带 JC 模型上先解析+数值验证,再看完整 SBE 能否捕捉这个周期特征。

## 6b. 自旋流(Tier 1b)——已实现(可插拔自旋算符)

新增 `src/mod_spin.f90` + propagator 累加,输出自旋-z 电流及其 HHG:

```text
J^{s_z}_a(t) = (1/2) <{S_z, v_a}>     (a=x,y)   -> Jt_spin.dat, HHG_spin.dat
```

**S_z 来源是可插拔的**(对应你选的方案):
```fortran
&spin
  spin_current = .true.
  spin_order   = 'interleaved'   ! 名义 diag(+-1/2):自旋为快指标(up,down,..)
  spin_sz_file = ''              ! 留空=名义近似;填入 .spn 导出的真实 S_z 矩阵=严格
/
```
- 默认 `spin_order='interleaved'` 的名义 diag(±1/2):SOC 下是**近似**(Cr-d 尚可,I-p 较粗)。
- 一旦在服务器用 `pw2wannier90 write_spn=.true.` + wannier90 生成 Wannier 基的 S_z 矩阵,
  写成 `m n Re Im` 的文本,设 `spin_sz_file` 指过去,即**无缝升级到严格自旋流**。

运行时会打印**平衡自旋自检**(BZ 平均 ⟨S_z⟩ 每带):
```text
Equilibrium spin check (BZ-averaged <S_z> per band):
  max |<S_z>_n| ; sum over valence bands (~0 for AFM); sum over all kept bands
```
> ⚠️ 用 **full nb1-112** 跑时,价带 ⟨S_z⟩ 之和应 ~0(AFM 两子格相消)。若名义近似下这个
> 自检明显偏离 0 或与已知磁结构矛盾,说明需要走 .spn 严格路线。

## 6c. ⚠️ 重要:量子几何/Berry 必须用 full band window(nb1-112)

`compute_quantum_geometry` 的 Kubo 求和只在**截断窗口** `[nb_start,nb_end]` 内进行。
PT ⟹ Ω=0 的论证要求对 **PT-完备**的能带集求和:
```text
nb1-112(完整 Wannier 流形,PT 完备)  -> Omega ~ 数值地板  ✅ 用这个做 j_anom 证明
nb1-104(砍掉最高 8 条导带,不完备)  -> Omega 小但非零(窗口伪贡献)
小窗口(如 nb80-92)                  -> Omega 可达 ~1e2(纯属截断伪影,非 bug)
```
本地 smoke test(nb80-92)实测 `max|Ω|≈434 a.u.`,**正是截断窗口的预期行为**,不是错误。
**做 j_anom/PT 验证时务必用 `nb_start=1, nb_end=112`。** 量子度规 g 在任何窗口都非零(正常)。
