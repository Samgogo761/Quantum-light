## 2. 退相干参数语义

旧求解器输入：

```text
deph_t2 = 0.5
```

不是 `0.5 fs`，而是 `0.5 optical cycle`。对 3200 nm：

```text
T_cycle ≈ 10.674 fs
0.5 cycle ≈ 5.337 fs
```

新求解器已支持：

```fortran
&dephasing
  T2_cycles = 0.5
/
```

当 `T2_cycles > 0` 时，它覆盖 `T2_fs`。

## 6. 当前理论判断

1. Peierls VG 的简单截断不适合作为生产路线，原因是截价带会破坏速度规范中的基态电流抵消。
2. `lg_cov` 的截断误差更温和，表现为虚跃迁完备性误差，而不是低阶伪背景电流。
3. 只有“保留全部 84 条价带、只截去高导带”的截断方式目前被数据支持。
4. `nb1-104` 是当前最好的经济候选；`full112` 仍是经典光绝对基准。
5. 不建议现在重做少带 Wannier90。当前 112-band 模型对应双层 CrI3 的 Cr-d/I-p spinor 化学完备基。少带 Wannier 是新的有效模型，必须重新对 full112 验证，不能自动解决规范和截断问题。

## 12. 新增 AFM Néel 选择定则检查

下一项建议加入的物理 debug 是比较两套相反反铁磁序参量 TB 数据：

```text
N       : AFM Néel vector = N
-N      : AFM Néel vector = -N
```

理想选择定则：

```text
J_n(-N) = (-1)^(n+1) J_n(N)
```

因此：

```text
奇次谐波主要在 evenN = [J(N)+J(-N)]/2 通道
偶次谐波主要在 oddN  = [J(N)-J(-N)]/2 通道
```

注意这必须在 `Jt.dat` 的复数 Fourier 电流振幅上做，不能直接对 `HHG.dat` 的强度平方相加相减。

已新增说明与工具：

```text
docs/AFM_Neel选择定则检查方案_20260526.md
tools/analysis/afm_neel_symmetry_check.py
```

这项检查需要真正的两套 `N/-N` Wannier TB 文件。不能只改 `input.nml` 里的 `SOC` 参数，因为当前磁序和 SOC 信息都已经编码在 `wannier_tb_file` 中。
