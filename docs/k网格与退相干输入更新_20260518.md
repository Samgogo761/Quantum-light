## 2. 退相干输入语义已经修正

旧求解器中：

```text
deph_t2 = 0.5
```

含义不是 0.5 fs，而是 0.5 个驱动光周期。对 3200 nm 驱动光：

```text
T_cycle ≈ 10.674 fs
0.5 optical cycle ≈ 5.337 fs
```

新求解器现在支持两种输入：

```fortran
&dephasing
  T2_fs = 5.337
  T2_cycles = -1.0
/
```

或者更推荐用于复现旧代码语义的写法：

```fortran
&dephasing
  T2_cycles = 0.5
/
```

规则：

```text
若 T2_cycles > 0，则 T2 = T2_cycles * T_cycle，并覆盖 T2_fs。
若 T2_cycles <= 0，则使用 T2_fs，单位为 fs。
```

程序启动时会打印：

```text
T2 input
T2 effective
```

因此以后可以直接从 `run.log` 判断实际使用的退相干时间。

## 3. 脚本使用方式

无退相干测试仍然使用：

```text
T2_fs = 1.0e30
T2_cycles = -1.0
```

在服务器脚本中，已经加入 `T2_CYCLES` 环境变量。例如复现旧求解器 `deph_t2=0.5`：

```bash
T2_CYCLES=0.5 sbatch --array=0-1 deploy/run_lg_cov_fullvalence_scan.sh
```

如果要显式使用 fs：

```bash
T2_FS=5.337 T2_CYCLES=-1.0 sbatch --array=0-1 deploy/run_lg_cov_fullvalence_scan.sh
```

T2 扫描脚本也已加入一个旧语义 case：

```bash
sbatch --array=0-6 deploy/run_lg_cov_t2_full112_scan.sh
```

其中：

```text
array 4: T2_cycles = 0.5
array 5: T2_fs = 5.337
```

在 3200 nm 下这两者应等价；保留两者是为了排查单位语义。

```text
1. full112 的 k 网格收敛要看 fig03、fig09、fig10。
2. 30x30 到 40x40 已经稳定；20x20/full112 尚未单独加入图中。
3. 当前规范、带窗、k 网格收敛测试仍是无退相干测试。
4. 若要复现旧求解器 deph_t2=0.5，不要写 T2_fs=0.5，应写 T2_cycles=0.5。
5. 新代码保留 T2_fs，因此文献中的 5 fs 可以直接写 T2_fs=5.0。
```
