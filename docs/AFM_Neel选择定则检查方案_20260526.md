# AFM Néel 选择定则检查方案（2026-05-26）

## 1. 要检查的物理关系

对两个相反反铁磁序参量的畴，记为 `N` 和 `-N`。理想对称性要求复数谐波电流振幅满足：

```text
J_n^a(-N) = (-1)^(n+1) J_n^a(N)
```

因此：

```text
奇次谐波 n=1,3,5,... : J_n^a(-N) =  J_n^a(N)
偶次谐波 n=2,4,6,... : J_n^a(-N) = -J_n^a(N)
```

这不是只看 `HHG.dat` 中的强度平方，而是要比较 Fourier 后的复数电流振幅。强度平方会丢掉相位和符号，不能直接验证上面的关系。

## 2. 建议使用的分解

从两条时间域电流轨迹构造：

```text
J_evenN(t) = [J(t;N) + J(t;-N)] / 2
J_oddN(t)  = [J(t;N) - J(t;-N)] / 2
```

然后分别 Fourier 到谐波频率：

```text
J_evenN(nω) = FT[J_evenN(t)]
J_oddN(nω)  = FT[J_oddN(t)]
```

理想情况下：

```text
奇次谐波：evenN 分量允许，oddN 分量应接近 0
偶次谐波：oddN 分量允许，evenN 分量应接近 0
```

换句话说，AFM 磁序诱导的偶次谐波应该主要出现在 `oddN` 通道；普通晶格背景的奇次谐波应该主要出现在 `evenN` 通道。

## 3. 这项检查需要什么数据

必须有两套物理上互为 `N` 和 `-N` 的 Wannier TB 数据：

```text
TB_N       : AFM Néel vector = N
TB_minus_N : AFM Néel vector = -N
```

注意：

```text
不能只改 input.nml 里的 SOC=1/0。
当前代码中的 SOC 参数主要是输入记录/维度语义，真正的磁序和 SOC 信息已经写在 wannier_tb_file 里。
如果只有一套 TB 文件，就还不能做这个 N/-N 选择定则检查。
```

两组计算必须保持完全相同：

```text
gauge_method
k 网格
nb_start / nb_end
T2_fs 或 T2_cycles
laser 参数
dt / ncyc / CEP / polarization
```

推荐第一轮使用：

```text
lg_cov / full112 / 40x40 / T2_cycles=0.5
```

若计算成本较高，可先用：

```text
lg_cov / nb1-104 / 40x40 / T2_cycles=0.5
```

但最终最好用 full112 做一次确认。

## 6. 如何判断是否通过

优先看 H1-H10，因为 CrI3 经典光谱在 H11 以后已经接近 cutoff/数值地板。

通过迹象：

```text
H1, H3, H5, ... 主要在 evenN 通道
H2, H4, H6, ... 主要在 oddN 通道
forbidden-channel leakage 明显小于 allowed-channel
```

如果泄漏很大，优先排查：

```text
1. 两套 TB 文件是否真的是 N 和 -N，而不是结构、轨道顺序或能量窗口也变了。
2. 两组输入是否完全相同，尤其是 CEP、偏振、T2、k 网格、带窗。
3. k 网格是否足够对称和足够密，先用 40x40。
4. 是否误用了截价带窗口；选择定则检查不建议用 nb10-104、nb20-104 或任何对称截断窗口。
5. 是否在强度平方的 HHG.dat 上直接做加减；正确做法是对 Jt.dat 的复数 Fourier 振幅做分解。
```

## 7. 当前结论

这项检查应作为经典光阶段的下一个高优先级 debug/物理验证项。它不替代已经完成的 k 网格、T2 和带窗收敛测试，而是补充验证：

```text
lg_cov 电流输出是否保留 AFM 选择定则；
偶次谐波是否确实来自 AFM 序参量奇通道；
后续 BSV 关联函数是否可以按 evenN/oddN 通道做物理分解。
```

但在 BSV 前只做平均电流的选择定则检查即可，不进入量子光关联函数。
