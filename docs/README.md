## 分析脚本速查（tools/analysis/）
- `construct_p_conjugate_tb.py` — 从 +N TB 构造严格 P 共轭 -N TB（4 道验证门）
- `compare_tb_eigenvalues.py` — 比较两套 TB 在高对称 k 点的本征值
- `map_wannier_inversion_pairs.py` — Wannier 中心反演配对检查
- `afm_neel_symmetry_check.py` — N/-N 复数谐波电流的选择定则分解
- `harmonic_intra_inter_decomp.py` — 谐波分辨的 intra/inter 通道分解
- `analyze_quantum_geometry.py` — 读 quantum_geometry.dat：Berry 曲率 PT 判据 + 量子度规（j_anom≈0 证据；须用 nb1-112）
- `read_occupation_snapshots.py` — 读 occupation_kt.dat：k 空间占据快照 + 导出 .npz 图
- `plot_hhg_spectrum.py` — HHG 谱诊断：峰宽=f(ncyc,T2)、整数谐波峰高表、对数谱图
- `spn_to_sz_wannier.py` — .spn(+u.mat/u_dis.mat) → Wannier 基 S_z 矩阵（严格自旋流的输入）
- `check_weakfield_scaling.py` — 弱场标度检查
