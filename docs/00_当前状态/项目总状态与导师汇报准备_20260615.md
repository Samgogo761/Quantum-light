## 4. 经典光验证结论

### 4.1 规范选择：速度规范截断不可作为生产路径

Peierls 速度规范在全带下可作为小网格参考，但带截断下会破坏速度规范中的背景电流抵消。对称带窗截断产生巨大的低阶伪信号，例如 H1 在 20/40/60 带时达到 10^1 到 10^2 量级，而 full112 仅约 0.08。

汇报图：

```text
docs/figures/classical_validation/fig01_peierls_vg_symmetric_truncation_failure.svg
```

导师汇报说法：

```text
速度规范截断不是“慢慢不收敛”，而是破坏 f-sum/background-current cancellation，低阶谐波直接失真。因此生产规范必须转向 lg_cov。
```

### 4.2 长度规范 lg_cov 是当前生产规范

`lg_cov` 方程：

```text
d rho/dt = -i[H0 + E·D, rho] + E·∇_k rho
```

协变导数使用平行输运有限差分，电流使用 `Pk_eq`。相比速度规范截断，它的误差表现为虚跃迁通道完备性误差，而不是背景电流灾难。

### 4.3 带窗：full112 是基准，nb1-104 是经济配置

双层 CrI3 的 112 带来自：

```text
4 Cr x 5 d + 12 I x 3 p = 56 orbitals
spinor/SOC x 2 = 112 bands
```

这不是随意的大窗口，而是双层 CrI3 d+p spinor 的自然母模型。

当前可用配置：

```text
基准:   lg_cov / 40x40 / nb_start=1 / nb_end=112
经济:   lg_cov / 40x40 / nb_start=1 / nb_end=104
```

`nb1-104` 保留全部 84 条价带，只截掉最高 8 条导带。它在 H1-H11 与 full112 基本一致，低阶和偶次信号误差在几 % 以内；H12 之后差异会增大，但那里已经接近当前经典谱的 cutoff/数值地板。若后续 BSV 重点研究 H12+，需要用 full112 或至少做高阶局部复查。

## 5. AFM Néel 选择定则闭环

选择定则：

```text
J_n(-N) = (-1)^(n+1) J_n(N)
```

该关系要求 +N 与 -N 的 TB 是严格空间反演 P 共轭对。独立做两套 SCF/Wannier 时，这一点并不会自动满足。

独立 -N 的失败诊断：

```text
SCF 总能差: 2.18 mRy ≈ 0.03 eV
Wannier Omega_I 差: 约 0.13 Ang^2
Gamma/K/M 本征值差: 50-110 meV
H2 leakage: 约 13，落在错误通道
```

解决方法：

```text
从 +N TB 后处理构造严格 P 共轭 -N TB：
原子置换 + 轨道宇称 + R -> -R + r -> -r
```

结果：

```text
H2 leakage: 13.1 -> 0.32
H1 leakage: 4.8e-5 -> 5.3e-8
H3 leakage: 5.9e-4 -> 8.9e-6
H4 leakage: 9.3e-2 -> 4.1e-2
H5 leakage: 3.3e-2 -> 2.0e-3
```

结论：

```text
H2 异常来自 DFT/Wannier 配对误差，不是 SBE 求解器错误，也不是选择定则理论错误。
```

## 8. 理论定位：R1/R2/R3

当前结果属于 R1：

```text
R1: 强度分布平均
BSV random phase -> exponential intensity distribution -> classical intensity average
可展示 BSV 平均谱和增强曲线，但不是严格量子优势。
```

下一层是 R2：

```text
R2: 输出光非经典性
计算二阶电流关联 C^{ab}(t,t')，用 QRT 或等效响应函数得到输出谐波模式协方差。
目标观测量包括 squeezing, g2, inter-harmonic entanglement, Neel-odd correlation C_oo。
```

长线是 R3：

```text
R3: 严格量子优势
证明某个输出观测量无法由任意经典强度/相位分布复现，涉及凸优化、moment problem、Gaussian QFI 等。
```

导师汇报建议：

```text
把 R1 作为当前阶段成果；
把 R2 作为下一阶段主攻；
把 R3 作为长期理论目标，不在当前汇报中承诺短期完成。
```

详见：


## 14. 仍需谨慎表述的点

```text
1. 当前 BSV 增强不是严格量子优势，而是强度分布平均。
2. nb1-104 对 H1-H11 很好，但不能无条件声称 H12+ 也定量可靠。

5. quantum geometry 的 per-band Berry curvature 有 Kramers 数值发散，解释时必须用 occupied manifold。
6. Liu 2022 EPL 等文献的具体参数和图号在写论文前需要逐条核对。
```
