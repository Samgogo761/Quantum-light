## 4. 已完成的物理与数值验证

### 4.1 速度规范问题

已确认：

```text
matrix_vg 只是 H(k+A) 的一阶近似 H0 + A·P，不适合作为强场生产规范。
Peierls VG 全带可作为小网格规范参考，但截断后会破坏 f-sum rule，产生价带背景虚电流。
对称带窗截断在 VG 中失效，不作为生产路径。
```

### 4.2 长度规范 `lg_cov`

已确认：

```text
运动方程：d rho/dt = -i[H0 + E·D, rho] + E·D_k rho
协变有限差分、RK4、电流计算、退相干处理逻辑通过多轮审查。
初始电流 |J(0)| 在 full112 和 nb1-104 中均为机器零。
```

### 4.3 带窗结论

错误或不推荐：

```text
对称窗口，例如 nb_start=70, nb_end=99
截价带窗口，例如 nb_start=30, nb_end=112
Peierls VG 截断
```

推荐：

```text
lg_cov / nb_start=1 / nb_end=104
```

物理原因：保留全部 84 条价带，截掉最高 8 条导带。这样不会破坏基态占据子空间，H1-H11 与 full112 基本一致。

### 4.4 k 网格

已完成：

```text
full112: 30x30 -> 40x40，H1-H15 基本 0%-2% 变化。
full112: 60x60 / T2=0.5 cycle 确认点已完成。
```

结论：`40x40` 足以作为当前经典光和 BSV pilot 的主网格。`60x60` 可作为论文补强，不是推进 BSV pilot 的必要门槛。

### 4.5 退相干

旧代码输入 `0.5` 不是 `0.5 fs`，而是约 `0.5 optical cycle`。新代码已支持 `T2_cycles`：

```text
T2_cycles = 0.5
lambda = 3200 nm
T2 effective ~= 5.337 fs
```

这是目前推荐的主配置。`T2_fs=0.5 fs` 太强，不能等同旧代码。

### 4.6 弱场 scaling

已完成：

```text
output_weakfield
output_weakfield_I2e10
```

结论：H1 的线性响应 scaling 干净；H2/H3 在原场强附近未完全进入微扰极限，但弱场方向上指数改善，符合非微扰 HHG 预期。此项支持代码正确性，但不是最终生产参数。

### 4.7 AFM Neel 选择定则

旧独立 `-N`：

```text
H2 主要落在错误的 evenN 通道，leakage ~= 13。
```

诊断发现：

```text
+N/-N 独立 SCF 总能差约 2.18 mRy = 0.0297 eV。
Wannier90 Omega_I 差约 0.1315 Ang^2。
Gamma/K/M 的 TB 本征值差约 50-110 meV。
```

因此旧独立 `-N` 不是严格 P 共轭。

严格 P 共轭 `-N`：

```text
H2 leakage: 13.1 -> 0.32
H1 leakage: 4.8e-5 -> 5.3e-8
H3 leakage: 5.9e-4 -> 8.9e-6
H4 leakage: 9.3e-2 -> 4.1e-2
H5 leakage: 3.3e-2 -> 2.0e-3
```

结论：H2 异常来自 DFT/Wannier 配对误差，不是 SBE 求解器错误，也不是选择定则理论错误。`lg_cov` + P 共轭 TB 的选择定则验证已经收口。

```text
1. BSV 输入强度语义是否清楚：bsv_mean_intensity 是否代表真实均值，还是采样分布参数。

3. BSV 使用的 E(t)/A(t) 与 classical 配置一致。

```

3. 比较 BSV 平均谱与经典光谱的相对比值。

## 7. 仍需思考的理论点

```text
1. BSV 论文叙事应强调“量子光相对于经典光的相对差异”，而不是只追求绝对谱。
2. 偶次谐波的 AFM 选择定则必须基于严格 P 共轭 TB；不能用独立 SCF/Wannier 的 -N 作为严谨证明。
3. 若展示 H2，需要诚实说明其绝对强度很弱，40x40 下残余 leakage 受数值地板限制。
4. Houston/旧 VG 可以作为历史对照，但不适合当前 SOC 双层 CrI3 的最终生产路径。
5. 少带 Wannier 不是当前首选；112-band d+p spinor 是双层 CrI3 的自然完备母模型。若未来 BSV 成本太高，再考虑少带有效模型，但必须重新验证。
6. HHG-XR demo 需要额外导出 rho(k,t) 或 population 快照，否则 k-space occupation 只能做概念示意。
```
