本地使用 MSYS2 / MinGW-w64 的 `gfortran` 编译：

```bash
export HOME="/c/Users/26507/Documents/New_SBEs/Quantum-light/.tmp"

export PATH=/mingw64/bin:/usr/bin:$PATH

```

生成的可执行文件为：

```text

```

编译时出现过一个与 BSV 分支相关的 gfortran 静态警告：


本轮所有计算均为经典光单轨迹，`bsv_enabled = .false.`，没有进入 BSV 分支。因此该警告不影响本轮经典光测试结论。但在进入 BSV 前应单独检查/清理这个警告。

## 3. 遇到的问题与解决方案

### 3.1 MSYS2 默认 HOME 无法创建

现象：

```text
/home/CodexSandboxOffline could not be created.
Setting HOME to /tmp.
mkdir: cannot create directory '/home/CodexSandboxOffline': Permission denied
```

原因：Codex 桌面会话中的默认 MSYS2 HOME 指向不可写位置。

解决：显式把 `HOME/TMPDIR/TMP/TEMP` 指向仓库内部 `.tmp`：

```bash
export HOME="/c/Users/26507/Documents/New_SBEs/Quantum-light/.tmp"
export TMPDIR="$HOME"
export TMP="$HOME"
export TEMP="$HOME"
```

### 3.2 `C:\tmp` 实际不可写

尝试将临时目录改为 `C:\tmp` 后，PowerShell 和 bash 都出现 permission denied。

结论：虽然沙盒声明中包含 `C:\tmp`，但当前桌面会话实际不能在那里创建普通文件。后续本地编译/运行统一使用仓库内部 `.tmp`。

### 3.3 PowerShell 脚本中的中文路径被转码损坏

现象：`tools/run_local_peierls_window_tests.ps1` 中硬编码中文路径后，PowerShell 5 读取 ASCII 脚本时路径变成乱码，例如：

```text
Cannot find local TB file: C:/Users/26507/Documents/閲忓瓙鍏夌爺...
```

原因：脚本保存为 ASCII，而 TB 文件路径包含中文字符。

解决：避免在运行输入文件中写中文路径。将 TB 文件复制到仓库内部 ASCII 路径：

```text
local_runs/CrI3_tb.dat
```

说明：曾尝试创建 hardlink，但 Windows 返回 `Access is denied`，因此本轮采用复制文件。该副本约 1.1 GB。

### 3.4 Windows 原生运行 `hhg_sbe.exe` 时缺 DLL

现象：

```text
exit code -1073741515
```

该错误通常表示 Windows native 可执行文件缺少运行时 DLL。

解决：运行前确保 MSYS2/MinGW DLL 路径在 PATH 中：

PowerShell 中：

```powershell
$env:PATH = "C:\msys64\mingw64\bin;C:\msys64\usr\bin;$env:PATH"
```

bash 中：

```bash
export PATH=/mingw64/bin:/usr/bin:$PATH
```

### 3.5 PowerShell 后台启动不稳定

尝试用 `Start-Process` 或 `.NET ProcessStartInfo` 后台启动测试时，遇到 `Path/PATH` 大小写重复、参数传递和进程环境继承问题。部分进程会立即退出而不留下有效输出。

结论：当前本地会话中，长时间本地测试推荐直接用前台命令逐个算例运行，而不是依赖 PowerShell 后台进程。

### 3.6 MSYS2 bash 后台进程会随父进程退出

尝试在 `bash -lc` 中使用 `nohup ... &` 或 `(sleep ...)&`，父 bash 退出后后台进程没有可靠保留。

结论：当前本地环境中不要依赖 bash 后台任务。逐个前台运行更可靠。

### 3.7 bash 中使用 `/c/Users/...` 绝对路径创建目录时偶发 permission denied

在脚本内对 `/c/Users/26507/...` 做 `mkdir -p` 时出现：

```text
mkdir: cannot create directory "/c/Users/26507": Permission denied
```

解决：脚本中尽量使用仓库相对路径，例如：

```bash
ROOT_REL="local_runs/peierls_window_20260517_nodeph"
mkdir -p "${ROOT_REL}"
```

运行前由外层命令 `cd` 到仓库根目录。

## 5. 推荐的本地运行策略

1. 本地适合做 `10x10`、`20x20` 的经典光小测试，特别是代码路径、规范差异、带窗趋势和退相干参数检查。
2. `20x20 / 40 bands` 在本机可运行，但耗时约 50 分钟量级；更大规模建议上服务器。
3. 不建议本地跑 BSV。
4. 不建议依赖 PowerShell 后台任务长期监控；本地长算例建议前台逐个跑。
5. 若后续新建脚本，避免中文路径进入输入文件；优先使用 ASCII 路径或相对路径。
