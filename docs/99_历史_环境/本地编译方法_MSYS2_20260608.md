## 1. 工具链位置（已确认存在）

```text
gfortran : C:\msys64\mingw64\bin\gfortran.exe   (GNU Fortran 15.2.0)
make     : C:\msys64\mingw64\bin\mingw32-make.exe
库       : C:\msys64\mingw64\lib\  下均存在：
           libblas.a  liblapack.a  libopenblas.a  libfftw3.a (+ _omp/_threads 变体)
```

Makefile 默认 `LDFLAGS = -llapack -lblas -lfftw3`，与上面的库匹配，无需改动。
（`libblas` 存在，所以不必换成 `-lopenblas`；若将来缺 `libblas`，改成 `-lopenblas` 即可。）

## 2. 编译步骤（在 MSYS2 bash 或 Git-bash 里）

```bash
# (1) 环境：把 HOME/临时目录指到仓库内部 .tmp，避免 MSYS2 默认 HOME 不可写
export HOME="/c/Users/26507/Documents/New_SBEs/Quantum-light/.tmp"
export TMPDIR="$HOME"; export TMP="$HOME"; export TEMP="$HOME"
mkdir -p "$HOME"

# (2) 把 MinGW-w64 工具链放到 PATH 最前
export PATH="/c/msys64/mingw64/bin:/c/msys64/usr/bin:$PATH"

# (3) 编译
cd "/c/Users/26507/Documents/New_SBEs/Quantum-light"
mingw32-make SHELL=/usr/bin/bash clean
mingw32-make SHELL=/usr/bin/bash
# 产物：hhg_sbe.exe（约 405 KB）
```

PowerShell 里若要先把 DLL 路径准备好再调用，可：
```powershell
$env:PATH = "C:\msys64\mingw64\bin;C:\msys64\usr\bin;$env:PATH"
```

## 3. 运行

```bash
export PATH="/c/msys64/mingw64/bin:/c/msys64/usr/bin:$PATH"
cd <某个输出目录>
/c/Users/26507/Documents/New_SBEs/Quantum-light/hhg_sbe.exe input.nml
```
运行时确保 `C:\msys64\mingw64\bin` 在 PATH 中（否则缺 `libgfortran`/`libfftw3` DLL）。
OpenMP 线程：`export OMP_NUM_THREADS=<物理核数>`。
