# 0. 本计划的唯一主线

当前研究重心是：

> **双层 HT-AFM CrI₃ 中，磁序如何改变 HHG 的复振幅、相位、选择定则与微观通道，并为后续量子光统计计算提供可信的低成本电子模型。**

本轮不进入量子光、QRT、协方差或 QFI。先选出一个能在较高 $k$ 密度下可信描述**磁性 HHG**的 parent Wannier 模型及其 SBE active band space。

---

# 1. 当前已确认的事实

## 1.1 参考与旧模型

| 模型 | 状态 | 结论 |
|---|---|---|
| full112 | 完整参考 | Cr-$d$ + I-$p$，所有后续模型的主参考 |
| nb1-104 | 已有大量 SBE 数据 | H1–H9 相对稳定；H11 后不能宣称收敛 |
| 对称 Bloch 窗口 | 已测试 | 当前 CrI₃/lg_cov 下失败，不作为生产 |
| 40-pilot / 40-opt1 | 已审计 | 数值可运行，但价带、子空间、hopping 和 HHG 均不合格 |

## 1.2 新 Wannier 模型

| 模型 | $N_{\rm WF}$ | 显式轨道 | 初步 $N_{\rm occ}$ | 当前静态结论 |
|---|---:|---|---:|---|
| M52 | 52 | 40 Cr-$d$ + 6 界面 I-$p_z$ spinor pairs | 24 | 层间机制候选 |
| M64 | 64 | 40 Cr-$d$ + 全部 I-$p_z$ | 36 | 磁性—成本主候选 |
| M88 | 88 | 40 Cr-$d$ + 全部 I-$(p_x,p_y)$ | 58 | 普通 HHG/面内光学候选 |

三者 Γ gap 均为 0.6672 eV。静态评分：

```text
M112 > M88 > M64 > M52 > M40
```

但现有评分的 optical、HHG、magnetic-HHG 权重均为 0，因此不能据此直接选最终模型。

# 3. Cr-$d$ 轨道取舍：先不创建新模型

## 3.1 当前默认

M52/M64/M88 均保留四个 Cr 上全部五个 $d$ 轨道及 spinor：

```text
t2g: dxy, dxz, dyz
eg: dz2, dx2-y2
```

现阶段不要删除 $e_g$。原因：

1. CrI₃ 的 FM 超交换包含重要的 $t_{2g}$–I-$p$–$e_g$ 通道；
2. $e_g$ 进入低能未占据导带，可能直接参与 HHG；
3. SOC 下不能未经验证按自旋或 Kramers 对减半。

## 3.2 需要增加的诊断代码

在 full112、M64、M88 的短 SBE 中输出：

```text
t2g population(t)
eg population(t)
t2g-eg coherence(t)
orbital-resolved J(t)
orbital-resolved Jq
```

只有证明 $e_g$ 在目标谐波和磁序奇通道中贡献可忽略，才允许设计 24-WF t2g-only 模型。

`t2g-only` 的定位必须是机制/负面对照，不得预先当成生产模型。

# 5. Phase S1：parent 模型短磁性 HHG

## S1.1 统一参数

```text
gauge       = lg_cov
lambda      = 3200 nm

polarization= x
ncyc        = 4
CEP         = 90 deg
T2_cycles   = 0.5

```

对每个模型运行：

```text

-N
```

参考：

```text
primary   = full112
secondary = nb1-104
```

不得只和 nb1-104 比较 H11 以上。

## S1.2 必须输出

```text
Jt.dat
Jt_decomposed.dat
complex_Jq.dat
HHG.dat
band_population_t.dat

```

`complex_Jq.dat` 至少包含：

```text

```

## S1.3 磁序通道

计算：

\[
J_e=\frac{J(+N)+J(-N)}2,\qquad

输出：

```text

```

```text

```

# 6. Phase S2：三 parent 模型的 Bloch 带截断诊断

任何截断都从各自 parent 的完整 Bloch 本征带开始，不直接删 Wannier 矩阵行列。

## S2.1 M52

初步 Nocc≈24：

| 标签 | active space |
|---|---|
| M52-full | 52 |
| M52-v24c6 | 24v + 6c = 30 |
| M52-v24c10 | 24v + 10c = 34 |
| M52-v20c10 | 20v + 10c = 30，近费米诊断 |

M52-v24c6 是当前唯一能够在 30 带内保留 parent 全部价带的候选。

## S2.2 M64

初步 Nocc≈36：

| 标签 | active space |
|---|---|
| M64-full | 64 |
| M64-v36c6 | 42 |
| M64-v36c12 | 48 |
| M64-v36c20 | 56 |
| M64-v24c6 | 30，strict-30 诊断 |
| M64-v20c10 | 30，strict-30 诊断 |

若全价带系列收敛而 strict-30 失败，结论应是：

> M64 是合格 parent，但不能通过裸 Bloch 截断直接压到 30；需要后续 24–30 带 composite/downfolded model。

## S2.3 M88

初步 Nocc≈58：

| 标签 | active space |
|---|---|
| M88-full | 88 |
| M88-v58c10 | 68 |
| M88-v58c20 | 78 |
| M88-v20c10 | 30，仅作截价带反例 |

M88 不以 strict-30 成功为预期目标，主要用于判断恢复面内 I-$p$ 后普通与磁性 HHG 如何变化。

## S2.4 比较指标

每个 active space 与 parent、full112 同时比较：

```text
time-domain relative L2
complex amplitude ratio
phase error
HHG intensity ratio
Je / Jo error
inter/intra mechanism
zero-field current
```

H11 后不能用“机器精度”解释数量级差异；必须结合绝对强度、deleted-band transition energy、population 和 coherence 判断。

# 8. 模型评分器升级

现有：

```text
L_E
L_sub
L_loc
L_hop
```

保留为静态预筛。

新增：

## 8.1 L_opt

```text
linear absorption
weighted JDOS
|r_vc(k)|
partial f-sum
polarization anisotropy
```

## 8.2 L_HHG

\[
L_{\rm HHG}
=
{\rm RMS}_{q\in Q}
\left|
\frac{J_q^{\rm red}-J_q^{\rm ref}}
{J_q^{\rm ref}+\epsilon}
\right|.
\]

## 8.3 L_magHHG

\[
L_{\rm magHHG}
=
{\rm RMS}_{q\in Q}
\left|
\frac{J_{o,q}^{\rm red}-J_{o,q}^{\rm ref}}
{J_{o,q}^{\rm ref}+\epsilon}
\right|
+
\lambda_\phi{\rm RMS}_q|\Delta\phi_{o,q}|.
\]

## 8.4 L_cost

记录实际：

```text
walltime
peak memory
N_b
N_k total
```

评分权重至少提供两套：

```yaml
profile: ordinary_hhg
profile: magnetic_hhg
```

`magnetic_hhg` 应提高 `L_magHHG` 权重，不能继续只按静态 M88 > M64 排序。

# 9. 模型决策规则

## 优先采用 M64 的条件

同时满足：

```text
1. M64-full 的 Jo_q 与 full112 接近；
2. 偶/奇选择定则保持；
3. 普通谱误差不造成机制翻转；
4. k80 成本可接受；
5. M64-v36c6/12 给出稳定 active space。
```

若成立，M64 作为量子光前的主 parent。

## 优先采用 M52 的条件

```text
M52-full 已能复现磁序通道；
M52-v24c6 仍稳定；
```

此时 M52-v24c6 是最符合“≤30 带 + 高 k 网格”的候选。

## M88 的使用条件

若 M88 普通谱显著优于 M64，但 Jo 较差：

```text
M88 = 普通 HHG / 光学参考
M64 = 磁性 HHG parent
```

不要仅因 M88 静态总分最低就把它作为量子光主模型。

## 三者都失败

转向：

```text
24–30 band magnetic-response composite model
effective-operator downfolding
或重新评估 CrI3 作为量子光生产材料的成本
```
