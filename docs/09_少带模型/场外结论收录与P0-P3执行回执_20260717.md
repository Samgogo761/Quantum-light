## 3. P1：`r` 反厄米诊断定义（关键）

源码 `mod_sbe.f90::diagnose_tb_quality`：

1. 用 `ndegen` 做 \(H(\mathbf R),r(\mathbf R)\to H(\mathbf k),r(\mathbf k)\)；  
2. 检查 **`r(k) - r†(k)`**（即 `D_full - conjg(transpose(D_full))`）。

因此属于场外 **情况 B**（正确的 k 空间厄米性检查），**不是**错误的 \(r(R)-r†(R)\)。

但另有限制：

\[
\boxed{
\text{SBE 的 }tb.dat\text{ 读取器 }不\text{ 使用 }seedname\_wsvec.dat\text{；仅用 }ndegen。
}
\]

见 `mod_wannier.f90::read_tb_file`。若 Wannier90 依赖 wsvec 修正插值，则当前诊断与动力学均可能系统偏差——M64 异常可能被放大。  
**尚未**做：按 WF 定位最大残差、`r_sym` 诊断短跑、与 `write_rmn` 对照（列入下一轮）。
