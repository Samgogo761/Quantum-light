## 1. 总体结论

当前经典光主线 `lg_cov` 的核心公式没有发现硬错误。代码实现的是：

```text
d rho/dt = -i[H0(k) + E(t).D(k), rho] + E(t).D_k rho
```

其中 `D_k rho` 通过相邻 k 点之间的本征矢重叠矩阵做平行输运有限差分，不是普通 `∂k rho`。这正好对应审查标准中要求的“dipole commutator + 协变导数”结构。

因此，已完成的经典光结论仍然成立：

```text
生产规范：lg_cov
经典基准：full112 / 40x40 / T2_cycles=0.5
经济候选：nb1-104 / 40x40 / T2_cycles=0.5
禁止路线：Peierls VG 截断、对称截断、截价带窗口
```

但严格按审查标准，仍有几类未闭合项：

```text
1. 还没有自动化的 tb.dat 矩阵质量审计。
2. 还没有 N/-N 两套 TB 的 AFM 选择定则数值检查。
3. 还没有弱场 E0, E0/2, E0/4 的 scaling 检查。
4. BSV 脚本和输出统计还没达到生产标准。
```

### 2.2 长度规范矩阵构造

`precompute_lg_matrices()` 中：

```text
H_full(k) = sum_R exp(ikR) H(R)
D_full(k) = sum_R exp(ikR) r(R)
dH_full/dk = sum_R i R exp(ikR) H(R)
P_full = dH_full - i[D_full,H_full]
```

然后投影到截断本征态子空间：

```text
Hk_eq = U† H_full U
Dk_eq = U† D_full U
Pk_eq = U† P_full U
```

这套构造与长度规范下电流算符的标准形式一致。

对应代码：

```text
src/mod_sbe.f90:105-200
```

### 2.3 协变导数

`lg_covariant_rhs_all()` 先计算：

```text
-i[H0 + E.D, rho]
```

再调用：

```text
add_lg_covariant_gradient()
```

后者用 `transport_density_to_k()` 把相邻 k 点的密度矩阵平行输运回当前 k 点，再做四阶中心差分。

这意味着 Hamiltonian gauge 中的额外项：

```text
i U† ∂k U
```

没有显式写在 `Dk_eq` 中，而是隐含在平行输运有限差分里。这一点是合理的。

对应代码：


### P2. 截断平行输运还不是严格幺正投影

`transport_density_to_k()` 使用：

```text
S = U_trunc(k0)† U_trunc(k1)
rho_dst = S rho_src S†
```

当 `n_trunc = 112` 时，`U_trunc` 是完整方阵，`S` 幺正，这没有问题。

当 `n_trunc < 112` 时，例如 `nb1-104`，`S` 不严格幺正。严格的做法是对 `S` 做 polar decomposition / SVD：

```text
S = U Σ V†
W = U V†
rho_dst = W rho_src W†
```

目前 `nb1-104` 的谱和 `|J(0)|` 表现很好，说明这个误差没有主导经典低阶结果；但按审查标准，它仍应作为诊断选项补上。

涉及位置：

```text
src/mod_sbe.f90:1095-1116
```

### P2. namelist 读取没有检查 iostat

这对服务器批量任务比较危险，建议增加 `read_required_namelist` / `read_optional_namelist` 风格的错误检查。

### P2. tb.dat 矩阵质量审计尚未自动化


这不是当前谱结果的直接 bug，但不满足审查标准的“基础矩阵质量”项。建议增加一个只读诊断模式，输出 max/rms 指标。

### P2. 弱场 scaling 尚未完成

这项应放在 BSV 之前，尤其用于确认偶次谐波确实是低阶非线性响应，而不是窗口、FFT 或数值误差。

### P3. HHG.dat 谱定义需要论文中写清楚

当前输出是：

```text
S(ω) = dt^2 |FFT[Hanning-windowed J(t)]|^2
HHG_total = HHG_x + HHG_y
```

不是：

```text
|ω J(ω)|^2
```

也不是：

```text
|ω^2 P(ω)|^2
```

这对相对比较和收敛测试没有问题，但写论文时必须明确；如果要对接辐射强度定义，需要额外输出 `ω^2` 加权版本或在后处理里统一转换。

涉及位置：

```text
src/mod_hhg.f90:30
src/mod_hhg.f90:52-53
```

### P3. 退相干保持 Hermiticity/trace，但还未监控 positivity

退相干在瞬时本征态基中把 off-diagonal 乘以 `deph_factor`，再变回原基，并 Hermitize。它应保持 trace 和 Hermiticity。

但目前没有输出：

```text
min eigenvalue of rho
max eigenvalue of rho
trace drift
```

近简并子空间中，瞬时本征基退相干也可能带来 basis artifact。建议作为诊断输出，而不是立即视为代码错误。

涉及位置：

```text
src/mod_sbe.f90:1123-1164
```

## 5. 建议下一步

不要马上进入 BSV 生产。按审查标准，建议顺序是：

```text
1. 先完成 AFM N/-N 选择定则检查。
2. 增加 tb.dat 基础矩阵审计脚本或诊断模式。
3. 增加弱场 scaling 扫描脚本：E0, E0/2, E0/4。
4. 给 lg_cov 的截断平行输运增加可选 polar/SVD 版本，用 nb1-104 对照当前实现。
5. 修正 BSV 脚本 WORKDIR，并给 BSV 输出样本方差/标准误。
6. 之后才做 BSV N=50-100 pilot。
```

当前经典光物理路线不需要推翻；但若按外部审查标准，要把上述诊断补齐后，再说“求解器已满足 CrI3-AFM 论文级审查”。
