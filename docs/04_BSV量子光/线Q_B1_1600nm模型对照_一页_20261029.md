## 判定

1. **H2 振幅不是缺通道问题。** 三个模型同量级，2×2 上 M52 没有把磁性 H2 丢掉 0.4–2.5 那种硬截断。
2. **相位和偏振才是模型差。** M52 相对 M88 相位差约 **158°**，Jy/Jx 从 2.43 降到 1.31。M88 与 full112 相位差 **12.6°**，偏振 1.31 vs 1.35，已经同族。
3. **H4 不能当 2×2 论文观测量。** M88 去边窗相位跳 −64°；full112 的 H4 偏振 (Jy/Jx=0.20) 与 M52/M88 完全不同。只保留 H2。
4. **后续材料抽检优先 M88，不再加密 M52。** M52 的 2×2→4×4 振幅降 6.6 倍仍待 M88 同协议 4×4 判断是不是 k 采样。两畴约 180° 是 AFM SHG 对称性，不是量子光效应。
