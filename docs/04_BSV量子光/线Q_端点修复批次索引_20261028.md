## 有效结论与旧记录关系

旧 Q1–Q6 传播和冻结预测全部保留。旧分析器的窗边界遗漏会将慢背景泄漏到 H2；它的振幅比、相位、磁畴反差及 B/A/C 数字应引用本批更新值，并保留有限采样和窗口限制。原先 Q6 是对旧估计量的传播前预测；本批对新估计量作追溯性四角训练/π4留出检验，不能倒改历史。

本批主估计器 `linear_exact`：准确窗端点，解析积分分段线性保存电流乘以 exp(+i q ω0 t)，再除完整实际窗宽。无电流去均值、无相位调整、无窗外外推。`endpoint_trapezoid` 与 `quadratic_exact` 是另列的敏感性；隔点抽稀评估数据重构敏感性。插值细分不等于新时间采样。

## 复算

程序均在 `tools/b0_small_model/`：

1. `test_qinput_spectrum_reanalysis_20261028.py`：六项解析测试，覆盖 DC、单/双频、线性/二次积分、缺窗拒绝、两畴干涉恒等式。
2. `qinput_spectrum_reanalysis_20261028.py`：约1.2秒；原始输出目录必须不存在，可用 `--out` 指定新的结果目录。不会启动求解器。
3. `qinput_reanalysis_report_20261028.py`：读取本批 JSON，生成数据表、协议数值、两张可复算 SVG。生成于独立批次目录，未覆盖旧研究归档。
4. `verify_qinput_reanalysis_20261028.py`：对44份原始时序，用每段12点 Gauss 积分独立比较振荡积分，复核所有原始输入哈希。

解释器使用本地捆绑 Python 3.12.14、NumPy；没有依赖生产传播程序。两张 SVG 用现有 Sharp 转为 PNG，并逐图检查过。未安装绘图库或后台服务。
