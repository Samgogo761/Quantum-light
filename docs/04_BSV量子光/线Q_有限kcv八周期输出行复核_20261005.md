## 2. 对象与不对象

同一有限参考：两点 \(k=(0,0),(0.23,0.12)\)，权重各 \(1/2\)，\(\pm N\)。直隙 \(2.156\)–\(7.625\)，没有采到完整 BZ 最小隙 \(\approx0.093\)。

输入列：8 个正频 \(\times\) 4 端口偏振 \(=32\) 光子列，加 20 个暗组合点列。频点 \(\{0.025,0.05,0.10,0.18,0.35,0.60,0.90,1.20\}\)。其中 \(\{0.025,0.10\}\) 仍是接线；\(\{0.05,0.18\}\) 扩带内诊断；尾频只估驱动混频，**不是** \(d\nu\) 真空积分。

驱动：冻结 `p1_a2_protocol(0.8)`，八周期 \(\sin^2\) 包络。零泵对照：同一协议 \(A^*=0\)，电子仍演化，不重置基态。脉冲后再走一周期，检验探测核时间尾。

输出行是探测核在同一组输入列上的在线收缩：

\[
\delta b_\mu=\int dt\,K_\mu^{\mathrm{det}}(t)\,I(t),\qquad
K(t)=i\sqrt{\gamma}\int_0^\infty d\omega\,\frac{\phi(\omega)}{\sqrt{\omega}}e^{+i\omega t}.
\]

\(\phi\) 是冻结 H2 包。偏振投影用既有 \(ê_\parallel,ê_\perp\)（相对 a2 / 镜面法向），两畴共用。增量是驱动行减零泵行，不是两份噪声矩阵相减。

这还不是

\[
n=V^*V^{\mathsf T},\qquad m=UV^{\mathsf T}.
\]

完整 \(U,V\) 需要正频输入测度。`assemble_ground_or_photon_moments` 仍是 `NotImplemented`。

## 4. 为什么这里必须停，不写 \(n,m\) 基准

任务单 C 的目标句子是“首次获得有限模型的 \(n,m\) 数值基准”。当前对象只闭合了：

1. 修正后的中点调用方跑完整八周期；
2. 探测核在线累加，不是五点梯形；
3. 暗列仍在，没有第二套明真空；
4. 驱动后 H2 窗外输入频对输出行的贡献有一个选列估计（\(\sim0.65\%\)）；
5. 脉冲后一周期的时间尾相对脉冲 \(\sim10^{-7}\)。

未闭合、因此不能收缩 \(n,m\) 的项：

1. 正频光子连续谱的 \(d\nu\)（加已保留点列）才是该有限模型的输入真空。8 个频点没有 \(\sqrt{d\nu}\) 权重，不能当 CCR 基底。
2. \(UU^\dagger-VV^\dagger=I\) 和 \(UV^T-VU^T=0\) 需要完整通道。禁止用输出重新归一化去“修”。
3. \(m\) 必须含 \(U_0 V^T\)。本轮只有探测核\(\times I\) 的选列行，没有完整 \(U_0\)。
4. 零泵浦下 \(\Delta U,V\) 应回到数值零：当前零泵行本身非零（静止输出），增量才是 \(\Delta\)。增量暗列已回到 \(\sim10^{-9}\) 量级，但这不是完整通道上的 \(\Delta U=V=0\)。

文献（Rivera-Dean PRB 109, 035203；Stammer PRL 132, 143603）支持固体 Bloch + 量子光输出、保留物质关联的动机；它们没有证明当前共同基态与输出行已经可以收缩 \(n,m\)。
