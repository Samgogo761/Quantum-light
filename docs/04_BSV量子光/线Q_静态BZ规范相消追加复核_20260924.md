# 线 Q：静态 BZ 规范相消追加复核（2026-09-24）

## 结论

本记录只更新一个门：

> **`P1=0`、均匀矢势、静态电子 BZ 求积的规范相消门，本轮通过有限静态资格。**

这不是联合电子—光子动力学资格，也不是连续谱、真空涨落、初态或材料物理结论。以下事项继续关闭：

- 接触项、Hamiltonian、P1、规范和初态的任何修改。

本轮没有修改模型，只扩展并执行了静态均匀 BZ 诊断脚本。


脚本保持冻结的 M0 Hamiltonian、权重、规范和物理参数不变，计算两条独立路径：

\[
M^{\rm Kubo}_{ab}
=\langle D_{ab}\rangle
-2\sum_{k,cv}w_k
\frac{\operatorname{Re}(X_{a,kcv}^*X_{b,kcv})}{E_{c,k}-E_{v,k}},
\]

以及占据能量对统一动量平移的有限差分曲率

\[
M^{\rm FD}_{ab}
=\frac{\partial^2 E_{\rm occ}(A)}{\partial A_a\partial A_b}\bigg|_{A=0}.
\]

两者使用同一个冻结 Hamiltonian，但导数路径独立；有限差分步长为 `1e-4`。

## 3. 对两点异常的边界判断

两点探针给出

\[
\operatorname{spec}(M_{2k})
\approx(-25.5931,\ 9.6385),
\]

而 `192²` 均匀网格给出

\[
\operatorname{spec}(M_{192^2})
\approx(-6.6532\times10^{-6},\ -2.8825\times10^{-9}).
\]

因此可以确认：两点模型的巨大负曲率不是完整静态 BZ 积分的代表性结果。它足以在两点联合模型中制造一个软方向，但不能据此宣布真实晶体的零驱动真空不稳定。

这条证据支持以下有限范围的解释：

> 两点联合模型的零驱动增长，至少受到电子静态 BZ 规范相消被粗略求积破坏的强烈影响；它不再是可以提交物理初态选择的人审证据。

这里不把“`M` 趋近零”进一步推导成“联合光子模型已经稳定”。光子低频涨落仍有独立的 `sum(w/omega)` 非收敛问题，且此前真实源有限截止与瞬时自场的比较也不能替代该低频资格。
