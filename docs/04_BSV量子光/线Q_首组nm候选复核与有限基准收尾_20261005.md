## 3. 两处必须修正的谱公式

### 3.1 电子 CCR 漏了产生系数项

electronic_measure_report（约 423–470 行）目前只累计 b b†，并以 b b†+Pdark−I 为 CCR。这不是当前含 bdag 的完整变换。

沿用程序约定：B、Dcol 分别是 ColumnState.b、ColumnState.bdag 对同一入射湮灭算符 c 的系数。电子算符为
\[
\hat b_{\rm el}=B c+D_{\rm col}^*c^\dagger+\text{点谱项}.
\]
于是需要检查
\[
\int_0^\infty (BB^\dagger-D_{\rm col}^*D_{\rm col}^{\mathsf T})\,d\nu+P_{\rm dark}=I,
\]
以及
\[
\int_0^\infty(BD_{\rm col}^\dagger-D_{\rm col}^*B^{\mathsf T})\,d\nu=0
\]
（当前纯湮灭暗点列对后一式为零）。

不要混淆这里的 Dcol 与冻结的接触项 D；接触项不改。

只读重算同一有限样本：
- 601 节点：漏项 maxabs 3.6845e-4、迹 0.00151386；正确正常 CCR 约 0.00384782，反常 CCR 1.9942e-5；
- 843 节点（已有 96-panel 加密）：正确正常 CCR 0.000694769，反常 CCR 8.27e-6。

遗漏并未导致当前有限结果立即失效，但原检查不能再叫完整电子 CCR。保留旧数，新增正确字段。

### 3.2 dressed 谱不能与 bare resolvent 当作恒等式比较

resolvent_from_measure（约 475–510 行）把已经包含电磁耦合的正频 b b† 谱除以 ν−z，拿去对比未耦合 diag[1/(Δ−z)]。二者在有限耦合下一般不相等。当前 0.003 并不证明所声称的 Stieltjes 恒等式。

复用已有 ContinuumGroundBridge，勿另建一套理论。推荐在实电子坐标上对比完整正负频谱：

\[
F(\nu)=\frac{1}{\sqrt2}
\begin{pmatrix}B+D_{\rm col}\\-i(B-D_{\rm col})\end{pmatrix},
\]
\[
R_{\rm spec}(z)=\int_0^\infty
\left[\frac{FF^\dagger}{\nu-z}+
\frac{F^*F^{\mathsf T}}{\nu+z}\right]d\nu
+\text{同约定的暗点谱正负频项}.
\]

独立解析目标从现有桥的块消元得到。令
Re = bridge.electron_action(z,I)，C = bridge.ci，
qa = photon_resolvent(z,gamma)，K = bridge.electronic_kernel(z)，则
\[
R_{\rm dressed}
=R_e+R_e C^{\mathsf T}(I+q_aK)^{-1}q_a C R_e .
\]

这保留同一个接触项、耦合、光子连续谱及原电子坐标。裸 Re 可以保留作对照，不能作有限耦合恒等式目标。

只读核对三个既有复频点：
- 64-panel 最大相对差约 0.00217；
- 96-panel 降到约 0.000609；
- dressed 与 bare 的差确实非零。

因此不需要本人重新决定模型，修正独立参照即可。不得通过令 gamma→0、删反旋项或松门槛来让旧目标成立。
