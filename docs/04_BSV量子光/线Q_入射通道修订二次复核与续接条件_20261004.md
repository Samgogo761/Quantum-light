# 线 Q：入射通道修订夹具二次复核与续接条件

日期：2026-10-04。只读审核修订源码、报告及 revision_checks.json；执行秒级内存反例，没有修改程序或运行新传播。新两份源码哈希匹配，旧 JSON SHA256 与 Cursor 报告一致。

## 验收结论

**遗漏/错列、重叠频带、谱权重重复计数、绝对/相对误差口径的修订可以保留。暗空间接口仍须修复，暂不能将当前 bundle 当成一般复顶点下的完整入射构造。**

不要推翻已验证的连续反馈传播器；问题在新加的初始列接口与连续谱分类。

### 1. 暗湮灭列的共轭约定错位

已冻结的电流：
\[
I=u^*b+u\,d-DA.
\]
若某个入射暗湮灭列为 b=v、d=A=0，必须满足
\[
u^*v=0.
\]

当前 dark_subspace 求 u†u 的核，得到 u v=0；stationary_dark_basis_columns 将这个 v 原样填入 b，并且也用 u v 检查。这与实际 current 不一致。可以直接求 ker(u*)，或在转换到 b 系数时正确取共轭，但所有投影和基底映射必须统一，不能只修一个测试符号。

独立反例：
\[
u=\begin{pmatrix}0.2&0.2i\\0.1&0.1i\end{pmatrix},\quad
\Delta=(1.1,1.1).
\]
现实现给出 max|uv|=0，但调用真实 current 后 max|I|=0.2828427。将所得基底适当共轭后的电流为零。

现测试中，暗组合传播及电子投影使用实顶点；复杂旋转只检验了自身定义的投影，没有把旋转后的暗列送入真实 current/RHS，因此漏检。

修复验收必须包括：

- 非平凡复顶点、同能隙，点列通过实际 current 和完整 RHS；
- 简并空间任意复幺正旋转，电子坐标、顶点和点列成套变换，物理电流与谱投影不变；
- 不同能隙下瞬时抵消不能冒充所有时间都暗；
- photon 电子投影与正确暗投影正交，而不只是“求核与自身相乘为零”；
- 暗列无驱动演化保持其自由运动。

当前两个 M0 诊断点恰好给出实际暗电流约 1.3e-15 / 2.0e-14，故本次不宣称其存量数据已出现大的错误；但这不能替代一般复基底的正确性。20 维读数也不能据此升格为连续 BZ 结论。

### 2. 零空间阈值作用在平方量上，可能把弱耦合当成零

当前用 Gram 本征值 <= 1e-12 * max(max|eval|,1) 判核。对顶点幅度来说，这可把约 1e-6 以下非零耦合判成暗，而非名字 svd_rel 暗示的奇异值相对精度。

内存反例：不同能隙 (1,2)，u=diag(1,1e-7)。程序报一个暗方向，其实际耦合仍为 1e-7；之后装配又因 leftover>1e-12 抛错。

应直接对实际耦合矩阵做秩判定，统一奇异值、绝对/相对尺度和残差口径。保留弱非零方向；证据不足时标记秩未定，不强制为零。近简并亦应保留为数值诊断，严格退化需由解析结构或受控舍入误差支持。

阈值实现属于工程，不需要用户选择；不能用更宽阈值来删除物理自由度。

### 3. 点谱元数据仍按旧坐标轴索引生成

assemble_incoming_bundle 已按暗组合生成 point.b，但 point_gaps 仍来自轴上近零列 axis。

现人工简并例子：n_point_columns=1，len(point_gaps)=0，标签却记录一个 gap=1.1。当前传播暂未读这个数组，故未暴露；以后频率权重会错位。

每个暗组合须有对应的能隙、不变子空间来源和原始标签映射；检查列数、标签数、能隙数一致。无需改物理。

### 4. 连续谱里的暗方向不能一律写成点谱

接入方案中“暗组合始终作为点列”应改写。

有限离散电子模型内，严格解耦的本征模可给出离散点谱。完整 BZ 中，若该暗方向的能量随 k 变化，它通常仍属于电子连续谱，保留在相应谱测度里；只有真正的原子谱权重/束缚模等才单独作为点谱。

同时，“自由电子列带 delta(omega-Delta_kcv)”只能作为广义谱的形式提示。实现不能把 delta 当普通数组列后平方。需说明采用哪种等价表示：

- 保留原始 k,c,v 积分，由能量 delta 定义谱测度；或
- 按能量壳分解，明确等能面简并标签、Jacobian 和归一化。

这两种只是数学表示选择，Cursor 可自行推导并验证，不必让用户选择。遇到临界点、平带或独立点谱须说明积分意义。原有暗自由度不可删，也不可追加重复真空。
