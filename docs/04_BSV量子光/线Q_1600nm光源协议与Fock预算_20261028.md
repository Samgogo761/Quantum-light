# 一个现实波长工作点与最少 Fock 对照预算

2026-10-28；协议草案与只读成本估计，不是获批的新传播任务。

## 1. 工作点的用途和文献依据

目标是在现实波长/脉宽下，检查压缩相位能否控制磁序敏感的复电流及固定分析器的相干源干涉。先研究同一 h8 M0 的机制；不将其称为真实 CrI3 定量预测。

[Rasputnyi 等，Nature Physics 20, 1960–1965 (2024)](https://www.nature.com/articles/s41567-024-02659-x) 实验用 1600 nm BSV、25 fs FWHM、30 μm 的 1/e² 光斑直径，在 LN/a-Si 研究 HHG，部分比较采用约 2 TW/cm² 的平均强度。本文只取波长、脉宽和光斑作参考。拟定 **0.1 TW/cm²** 作为更低的第一计算点，是研究设计选择，不是该论文给出的磁性样品参数或安全阈值。

明亮位移压缩光的锁相、损耗与噪声参数需要实际光源确认；不能把论文中的纯 BSV 实验说成已实现本协议全部 DS 条件。

## 2. 唯一主要工作点

| 项目 | 草案 |
|---|---|
| 真空中心波长 / 光子能量 | 1600 nm / 0.774901 eV |
| 周期 / H2 | 5.3370 fs / 1.54980 eV（800 nm） |
| 时间形状 | 无平台 Gaussian；强度 FWHM 25 fs（约 4.68 周期）；固定 CEP |
| 空间形状 | Gaussian，强度 1/e² 半径 w0=15 μm，样品处定义 |
| 统计平均的周期平均峰值强度 | 0.1 TW/cm² = 10¹¹ W/cm² |
| 偏振 | 现有 a2 线偏振；同时记录 Cartesian x/y，保留统一时间与相位参考 |
| 主态 | 单个理想有效脉冲模式的 DS；相干能量份额 80%，压缩真空份额 20% |
| 首个压缩角对照 | θ=0/π，固定位移与能量；若信号可靠，再选协方差符号对照 |
| 必要光态对照 | 同平均能量、同脉宽的 coherent 与 α=0 纯 BSV |
| 首个计算近似 | 规定外场的共享 Wigner 样本 + 小矩阵电子动力学；不宣称精确 QED |

总能量按照 `Aeff=π w0²/2`、`τeff=τFWHM sqrt(π)/(2 sqrt(ln2))` 定义：

\[
 U=I_0 A_{\rm eff}\tau_{\rm eff}=9.40534\ {\rm nJ},\qquad
 \bar n=U/(\hbar\omega_0)=7.57561\times10^{10}.
\]

理想 DS 数值为 `α=246180.657`（实数），`r=12.41382`；纯 BSV 同能量对照为 `r=13.21854`，相干对照 `α=275238.341`。θ 扫描中这些数固定。这里的巨大每脉冲光子数来自所定义的宏观模式；并非把旧 g=.005 与 α 一起原样放大。

**这不是将 r=.3 的旧态只增大 α。** 那会使有限压缩涨落相对宏观平均场变得极小，不能保持当前研究的统计调控条件。选取 20% 压缩能量份额，是一个明确、待实验评估的统计目标；实际损耗/多模会改变协方差与可见度。该理想态不能冒称已有实测光源。

## 3. 模式和场的归一化

先按正频脉冲模式给定 E，A 由 `E=−∂t A` 得到，而不是把旧 s(t) 耦合开关直接叫作激光包络。窄带、真空平面波/近轴参考下，可取

\[
 E^{(+)}(t)=\sqrt{\frac{\hbar\omega_0}{2\epsilon_0c A_{\rm eff}}}
 u_E(t)a,\qquad \int dt\,|u_E(t)|^2=1.
\]

`uE` 的包络为 Gaussian、载波 exp(−iω0t)，CEP 与相干参考锁定；实际实现采用正频谱和谱能量归一化，并检查得到的 FWHM 与能量。上述公式是窄带表达；若需要精确有限带宽，必须保留频率依赖单光子权重和谱归一化，不能自行省略。

Peierls 位移按 `q=e A_SI/ħ` 转成 Å⁻¹。该工作点的同能量经典参考 E峰≈`8.6802×10⁸ V/m`，q峰≈`0.1120 Å⁻¹`；DS 平均场 E峰约 `7.7638×10⁸ V/m`，量子涨落另计。它们是自由空间模式参考值，未包含界面透射、介电局域场、样品吸收或自洽 Maxwell 传播。

纯 BSV 虽 <E>=0，仍有上述非零正常序能流。强度应按统计平均与周期平均说明，不能用 <E>² 给 BSV 定强度，也不能把每次统计样本的瞬时峰值误当同一个 I0。

高增益压缩协方差需用 `exp(±2r)` 的主轴旋转构造，避免 `cosh(2r)−sinh(2r)` 的浮点抵消。旧 GH5 五点在大涨落非线性工作点未获认证；后续批准后仅对一个点检查统计求积，不能自动继承旧 GH5 精度。

## 4. 磁性观测量和纯 BSV 对照的意义

统一保存 Jx/Jy 的完整复源投影、Je/Jo、45°/135°分析器强度代理、畴差及相对相位。短脉冲使用固定物理窗与固定频带；谱线宽度和密集采样步长分别报告。

对满足电子反演配对、同端口定义的当前模型，联合映射 `(N,α,ξ)→(−N,−α,ξ)` 成立。纯 BSV 光子宇称不变，因而 `<J>−N=−<J>+N`；固定分析器的**相干源**两畴强度相等。这不等于没有 H2，亦不推出完整光子产额/涨落为零。

位移主态保留相干相位参考，纯 BSV 对照优先读复振幅/外差，或研究将来的电子源关联。若用共同外部本振，强度畴差含 `4 Re[(ELO+Ee)* Eo]`；其强弱依赖相位和实际出射标定，不能由现有模型电流直接承诺实验信噪比。

已有 1600 nm 实验不能认证磁性样品和本模型的可测性。当前只确认值得研究的读出结构；实际光子计数还缺片电流单位、面积、辐射/收集几何及探测噪声。相关理论：[Liu 等，PRR 8, 023326 (2026)](https://doi.org/10.1103/y3gr-tsns) 强调量子光驱动辐射中的两时涨落，支持后续 CJJ，但本轮不运行输出统计。

## 5. 现实计算方法与全 BZ

宏观光态不作 nmax≈10 的 Fock 展开。第一计算采用按物理场归一化的 Wigner 样本，每个样本驱动所有 k，先对 BZ 复电流加权求和，再做所需统计与频率分析。若以后加入 MTEF 反馈，同一样本的全部 k 必须共同驱动同一个光场；BZ 加密不是增加物理电子数。

此协议可用现有 8×8 Hamiltonian 实现，避免显式 `36^Nk` 张量积。禁止把独立 k 对各自有反馈的 QED 结果直接相加。当前 QED 的成功不保证新高增益/新波长近似有效；本卡只是规定一个可算、可检验的起点。本轮没有做 BZ 传播或预报新信号大小。

## 6. 原工作点 nmax=8→10 的最小批次预算

这是先于新波长传播的一次必要观测量检查：θ=0/π，±N，共四路；其他参数、PDPS 制备规则、dt 与旧协议相同，终点准确 4T0。nmax=8 已有，不重复长跑。

| 项目 | 依据与预计 |
|---|---|
| 两点电子空间 | 36×36；单光模从 9 个数态增至 11 个 |
| 联合维数 | 11664→14256；一根 complex128 向量约 0.178→0.218 MiB，临时缓存另计 |
| 到 4T 的步数 | 7436（同旧 dt=0.0675974751） |
| 旧 θ=0 的两路并行实测 | 各约 0.161 s/step；4T 约 20 min/路 |
| 旧 θ=π 的两路并行实测 | 各约 0.0984 s/step；4T 约 12.2 min/路 |
| nmax=10 成本推估 | 每路约 15–40 min，依旧负载、张量收缩及采样频度而变 |
| 四路分两批、每批 ±N | 合计约 40–65 min；建议总预算上限 90 min，含短成本预检和保存余量 |

上述是旧实测外推，**没有测量 nmax=10 的吞吐**。只有后续获批才运行。先以原归档参数和进程安排做短预检，预算不够则留下 checkpoint 和明确未完成状态，不自行扩充墙时。

新批次应准确保存 `[1,2,3,4]T0`，电流保存间隔建议从 32 步减至 8 步，另生成“只保留每32步”的同一新传播时序。这能评估 nmax=10 结果自身的保存采样误差，并在相同稀疏采样下与旧 nmax=8 比较。不能因此宣称独立消除了旧 nmax=8 的全部采样误差。检查初态实际资源、顶部数态概率、范数、H2 复差及相位，不仅看输入尾概率。
