短窗口里的对易残差变大，不能单独证明 H2 收集程序写错。这一轮把同一条两点轨迹上的 \(UU^\dagger\)、\(VV^\dagger\)、时间分段和收集求积分开。\(\gamma,\eta,D\)、波包和初值列都没有改。

上一轮那个 \(0.008988\) 还有一个诊断脚本的时钟问题：自由场相位从 0 起算，收集核和顶点却放在脉冲中点。生产传播用的是同一个 \(t_0\)。下面的数都改成了这一个时钟。

## 1. 左右端口的 \((0,0)\) 元可以相加

脉冲中点附近一个光学周期、每周期 128 步。以前写的 0.6687、0.4555 和 \(4.3\times10^{-5}\) 是各块 \(2\times2\) 矩阵的最大模，不是 \((0,0)\) 元，所以三个正数加起来对不上 \(1.008988\)。

同一矩阵元上，\(UU^\dagger-VV^\dagger\) 的 \((0,0)\) 实部是：

| 通道 | \(UU^\dagger\) | \(VV^\dagger\) | \(UU^\dagger-VV^\dagger\) |
|---|---:|---:|---:|
| 左端口 | 0.569728 | 0.007918 | 0.561810 |
| 右端口 | 0.448760 | 0.007918 | 0.440842 |
| 暗列 | \(9.71\times10^{-6}\) | \(5.25\times10^{-5}\) | \(-4.28\times10^{-5}\) |
| 相加 | 1.018498 | 0.015889 | 1.002609 |

再减去单位阵的 1，得到 \(0.00260915\)。这就是这一窗的正常残差 \((0,0)\) 元，也是它的最大模。三路贡献是相加，不是三个正数互相抵消。\(VV^\dagger\) 只有 0.016，没有把 1.12 消成 1.003。

电子 even 测度是另一件事。它在电子通道上算 \(bb^\dagger-dd^\dagger+P_{\mathrm{dark}}-I\)，用的是单侧 \(\sqrt{2}\) 频率测度。它不进入这张 \(2\times2\) 的 H2 行。

每周期 128 步，从 \(t=0\) 积到脉冲结束后两个周期。各段来自同一次传播，加起来就是整段 \(\Delta U,\Delta V\)。

| 段 | \(\|\Delta U\|_{\max}\) |
|---|---:|
| 前两个周期 | 0.001552 |
| 中间四个周期 | 0.052574 |
| 脉冲末两个周期 | 0.002018 |
| 第一周尾 | \(1.69\times10^{-6}\) |
| 第二周尾 | \(4.57\times10^{-7}\) |

| 积分范围 | \(\|R_N\|_{\max}\) | \(\|R_A\|_{\max}\) |

单独一段不要求成为正则出射算符。尾部几乎不改变整段残差。

## 3. 收集求积和驱动幅度

同一组端点和中点状态上，把中点矩形换成每步 Simpson。整段 \(\Delta U\) 的差是 \(2.19\times10^{-5}\)，正常残差从 0.008038 变到 0.008076。收集权重不是这 0.008 的来源。

\(A^\star=0\) 时，驱动减无泵的 \(\Delta U,\Delta V\) 是 0。同一中点周期上，\(A^\star=0.2\) 的正常 \((0,0)\) 元是 \(-0.001789\)，仍贴着波包缺口 \(-0.001889\)；\(A^\star=0.8\) 是 \(+0.002609\)。

静态行仍然是 \(U_0U_0^\dagger=(0.99811063)I\)。生产式是 \(U=U_0+\Delta U\)，\(\Delta U\) 只含驱动减无泵。这个减法是对的。整段积分之后，这套两点、每周期 128 步、526 个频率的正常残差停在 0.008038。它不是尾部截断，也不是中点收集换成 Simpson。\(\Gamma 12\) 的 0.007439 仍是另一套网格和步长，没有在这里被定位成同一个数。G1 未通过，不进入 G2/G3。
