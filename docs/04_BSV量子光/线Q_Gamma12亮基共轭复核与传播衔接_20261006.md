## 2. 确定错误与最小修正

文件：`tools/b0_small_model/q8_m0_p1_h2_finite_kcv_gamma12_ccr_fix_20261006.py`。

`bright_ccr` 第 218 行目前为：

```python
buf_d.append(B.conj().T @ (s * bd))
```

应改为：

```python
buf_d.append(B.T @ (s * bd))
```

第 217 行对 b 使用 `B.conj().T` 是正确的；第 205–207、222–223 行的收缩不需要一起反改。

这里 b、bd 分别是电子湮灭算符与产生算符对同一入射湮灭列的系数，不是彼此可以直接共轭替代的两份数据。若定义亮坐标

\[
\hat c_B=B^\dagger\hat c,
\]

则产生坐标必须是

\[
\hat c_B^\dagger=B^{\mathsf T}\hat c^\dagger.
\]

所以两种列分别变换为 `B† b` 与 `Bᵀ bd`。对二者都用 B† 会制造虚假的反常残差，不能因为低于 0.05 就将其接受为数值误差。

旧亮投影 `trace_dd≈0.0238083` 也受影响；正确值约 0.0567859，与原坐标廉价积分一致。应比较

\[
\mathrm{tr}(bb^\dagger)-\mathrm{tr}(bd^*bd^{\mathsf T})\to328,
\]

而不是把 `trace_bb→328` 单独当作理论目标。328 是当前有限网格的亮秩，非实际样品的通道数定理。trace refine 很小也不能代替各矩阵残差。

### 独立代数核对

- 三模精确 canonical Bogoliubov 夹具：正确投影正常/反常误差不超过 9e-16；错误共轭给出伪误差约 0.0527 / 0.0945。
- Γ12 任意复酉亮基旋转 B→BR：列变换误差不超过 3.4e-16；正常矩阵按 R†NR、反常矩阵按 R†AR* 协变，残差约 1.22e-15 / 2.96e-17。
- 不要求各基底的逐元素 maxabs 数字不变；要求矩阵按正确规则协变。既有 0.05 试算门继续使用固定参考亮基。

### 可复现的廉价静态算法

同能隙簇内亮列满足 ΔB≈BΔ_B。预计算

\[
U_B=B^\dagger u^{\mathsf T},\qquad D_B=B^{\mathsf T}u^\dagger,
\]

再在每个频率使用原 `even_bd` 对应的偶通道场 A：

\[
b_B=U_BA/(\Delta_B-\omega),\qquad bd_B=D_BA/(\Delta_B+\omega).
\]

与原 2304 维逐列投影的三频对照不超过 8.5e-14，能隙交换残差约 4.9e-15。只读复算约数秒。这是静态等价计算，不是强驱动降秩，也不是 GPU 加速。P1 仍须保留全部 2304 个电子坐标，包括 1976 个静态暗方向。
