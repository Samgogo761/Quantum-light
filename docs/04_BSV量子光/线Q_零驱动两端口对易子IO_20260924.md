# 线 Q：P1=0 两端口对易子 I/O（2026-09-24）

## 本轮结论与执行范围

正实性可以按增量账整个 UHP 结案。外层建议开 canonical I/O，范围收成对易子、不算协方差。本轮接受这一门，**拒绝**照抄外层的 \(I=F^{-1}(\xi-K\kappa_{\rm in})\) 预因子、\(T=0\) 和未定系数的 \(SS^\dagger+C_{\rm el}=I\)。

**已完成：冻结 \(A\) 端口的偶/奇分解、隙下酉性、隙上带电子跳跃的对易子恒等式。** 没有 \(n,m,V\)、收集波包、初态、Pauli、P1。

## 1. 从冻结端口推，不抄外层

`q8_m0_gsheet.py`：

\[
A_{R,{\rm out}}=A_{L,{\rm in}}+A_{\rm self},\qquad
A_{L,{\rm out}}=A_{R,{\rm in}}+A_{\rm self},\qquad
A_{\rm self}=\frac{i\gamma}{z}I.
\]

电子 \(I=\xi-K A_{\rm loc}\)，\(A_{\rm loc}=A_{L,{\rm in}}+A_{R,{\rm in}}+A_{\rm self}\)。与已冻结 \(F=I_2+(i\gamma/z)K\) 一致：

\[
I=F^{-1}\bigl(\xi-K(A_{L,{\rm in}}+A_{R,{\rm in}})\bigr).
\]

偶/奇（每个面内极化仍是 \(2\times2\)）

\[
A_\pm=\frac{A_L\pm A_R}{\sqrt2}.
\]

奇通道不进薄片：\(A_{-,{\rm out}}=-A_{-,{\rm in}}\)。偶通道

\[
S=2F^{-1}-I_2,\qquad
G=\sqrt2\,\frac{i\gamma}{z}F^{-1},\qquad
A_{+,{\rm out}}=S A_{+,{\rm in}}+G\xi.
\]

\(\xi\) 的跳跃由已审核恒等式给出：\(C_I=i(K^R-K^A)=S^>-S^<\)。标量 Cayley 加上 \(A\) 的谱权重 \(\omega/\gamma\)（因为 \(E\sim\omega A\)、\(\gamma\) 来自 \(E_{\rm self}=-\gamma I\)）得到

\[
\boxed{SS^\dagger+\frac{\omega}{\gamma}G\,C_I\,G^\dagger=I_2\qquad(\omega>0).}
\]

这是本轮的验收式。外层的 \(SS^\dagger+C_{\rm el}=I\) 只是结构提示。P1=0 的 \(K\) 把 \(A\) 和 \(A^*\) 混在一起，不能先验 \(T=0\)；本轮直接在 \(A_\pm\) 上验对易子，不引入光子 \(a(\omega)\) 的新归一。

隙下未展宽 \(C_I=0\)、\(K\) 厄米，上式退化为 \(S^\dagger S=I_2\)。隙上 \(S^\dagger S\neq I\)，缺的重量必须由同一条 \(C_I\) 补回，不能另加浴。

## 2. 外层哪些对、哪些过档

接受：先对易子后协方差；两端口；奇通道解耦；隙下光子子空间应酉；隙上电子通道必须补回 canonical 重量；不算 \(n,m,V\)。

修正：

- 正实性结案只对**增量账、线性推迟动力学**。raw \(M_N\) 假根仍在。
- \(T=0\) 不是本约定的先验。\(A\) 语言里 \(S\) 已经是 \(2\times2\) 实线性映射。
- 验收式必须带 \(\omega/\gamma\)。没有这个因子，隙上恒等式不会到机器精度。
- 本轮核的是 \(A\) 端口对易子，不是远场 \(a_{\rm out}(\omega)\) 的 SI 归一光子。收集波包仍 BLOCKED。
