## 2. 有限联合模型保持正则

取 Γ12 里顶点范数最大的 \(k=72\)，16 条电子通道用库存的含权重顶点，接触项和 \(\gamma\) 用库存值，再加两个偏振振子。传播 8 步。

驱动情形：生成矩阵的 \(\|JK+K^T J\|=5.20\times10^{-18}\)，\(\Phi^T J\Phi-J=3.23\times10^{-18}\)。完整 Nambu 正常残差 \(5.55\times10^{-16}\)，反常残差 \(1.63\times10^{-18}\)。无驱动的 \(\Phi^T J\Phi-J=7.39\times10^{-18}\)。

这一层没有破坏玻色正则关系。电子坐标与有限振子公式的接线误差是 \(2.78\times10^{-17}\)。

实偏振、冻结波形下的 \(\dot A\) 比较不作数：\(\operatorname{Re}F\) 与 \(\operatorname{Im}F\) 平行时，有限振子对 \(\dot A\) 的贡献恒为零，而生产方程里的 \(\gamma I\) 不是零。这是恒等式，不是测到的残差。

## 3. 生产用的 \((q,p,A)\) 没有非退化正则形式

生产中点方程写成实变量 \((q,p,A)\) 后，实截面是闭合的：\(b^\dagger=\overline{b}\)，\(A\) 保持实数。它和自己的线性生成矩阵一致到二阶。\(h=10^{-3}\) 时，\((M-I)/h-K-(h/2)K^2\) 的最大元是 \(6.56\times10^{-10}\)。\(h=10^{-6}\) 时 \((M-I)/h-K\) 约为 \(2.3\times10^{-8}\)，这是 \((h/2)K^2\)，不是步进写错。

在这个 34 维实空间里，反对称矩阵有 561 个自由度。条件 \(JK+K^TJ=0\) 的数值核是 438 维。核里随机组合出来的 \(J\) 都是奇异的，最小奇异值与最大奇异值之比约 \(1.5\times10^{-16}\)。一步生产映射的核同样是 438 维，最好的比约 \(1.7\times10^{-16}\)。没有找到可逆的守恒 \(J\)。

把 \(q\) 配 \(p\)、\(A_0\) 配 \(A_1\) 的标准辛形式，残差在这个 \(k\) 上是 0.818，在全部 2304 条通道上是 0.908。

两个 \(k\) 拼在一起时，生成矩阵的约束比同样落到数值零附近，结论与单 \(k\) 相同：这不是某一个 \(k\) 的偶然。

## 4. 现在能分开的两层

物理问题：从应保持玻色正则关系的二次型出发，哪一层先失去可逆的正则形式？

证据：含两个显式振子的有限联合模型，用的是库存顶点和接触项，\(\Phi^T J\Phi=J\) 到 \(10^{-18}\)。生产传播实际积分的是 \((q,p,A)\)。这一层没有可逆守恒 \(J\)，标准配对残差是 \(O(1)\)，而且步进与生成矩阵一致。含 \(0.07\)–\(0.13\) 的那块核心加密到 640 点后，输出残差仍是 \(\|R_N\|_{\max}=0.0074392606\)，\(\|R_A\|_{\max}=0.0022315789\)。

备选解释：

1. \((q,p,A)\) 是约化后的变量，本来就不是完整的 Nambu 向量 \((c,c^\dagger)\)。正则性留在含光子振子的那一层，有限模型已经保持。输出上的 \(0.007\) 仍要在约化之后的输入装配或 \(H_2\) 投影里找。
2. Γ12 的输出正则关系应当由这套 \((q,p,A)\) 步进传下来。这套步进没有非退化的守恒辛形式，标准配对已经是 \(O(1)\)。这比频段加密更早。
