## 必须先记住的四个结论

\[
\boxed{
\text{Husimi-}Q\text{ 平均谱}
\neq
\text{完整输出量子态}.
}
\]

\[
\boxed{
\langle\hat J(t)\rangle
\text{ 决定平均场，}
\qquad
\langle\Delta\hat J(t)\Delta\hat J(t')\rangle
\text{ 决定二阶场噪声}.
}
\]

\[
\boxed{
\text{精确 }g^{(2)}
\text{ 一般需要四时刻电流关联；}
\quad
\text{两时关联只在 Gaussian/闭合近似下足够}.
}
\]

\[
\boxed{
C_{oo}\text{ 对磁畴反转为偶；}
\qquad
\text{磁畴奇二时关联来自 }C_{eo}+C_{oe}.
}
\]

## 第一部分的校订说明

后续代码实现应以下列更严格表述为准：

1. 一般探测谱使用
   \[
   S_n=\sum_{ab}J_{n,a}^*\mathcal C_{ab}^{(n)}J_{n,b},
   \]
   不能默认没有不同偏振分量的交叉项。

2. Husimi-\(Q\) 样本对应反正常序：
   \[
   \mathbb E_Q|\alpha|^2=\langle\hat n\rangle+1.
   \]
   不能把 \(Q\) 样本强度直接当成正常序物理光子数。

3. 压缩真空的相空间椭圆转角是压缩相位 \(\theta_s/2\)。

4. 第一部分式 (3.18) 只能称为
   `classical_coherent_mixture_benchmark`，不能称为一般量子输出态。
