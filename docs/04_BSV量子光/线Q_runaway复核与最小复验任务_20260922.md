## 2. 已核对的实现边界

线性与非线性使用同一 P1、+N、初态、小 k 集及权重、种子和 gamma。非线性使用

\[
H[k+\kappa_{\rm P1}+\kappa_{\rm seed}+\kappa_{\rm self}],
\qquad
\dot\kappa_{\rm self}=\gamma(I-I_{\rm P1}).
\]

它检验的是非线性电子传播与经典自场反馈，不是完整量子光—电子联合传播。

## 3. 必须先修正的三个地方

### 3.1 自场幅度与 P1 比较混了单位

程序里 A_self 直接加入 kappa，其单位为 Å^-1。P1 的 A*=0.8 是无量纲量。

存量 probe6 轨迹：

- P1 的动量位移峰值约 0.19798 Å^-1。
- 自场峰值模约 0.52567 Å^-1（最大 Cartesian 分量约 0.48345 Å^-1，二者勿混）。
- 自场峰值模约为 P1 峰值的 2.66 倍；换成 A* 约 2.12。

因此扰动确实不小，但图中的 0.8 水平线不能与原始 A_self 曲线直接比较。应统一为 Å^-1，或全部乘 a_NN 后用 A*。

### 3.2 能量分账目前没有在离散层面闭合

当前实现：

\[
A_{{\rm self},n}=\gamma\Delta t\sum_{m<n}I_m .
\]

对 A 做后向差分得到的自场是 -gamma I_{n-1}；单独计算 W_self 时却用了 -gamma I_n。因此 W_el 与 W_in+W_self 并非同一个时间离散。

由原 JSON 直接重构，probe6 物理 gamma 早窗：

\[
W_{\rm el}-W_{\rm in}-W_{\rm self}
=1.70645\times10^{-4}.
\]

这约为 |W_self| 的 2.96%，却是所报告 W_in 的约 39.7 倍。gamma scale=0.03 时残差约 1.21e-9，约为 |W_self| 的 0.13%。

现有 W_self+gamma*积分I²=0 测试只是用相同表达式抵消，不能证明总功账闭合。

下轮必须统一同一时间单元上的场和电流，保留实际离散余项。例如区间前向差分配同区间左端电流可用于原方法账目；若改用中点方法，应对完整反馈同步更改并检查时间收敛。不能只强制令 W_el=W_in+W_self 后就宣布能量守恒。

### 3.3 强反馈还没有时间步与零种子验证

非线性传播虽然在中点取外场 Hamiltonian，自场仍使用上一步 A_self，再左矩形更新。反馈整体是一阶离散。线性反馈也采用左矩形。

弱 gamma 时两条曲线吻合，不足以排除物理 gamma 下的离散放大。原零反馈响应验证也不能替代这一项。

另外，基线由占据基 Vv 演化生成，非线性分支传播 rho；两者数学等价，浮点误差不同。强反馈可能放大这类微小差，所以同表示同步生成基线与 seed=0 对照是必要检查。

## 4. 增益解释不能只看 W_el，也不能只看 W_in

报告正确地撤回了“W_el<0 就发现增益介质”，但“负值主要来自自场，所以不是探测增益”仍过强。

在同一单位、同一时间定义下，设单侧增量入射场为 e，增量电流为 i，自场为 -gamma i，则

\[
e_{R,\rm out}=e-\gamma i,\qquad
e_{L,\rm out}=-\gamma i .
\]

两侧增量输出减去增量输入的平方通量满足

\[
\frac{1}{2\gamma}\int
\left(|e-\gamma i|^2+|\gamma i|^2-|e|^2\right)dt
=-W_{\rm el},
\quad \gamma>0.
\]

所以 W_in>0 本身不能排除增量出射能量大于增量入射。W_self 的负号描述辐射带走能量；还要追问能量由哪里提供，不能因它恒负而否认可能的放大。

与此同时，Wel=积分 deltaE*deltaI 不是与泵浦基线相减的完整电子能量差。令 U0、I0 对应 P1 基线，则

\[
\frac{d(U-U_0)}{dt}
=E_{\rm P1}\cdot\delta I
+\delta E\cdot I_0
+\delta E\cdot\delta I.
\]

积分时应保留初始能量差；种子初值未严格为零时尤其不能省略。前两项是泵背景的交叉贡献，不能在非线性强偏离后忽略。

需要区分：

1. 增量场的总出入能量；
2. 加种子前后实际总场能量差（含背景干涉）；
3. 指定 H2 波包的相位敏感或能量增益；
4. 已经过数值资格的材料增益机制。

当前结果没有完成这些对应关系，且动量采样不稳，因此既不宣布增益，也不宣布已排除增益。

强场后固体出现受激发射在理论上有先例，但不能用文献替本模型作判定：[Qasim 等，PRL 127, 087401](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.127.087401)。

## 5. 低频证据也需要更精确的口径

- “DC 带”实际是 0 <= omega < 0.25 omega0，不等于严格零频。
- band_power 的实 FFT 功率漏了非 DC、非 Nyquist 频点的双倍权重，不能作为 Parseval 一致的功率占比。
- 存量 probe6、gamma=0：修正后该低频带约 14.43%，旧值约 17.03%；严格 DC 单 bin 约 3.13%。
- gamma scale=0.03 的自场低频份额约由 91.23% 改为 86.77%。低频仍占主导，但不能继续笼统引用“90%+”。
- gamma*平均I*T/A_self(T)≈1 主要来自 A_self 本身就是 I 的积分，是端点积分一致性，不是独立的失稳机制证明。
- 矢势频谱不是辐射能量谱；电场涉及时间导数。有限窗的泄漏与初值也应记录。

这些可先用存量后处理修正；不删低频、不扣 DC、不改窗来制造稳定。
