# 第四部分：现有代码审计、扩展接口与分阶段计算方案

> 本文件将前三部分的理论翻译为可交给本地 AI 的实现规范。  
> 它不直接修改代码，而是规定模块职责、输入输出、验证门槛和材料计算顺序。

## 11. 对现有代码的逐项审计

### 11.1 当前实现真正计算了什么

现有主路径的流程是：

\[
\boxed{
(I_s,\phi_s)
\longrightarrow
E_s(t)
\longrightarrow
J_s(t)
\longrightarrow
|J_s(\omega)|^2
\longrightarrow
\frac1{N_s}\sum_s|J_s(\omega)|^2.
}
\tag{11.1}
\]

其中：

- \(s\) 是随机轨迹编号；
- \(I_s\) 是该轨迹的峰值强度；
- \(\phi_s\) 是载波相位；
- \(E_s(t)\) 是对应经典驱动场；
- \(J_s(t)\) 是经典 SBE 电流；
- \(N_s\) 是样本数。

因此当前代码属于：

\[
\boxed{
\text{量子输入相空间抽样}
+
\text{经典材料传播}
+
\text{非相干平均谱}.
}
\tag{11.2}
\]

它尚不包含：

- 真正单模或多模 BSV 的椭圆 Husimi-\(Q\) 采样；
- 输出谐波模式的量子化；
- 两时刻电流关联；
- 输入—电流交叉项；
- \(N_{nm}\)、\(M_{nm}\)；
- \(g^{(2)}\)、Mandel \(Q\)、压缩或纠缠。

### 11.2 `mod_quantum_light.f90`：当前分布不是固定压缩角的单模 BSV

当前采样规则为

\[
\boxed{
I
=
-2I_{\rm bar}\ln(1-u),
\qquad
\phi=2\pi v,
}
\tag{11.3}
\]

其中 \(u,v\) 是区间 \((0,1)\) 上相互独立的均匀随机数，\(I_{\rm bar}\) 是代码输入的强度尺度。

对应概率密度是

\[
\boxed{
p(I)
=
\frac1{2I_{\rm bar}}
\exp
\left(
-\frac{I}{2I_{\rm bar}}
\right),
\qquad
p(\phi)=\frac1{2\pi}.
}
\tag{11.4}
\]

其平均值为

\[
\boxed{
\langle I\rangle
=
2I_{\rm bar}.
}
\tag{11.5}
\]

式 (11.4) 是圆对称复 Gaussian/热光型轨迹分布。它没有固定的压缩轴，因此不能命名为一般的 `single_mode_bright_squeezed_vacuum`。

应将当前状态类型改名为

```text
random_phase_exponential
```

或

```text
circular_gaussian_intensity_benchmark
```

并单独实现 coherent、thermal、single-mode squeezed vacuum、displaced squeezed state、two-mode squeezed vacuum 和 custom Gaussian。

### 11.3 Husimi-\(Q\) 样本含有反正常序真空宽度

对模式 \(\mu,\nu\)，定义

\[
N_{\mu\nu}^{\rm in}
=
\langle
\Delta\hat a_\mu^\dagger
\Delta\hat a_\nu
\rangle,
\qquad
M_{\mu\nu}^{\rm in}
=
\langle
\Delta\hat a_\mu
\Delta\hat a_\nu
\rangle .
\]

Husimi-\(Q\) 样本满足

\[
\boxed{
\mathbb E_Q
\left[
\delta\alpha_\mu^*
\delta\alpha_\nu
\right]
=
N_{\mu\nu}^{\rm in}
+
\delta_{\mu\nu},
}
\tag{11.6}
\]

\[
\boxed{
\mathbb E_Q
\left[
\delta\alpha_\mu
\delta\alpha_\nu
\right]
=
M_{\mu\nu}^{\rm in}.
}
\tag{11.7}
\]

因此单模物理平均光子数是

\[
\boxed{
\langle\hat n\rangle
=
\mathbb E_Q|\alpha|^2-1,
}
\tag{11.8}
\]

不能未经修正地把 \(\mathbb E_Q|\alpha|^2\) 直接当成 \(\langle\hat n\rangle\)。

更重要的是：若把所有 \(Q\) 样本原封不动当成经典驱动，真空的 \(Q\) 宽度也会变成随机经典场。采用 Gorlach 类型强占据近似时，必须在文中明确这一近似及其大光子数条件；不能把 \(Q\) 的正概率性误解为一般量子态的经典混合。

### 11.4 `mod_hhg.f90`：复振幅被过早丢弃

当前 FFT 后立即执行

\[
\boxed{
S_x(\omega)
\propto
|J_x(\omega)|^2,
\qquad
S_y(\omega)
\propto
|J_y(\omega)|^2.
}
\tag{11.9}
\]

因此：

- \(\arg J_x(\omega)\)、\(\arg J_y(\omega)\) 被丢弃；
- \(x/y\) 偏振的相干交叉项被丢弃；
- 跨谐波的 \(J_n^*J_m\) 和 \(J_nJ_m\) 无法累计；
- 磁畴相位与异常协方差无法构造。

正确的探测谱一般应写成

\[
\boxed{
S_n
=
\sum_{ab}
J_{n,a}^*
\mathcal C_{ab}^{(n)}
J_{n,b},
}
\tag{11.10}
\]

其中 \(\mathcal C^{(n)}\) 是由探测方向和偏振定义的 Hermitian 半正定矩阵。只有在 \(\mathcal C^{(n)}\) 对角时，才可退化为简单的 \(\sum_aC_a|J_{n,a}|^2\)。

### 11.5 `main.f90`：只累计单频功率均值和标准误

当前累计量为

\[
\boxed{
\overline S(\omega)
=
\frac1{N_s}
\sum_s S_s(\omega),
}
\tag{11.11}
\]

以及其 Monte Carlo 标准误。它没有保存样本级复数 \(J_n^{(s)}\)，也没有累计跨频率矩阵。

至少应增加

\[
\boxed{
A_{nm}
=
\sum_s w_s
J_n^{(s)*}J_m^{(s)},
}
\tag{11.12}
\]

\[
\boxed{
B_{nm}
=
\sum_s w_s
J_n^{(s)}J_m^{(s)},
}
\tag{11.13}
\]

\[
\boxed{
F_{nm}
=
\sum_s w_s
|J_n^{(s)}|^2|J_m^{(s)}|^2.
}
\tag{11.14}
\]

这些量仍只是相空间轨迹的**经典 benchmark 矩**，不能直接命名为量子 \(N_{nm}\)、\(M_{nm}\) 或精确 \(g^{(2)}\)。

### 11.6 `mod_ensemble.f90`：`S_quant` 命名错误且路径未完成

该模块把

\[
\boxed{
S_{\rm total}
-
S_{\rm coh}
}
\tag{11.15}
\]

写成 `S_quant`。对相空间轨迹而言，这只是经典 ensemble variance，并不自动等于量子源噪声。应改名为：

```text
S_classical_trajectory_variance
```

或

```text
S_incoherent_minus_coherent
```

此外模块中轨迹 FFT 仍为 TODO，主程序也未采用该 accumulator；因此不能把它视为已完成的 photon-statistics 模块。

### 11.7 `mod_sbe.f90`：现有传播器不能直接复用于 QRT 辅助算符

当前退相干和并行输运路径会显式执行

\[
\boxed{
\rho
\leftarrow
\frac12
\left(
\rho+\rho^\dagger
\right).
}
\tag{11.16}
\]

这对物理密度矩阵可用于压制舍入误差，但 QRT 的辅助对象

\[
X(t')
=
\hat B\varrho(t')
\]

一般非 Hermitian。若对 \(X\) 使用式 (11.16)，会改变量子回归所需的左右算符顺序。因此必须将：

- `propagate_density_matrix`
- `propagate_general_operator`

分成两个明确接口。

## 12. 建议的模块化代码架构

### 12.1 输入态数据结构

建议新增：

```text
type quantum_input_t
  character :: representation       ! Q / Wigner / positive-P
  character :: state_type           ! coherent / thermal / SV / DSV / TMSV / custom
  integer   :: n_modes
  complex   :: displacement(:)
  real      :: covariance(:,:)
  complex   :: mode_functions(:,:)
  real      :: carrier_frequencies(:)
  complex   :: polarization_vectors(:,:)
  real      :: pulse_energy
  real      :: focal_area
end type
```

对应接口：

```text
build_physical_covariance(input, V)
build_Q_covariance(input, VQ)
sample_Q_nodes(input, nodes, weights)
build_classical_field(node, time_grid, E_t, A_t)
validate_input_moments(input, nodes, weights, report)
```

若物理正交分量协方差为 \(V_{\rm in}\)，则 Husimi-\(Q\) 协方差为

\[
\boxed{
V_Q
=
V_{\rm in}
+
\frac12 I_{2M}.
}
\tag{12.1}
\]

令 \(\boldsymbol d\) 是正交分量均值，\(L\) 是满足 \(LL^T=V_Q\) 的 Cholesky 因子，\(\boldsymbol z\sim\mathcal N(0,I)\)，则样本为

\[
\boxed{
\boldsymbol\xi_s
=
\boldsymbol d
+
L\boldsymbol z_s.
}
\tag{12.2}
\]

把 \(\boldsymbol\xi_s\) 映射为复振幅时采用

\[
\boxed{
\alpha_{\mu,s}
=
\frac{
\xi_{2\mu-1,s}
+
i\xi_{2\mu,s}
}{\sqrt2}.
}
\tag{12.3}
\]

压缩椭圆相对于 \(x\) 轴的旋转角是压缩相位的一半，即 \(\theta_s/2\)，不是 \(\theta_s\)。

### 12.2 输入态验收门 Q0

对所有求积或 Monte Carlo 节点，检查

\[
\boxed{
\sum_s w_s=1,
}
\tag{12.4}
\]

\[
\boxed{
\sum_s w_s\boldsymbol\xi_s
\simeq
\boldsymbol d,
}
\tag{12.5}
\]

\[
\boxed{
\sum_s w_s
(\boldsymbol\xi_s-\boldsymbol d)
(\boldsymbol\xi_s-\boldsymbol d)^T
\simeq
V_Q.
}
\tag{12.6}
\]

对单模压缩真空还应复现

\[
\boxed{
N
=
\sinh^2r,
\qquad
M
=
-e^{i\theta_s}\sinh r\cosh r.
}
\tag{12.7}
\]

对 TMSV 必须同时复现模间 \(N_{\mu\nu}\) 与 \(M_{\mu\nu}\)。

### 12.3 复电流与探测模式模块

建议新增：

```text
compute_complex_current_spectrum(Jt, window, Jw_xyz)
project_detector_modes(Jw_xyz, detector, Jmode)
accumulate_trajectory_moments(Jmode, weight, accumulator)
write_sample_level_modes(metadata, Jmode)
```

其中 `detector` 至少包含：

```text
observation_direction
polarization_vectors
spectral_filters
spatial_mode
normalization
```

每个轨迹保存：

\[
\boxed{
\{
J_n^{(s)},
J_n^{(s)*}J_m^{(s)},
J_n^{(s)}J_m^{(s)},
|J_n^{(s)}|^2|J_m^{(s)}|^2
\}.
}
\tag{12.8}
\]

同时写入 Fourier convention、时间步、窗函数、单位、探测带宽和谐波中心频率。

### 12.4 经典平均谱模块

该模块只负责层 A：

```text
run_phase_space_ensemble(...)
accumulate_ICS_spectrum(...)
accumulate_CS_amplitude(...)
compute_classical_mixture_correlations(...)
```

必须并行输出

\[
\boxed{
S_n^{\rm ICS}
=
\sum_sw_s|J_n^{(s)}|^2,
}
\tag{12.9}
\]

\[
\boxed{
S_n^{\rm CS}
=
\left|
\sum_sw_sJ_n^{(s)}
\right|^2,
}
\tag{12.10}
\]

二者之差命名为 `classical_trajectory_variance`。

只有经过 CEP/相位扫描证明

\[
\boxed{
S_n^{\rm cl}(r,\phi)
\simeq
S_n^{\rm cl}(r)
}
\tag{12.11}
\]

后，才允许用一维强度 Gauss–Laguerre 求积替代二维相空间采样。

### 12.5 电流关联模块

建议统一接口：

```text
compute_current_correlator(method, ordering, domain, modes, result)
```

其中：

```text
method   = quasifree_wick / keldysh / fockspace_qrt / msa
ordering = greater / lesser / symmetric / normal_projected
domain   = plus_N / minus_N
```

若选择 QRT，另设：

```text
apply_liouvillian(t, X, dX)
propagate_density_operator(...)
propagate_general_operator(...)
propagate_auxiliary_operator(...)
```

若选择 quasifree/Wick：

```text
propagate_G_less_greater(...)
contract_current_bilinears(...)
validate_equal_time_pauli_factor(...)
```

### 12.6 电磁输入—输出模块

建议数据结构：

```text
type em_geometry_t
  green_tensor
  observation_direction
  detector_polarization
  spectral_filter
  spatial_mode
  collection_efficiency
  propagation_phase
end type
```

接口：

```text
build_output_mode_kernel(geometry, modes, K)
compute_output_beta(...)
compute_output_NM(...)
add_input_current_cross_terms(...)
validate_output_commutators(...)
```

最低测试：

\[
\boxed{
g_{\rm coupling}\rightarrow0
\quad\Rightarrow\quad
\rho_{\rm out}=\rho_{\rm in},
}
\tag{12.12}
\]

\[
\boxed{
[\hat b_n^{\rm out},\hat b_m^{{\rm out}\dagger}]
=
\delta_{nm}.
}
\tag{12.13}
\]

### 12.7 Gaussian 统计模块

接口：

```text
build_quadrature_covariance(beta, N, M, V)
check_uncertainty(V, Omega)
compute_quadrature_squeezing(...)
compute_g2_gaussian(...)
compute_mandel_Q(...)

```

单元测试态：

- coherent；
- thermal；
- single-mode squeezed vacuum；
- displaced squeezed state；
- two-mode squeezed vacuum。

任何式 (8.11) 的违反都应立即停止，不能静默修正。

### 12.8 非 Gaussian 模块

接口：

```text
compute_mode_projected_G2(method, modes, G2)
compute_connected_fourth_cumulant(G2, beta, N, M, kappa4)
compare_exact_and_gaussian(...)
```

其中

```text
method = nested_qrt / keldysh / quantum_trajectories / counting_field
```

禁止分配 \(N_t^4\) 的全四时张量；应在传播过程中直接对有限模式核 \(K_n(t)\) 做流式累计。

### 12.9 磁畴统计模块

接口：

```text
pair_domain_runs(shared_nodes, plusN, minusN)
compute_domain_even_odd(...)
build_common_basis_mapping(...)
compute_operator_parity_blocks(...)
```

对层 A，\(+\mathbf N\) 与 \(-\mathbf N\) 必须使用完全相同的：

- 相空间节点；
- 求积权重；
- 随机种子；
- k 网格；
- 探测模式；
- Fourier 网格。

否则差分噪声会污染磁畴奇通道。

## 13. 分阶段计算路线和硬门槛

### 13.1 阶段 A0：修正平均谱层

目标：

1. 把当前分布改名为随机相位指数 benchmark；
2. 实现一般 Gaussian \(Q\) 采样；
3. 保存复数 \(J_n\)；
4. 同时计算 ICS 和 CS；
5. 对 \(+\mathbf N/-\mathbf N\) 使用共享节点。

验收：

- 输入矩满足式 (12.4)–(12.7)；
- coherent 输入的 \(Q\) 采样在强占据极限恢复制定经典场；
- fixed-phase squeezed state 的相位扫描与二维采样一致；
- 样本数或求积阶数收敛；
- H2、H5、H7、H9 的复振幅和平均强度均收敛。

### 13.2 阶段 A1：建立 classical-mixture benchmark

用样本轨迹构造：

\[
\boxed{
\rho_{\rm out}^{\rm clmix}
=
\sum_sw_s
|\boldsymbol\gamma_s\rangle
\langle\boldsymbol\gamma_s|,
\qquad
\gamma_{n,s}
=
\kappa_nJ_{n,s}.
}
\tag{13.1}
\]

计算 classical-mixture 的 \(g^{(2)}\) 和跨谐波相关，明确标注 `classical_benchmark`。这一阶段不能输出：

- `quantum_squeezing`；
- `quantum_entanglement`；
- `sub_poissonian`；
- `exact_photon_statistics`。

### 13.3 阶段 B0：小系统电流噪声基准

在二能级、四带或小 Fermi–Hubbard 模型中同时实现：

1. 完整 Fock-space 精确传播；
2. quasifree/Wick；
3. 若有明确 Lindblad，则实现 QRT；
4. 可选 MSA。

比较：

\[
\boxed{
C^{>,<,S}(t,t'),
\quad
\beta_n,
\quad
N_{nm},
\quad
M_{nm}.
}
\tag{13.2}
\]

只有当等时 Pauli 因子、排序关系和解析极限全部通过后，才进入真实材料。

### 13.4 阶段 B1：CrI\(_3\) 的二时刻关联

第一轮模式：

\[
\boxed{
\mathrm{H2},\ \mathrm{H5},\ \mathrm{H7},\ \mathrm{H9}.
}
\tag{13.3}
\]

第一轮材料 parent 应使用 M88-full，而不是直接使用 M88-c20。理由是：

- M88-c20 对平均 H1–H9 已通过；
- 双时电流关联对被删远带和 Pauli 收缩的敏感性尚未验证；
- 平均 \(J_n\) 收敛不推出 \(N_{nm}\)、\(M_{nm}\) 收敛。

若 M88-full 成本过高，可先用 M88-c20 开发代码，但所有物理结论必须与 M88-full 对照。

### 13.5 阶段 B2：Gaussian 输出统计

对每个磁畴输出：

\[
\boxed{
\beta_n,\quad
N_{nm},\quad
M_{nm},\quad
V,\quad
V_{\min},\quad
g_{\rm G}^{(2)},\quad
Q^{\rm Mandel},\quad
\mathcal R,\quad
E_{\mathcal N}.
}
\tag{13.4}
\]

必须同时给出：

- 物理性残差；
- 探测带宽依赖；
- 输入—物质交叉项大小；
- M88-c20/M88-full 带空间误差；
- \(k40/k60\) 误差；
- 磁畴差的绝对量和相位。

### 13.6 阶段 C0：非 Gaussian 验证

至少在最有希望的两个模式对上计算精确四阶矩：

\[
\boxed{
(\mathrm{H2},\mathrm{H5}),
\qquad
(\mathrm{H2},\mathrm{H7}).
}
\tag{13.5}
\]

比较

\[
\boxed{
\kappa_{25}^{(4)},
\qquad
\kappa_{27}^{(4)}.
}
\tag{13.6}
\]

若 \(\kappa^{(4)}\) 在误差内为零，Gaussian 路线可用于更大参数扫描；否则只能把 Gaussian 结果称为二阶矩见证。

### 13.7 量子优势阶段不能提前

定义允许的经典输入资源集合

\[
\boxed{
\mathcal C
=
\left\{
\rho_{\rm in}
\ \middle|\
P_{\rho}(\boldsymbol\alpha)\ge0
\right\},
}
\tag{13.7}
\]

并固定：

- 平均光子数或脉冲能量；
- 带宽和脉宽；
- 聚焦面积；
- 偏振；
- 时间模数；
- 样品和探测效率。

只有在相同资源约束下证明任务性能超过所有 \(\rho_{\rm in}\in\mathcal C\)，才可称为量子优势。观察到量子效应或非经典输出不自动等于量子优势。

## 14. 材料模型与数值收敛策略

### 14.1 层 A 的现有生产模型

当前已验收的经典低中阶生产配置是：

\[
\boxed{
\text{M88-c20}
=
58\text{ 条占据带}
+
20\text{ 条导带}
=
78\text{ 条 active bands}.
}
\tag{14.1}
\]

在当前 \(3200\,\mathrm{nm}\)、场强、脉冲和 \(T_2\) 参数下，其可信范围为：

\[
\boxed{
\text{普通 H1--H9},
\qquad
J_o\text{ 的 H2--H8}.
}
\tag{14.2}
\]

日常平均谱可用 \(40\times40\) k 网格；\(60\times60\) 用作最终基准。H10 的磁序奇复振幅未通过 c20 截断验收，若研究 H10 应用 M88-full。

### 14.2 BSV 高场尾部需重新验收

BSV 或其他强涨落输入的相空间分布包含高场尾部。令第 \(s\) 个节点场强为 \(E_s\)，则 active-space 误差是场强依赖的：

\[
\boxed{
\epsilon_{\rm band}(n;s)
=
\frac{
\left|
J_n^{\rm c20}(E_s)
-
J_n^{\rm full88}(E_s)
\right|
}{
\left|
J_n^{\rm full88}(E_s)
\right|
+
\delta
}.
}
\tag{14.3}
\]

因此不能只在平均强度节点验证 c20。至少检查：

1. 最大统计权重节点；
2. 平均场附近节点；
3. 最大有效场强节点；
4. 对高阶矩贡献最大的节点。

### 14.3 量子统计需独立带数收敛

\[

=

}{
