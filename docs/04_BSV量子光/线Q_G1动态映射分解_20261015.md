# G1 工作记录：动态输入输出映射的分解（2026-10-15）

使用已经核对过 sha256 的宏步 2048 伴随行，没有重跑传播，也没有覆盖那两份缓存。显式循环和 einsum 收缩在同一条输入列上差 \(1.11\times10^{-14}\)。光子列顺序是每个频率的 L0、L1、R0、R1。

## 1. 已证明

在九面板配置加上 \(10^{-8}\) 红外段之后，正常残差可以写成

\[
R_N=(U_0U_0^\dagger-I)+(U_0\Delta U^\dagger+\Delta U U_0^\dagger)+(\Delta U\Delta U^\dagger-VV^\dagger).
\]

宏步 2048 的 \((0,0)\) 是：

| 项 | \((0,0)\) |
|---|---:|
| \(U_0U_0^\dagger-I\) | \(+2.13\times10^{-12}\) |
| \(U_0\Delta U^\dagger+\mathrm{h.c.}\) | \(+20.11770\) |
| \(\Delta U\Delta U^\dagger\) | \(+79710.08\) |
| \(VV^\dagger\) | \(+79730.20\) |
| \(\Delta U\Delta U^\dagger-VV^\dagger\) | \(-20.11769\) |
| 合计 \(R_N\) | \(+1.60627\times10^{-5}\) |

反常矩阵最大模是 \(7.09\times10^{-7}\)。合计与上一份直接收缩的 \(+1.60627\times10^{-5}\) 一致到 \(10^{-10}\)。初始历史、自由场强迫和二者的交叉项重新加回光子 Gram，差 \(5.1\times10^{-11}\)。

所以这一笔 \(1.6\times10^{-5}\) 不是静态 \(U_0\) 的缺口，也不是求和舍入。它是两个大约 20 的块抵消之后的余数。左右端口的 \(\Delta U\Delta U^\dagger-VV^\dagger\) 在整张矩阵上差是 0：同一频率的 L、R 入射列里，\(A\)、自由场和 \(b\) 是同一份拷贝（`stationary_photon_columns` 把同一组偏振自由场放到两侧）。\(U_0\) 则按端口区分，左侧用 \(a\)，右侧用 \(a-A_f\)。交叉项因此左右不同，\((0,0)\) 分别是 \(+12.328\) 和 \(+7.790\)。

暗列的 \(U_0\) 和交叉项都是 0，只贡献二次项 \((0,0)=-291.657\)。红外段几乎全在二次项里，\((0,0)=+1.95489\times10^{-4}\)，交叉项只有 \(-4.3\times10^{-7}\)。

## 2. 已排除

- 读取了错误的四阶缓存。sha256 与身份记录一致才开始收缩。
- einsum 与手写收缩不一致。差是 \(10^{-14}\)。
- 剩余残差来自 \(U_0U_0^\dagger-I\)。该项是 \(2\times10^{-12}\)。
- 剩余残差来自这条红外尾还没加进去。加上之后余数仍是 \(1.6\times10^{-5}\)。
- 把 \(5.2\times10^{-7}\) 的时间模型差别说成严格上界，或者把 \(h^5\) 说成已经数学排除。上一份记录的判别仍然有效：\(h^5\) 不是这三档的领头项，更高阶没有独立约束。

## 3. 尚未排除

左右端口携带同一份动力学列，而 \(U_0\) 对两侧定义不同。静态对易在这套定义下能收到 \(10^{-12}\)，所以不能把“两侧自由场相同”直接改成删掉一端口。动态二次项对两侧完全相同，交叉项不对。两者抵消到 \(1.6\times10^{-5}\)。这是结构事实，还不是已经定位的写错一行。

有限浴和两点模型用的是正向中点或同一类 Richardson，不是这条 Γ12 伴随收缩的另一套公式。先前 16 列、宏步 64 上，正向和伴随差 \(5.43\times10^{-13}\)，覆盖的是离散映射自身，不是“这个映射等于连续输入输出算符”。两点模型能收到 \(2.7\times10^{-7}\)，说明同一套列构造不是在每个问题上都留下 \(10^{-5}\)。
