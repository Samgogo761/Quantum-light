## 1. 本轮做了什么、没做什么

20261117 已经冻结：原四类线偏振分析器下，八周期 `P1_a2_A0.8` 没有已认证磁畴**强度**读出。外审不接受由此推出「偶次磁性 HHG 没有值得研究的信号」，并指出：在理想半周期反号驱动且响应已进入相应时间平移协变时，

\[
J^e(t+T_0/2)=-J^e(t),\qquad J^o(t+T_0/2)=+J^o(t),
\]

从而 \(\mathcal J^e_{2m}=0\)、\(\mathcal J^o_{2m+1}=0\)。若同一谐波上磁偶与磁奇不同时存在，则

\[
D_\epsilon(q)=4\operatorname{Re}\bigl[(\mathcal J_q^e)^*\mathcal J_q^o\bigr]_\epsilon=0.
\]

纯磁序奇的 H2 可以满足 \(\mathcal J_2(+N)=-\mathcal J_2(-N)\)，两畴强度相同、相位差 \(\pi\)。所以延长脉冲若更接近该对称性，某些 \(D_B\) 甚至可能进一步变小。

本轮只在已有电流上执行 A′：

1. 提取 H1–H9 的磁序奇偶复源矢量 \(\boldsymbol{\mathcal J}^{e,o}(\Omega)\)（∥ / ⊥ 与复相位）。
2. 对固定频带 \(B\) 构造 \(K_\pm=\int_B \boldsymbol{\mathcal J}_\pm\boldsymbol{\mathcal J}_\pm^\dagger\,d(\Omega/\omega_0)\)，\(\Delta K=K_+-K_-\)。
3. \(\max_{\lVert\epsilon\rVert=1}\lvert D_{\epsilon,B}\rvert=\lVert\Delta K\rVert_{\rm op}\)。本征偏振在 **Γ96 参考窗**上冻结，再用于 Γ48 / shift48，禁止逐网格优化分析器冒充稳定。
4. 分开报告 \(\lVert\mathcal J^o\rVert\) 与 \(\lVert\Delta K\rVert_{\rm op}\)。
5. 脉冲中心若干周期的半周期残差；明确不得称为严格选择定则。
6. 保留既有窗与带宽：参考窗仍是 `sin² × 0.25`。

合并规则不变：\(J_{96}=(J_{00}+J_{11}+J_{10}+J_{01})/4\)。禁止平均归一化反差。单位仍是片电流模型单位，不是 SI 光强。

分类器只用于把偶次通道标成「奇源存在但网格不稳 / 相位型候选 / 强度型未认证」，**不是认证**。偶次被标成 `odd_source_present_but_grid_unstable` 的条件是：48→96 或 48↔shift 的奇源向量相对变化 \(>0.5\)。H2–H8 四个偶次全部落入这一类。

### H2：最强的偶次奇源，强度型干涉，网格不稳

Γ96 整数频率：

- \(\mathcal J^e\) 相位（∥）168.28°，\(\mathcal J^o\) 相位（⊥）167.85°，几乎同相。
- 峰在 \(\nu=2.02\)，偏离整数 0.02，**不是频带边伪峰**。
- 四种线偏振里 45° 达到 \(\lVert\Delta K\rVert_{\rm op}\) 的 99.98%（\(2.8460\times10^{-11}\) vs \(2.8465\times10^{-11}\)）。冻结本征偏振 \(\epsilon\approx(0.707,\,0.707-0.014i)\)，本质就是 45° 线偏振。
- 因此 H2 属于**强度型干涉**：无参考分析器原则上能看见磁畴差，而且 45° 已经几乎穷尽椭圆偏振的上限。20261117 对 45° 的负结果，不是因为漏掉了某个椭圆分析器。
- 48→96 奇源向量相对变化 0.272，比 \(D_B\) 的 48↔shift 翻号稳得多；但 48↔shift 源相对变化仍是 0.821。冻结 \(D\)：+6.84e−11 → −3.76e−11 → +2.85e−11。`sin²×0.50` 令冻结 \(D\) 在 Γ96 翻号。

**H2 不能认证，也不能上压缩光。** 它证明的是：偶次磁序奇复源可以存在，而且当前协议下它更接近「偏振干涉的强度差」而不是「纯相位差」。

### H4：椭圆分析器能超过四种线偏振，但源最不稳

Γ96 上 \(\lVert\Delta K\rVert_{\rm op}=1.84\times10^{-11}\)，四种线偏振最大绝对差只有 \(6.79\times10^{-12}\)（约 37%）。冻结本征偏振 \(\epsilon\approx(0.707,\,0.262+0.657i)\)，是真椭圆。这解释了「36 个线偏振通道全灭」并不能严格排除全部偏振测量——对 H4，椭圆上限确实更大。

但奇源向量 48→96 相对变化 **1.80**，是四个偶次里最差的；冻结 \(D\) 虽不翻号，幅度从 4.73e−11 落到 4.41e−12 再回到 1.84e−11。峰在 \(\nu=4.14\)（偏整数 0.14）。**椭圆分析器救不了 H4。**

### H6：最接近相位型，仍未过关

\(\rho=0.086\) 低于分类器的 0.15 阈值，Cauchy 界几乎吃掉全部无参考强度差。若源网格稳定，它会被标成 `phase_type_candidate`。实际 48↔shift 相对变化 0.62，48→96 虽然只有 0.237，分类器仍把它打成网格不稳。冻结 \(D\) 三套网格同号为负，但 `sin²×0.50` 以及 `boxcar×{0.125,0.25,0.50}` 全部翻号。峰在 \(\nu=5.88\)。

**H6 是「相位型」假说的最近邻，不是已认证的相位读畴通道。**

奇/偶比 0.039，与 H6 同类量级，但 48↔shift 源相对变化 1.17，冻结 \(D\) 翻号。不作候选。

## 6. 对外审三个问题的回答

**(a) 当前模型是否存在比磁畴强度反差更稳定的磁序奇偶次谐波复源？**

存在**可辨识的**偶次磁序奇复源，H2 最强。H2 的 48→96 奇源向量相对变化 0.27，优于 \(D_B\)（48↔shift 翻号）。但 48↔shift 源相对变化 0.82，H4 的 48→96 更是 1.80。所以：比强度反差「更像一个物理对象」，**还不是**稳定的生产通道。分类器把四个偶次全部标成 `odd_source_present_but_grid_unstable`。

**(b) 是否存在任意椭圆偏振也无法产生强度畴反差、但可以通过相位读取磁序的候选？**

没有已认证者。H6 最近（\(\rho=0.086\)），仍失败于网格与窗口。H2 相反：45° 已经饱和 \(\lVert\Delta K\rVert_{\rm op}\)，它不是相位型。

**(c) 下一步若延长脉冲，应当改善哪一个明确的物理量？**

不要以「让 45° 的 \(D_B\) 更稳、更大」为成功标准。若采用更长、带中心平台的经典驱动（原方案 B 的物理动机，但指标必须改写），应盯：

1. **\(J^o\) 的半周期协变**：Γ96 周期 3–5 的奇残差从 ~1.5 降下来（目标量级应明显小于 1，并与 \(J^e\) 残差可比较）。
2. **偶次 \(q\) 的 \(\lVert\mathcal J^o\rVert/\lVert\mathcal J^e\rVert\)**：H2 现为 0.284，H4/H6/H8 为 0.04–0.06；若趋近选择定则，该比值应上升，同时 \(\lvert J_+-(-J_-)\rvert/\max\) 应从 ~2 降向 0。
3. **奇源向量的 BZ 稳定性**：48↔shift 相对变化从 H2 的 0.82、H4 的 0.86 降下来；并继续禁止平均反差。
4. **谱隔离**：峰应留在整数附近、不靠频带边，且参考窗变体不翻号。

接近选择定则时，\(\lVert\Delta K\rVert_{\rm op}\) 与 \(D_B\) **可以变小**。那不是失败，而是从强度读畴转向相位/相干探测的信号。若 B 之后 \(D_B\) 变大而半周期残差和奇/偶比没有改善，应视为包络泄漏，而不是磁性选择定则被「验证」。
