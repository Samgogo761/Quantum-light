# G1 工作记录：生产残差从哪一层出现（2026-10-14）

有限浴的输出恒等式不再重做。这一轮在两个 \(k\) 点上用生产的频率求积、稳态入射列、中点步进和 \(H_2\) 核，把静态行和驱动电流积分分开。\(\gamma,\eta,D\) 和波包定义都没改。完整 \(\Gamma 12\) 没有重跑。

## 1. 输入装配

526 个频率，左、右端口各 1052 列，暗列 20。\(\sqrt{w}\) 只进一次，和 \(\eta/\sqrt{\omega}\) 的差是 \(1.7\times 10^{-18}\)。有泵和无泵用同一份初值列。

只有静态出射行 \(U_0\)、\(V=0\) 时，正常残差是 \(0.00188937\)，反常残差是 0。波包质量是 \(0.99811063\)，\(1\) 减去它正好等于这个正常残差。静态行上没有额外的通道重复或漏项。

同一频率上，电子侧的 even 测度正常残差 \(4.95\times 10^{-4}\)，反常 \(1.92\times 10^{-7}\)。

## 2. 残差变大的那一层

脉冲中点附近一个光学周期、每周期 128 步：

| 装配 | \(\|R_N\|_{\max}\) | \(\|R_A\|_{\max}\) |
|---|---:|---:|
| 只有 \(U_0\) | 0.00188937 | 0 |
| \(U_0\) 再叠加无泵电流积分 | 0.329424 | \(5.57\times 10^{-6}\) |
| 生产公式：驱动减无泵 | 0.00898808 | 0.00027123 |

无泵积分已经包含在稳态行里。再加一次，正常残差升到 0.329。生产代码是驱动减无泵，这一步把 0.329 消掉，留下 0.00899。

消掉之后，各通道在减去单位阵之前的正常 Gram 仍是：左端口 0.6687，右端口 0.4555，暗列 \(4.28\times 10^{-5}\)。暗列不是这个残差的来源。左右端口的大块互相抵消后才得到 0.00899，不能把抵消后的数当成每一路都已经正确。

每周期只有 32 步、再积满八个周期时，输出残差会到约 \(3\times 10^{4}\)。那是步长太粗造成的发散，不是这一层的物理残差，`production_layers_fullpulse.json` 里的那个数不要引用。已归档的两点全脉冲、每周期 1024 步，输出 CCR 约 \(5.8\times 10^{-4}\)。

## 3. 和 \(\Gamma 12\) 的关系

\(\Gamma 12\) 上静态行的包归一化约 \(10^{-12}\)，因为那套求积把波包质量补到了 1 附近。剩下的 \(\|R_N\|_{\max}=0.00743926\)、\(\|R_A\|_{\max}=0.00223158\) 在驱动减无泵的电流积分里。两点上的分层和这个次序一致：输入行停在波包质量的缺口，驱动积分才把正常残差推到 \(10^{-2}\) 这一档；窗口和步长加密之后它还会再降，但不是从 \(W_{\mathrm{in}}\) 的静态 Gram 里开始的。

有限浴已经闭合的那条恒等式没有改写生产方程。G1 仍未通过，不进入 G2/G3。
