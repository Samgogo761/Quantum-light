## 1. 外部意见如何收紧，代码证据如何对齐

上一轮有限标签接入停在分叉：把每个有限 \(B_{cvk}\) 当独立物理振子，还是构造电子连续入射列。暗零维随网格 12、48、118、210 上涨，已经说明“振子个数”不是材料不变量。

用户后来给出的**可执行**版本不是“连续电子 in-channel 更真实、必须先做”。收紧后的结论是：

1. 固体强场电子动力学用 Bloch-\(k\) 是成熟路线。Yue & Gaarde, *Phys. Rev. A* **101**, 053411 (2020) 把半导体 Bloch 方程写成固体 HHG 的常用方法，电子自由度就在 \(k\) 空间。有限样品的 \(k\) 本就是 \(2\pi/L\) 的准连续网格。因此 \(B_{cvk}\) 作为**内部材料激发的数值基底**合理，不是因为用了有限网格就不物理。
2. 传播场的连续 input–output 也是成熟路线。Gardiner & Collett, *Phys. Rev. A* **31**, 3761 (1985) 把外部环境写成 \(a_{\mathrm{in}}(\omega),a_{\mathrm{out}}(\omega)\)。我们的光子从无穷远入射再向无穷远出射，适合这套语言。
3. 这两件事**不能**直接拼成：“P1 驱动的 PT-AFM 里，每个内部 \(B_{cvk}\) 都必须改写成电子入射散射连续谱。”粒子—空穴模式是材料内部自由度。当前没有电子电极或载流子库从外部入射。把它们叫 \(b_{\mathrm{el,in}}(\omega)\) 只是 canonical factorization，不是真实电子束。
4. 连续电子通道 / 谱本征通道保留为**后续低秩降维**。没有完整 \(kcv\) 参考的 \(C_{JJ},n,m\) 对照前，不升生产。这才符合“先 microscopic reference，再 reduced representation”，也符合现有 GPU 讨论：离散 \(k\) 天然可批处理。

因此本轮**不**构造连续电子入射边界，**不**把 leftover 扫描里的暗维数写成生产 bath 数。内部传播仍用原始 \((k,c,v)\)。暗组合保留：P1=0 时 \(\langle 0|\hat I|d\rangle=0\) 不蕴含驱动全程无关。

## 2. 本轮对象是什么，不是什么

做的是：

- 两点冻结 \(k\)、\(\pm N\)；
- `assemble_incoming_bundle`：光子连续列 + 暗组合点列；
- 已验证的 implicit midpoint，前一周期（原八周期波形不缩短）；
- 冻结 H2 包中心 \(2\omega_0\) 的 source-only 收缩；\(\parallel/\perp\) 实验室轴来自 `parallel_perp_basis`。

不是：

- 生产 \(n=\langle b^\dagger b\rangle\) 或 \(m=\langle bb\rangle\)；
- canonical 输出（须保留入射真空，`compose_relative_output` 的 \(U_0+\delta U,V\)）；
- `chi_rad` 已定后的光子数；
- 完整脉冲、远场、全 BZ、GPU、连续电子 in-channel。

`assemble_ground_or_photon_moments` 仍是 `NotImplementedError`。本轮没有去实现它。

## 5. 本轮证明了什么，没证明什么

证明（有限诊断）：

1. 路线决策可以落到现有代码：内部 \(kcv\) + 光子连续列 + 保留暗列，不必先做电子连续入射。
2. 真实八带两点可以在冻结 P1 下走进已有 midpoint，并把电流投到冻结 H2 窗。
3. P1=0 暗组合在驱动后可以携带电流。
4. 权重一次、冻结 \(D/\gamma_{\mathrm{self}}\)、原始标签，与有限标签接入一致。

没有证明：

- 任何 \(n,m,V\)；
- 磁畴对比；
- 完整脉冲或包络求积误差界；
- 电子连续入射边界；
- `chi_rad`；
- GPU 已经必要或已经值得写。

## 6. 真正缺失的物理接口（只列与首个有限结果有关的）

按“尽快看到物理图像、必要时再上服务器/GPU”排序：

1. **Canonical 输出，不是 source Gram。** 现有 `compose_relative_output` 要求完整入射基上的 \(U_0,\delta U,V\)。本轮只有源电流窗。没有入射真空就没有合法 \(n,m\)。
2. **`chi_rad` 仍未定。** `q8_m0_k1_chi_interface.py` 状态仍是 `unset_awaiting_theory`。没有它，H2 包不能从源收缩变成光子数。这是比网格更硬的接口。
3. **完整八周期 + 正规 H2 频率求积。** 三节点、五时刻只证明链路接通。`packet_quadrature` 已存在，不要另造第二套独立 H2 窗物理。
4. **\(k\) 收敛看可观测量，不看振子个数。** 下一步若扩大，应报 \(n,m,J,C_{JJ}\) 随网格的变化，而不是暗维数。两点禁止外推。
5. **GPU。** 存量方案仍是：先 CPU 剖析一步的 `eigh`/乘/窗，再决定是否写与 `propagate_cjj` 同一时间步的批处理核。本轮 0.1 s 的两点作业不能成为写 GPU 的证据。连续电子降维只有在完整 \(kcv\) 参考成为瓶颈、并能复现 \(C_{JJ},n,m\) 之后才升级。

不要再增加与首个结果无关的 P1=0 极点/红外/对易子审计，不要重开真空选择，不要把联合演化升为生产对象。

## 7. 人审停止点

两点 \(\pm N\) 的源 Gram 差不是磁畴信号。`chi_rad` 未定，moments 未实现，脉冲未完整。

若继续，授权对象应是：**同一内部 \(kcv\) 解释下，把 source 收缩换成保留入射的 canonical 输出行，并明确 `chi_rad` 是否仍阻塞光子数。** 在那之前，不启动全 BZ、服务器大批量、GPU 生产核、连续电子入射通道。
