# G1 工作记录：尾部节点收敛、预测公式与 Γ12 面板（2026-10-14）

两点模型上，时间步和最低亮极点左尾是已经分开的两项。这一轮只加了节点比较、一份不覆盖旧文件的公式修正，以及 Γ12 面板筛查。没有改 Γ12 生产求解器，也没有重跑它的输入列。

## 1. 两点模型：72、108、144 节点

同一条左尾，\(t\in[-15.111811338954,-12]\)，权重固定为 \(1.77377726334822\)。H2 波包求积和其他输入节点不动。比较的是整张复数矩阵。

2048 步上，相对 72 节点的最大变化：

| 尾节点 | \(\|\Delta C\|_{\max}\) 的变化 | \(\|R_N\|_{\max}\) 的变化 | \(\|R_A\|_{\max}\) 的变化 |
|---:|---:|---:|---:|
| 108 | \(5.44\times10^{-7}\) | \(5.44\times10^{-7}\) | \(4.72\times10^{-9}\) |
| 144 | \(5.41\times10^{-7}\) | \(5.41\times10^{-7}\) | \(4.75\times10^{-9}\) |

144 与 72 在 1024 步的 \(\Delta C\) 最大差是 \(5.36\times10^{-7}\)，和 2048 步的 \(5.41\times10^{-7}\) 相同。108 与 144 的 \(\Delta C(0,0)\) 只差 \(3.3\times10^{-9}\)。变化落在整张矩阵上，最大元就是 \((0,0)\) 的 \(5.41\times10^{-7}\)，没有另一对大数互相抵消。

144 节点、中点法 2048 步的实际 \(\Delta C(0,0)\) 仍是 \(4.867\times10^{-5}\)。1024/2048 外推是 \(2.00\times10^{-7}\)。节点再加密已经进到 \(10^{-7}\)，实际残差里剩下的是时间步。

## 2. 更高阶的时间步，只在两点模型上试

每一步仍调用原来的中点传播：宏步 \(H\) 上算一次，半步上算两次，状态和 H2 增量按 \((4\times\text{细}- \text{粗})/3\) 合并。没有负步长，也没有改 Γ12 求解器。求积用 72 节点尾。

| 宏步每周期 | 中点求解次数 | \(\|\Delta C\|_{\max}\) | \(\|R_A\|_{\max}\) |
|---:|---:|---:|---:|
| 256 | 6144 | \(1.075\times10^{-4}\) | \(3.48\times10^{-6}\) |
| 512 | 12288 | \(7.176\times10^{-6}\) | \(2.56\times10^{-7}\) |
| 1024 | 24576 | \(8.16\times10^{-7}\) | \(9.09\times10^{-9}\) |

256 到 512 的缩小倍数是 15.0，四阶对应的 16 倍。1024 宏步的实际 \(\|R_N\|_{\max}=8.16\times10^{-7}\)。同一套 72 节点上，普通中点法 2048 步用 16384 次求解，实际 \(\|R_N\|_{\max}=4.81\times10^{-5}\)。

这组实际矩阵低于 \(10^{-6}\)，用的是诊断步，不是生产中点法。G1 因此还没有按生产求解器通过。

## 3. 2048 预测公式

旧文件 `timestep_2048.json` 里的 `predicted_2048_from_512_1024` 仍是 \(3.108\times10^{-4}\)，没有改。正确的半步预测是

\[
R(h/2)=R(h)+\frac{R(h)-R(2h)}{4}.
\]

由此得到的 \(\Delta C(0,0)\) 预测是 \(2.065\times10^{-5}\)。修正结果写在 `timestep_2048_prediction_corrected.json`。`test_q8_m0_g1_richardson_predict_20261014.py` 用一个精确的 \(R_0+Ch^2\) 例子，并核对旧文件仍是反号结果。

## 4. Γ12 面板筛查

当前求积是 12×12、核心 160、翼因子 2、频率 \(10^{-4}\) 到 12，共 32904 个节点，权重合计 \(11.9999\)。完整面板：核心 167、sinh 尾 171、H2 窗 5。没有外直段。

每条尾在同一 \(t\) 区间上把节点数加倍，比较 \(\sum w\,e^{i\omega/0.05}\)。两点模型那条已经证实的左尾，18 节点对 72 节点的这个差值是 \(0.0173\)，对应固定时间步上 \(\Delta C\) 变化 \(2.3\times10^{-5}\)。

Γ12 的 171 条尾里，170 条加倍后的差值在 \(10^{-14}\) 以下。剩下一条：

| 项 | 值 |

| 极点 | \(7.6246211251\) |
| 宽度 | \(7.936\times10^{-8}\) |
| 频率区间 | \([7.631,\,12]\) |
| 节点 / 权重 | 52 / \(4.369\) |
| 最大频率间隙 | \(0.275\) |

| 104 节点 | 与解析积分一致到 \(10^{-13}\) |

这条尾的求积在激光频率尺度上还没有积完。它的对易矩阵没有重算，也没有把两点模型的 18→72 直接搬过来。完整 12×12 上重跑这 52 个频率的输入列还没有启动。

## 5. 三件事分开

- 两点模型里已经确认的，是二阶中点误差，以及这条左尾从 18 节点收到 72 节点后消失的 \(2.4\times10^{-5}\) 外推平台。72 再到 144，整张矩阵只再动 \(5.4\times10^{-7}\)。
- Γ12 的 \(0.007439\) 和 \(0.002232\) 还没有归到某一条尾。目前只标出极点 \(7.625\) 的高频尾。
- 中点法 2048 步的实际残差仍是 \(4.81\times10^{-5}\)。外推和外推之后的诊断步可以到 \(10^{-7}\) 量级；诊断步 1024 宏步的实际值是 \(8.16\times10^{-7}\)。
