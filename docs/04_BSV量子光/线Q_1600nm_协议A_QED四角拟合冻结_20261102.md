## 1. 口径修正：旧 8.778 不能再当生产参考

1600 nm GH5 原先调用遗漏窗口端点的 `rect_jq`。在同一保存网格上，常数信号会给出假 H2 \(\lvert J_2\rvert\simeq 0.01015\)；端点修正 `linear_exact` 后约为 \(2.6\times10^{-16}\)。

QED 与 GH5 现已统一为：

\[
J_q=\frac{1}{t_b-t_a}\int_{t_a}^{t_b} e^{+iq\omega t}\,J(t)\,dt,\qquad
\omega=0.775,\quad [t_a,t_b]=[2T_0,4T_0],

无 Hann。主对象是笛卡尔 **\(x\)** 方向 Néel-odd H2。旧 Q6 的 **4.98 是二维振幅比**，旧 GH5 的 **8.778 是漏端点的 \(x\) 分量比**，二者本来就不是同一指标。

## 3. 现在允许说什么

允许（仅四角、仅本协议、仅主窗电流）：

1. 近反相干涉在精确 QED 四角上**看起来还在**：\(179.391^\circ\)，距 \(\pi\) \(0.609^\circ\)。
2. \(\rho\) 接近输入 \(R\)：\(\rho/R_{\mathrm{ideal}}=0.9953\)。这比 24.8 μm Q6 的 \(\rho=1.456\) 更靠近 \(R\)，但是**四角描述，不是已验证的频率定律**。
3. \(\|C/A\|\approx 0.32\%\)，三项拟合相对残差 \(5.81\times10^{-4}\)。四点不能排除 \(e^{\pm 2i\theta}\) 混叠。
4. 同口径下精确 QED 与修正 GH5 的 \(\rho\)、相位、振幅比都接近；差别是百分位到度的量级，本轮不把差别解释成纠缠或材料核。

不允许：

1. 写成 1600 nm 机制已通过、精确 QED 留出已通过、或 \(n_{\max}=8\) 对 H2 已与 \(n_{\max}=10\) 收敛。
2. 把 8.534 / 8.498 写成产额增强，或拿来直接对比 Q6 的 4.98。
3. 把 \(\rho\approx R\) 写成 \(K_A/K_B\) 定理，或把拟合 \(B,A,C\) 写成已经独立重构的三个微观核。
4. 写成 25 fs 实验室 BSV、宏观光子数、已标定 W/cm²、全 BZ 或真实 CrI₃。

邻窗敏感性（不是误差界）：linear−quadratic 最大 \(3.41\times10^{-7}\)；前/后窗相对主窗最大 \(1.31\times10^{-5}\) / \(1.41\times10^{-5}\)，与弱角 \(\lvert H2(\theta=0)\rvert\approx 1.05\times10^{-5}\) 同量级。**窗口依赖仍在，主窗数字不是稳态谐波产额。**
