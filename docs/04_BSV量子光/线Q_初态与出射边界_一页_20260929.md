# 线 Q：初态与出射边界——先读这一页

2026-09-29，Codex。

**W_in/W_out 的实现是工程，但它们对应什么实验、是否在当前模型里存在，是理论问题。本轮已完成条件性推导和有限解析验证，尚未启动真实 P1。**

## 这一次真正纠正了什么

上一轮把流程简写成“准备 → 演化 → 出射”的三个矩阵，容易让人以为只剩矩阵乘法。现在明确：

- 激光前，不能只说“外面没有光”，就假定程序里所有电子与光坐标都是独立裸真空。耦合一直存在时，初始涨落通常已有相关。
- 激光后，当前模型没有退相干，电子可能持续激发、振荡。不能自动用关泵浦基态的散射关系描述它。
- 所谓“incoming 真空”与完整耦合系统基态，在适用条件下可能是同一准备的不同表述；不是一种自动绕开低频数学问题的捷径。

## 已经推出来什么

对有限、稳定、正定的联合二次 Hamiltonian，已明确构造正常模变换与初始协方差，验证：

1. 保持玻色对易关系；
2. 正确初态在无驱动时不变；
3. 用独立公式得到同一协方差；
4. 裸乘积真空则可因突然开耦合发生变化。

小模型最大相关残差约 2.1×10^-13。它证明公式与实现一致，不是 M0 的光子结果。

对当前 8 周期的 H2 波包还证明：它在零频率线性趋零，含辐射系数后仍可积；探测核本身没有新增 IR/UV 不可积，但有脉冲外时间尾。电子—光初态是否良好仍需另证。

还验证了一个反例：内部一个暗自由度的状态可以变化，而光子输出不变。因此之前合法的光子散射行，不能反推出所有内部初态。

## 哪些数学问题是真正剩下的

- 我们的通道是否覆盖所有会参与 P1 演化的电子与光自由度；
- 完整连续谱下，所需协方差和 H2 波包投影是否有限；
- 脉冲后持续的电子运动是否使探测积分有定义；
- 是否仍处在围绕经典轨迹的小涨落近似范围内。

这些不是换积分器能解决的问题，也不需要本人替 AI 想算法。
