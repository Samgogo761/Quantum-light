# 线 Q：M0 v1 / R0 / P0 物理解读（一页，2026-09-12）

数字来自同日 spec/静态报告与经典基线报告；本页只把它们放在一起并列出待你判断的事项，不宣布机制。

## 1. R0 的能带与驱动区间

- 低能物理是**环状小隙**：无层间耦合时同自旋块的上层带 \(\Delta-\sqrt{t_h^2|f|^2+\lambda^2g^2}\) 与下层带 \(-\Delta+\sqrt{\cdots}\) 在 \(\sqrt{\cdots}=\Delta\) 的闭环上交叉，\(T_0\)（尺度 \(u,v=0.1\)）把它打开为 \(0.09\)–\(0.11\,t_h\) 的反交叉隙。\(E_g^{\rm ind}=0.0916\)，\(E_g^{\rm dir}=0.0925\)，两者都在环上、不在 \(K\)。远离环处带宽 \(\sim6t_h\)。
- P0 的 \(\hbar\omega_0=0.2t_h\)：\(E_g/\hbar\omega_0=0.46\)。BZ 里存在 \(E_5-E_4=\hbar\omega_0\) 的单光子共振曲线；\(e a_{\rm NN}E_{\rm peak}/\hbar\omega_0=0.40\)，\(\kappa\) 偏移约 BZ 的 10%。
- 结果：峰值激发 7.4%、残留 5.1% 电子/占据数；\(J_e\) 谱 \(|\mathcal J|^2\) 从 \(H_1\) 到 \(H_9\) 整体下降约七个量级（奇次略高于相邻偶次），**没有 plateau**；\(J_o\) 谱以 \(\omega\to0\) 最强。按数据，这是**共振/带上强激发区间**，不是亚带隙 HHG 区间。这不是我给的定性，是 \(E_g/\hbar\omega_0\) 与 \(N_{\rm exc}\) 的直接读数。

## 2. \(J_o\) 是否被解析

- 时域：\(|J_o|_{\max}=1.2\times10^{-4}\)，是 \(|J_e|_{\max}=2.4\times10^{-2}\) 的 0.5%；以 \(y\)（垂直于驱动）为主，在脉冲内累积，\(t=T_p\) 仍有限。传播只到 \(T_p\)，没有「脉冲后持续」的独立记录。
- 谱：\(\mathcal J_{o,y}(0)=2.3\times10^{-5}\)（末级变化约 1.1%，接近但未 <1%），\(\mathcal J_{o,y}(2)=2.8\times10^{-6}\)、\(\mathcal J_{o,x}(2)=1.8\times10^{-6}\)（高于最后两级变化 27–50×，末级 k 变化 2–4%；该倍数是收敛指标，不是独立误差上界）。\(J_o\) 的 \(H_4\) 部分解析；\(H_6\) 以上不足 10×。
- 判定：**\(J_o\ne0\) 在有限网格上是稳定的非零候选**（低频/DC 与 \(H_2\)），但**未收敛到 1%**；脉冲末段均值未收敛。没有改任何定义去得到它。P0 整体仍标「部分量未收敛」。

## 3. 哪些零来自已证明的选择定则

- 对 \(x\) 驱动，**没有**对称性强制 \(J_{o,x}\) 或 \(J_{o,y}\) 为零。唯一精确约束是 \(P\)：\(J_N[\mathbf A]=-J_{-N}[-\mathbf A]\)，数值满足到 \(10^{-15}\)。\(C_{2h}\) 的镜面/\(C_2\) 对 \(x\) 不给约束（对 \(\mathbf a_2\) 偏振才会强制 \(J_o\perp\) 驱动）。
- \(\Delta=0\) 对照 \(J_o\equiv0\)（严格），这是代码路径检查，不是物理零。
- \(J_e\) 的偶次（\(H_2/H_1=1.5\%\)）与 \(J_o\) 的奇次（\(H_1/H_2\approx0.3\)）来自有限包络与共振背景。有限脉冲下的磁畴宇称 \(J_e\) 奇 / \(J_o\) 偶（对 \(\mathbf A\)）成立到 \(10^{-14}\)，但它不等于严格谐波奇偶律。
- 旧四带那种同-\(\mathbf k\) 常数隐藏映射在 M0 中不存在（64 元 SVD 最小奇异值 0.40）。

## 4. 一条结构性事实（解析证明，数值 \(10^{-15}\)）

\(E_{+N}(\mathbf k)=E_{-N}(\mathbf k)=E_N(-\mathbf k)\) 对所有 \(\mathbf k\) 精确成立（证明已于 2026-09-14 按正规 \(T_0\) + 对角相位使 \(\bar h\) 为实的构造更正；不是 \(X(\Delta)^T\) 那条不成立的写法）。**两个 Néel 畴的能带完全相同**，排除能带能量差作为 \(J_o\) 来源。差异须通过态投影、矩阵元和受驱布居/相干体现；不能直接指定全是 Berry 曲率或价导交叉电流。这与 §2 看到的「\(J_o\) 以低频累积、横向为主」相容，但定位不等于机制证明。

## 5. 仍不确定

- k 收敛慢：单光子共振曲线宽度 \(\sim(1/T_p)/|\nabla_k\Delta E|\sim10^{-3}\) Å\(^{-1}\)，nk=192 的间距 0.0054 Å\(^{-1}\) 仍粗；\(J_e\) 高阶与 \(J_o\) 高阶未收敛，脉冲末段残留电流是网格噪声。
- 闭系统、无退相干：\(t=T_p\) 时带间相干仍在分析窗内；没有 \(t>T_p\) 的独立观测。
- R0/P0 是机制参考点，不是材料参数；\(u=v\) 使 \(T_0\) 在 \(\mathbf k\cdot\mathbf a_2\in2\pi\mathbb Z\) 线上降秩，本轮未见由此导致的病态。
- 近似 \(C_{2h}\) 只到 \(3\times10^{-5}\)（生产 metric）；\(U_{C_2}\) 的层间条件是 \(T^\dagger(k)=T(-Mk)\)。
