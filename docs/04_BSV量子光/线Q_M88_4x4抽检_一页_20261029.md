## 判定

- 2×2 / 4×4 振幅比 = **1.50**（M52 同协议是 6.6）。
- **相位被网格改掉**：Δφ = **-134.4°**，Jy/Jx 从 1.31 到 0.40。2×2 的 M88 相位/偏振不能当材料定量。不上 8×8；下一步若做材料只做代表 k。
- 4×4 相位 -3.1°，B1 2×2 是 131.3°。去边窗 6.4%；H4 去边 Δφ=-1.3°。
