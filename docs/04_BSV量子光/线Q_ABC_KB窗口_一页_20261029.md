# 线 Q：奇通道 K_B 窗口变号的来源（2026-10-29）

无新 QED。两角代理 B=(J₀+Jπ)/2，A+C=(J₀−Jπ)/2。权威数字不改写：ρ=1.456，R=1.273，主窗 K_B 比=0.868，K_M 比=1.003。
比较对象：精确 QED、GH5 kick=True（R 扫描 a05r03）、A2b Ehrenfest kick=False。

## 判定

- 平台内窗（中心 ≥ 3 T₀，即 2–4 T₀ 及更后）：QED/GH5 的 K_B 均值 **0.853**，散度 **1.3%**。不是乱翻符号，而是稳定压低约 **14.7%**。
- 早窗（中心 ≤ 2.25 T₀，覆盖升沿结束后的前两周期）：K_B 均值 **1.136**。所谓变号，是开关附近 QED 的 |B| 暂时高于 GH5。
- 全程 K_M：QED/GH5 均值 **1.001**，散度 **1.6%**。异常关联核不被窗口改写。
- Ehrenfest on/off 的 K_B：主窗 **0.968**，平台内均值 **0.990**。kick 解释相位，不解释这 14%。
- QED 与 kick=True 主窗 K_B 比 **0.868**，与 QED/GH5 的 0.868 一致，余量不在 Wigner 采样细节。
- 时域：升沿 (0–1 T₀) B 残差相对 **2.85**；主窗平台 B 残差相对 **3.53**；同一主窗 AC 残差相对 **0.42**。波形差主要在 Δn=0。
- 主窗波形：AC 相关 **0.92**，B 相关只有 **0.38**。去掉准直流后 B 残差从 3.53 降到 **1.09**。QED 的 Δn=0 奇电流多了一块慢分量，它污染升沿附近的 H2 窗，但不改写平台内 H2 的稳定 14% 压低。
- QED 自身 |B| 邻窗变化 **15.8%**；GH5 自身 **31.0%**。已知 16%–39% 是复响应窗口敏感；**QED/GH5 的平台比是另外一个稳定的量子映射余量。**
- 因此不能写成材料选择定则，也不能把 14% 当成邻窗噪声后丢掉。正确边界：有限时间开关下，精确量子映射在 Néel-odd 的 Δn=0 块留下 O(10%)、窗口依赖的余量；生产主窗上它稳定为压低，前窗因升沿而反号。
