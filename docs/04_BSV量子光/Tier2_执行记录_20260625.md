## 3. 建立的"验证门"(自动对称搜索,不手猜算符)

`model4band.py` 里实现了对任意 `model.H(kx,ky,Nz)` 的批量检查:
```
find_antiunitary_fixingk  搜 16 个 Pauli 双线性中满足 U H(k)* U⁻¹=H(k) 的 → PT(不挪 k)
find_inversion_nparity    搜 P 满足 P H(k;N) P⁻¹=H(-k;-N)            → N 翻转反演(选择定则根基)
find_inversion_fixedN     搜 P' 满足 P' H(k;N) P'⁻¹=H(-k;N)          → 必须"不存在"(否则中心对称,偶次禁戒)
find_neven_unitary        搜 W 满足 W H(k;N) W⁻¹=H(k;-N)             → 必须"不存在"(否则 J 对 N 偶,磁序不可见)
berry (Kubo, 占据→空)     占据流形 Berry 曲率                        → PT ⇒ ~0
gap_value                 直接带隙
```
**Gate A(静态)** = 上面全过。**Gate B(动力学)** = 跑 ±N 的 SBE,要求
`J_o=(J(+N)-J(-N))/2` 非机器零(磁序在电流里可见)。

## 4. 迭代过程与每步具体发现(关键)

**v1 — 单层 Dirac 直接叠加(失败:非 PT)**
- `H = v sinkx(τx⊗s0)+v sinky(τx⊗sy)... ` 含虚 σy 项。
- Gate A:N 宇称 P 精确(dev=0),但 **PT 失败(dev=1.985)**。代数证明:该 Γ 集不容许 PT
  (没有算符能只翻 σy)。教训:单个有质量 Dirac 自带 Berry 曲率,本就非 PT。

**v2 — 实对称构造(Gate A 过,Gate B 暴露寄生对称)**
- `H = v sinkx(τx⊗s0)+v sinky(τy⊗σy)+M(k)(τz⊗s0)+Nz(τz⊗σz)`,全实 → PT=K 由构造保证。
- Gate A:PT=K(dev=0)、N 宇称 P=τz⊗σy(dev=0)、Berry=0(Kubo)、gap=0.155 → **PASS**。
  (插曲:Fukui-Hatsugai 格点 Berry 在小隙+简并给伪迹 45.8,换 Kubo 求和后精确 0。)
- Gate B:**`J(-N)/J(N)=1.000` 全谐波**,N=0 偶/奇=0.43。

**λ 项尝试(错误的修法)**
- 加 `λ sin(kx)(τ0⊗σz)` 想破反演。结果偶次出现但**与 N 无关**,且**破坏了 N=0 中心对称**(偶/奇@N=0=0.39)。
- 弃用(lam=0)。

**决定性诊断**
- 直接算 `J_o=(J(+N)-J(-N))/2`:**max|J_o|=1.08e-15(机器零)** → x 电流精确 N-偶,
  偶次谐波不随 N 翻转。根因厘清:① Néel 项须在物理反演下为奇(我取的在反演下偶);
  ② 要 PT(Berry=0)须两个手性相反、PT 联系的 Dirac(双层加倍)。

**文献 canonical(MnBi2Te4 族,model4band_bilayer.py)**
- `H = M(k)(τz⊗s0)+v sinkx(τx⊗sx)+v sinky(τx⊗sy)+N·G_N`。
- 试 `G_N = τz⊗sz`:有 fixed-N 反演 τ0⊗sz(dev=0)→ J_o=3e-16(机器零)。
- 试 `G_N = τy⊗sz`:PT 存在(t0sx)、N-flip P 存在(tzs0)、Berry=0、gap=1.02,但
  **冒出 N-even 自旋旋转 W=τz⊗sz(dev=0)** → J_o=2.8e-16(机器零)。

## 5. 稳健结论(本阶段最重要的产出)

> **任何"对称到 PT 保护(Berry=0)"的 4 带玩具,自旋空间都太对称,必带一个翻转 Néel 却保持
> 电流不变的意外对称 W ⟹ J 对 N 精确偶 ⟹ 磁序在电流里不可见。** 每换一种 Néel 放法就冒出一个新
> 寄生对称(fixed-N 反演 或 N-even W),是 4 带玩具的内在毛病,不是代码错误。

**真实材料没有这种偶然对称**(用户已在 112-WF Fortran 求解器验证:H2 leakage 13→0.32 随 N 正确翻转)。
⟹ **决定:提前转路线 2,从 112-WF 下折叠 4 带**,它继承真实对称、保证 N-奇。
