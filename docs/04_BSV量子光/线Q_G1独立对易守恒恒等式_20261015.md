# G1 工作记录：独立的对易守恒恒等式（2026-10-15）

本轮不再做左右端口基变换、静态 \(U_0\) 归一化，也不再拆同一份 \(U,V\) Gram。没有改 Hamiltonian、\(\gamma\)、\(\eta\)、\(D\)、初态或光学环境，没有重跑 Γ12 传播，没有进入 G2/G3，没有把 \(U,V\) 配成正则。

生产残差仍是宏步 2048、九面板加最低极点红外尾之后的 \(R_N(0,0)=+1.606\times10^{-5}\)。本轮没有把它收成某一步的程序错误，也没有据此要求改理论。

## 1. 从冻结方程写出的恒等式

二次理论的正则坐标记为 \(d\)，包含电子准玻色子和一套完整的光子振子。附录 D 的条件是：单体矩阵 \(h=h^\dagger\)，配对 \(\mathfrak{D}=\mathfrak{D}^T\)。这时

\[
i\dot d=h d+\mathfrak{D} d^\dagger
\]

的 Nambu 传播 \(\mathcal{S}\) 满足 \(\mathcal{S}\Sigma\mathcal{S}^\dagger=\Sigma\)，\(\Sigma=\mathrm{diag}(I,-I)\)。选定的输出行再写成 \(U,V\)。这条恒等式的前提是输入列完备。删掉输入列、漏掉权重、删掉暗方向，或频率积分没有收敛，输出对易都会坏；传播本身保持辛结构也补不回缺失的输入测度。

电流片已经含连续谱的 Maxwell 回馈。约化变量 \((b,b^\dagger,A)\) 上的瞬时律是 \(\dot b=i u^T A\)、\(\dot A=\gamma I\)，\(I=u^*b+ub^\dagger-DA\)。这份 \(A\) 不是上面那套光子振子之外的第二份自场。\((b,b^\dagger,A)\) 本身不带一份非退化、不随时间变的辛形式。输出光子的对易要靠边界读出，不靠把这三个变量当成完整正则坐标。

边界读出沿用已经核过的片关系：两侧收到同一份自场，探测侧的稳态 \(U_0\) 在左行入射列上用片上场 \(a\)，在右行入射列上用 \(a-A_f\)。时间积分只累加电流历史。因此无驱动的时间积分应对准

\[
\phi(\omega)\,\frac{\sqrt{\omega}}{\eta}(A-A_f),
\]

左右端口是同一个数。左端口多出来的透射波留在 \(U_0\) 里，不在这份电流积分里。生产装配 \(U=U_0+\mathrm{raw}_{\mathrm{driven}}-\mathrm{raw}_{\mathrm{undriven}}\) 在无驱动时自动得到 \(U_0\)，因为两套顶点相同、相减为零。这个相减本身不证明时间积分等于上面的辐射片场。

有限振子浴的有色记忆核不是生产里的瞬时 \(\gamma\) 回馈。下面的封闭模型只用来检验二次生成元，不把它和生产残差直接相减。

## 2. 封闭二次模型

脚本 `q8_m0_g1_ccr_identity_20261015.py` 不调用生产 \(U,V\) 装配。系数取冻结的 \(\gamma=1.0807892763646022\times10^{-3}\)、\(\eta=1.3115370973561481\times10^{-2}\)，以及顶点最大的一条电子列，能隙 \(2.0246211251235318\)。光子是四个振子，频率 \(0.05,0.10,0.20,0.40\)，权重都是 \(0.25\)。耦合 \(g=\eta\sqrt{w/\omega}\) 只加一次。

\(h\) 的厄米偏差和配对的对称偏差都是 0。用矩阵指数传播到时间 1：

| 对象 | 最大绝对值 |
|---|---|
| \(\mathcal{S}\Sigma\mathcal{S}^\dagger-\Sigma\) | \(4.442441202370322\times10^{-16}\) |
| 全部输出的 \(UU^\dagger-VV^\dagger-I\) | \(6.661338147750939\times10^{-16}\) |
| 全部输出的 \(UV^T-VU^T\) | \(6.992893892674703\times10^{-18}\) |
| 删掉最高那个振子的输入列之后 | \(0.999992443905912\) |

删一列就破坏对易，说明恒等式要求输入完备。精确传播没有把丢掉的列补回来。

同一条冻结电流律写在 \((b,b^\dagger,A)\) 上，并取退化对易 \(\mathrm{diag}(1,-1,0,0)\)。时间 0 的偏差是 0，时间 0.1 是 \(6.359351430409253\times10^{-5}\)，时间 1 是 \(6.200539941880852\times10^{-4}\)。这与先前「\((q,p,A)\) 上没有一份守恒的非退化辛形式」是同一件结构事实，不是新的步进错误。

## 4. 这一轮能说什么

已经独立核到的是：完整二次生成元保持 \(\Sigma\)；输入缺一列时对易按缺列的大小坏掉；无驱动电流积分对准两侧相同的辐射片场，透射波留在左端口 \(U_0\)。生产装配把无驱动积分减掉，是为了不把这份辐射算两次。

还没有独立核到的是：驱动减去无驱动之后，剩余的 \(\Delta U,V\) 与这份 \(U_0\) 合在一起，为什么正常对易还剩 \(1.61\times10^{-5}\)。封闭振子模型给出的是 \(10^{-16}\) 或删列后的 \(O(1)\)，没有再现这个 \(10^{-5}\)。有限浴和瞬时 \(\gamma\) 先前约 \(0.087\) 的差别仍是两套模型的差别，本轮没有把它当成生产缺陷。

尚未排除、但本轮没有新数字的来源：时间模型之间约 \(5\times10^{-7}\) 的差别，以及比 \(h^6\) 更高、现有三档约束不住的项；Richardson 组合没有第二套保结构传播器；334 个小面板没有再加倍；包络外有限时间窗留下的 \(10^{-7}\)–\(10^{-6}\)（权重 1）还没有按生产权重求和。

下一项最低成本、而且分得开「边界不匹配」和「内部 Gram 重算」的测试：用现有宏步 2048 行，对最终九面板加红外尾，只累加 \((\mathrm{raw}_{\mathrm{undriven}}-\text{辐射片场})\) 的列外积。不要重跑传播。若这组和 \(1.6\times10^{-5}\) 差一个数量级以上，边界匹配就不是这笔残差的主要来源。

没有找到可以在冻结定义内直接改掉的程序错误，所以没有改代码、没有做回归。冻结定义之间也没有出现必须停下来改模型的冲突。G1 仍未通过。
