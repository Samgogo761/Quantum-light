## 3. 八个问题

**1. 完整 Hamiltonian 与 frozen spec。** 见 §1 与 `PT_AFM_TOY.md` §2：\(H_0=\varepsilon\tau_0+t_\perp\tau_x+\lambda\tau_z(\sin k_y s_x-\sin k_x s_y)+\Delta_N\tau_z s_z\)。未改。

**2. CPU reference 是否逐时幺正。** 是。step Gram 残差 \(<10^{-12}\)；\(0\le\rho\le I\) 到 \(10^{-10}\)。

**3. \(J_o\simeq 0\) 的量级。** 实验室 \(\max_t|J_o(t)|=1.6\times10^{-15}\)，\(|J_o(2\omega)|\sim10^{-15}\)；对照 \(|J_e(\omega)|=0.108\)。\(C_+(t,t')-C_-(t,t')\) 全两时最大 \(7.5\times10^{-16}\)，对照 \(\max|C_+|=0.010\)。

**4. 算符级还是期望级。** **CASE_C_map_dependent。** 代数事实：\(V=\tau_x s_z\) 满足 \(VH(+\Delta_N,\mathbf k)V^\dagger=H(-\Delta_N,\mathbf k)\)、\(Vj_xV^\dagger=j_x\)（残差 0），且 \(\rho_-(\mathbf k,t)=V\rho_+(\mathbf k,t)V^\dagger\)（\(2\times10^{-14}\)）。

| 共同基底映射 | \(\max\|\hat j_o\|_F\) | \(\tilde\rho_-\) vs \(\rho_+\) | \(C_{oo},C_{eo},C_{oe}\) |
|---|---:|---:|---|
| \(U_P=\tau_x\)，\(\mathbf k\to-\mathbf k\) | 4.0 | 0.21 | \(0.010,\;10^{-17},\;10^{-17}\) |
| \(V=\tau_x s_z\)，同 \(\mathbf k\) | 0 | \(10^{-14}\) | \(0,0,0\) 恒等 |

\(U_P\) 映射下 \(A=0\) 时 \(\hat j_o=j_x\)（残差 \(2\times10^{-16}\)），且 \(\hat j_o\) 与 \(\Delta_N\) 无关——它不是 Néel-奇算符。\(V\) 映射下 \(\hat J_o\equiv0\)。哪一个是理论 (10.4) 的 \(\mathcal U_N\)，本轮不定。

**5. 等时 Wick 与两时 \(t=t'\) 极限。** 一致，残差 \(7\times10^{-18}\)（\(<10^{-12}\) 门）。(7.10) 与 Heisenberg 形式在 \(t\ge t'\) 上一致 \(<10^{-12}\)。

**6. 四块 N 宇称。** 见 §0 第 2 条：(10.6)/(10.7) 在各自态中残差 \(10^{-17}\)；(10.9) 残差 \(8\times10^{-16}\)。\(P\) 映射下 \(C_{eo},C_{oe}\) 为 \(10^{-17}\)，\(C_{oo}\) 承载 \(0.010\)（几乎全部 \(C_+\)），\(C_{ee}=7\times10^{-4}\)；\(V\) 映射下 \(C_{ee}=C_+\)，其余恒零。**未**断言「\(C_{eo}\) N-奇」为 PASS/FAIL。

**7. CPU 两时耗时与内存。** nt=97：nk=16 一对算符一畴 2.2 s；nk=36（备忘上限）4.8 s。14-packet 诊断束 37 s / 81 s。峰值内存 \(<17\) MB；\(C(t,t')\) 矩阵 150 KB。有效 0.11 GFLOP/s。

**8. GPU_PRIORITY。** **LOW。** 瓶颈是 Python 调用开销；同一式 (7.10) 的 \(k\)-批量 einsum 是第一步（预计 \(10^2\) 倍），GPU 只在之后 nt 或参数扫描真的变大时才有意义。
