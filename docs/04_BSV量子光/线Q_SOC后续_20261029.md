## 4. 建议的论文叙事，避免前后矛盾

1. **问题：** 非经典入射统计如何经 Néel/SOC 控制的电子通道，变成 H2 复电流。
2. **结构：** \(J=\mathrm{Tr}(\rho_{\mathrm{ph}}K)\) 给出 A/B/C；位移后 Δn=0 与 Δn=±2。
3. **输入窗口：** R≳1 才有 O(1) 干涉；这解释了为何旧 Q6 有 110°、1600 nm 80%/20% 没有。
4. **电子门控：** Néel 与 SOC 打开奇通道并缩放 \|K\|。Δ=0 是定义检验；SOC=0 是动力学门控，须同时报能隙。
5. **相位：** 主窗 arg(B) = 有限时间核 + Ehrenfest，不是平衡 χ⁽²⁾。相对相位 arg(A/B) 钉在输入几何 π 上，SOC 拉不开。
6. **量子映射余量：** 精确 QED 把奇 \(K_B\) 压低 O(10%)，不增强 M。
7. **材料：** 1600 nm 存在磁性 H2；M52/M88/full112 定量未收敛；WINDOW144 说明 full112 并非完备极限。

不要把 4 写成“新磁性选择定则”，不要把 5 的 π 钉死写成失败。钉死本身就是可证伪结论。
