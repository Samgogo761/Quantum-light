## 1. 现在站在哪

M0/R0 未改。P0 仍是共振对照。P1 三点经典试验已做完。真正量子光尚未开始。

P1 的中心频率满足 \(E_g^{\rm dir}/\hbar\omega_1\approx1.85\)。实际 \(E(t)\) 连续谱在隙上的权重为 **\(2.0683\times10^{-6}\)**，所以这是干净的**中心频率亚带隙**协议，不是「已经证明两光子过程主导」，也不是严格零隙上尾巴。

## 2. 等入射场资源时，电子侧发生了什么

P0 与 P1 \(A^*=0.8\) 的 \(F_E=\int E^2dt\) 相同（比值 1.000），脉冲长度变为 4 倍。

在 nk=96、**N=+1**：P0 峰值激发 7.4%、\(\Delta U_e=0.0852\,t_h\)；P1 \(A^*=0.8\) 峰值激发 9.16%、\(\Delta U_e=0.192\,t_h\)（nk96/nk96 比值 **2.25**）。与档案 P0 nk192 功积分 0.08839 相比约 **2.17**。概括为约 2.2 倍半定量证据，比值尚未最终收敛。等入射资源下电子吸收更多，本身就是对照结果，不是把 \(F_E\) 用错了。

这些因素都与结果相容，尚未辨别主因：更长脉冲的相干积累；两光子及更高阶通道在能量上开放；k 空间走得更远（\(\Delta k\) 为 P0 的两倍）。不要凭偏好选出事实。

同一 nk96 诊断峰时刻，局部 \(n_{\rm exc}(k_0)/4\) 最大 49.95%，超过 25% 的 k 占 17%。整体 9% 不是处处弱激发。

## 3. 三点 \(A^*\) 在说什么

同一 nk=48 上：\(A^*=0.4\) 激发 4.5%、\(\Delta U_e=0.056\)；\(0.8\) 为 9.4%/0.185；\(1.6\) 为 15.8%/0.723。没有一个是空响应，也没有一个把价带打空。

\(J_{o,y}(0)\) 在这张粗网格上对 \(A^*\) 非单调（0.8 最大）。所以不能按「最大场」或「最大 \(|J_o|\)」选量子工作点。\(A^*=1.6\) 更强，但不更干净。

## 4. 电流哪些量可以引用

- **可引用（研究候选，非偶次定量基线）**：P0 与 P1 \(A^*=0.8\) 的激发、\(\Delta U_e\)、\(J_{e,x}(H_1)\)（P1 的 48→96 复振幅 0.712%）。nk=48 上时间步对这些量不是问题。
- **非零候选、未到 1%**：P0 的 \(J_{o,y}(0)\) 与 \(J_o(H_2)\)。档案 nk=192：144→192 复振幅 \(J_{o,y}(H_2)\) 2.02%、\(J_{o,x}(H_2)\) 3.67%、\(J_{e,x}(H_1)\) 0.155%。P0 未整体按本轮 5% 三检查验收。
- **不要当精度结果**：P1 的 \(J_{o,y}(H_2)\)（复振幅 85.5%）和 \(J_{o,x}(H_2)\)（258%，相位变 58°）。两个分量必须分开报。

同阶谐波对应不同 \(\hbar\Omega\)。P1 的 \(H_1\) 在 \(0.05t_h\)，P0 的 \(H_1\) 在 \(0.2t_h\)。没有 plateau。这不是失败条件。

## 5. 子空间定位（nk=48，不是机制证明）

P1 \(A^*=0.8\) 的 \(J_{o,y}(0)\) 几乎全在 \(vv+cc\)，\(vc\) 小两个数量级。P0 的 \(J_o(H_2)\) 则是 \(vc\) 块最大，并且 BZ 求和有相消。因此 **DC 与 \(H_2\) 不必来自同一类子空间贡献**。k 图标的是初始 \(\mathbf k_0\)。不能由此宣布 injection、shift 或 Berry。未收敛的 P1 H2 分块比例也未证明已收敛。

## 6. 建议你怎么用这些点

把 **P1、\(A^*=0.8\)** 当作以后比较 coherent / squeezed / BSV 的经典主参考点**候选**；把 **P0** 留作一光子开放对照。在 \(J_o(H_2)\) 通过有限数值资格以前，不要用它作精确量子增强分母。\(A^*=0.4/1.6\) 是已经算完的同频率对照，不再加扫。

偶次电流非零可以只表现为两畴相位差：若 \(b_\pm=b_e\pm b_o\)，则 \(|b_+|^2-|b_-|^2=4\mathrm{Re}(b_e^*b_o)\)。\(b_o\neq0\) 不必给出光强磁畴对比。
