# 线 Q：P0/P1 一页读数（2026-09-14）

数字来自同日试验报告与 `results/q_line/m0_p0p1_20260914/`。本页只把它们放在一起，供你判断区间含义。不宣布 HHG 机制，不宣布量子优势。`quantum_input = not_run`。

## 1. 现在站在哪

M0/R0 未改。P0 仍是共振对照。P1 三点经典试验已做完。真正量子光尚未开始。

P1 的中心频率满足 \(E_g^{\rm dir}/\hbar\omega_1\approx1.85\)。实际 \(E(t)\) 频谱在隙上的权重 \(\sim10^{-11}\)，所以这是干净的**中心频率亚带隙**协议，不是「已经证明两光子过程主导」。

## 2. 等入射场资源时，电子侧发生了什么

P0 与 P1 \(A^*=0.8\) 的 \(F_E=\int E^2dt\) 相同（比值 1.000），脉冲长度变为 4 倍。

在 nk=96：P0 峰值激发 7.4%、\(\Delta U_e=0.085\,t_h\)；P1 \(A^*=0.8\) 峰值激发 9.2%、\(\Delta U_e=0.192\,t_h\)（约为 P0 的 **2.25 倍**）。等入射资源下电子吸收更多，本身就是对照结果，不是把 \(F_E\) 用错了。

备选解释（请你选，不要让计算代替）：更长脉冲的相干积累；两光子及更高阶通道在能量上开放；k 空间走得更远（\(\Delta k\) 为 P0 的两倍）。本轮数据不能单独指定哪一个为主。

## 3. 三点 \(A^*\) 在说什么

同一 nk=48 上：\(A^*=0.4\) 激发 4.5%、\(\Delta U_e=0.056\)；\(0.8\) 为 9.4%/0.185；\(1.6\) 为 15.8%/0.723。没有一个是空响应，也没有一个把价带打空。

\(J_{o,y}(0)\) 在这张粗网格上对 \(A^*\) 非单调（0.8 最大）。所以不能按「最大场」或「最大 \(|J_o|\)」选量子工作点。\(A^*=1.6\) 更强，但不更干净。

## 4. 电流哪些量可以引用

- **可引用**：P0 与 P1 \(A^*=0.8\) 的激发、\(\Delta U_e\)、\(J_{e,x}(H_1)\)（P1 的 48→96 只有 0.7%）。时间步对这些量不是问题。
- **非零候选、未到 1%**：P0 的 \(J_{o,y}(0)\) 与 \(J_o(H_2)\)。移位网格仍非零，但 nk=48 上可差 40–80%。档案 nk=192 仍是 P0 总量的最好记录。
- **不要当精度结果**：P1 的 \(J_o(H_2)\)（48→96 变化 45–66%）。

同阶谐波对应不同 \(\hbar\Omega\)。P1 的 \(H_1\) 在 \(0.05t_h\)，P0 的 \(H_1\) 在 \(0.2t_h\)。没有 plateau。这不是失败条件。

## 5. 子空间定位（nk=48，不是机制证明）

P1 \(A^*=0.8\) 的 \(J_{o,y}(0)\) 几乎全在 \(vv+cc\)，\(vc\) 小两个数量级。P0 的 \(J_o(H_2)\) 则是 \(vc\) 块最大，并且 BZ 求和有相消。因此 **DC 与 \(H_2\) 不必来自同一类子空间贡献**。k 图标的是初始 \(\mathbf k_0\)。不能由此宣布 injection、shift 或 Berry。

## 6. 建议你怎么用这些点

把 **P1、\(A^*=0.8\)** 当作以后比较 coherent / squeezed / BSV 的经典主参考点候选（等入射场能量原则与之对齐）；把 **P0** 留作一光子开放对照。\(A^*=0.4/1.6\) 是已经算完的同频率对照，不再加扫。

这只说明：有一个可核验、不太饱和、中心频率亚带隙的物质响应。它不证明该点量子统计效应最大，也不证明相对相干态的增强无法被经典强度涨落解释。
