## 0. 先给出结论：本课题必须分成三层，而不是两层混写

本课题涉及三个不同问题。

### 层 A：量子输入对平均 HHG 谱的影响

这一层把输入量子态的 Husimi-\(Q\) 相空间分布映射成许多经典驱动轨迹，再对每条轨迹的 HHG 强度作非相干平均：

\[
\boxed{
\overline S_n(\mathbf N)
=
\int d^{2M}\boldsymbol\alpha\,
Q_{\rm in}(\boldsymbol\alpha)\,
S_n^{\rm cl}[\boldsymbol\alpha;\mathbf N].
}
\tag{0.1}
\]

式中：

- \(n\) 是谐波阶数；
- \(\mathbf N\) 是双层 AFM 的 Néel 矢量；
- \(M\) 是保留的输入时域模式数；
- \(\boldsymbol\alpha=(\alpha_1,\ldots,\alpha_M)\) 是多模复相干振幅；
- \(Q_{\rm in}\) 是输入量子态的 Husimi-\(Q\) 函数；
- \(S_n^{\rm cl}\) 是由经典场 \(\boldsymbol\alpha\) 驱动 SBE 得到的第 \(n\) 阶谐波强度。

这一层回答平均强度、平台、截止和平均磁性通道，不足以证明输出光压缩、亚泊松统计或纠缠。

### 层 B：输出谐波的 Gaussian 二阶量子统计

这一层先定义有限带宽的量子化谐波探测模式，再计算

\[
\boxed{
\beta_n=\langle\hat b_n\rangle,\qquad
N_{nm}=\langle\Delta\hat b_n^\dagger\Delta\hat b_m\rangle,\qquad
M_{nm}=\langle\Delta\hat b_n\Delta\hat b_m\rangle .
}
\tag{0.2}
\]

式中：

- \(\hat b_n\) 是以 \(n\omega_0\) 为中心的归一化输出模式湮灭算符；
- \(\beta_n\) 是输出模式的相干位移；
- \(\Delta\hat b_n=\hat b_n-\beta_n\)；
- \(N_{nm}\) 是正常协方差；
- \(M_{nm}\) 是反常协方差。

两时电流关联可以决定这些二阶矩，因此可以严格研究正交分量噪声，并在 Gaussian 假设下研究 Gaussian 纠缠。

### 层 C：非 Gaussian 的精确光子统计

精确二阶光子关联是四算符量：

\[
\boxed{
g^{(2)}_{nm}
=
\frac{
\langle
\hat b_n^\dagger\hat b_m^\dagger
\hat b_m\hat b_n
\rangle
}{
\langle\hat n_n\rangle
\langle\hat n_m\rangle
},
\qquad
\hat n_n=\hat b_n^\dagger\hat b_n .
}
\tag{0.3}
\]

一般情况下，式 (0.3) 需要四时电流关联；只有输出近似 Gaussian 时，才能用 Wick 定理从式 (0.2) 重构。

因此，正确研究顺序是

\[
\boxed{
\text{Husimi-}Q\text{ 平均谱}
\ \longrightarrow\
\text{二阶量子输出 }(\beta,N,M)
\ \longrightarrow\
\text{四点统计与非 Gaussian 验证}.
}
\tag{0.4}
\]

**图 0.1**　平均谱层与输出量子统计层的逻辑边界。图中“层 II”再细分为本文所说的 B、C 两层。

## 1. 记号、约定与不能混用的对象

### 1.1 光场与材料对象

本文使用以下记号：

| 记号 | 定义 |
|---|---|
| \(\omega_0\) | 驱动光中心角频率 |
| \(n,m\) | 谐波阶数或谐波探测模式标签 |
| \(\mathbf N\) | Néel 矢量；\(+\mathbf N\) 与 \(-\mathbf N\) 表示两个 AFM 磁畴 |
| \(\hat\rho_{\rm mat}\) | 完整多电子物质密度算符 |
| \(\rho_{\mathbf k}\) | SBE 中的单粒子约化密度矩阵 |
| \(\hat J_a(t)\) | 沿 Cartesian 方向 \(a\) 的多电子电流算符 |
| \(J_a(t)=\langle\hat J_a(t)\rangle\) | 平均电流 |
| \(\hat a_\lambda(\omega)\) | 连续辐射场模式的湮灭算符 |
| \(\hat b_n\) | 经过偏振、频率和时间滤波后定义的第 \(n\) 个探测模式 |
| \(\Delta\hat O=\hat O-\langle\hat O\rangle\) | 任意算符 \(\hat O\) 的涨落 |

必须始终区分：

\[
\boxed{
\hat\rho_{\rm mat}\neq\rho_{\mathbf k},
\qquad
\hat J(t)\neq J(t),
\qquad
\hat b_n\neq J_n .
}
\tag{1.1}
\]

式中 \(J_n\) 是经典电流的 Fourier 复振幅，而 \(\hat b_n\) 是满足玻色对易关系的光场算符。

### 1.2 正交分量约定

定义单模正交分量

\[
\boxed{
\hat x_n=\frac{\hat b_n+\hat b_n^\dagger}{\sqrt2},
\qquad
\hat p_n=\frac{\hat b_n-\hat b_n^\dagger}{i\sqrt2}.
}
\tag{1.2}
\]

这里真空方差为

\[
\boxed{
\operatorname{Var}_{\rm vac}(\hat x_n)
=
\operatorname{Var}_{\rm vac}(\hat p_n)
=\frac12 .
}
\tag{1.3}
\]

后文所有压缩、辛本征值和不确定性关系均采用这个归一化。

### 1.3 三种算符排序

量子光探测会遇到三种不同排序：

\[
\boxed{
\begin{aligned}
&\text{正常序：}&&
\langle:\hat O:\rangle ,
\\
&\text{反正常序：}&&
\langle\vdots\hat O\vdots\rangle ,
\\
&\text{对称序：}&&
\frac12\langle\hat A\hat B+\hat B\hat A\rangle .
\end{aligned}
}
\tag{1.4}
\]

正常序对应理想直接光子计数；对称序对应 homodyne 正交分量协方差；Husimi-\(Q\) 自然生成反正常序矩。因此，未标注排序的

\[
\langle\Delta\hat J(t)\Delta\hat J(t')\rangle
\]

不足以唯一决定实验可观测量。

## 2. 输入量子光：从单模态到多时域模

### 2.1 归一化时域模式

一个超短脉冲不是无限时间的单频平面波。选择一组正交时域模式 \(u_\mu(t)\)，满足

\[
\boxed{
\int_{-\infty}^{\infty}
dt\,u_\mu^*(t)u_\nu(t)
=\delta_{\mu\nu}.
}
\tag{2.1}
\]

式中：

- \(\mu,\nu=1,\ldots,M\) 是输入时域模式标签；
- \(M\) 是截取的时域模式数；
- \(\delta_{\mu\nu}\) 是 Kronecker delta。

对应的湮灭算符满足

\[
\boxed{
[\hat a_\mu,\hat a_\nu^\dagger]
=\delta_{\mu\nu}.
}
\tag{2.2}
\]

实际电场正频部分可写为

\[
\boxed{
\hat E_{\rm drv}^{(+)}(t)
=
\sum_{\mu=1}^{M}
\mathcal E_\mu\,
u_\mu(t)e^{-i\omega_\mu t}
\hat a_\mu .
}
\tag{2.3}
\]

式中：

- \(\mathcal E_\mu\) 是单光子场归一化因子；
- \(\omega_\mu\) 是模式中心频率；
- \(\hat E_{\rm drv}^{(-)}=[\hat E_{\rm drv}^{(+)}]^\dagger\)；
- 总电场为 \(\hat E_{\rm drv}=\hat E_{\rm drv}^{(+)}+\hat E_{\rm drv}^{(-)}\)。

要把代码中的峰值强度映射成真实的 \(\alpha_\mu\)、光子数和压缩参数，必须给出有效光斑面积、脉冲能量及模式函数归一化。只有峰值强度 \(I_0\) 不足以唯一确定 \(\alpha_\mu\)。

### 2.2 相干态、热态与压缩真空

#### 相干态

相干态 \(|\alpha\rangle\) 定义为

\[
\boxed{
\hat a|\alpha\rangle=\alpha|\alpha\rangle .
}
\tag{2.4}
\]

式中 \(\alpha\in\mathbb C\) 是复相干振幅，平均光子数为

\[
\boxed{
\bar n_{\rm coh}=|\alpha|^2.
}
\tag{2.5}
\]

#### 单模压缩真空

定义压缩算符

\[
\boxed{
\hat S(\xi)
=
\exp\!\left[
\frac12
\left(
\xi^*\hat a^2-\xi\hat a^{\dagger2}
\right)
\right],
\qquad
\xi=re^{i\theta_s}.
}
\tag{2.6}
\]

式中：

- \(r\ge0\) 是压缩参数；
- \(\theta_s\) 是压缩角。

单模压缩真空为

\[
\boxed{
|{\rm SV}\rangle=\hat S(\xi)|0\rangle .
}
\tag{2.7}
\]

其平均光子数和反常矩分别为

\[
\boxed{
N_{\rm in}
=
\langle\hat a^\dagger\hat a\rangle
=\sinh^2r,
\qquad
M_{\rm in}
=
\langle\hat a\hat a\rangle
=-e^{i\theta_s}\sinh r\cosh r .
}
\tag{2.8}
\]

式中负号取决于式 (2.6) 的压缩算符 convention；所有数值模块必须固定同一 convention。

单模压缩真空的光子数展开为

\[
\boxed{
|{\rm SV}\rangle
=
\frac1{\sqrt{\cosh r}}
\sum_{\ell=0}^{\infty}
\frac{\sqrt{(2\ell)!}}{2^\ell\ell!}
\left(-e^{i\theta_s}\tanh r\right)^\ell
|2\ell\rangle .
}
\tag{2.9}
\]

所以它只含偶数光子数分量。其零延迟二阶关联为

\[
\boxed{
g_{\rm SV}^{(2)}(0)
=3+\frac1{N_{\rm in}}.
}
\tag{2.10}
\]

高亮度极限 \(N_{\rm in}\gg1\) 下，\(g^{(2)}\to3\)，而单模热态为 \(g^{(2)}=2\)。

#### 位移压缩态

定义位移算符

\[
\boxed{
\hat D(\alpha_0)
=
\exp(\alpha_0\hat a^\dagger-\alpha_0^*\hat a).
}
\tag{2.11}
\]

位移压缩态为

\[
\boxed{
|\alpha_0,\xi\rangle
=\hat D(\alpha_0)\hat S(\xi)|0\rangle .
}
\tag{2.12}
\]

式中 \(\alpha_0\) 是相干位移。它不同于均值为零的纯 BSV。

### 2.3 \(P\)、Wigner 与 Husimi-\(Q\) 表示

Glauber–Sudarshan \(P\) 表示定义为

\[
\boxed{
\hat\rho
=
\int d^2\alpha\,
P(\alpha)
|\alpha\rangle\langle\alpha|.
}
\tag{2.13}
\]

若 \(P(\alpha)\) 是普通、非负概率密度，则该光场在相干态混合意义下是经典的。

Husimi-\(Q\) 函数定义为

\[
\boxed{
Q(\alpha)
=
\frac1\pi
\langle\alpha|\hat\rho|\alpha\rangle,
\qquad
\int d^2\alpha\,Q(\alpha)=1 .
}
\tag{2.14}
\]

必须注意：

\[
\boxed{
\hat\rho
\neq
\int d^2\alpha\,
Q(\alpha)|\alpha\rangle\langle\alpha|
\quad\text{（一般不成立）}.
}
\tag{2.15}
\]

\(Q\) 函数生成反正常序矩。例如

\[
\boxed{
\int d^2\alpha\,
Q(\alpha)|\alpha|^2
=
\langle\hat a\hat a^\dagger\rangle
=
\langle\hat n\rangle+1.
}
\tag{2.16}
\]

因此，式 (0.1) 不是由“\(Q\) 是相干态经典混合”这一错误恒等式得到的；它来自 Gorlach 等人在特定大体积、强驱动和对角近似下的 HHG 推导。

### 2.4 Gaussian 输入态的 \(Q\) 采样

定义多模正交分量向量

\[
\boxed{
\hat{\boldsymbol R}
=
(\hat x_1,\hat p_1,\ldots,\hat x_M,\hat p_M)^T .
}
\tag{2.17}
\]

其位移和物理协方差矩阵为

\[
\boxed{
\boldsymbol d
=
\langle\hat{\boldsymbol R}\rangle,
\qquad
V_{ij}
=
\frac12
\langle
\Delta\hat R_i\Delta\hat R_j
+
\Delta\hat R_j\Delta\hat R_i
\rangle .
}
\tag{2.18}
\]

Gaussian 态的 Husimi 协方差是

\[
\boxed{
V_Q=V+\frac12 I_{2M}.
}
\tag{2.19}
\]

式中 \(I_{2M}\) 是 \(2M\) 维单位矩阵。

令

\[
\boldsymbol\xi
=
\sqrt2(
\operatorname{Re}\alpha_1,\operatorname{Im}\alpha_1,
\ldots,
\operatorname{Re}\alpha_M,\operatorname{Im}\alpha_M
)^T .
\]

以 \(d^{2M}\boldsymbol\xi\) 为测度的 \(Q\) 概率密度为

\[
\boxed{
q_Q(\boldsymbol\xi)
=
\frac{
\exp[
-\tfrac12
(\boldsymbol\xi-\boldsymbol d)^T
V_Q^{-1}
(\boldsymbol\xi-\boldsymbol d)
]
}{
(2\pi)^M\sqrt{\det V_Q}
}.
}
\tag{2.20}
\]

采样算法为

\[
\boxed{
\boldsymbol\xi
=
\boldsymbol d+L\boldsymbol z,
\qquad
LL^T=V_Q,
\qquad
\boldsymbol z\sim\mathcal N(\boldsymbol0,I_{2M}).
}
\tag{2.21}
\]

其中 \(L\) 可由 Cholesky 分解得到。

### 2.5 当前代码的“BSV”分布并非真正的单模 BSV

当前 `src/mod_quantum_light.f90` 实现

\[
\boxed{
p_{\rm code}(I)
=
\frac1{2I_{\rm bar}}
\exp\!\left(-\frac{I}{2I_{\rm bar}}\right),
\qquad
\phi\sim U(0,2\pi).
}
\tag{2.22}
\]

式中：

- \(I\) 是单条经典轨迹的峰值强度；
- \(I_{\rm bar}\) 是代码参数；
- \(\langle I\rangle_{\rm code}=2I_{\rm bar}\)；
- \(\phi\) 是均匀随机 CEP。

这一分布对应圆对称复 Gaussian/指数强度轨迹集，在高亮度相空间意义上更接近热光型随机场，而不是固定压缩角的单模 BSV。

单模压缩真空的精确 Husimi-\(Q\) 是椭圆 Gaussian。按式 (2.17) 的正交分量 convention，其

\[
\boxed{
V_Q^{\rm SV}
=
\frac12
\begin{pmatrix}
1+e^{-2r}&0\\
0&1+e^{2r}
\end{pmatrix}
}
\tag{2.23}
\]

需要先按压缩角 \(\theta_s/2\) 旋转，再采样两个不等方差的正交分量。

在强压缩、单有效模式且以平均强度 \(\bar I\) 归一化时，其主轴强度边缘近似

\[
\boxed{
p_{\rm SV}(I)
\simeq
\frac1{\sqrt{2\pi\bar I I}}
\exp\!\left(-\frac{I}{2\bar I}\right).
}
\tag{2.24}
\]

式 (2.24) 是一自由度 \(\chi^2\) 型分布，满足

\[
\boxed{
\langle I^q\rangle
=(2q-1)!!\,\bar I^q ,
\qquad
\frac{\langle I^2\rangle}{\langle I\rangle^2}=3 .
}
\tag{2.25}
\]

而式 (2.22) 的指数分布满足

\[
\boxed{
\langle I^q\rangle
=q!\,\langle I\rangle^q,
\qquad
\frac{\langle I^2\rangle}{\langle I\rangle^2}=2 .
}
\tag{2.26}
\]

所以二者从第二阶矩开始就不同。

## 3. 层 A：Husimi-\(Q\) 非相干平均谱

### 3.1 单条相空间轨迹的经典场

对单模输入，写

\[
\boxed{
\alpha=\frac{X+iP}{\sqrt2}
=|\alpha|e^{i\phi}.
}
\tag{3.1}
\]

式中：

- \(X\) 与 \(P\) 是两个正交分量；
- \(\phi=\arg\alpha\) 是相空间相位。

对应的经典场可写成

\[
\boxed{
E_\alpha(t)
=
2\operatorname{Re}
\left[
\mathcal E_1\alpha\,
u(t)e^{-i\omega_0t}
\right].
}
\tag{3.2}
\]

式中：

- \(u(t)\) 是归一化脉冲包络；
- \(\mathcal E_1\) 是由光斑、模式体积或时域模式归一化决定的单光子场强；
- \(\omega_0\) 是驱动中心角频率。

对多模输入，

\[
\boxed{
E_{\boldsymbol\alpha}(t)
=
2\operatorname{Re}
\left[
\sum_{\mu=1}^{M}
\mathcal E_\mu\alpha_\mu
u_\mu(t)e^{-i\omega_\mu t}
\right].
}
\tag{3.3}
\]

只采样 \(I\) 而不采样 \(\arg\alpha_\mu\) 会丢失压缩角、CEP、模间相位和偏振相关信息。

### 3.2 单条轨迹的 HHG 复振幅与强度

定义窗函数 \(W(t)\) 及第 \(n\) 阶复电流

\[
\boxed{
J_{n,a}(\boldsymbol\alpha;\mathbf N)
=
\int_{t_i}^{t_f}
dt\,
W(t)\,
e^{in\omega_0t}
J_a(t;\boldsymbol\alpha,\mathbf N).
}
\tag{3.4}
\]

式中：

- \(a\in\{x,y,z\}\) 是电流方向；
- \(t_i,t_f\) 是传播起止时刻；
- \(J_a(t;\boldsymbol\alpha,\mathbf N)\) 是 SBE 平均电流；
- \(W(t)\) 是 Hann 等时间窗。

给定实验几何后的单轨迹谱写为

\[
\boxed{
S_n^{\rm cl}(\boldsymbol\alpha;\mathbf N)
=
\sum_a
\mathcal C_{n,a}
|J_{n,a}(\boldsymbol\alpha;\mathbf N)|^2 .
}
\tag{3.5}
\]

式中 \(\mathcal C_{n,a}\) 含辐射几何、\(\omega_n^2\) 或 \(\omega_n^4\) 因子及单位换算。代码与论文必须明确使用的谱 convention。

### 3.3 非相干平均与相干平均不同

Gorlach 型非相干平均为

\[
\boxed{
S_n^{\rm ICS}(\mathbf N)
=
\int d^{2M}\boldsymbol\alpha\,
Q_{\rm in}(\boldsymbol\alpha)
S_n^{\rm cl}(\boldsymbol\alpha;\mathbf N).
}
\tag{3.6}
\]

其中 ICS 表示 incoherent combination of spectra。

若先平均复电流再取模平方，则得到

\[
\boxed{
S_n^{\rm CS}(\mathbf N)
=
\sum_a\mathcal C_{n,a}
\left|
\int d^{2M}\boldsymbol\alpha\,
Q_{\rm in}(\boldsymbol\alpha)
J_{n,a}(\boldsymbol\alpha;\mathbf N)
\right|^2 .
}
\tag{3.7}
\]

其中 CS 表示 coherent sum。

二者之差为经典轨迹复振幅的统计方差：

\[
\boxed{
S_n^{\rm ICS}-S_n^{\rm CS}
=
\sum_a\mathcal C_{n,a}
\left[
\langle|J_{n,a}|^2\rangle_Q
-|\langle J_{n,a}\rangle_Q|^2
\right]
\ge0 .
}
\tag{3.8}
\]

式 (3.8) 不能命名为“纯量子谱”或 `S_quant`，因为普通经典随机脉冲也可产生同样的差。

### 3.4 式 (3.6) 的适用条件

Husimi-\(Q\) 平均是受控近似，不是任意量子光可观测量的恒等式。应明确列出：

1. 初始光场与物质可分离；
2. 输入量子光由有限个强占据时域模式描述；
3. 其余辐射模式初始为真空；
4. 驱动反作用和自发辐射对平均谱为高阶修正；
5. 不同 \(\boldsymbol\alpha\) 分量之间的非对角相干在所用极限下被忽略；
6. 每个 \(\boldsymbol\alpha\) 条件下的物质动力学可由经典 SBE 表示；
7. 探测量是平均谱，而不是完整输出态。

González-Monge 与 Feist 的时域模预印本表明：在其自由空间、大光子数参数下，对平均谱的 temporal-mode 修正小于 \(10^{-4}\)。这个数值来自特定体系，不能直接套用到 \(3200\,{\rm nm}\) CrI\(_3\)，但它提示自由空间平均谱的量子修正可能很小。

### 3.5 二维相空间何时可以约化为一维强度积分

定义径向变量 \(r=|\alpha|\) 和相位 \(\phi\)。只有数值验证

\[
\boxed{
S_n^{\rm cl}(re^{i\phi};\mathbf N)
\simeq
S_n^{\rm cl}(r;\mathbf N)
\quad
\text{对所有有权重的 }\phi
}
\tag{3.9}
\]

后，才可定义径向边缘

\[
\boxed{
P_Q(r)
=
r\int_0^{2\pi}
d\phi\,Q(re^{i\phi})
}
\tag{3.10}
\]

并写成

\[
\boxed{
\overline S_n
=
\int_0^\infty dr\,
P_Q(r)S_n^{\rm cl}(r).
}
\tag{3.11}
\]

有限脉冲、CEP 敏感、双频、椭圆偏振和磁性偶次谐波都可能使式 (3.9) 失效。因此当前固定 CEP 的一维 Gauss–Laguerre 强度求积必须先通过相位扫描。

### 3.6 正确的数值求积

#### Monte Carlo

用式 (2.21) 产生 \(N_s\) 个样本 \(\boldsymbol\xi_s\)，等权估计

\[
\boxed{
\overline S_n
\approx
\frac1{N_s}
\sum_{s=1}^{N_s}
S_n^{\rm cl}(\boldsymbol\xi_s).
}
\tag{3.12}
\]

#### Gaussian 确定性求积

对少模 Gaussian 输入，可使用稀疏 Gauss–Hermite 或准 Monte Carlo：

\[
\boxed{
\overline S_n
\approx
\sum_{s=1}^{N_q}
w_s S_n^{\rm cl}(\boldsymbol\xi_s),
\qquad
\sum_s w_s=1 .
}
\tag{3.13}
\]

式中 \(N_q\) 是节点数，\(w_s\) 是归一化权重。

每套节点必须通过输入态矩检验：

\[
\boxed{
\sum_s w_s\,\boldsymbol\xi_s
\simeq\boldsymbol d,
\qquad
\sum_s w_s
(\boldsymbol\xi_s-\boldsymbol d)
(\boldsymbol\xi_s-\boldsymbol d)^T
\simeq V_Q .
}
\tag{3.14}
\]

对 BSV 还应至少检查二阶和四阶强度矩。

### 3.7 磁畴必须共享同一组相空间节点

对每个节点 \(s\)，分别运行 \(+\mathbf N\) 与 \(-\mathbf N\)，定义

\[
\boxed{
J_{e,n}^{(s)}
=
\frac{
J_n^{(s)}(+\mathbf N)
+
J_n^{(s)}(-\mathbf N)
}{2},
\qquad
J_{o,n}^{(s)}
=
\frac{
J_n^{(s)}(+\mathbf N)
-
J_n^{(s)}(-\mathbf N)
}{2}.
}
\tag{3.15}
\]

式中：

- 下标 \(e\) 表示对磁畴反转为偶；
- 下标 \(o\) 表示对磁畴反转为奇；
- 上标 \(s\) 表示相同的输入相空间节点。

必须使用相同 \((\boldsymbol\xi_s,w_s)\)，否则 Monte Carlo 差分噪声会污染 \(J_o\)。

实际磁畴强度差是

\[
\boxed{
\Delta_NS_n
=
\frac12
\int d^{2M}\boldsymbol\alpha\,
Q_{\rm in}
\left[
|J_n(+\mathbf N)|^2
-
|J_n(-\mathbf N)|^2
\right].
}
\tag{3.16}
\]

一般有

\[
\boxed{
\Delta_NS_n
\neq
\int d^{2M}\boldsymbol\alpha\,
Q_{\rm in}|J_{o,n}|^2 .
}
\tag{3.17}
\]

### 3.8 这一层可计算的“经典输出相关”

若人为把每个轨迹映射成输出相干态振幅

\[
\gamma_n(\boldsymbol\alpha)
=\kappa_nJ_n(\boldsymbol\alpha),
\]

则可以构造一个**经典替代模型**

\[
\boxed{
\hat\rho_{\rm out}^{\rm mix}
=
\int d^{2M}\boldsymbol\alpha\,
Q_{\rm in}(\boldsymbol\alpha)
|\boldsymbol\gamma(\boldsymbol\alpha)\rangle
\langle\boldsymbol\gamma(\boldsymbol\alpha)|.
}
\tag{3.18}
\]

这里 \(\kappa_n\) 是材料电流到探测模式振幅的比例因子。式 (3.18) 不是一般量子输出态，而是用于建立 classical-mixture benchmark 的构造。

它给出

\[
\boxed{
g_{nm,{\rm mix}}^{(2)}
=
\frac{
\int Q\,
|\gamma_n|^2|\gamma_m|^2\,d^{2M}\boldsymbol\alpha
}{
\left(\int Q|\gamma_n|^2d^{2M}\boldsymbol\alpha\right)
\left(\int Q|\gamma_m|^2d^{2M}\boldsymbol\alpha\right)
}.
}
\tag{3.19}
\]

式 (3.19) 可以大于 1，表示经典聚束；但正权重相干态混合不能给出：

\[
\boxed{
g_{nn}^{(2)}<1,\qquad
Q_n^{\rm Mandel}<0,\qquad
V_{\min}<\frac12,
}
\tag{3.20}
\]

也不能违反经典正常序 Cauchy–Schwarz 不等式。
