## 1. 模型定义（与任务单一致，逐项核对过）

基底 \((tA\!\uparrow,tA\!\downarrow,tB\!\uparrow,tB\!\downarrow,bA\!\uparrow,bA\!\downarrow,bB\!\uparrow,bB\!\downarrow)\)。嵌入 Bloch 约定 \(H_{ab}(\mathbf k)=\sum_{\mathbf R}t_{ab}(\mathbf R)e^{i\mathbf k\cdot(\mathbf R+\boldsymbol\tau_b-\boldsymbol\tau_a)}\)，\(\mathbf k\) 为 Å\(^{-1}\)，\(k_z=0\)。代码单位 \(\hbar=e=1\)，能量 \(t_h\)，长度 Å，时间 \(\hbar/t_h\)（\(t_h=1\,\)eV 时 0.658 fs）。

\[
h_{\ell,N}=t_h[\mathrm{Re}f\,\sigma_x-\mathrm{Im}f\,\sigma_y]s_0+\lambda_{\rm SO}g\,\sigma_zs_z+N\eta_\ell\Delta\,\sigma_0s_z,\qquad
f=e^{i\mathbf k\cdot\mathbf d}(1+e^{-i\mathbf k\cdot\mathbf a_1}+e^{i\mathbf k\cdot\mathbf a_2}),
\]
\[
g=2\{\sin[\mathbf k\cdot(\mathbf a_1+\mathbf a_2)]-\sin(\mathbf k\cdot\mathbf a_1)-\sin(\mathbf k\cdot\mathbf a_2)\},\qquad
T_0=e^{i\mathbf k\cdot\mathbf q}\begin{pmatrix}u&ve^{i\mathbf k\cdot(\mathbf d+\mathbf a_2)}\\ ve^{-i\mathbf k\cdot\mathbf d}&u\end{pmatrix},
\]
\[
H_{8,N}=\begin{pmatrix}h_{t,N}&T_0\otimes s_0\\T_0^\dagger\otimes s_0&h_{b,N}\end{pmatrix},\quad
\eta_t=+1,\ \eta_b=-1,\quad H_R=0,\ T_{\perp,\rm SOC}=0.
\]

三条层内键 \(\mathbf d,\ \mathbf d-\mathbf a_1,\ \mathbf d+\mathbf a_2\) 长度 4.0409/4.0397/4.0413 Å；\(g\) 的 \(\nu\) 符号由这三条键的叉积生成，与任务单公式一致。四条层间键（top\(\to\)bottom，\(\delta=\mathbf R+\boldsymbol\tau_{\rm to}-\boldsymbol\tau_{\rm from}\)）：AA \(\mathbf q\)，BB \(\mathbf q\)，AB \(\mathbf q+\mathbf d+\mathbf a_2\)（\(\mathbf R=(0,1,0)\)），BA \(\mathbf q-\mathbf d\)；长度均 7.052–7.055 Å。

解析对照（代码中断言）：\(\Gamma\) 处 \(f=3,g=0\)；\(K=(\tfrac13,\tfrac13)\) 处 \(|f|<10^{-15}\)，\(g=-3\sqrt3\)；\(K'\) 处 \(g=+3\sqrt3\)。\(\Gamma\) 能级 \(E_{r,\pm}=3t_hr\pm\sqrt{\Delta^2+(u+rv)^2}\) 与数值差 \(3.6\times10^{-15}\)。

## 6. 对称性清单与两条结构性事实

### 6.1 同-\(\mathbf k\) 常数 intertwiner：关闭

对 13 个抽样点联立 \(H_{-N}(\mathbf k)U=UH_{+N}(\mathbf k)\)（64 复未知量，832 方程）：最小奇异值 0.396，无零空间。不扩大 Pauli 枚举。

### 6.2 能谱对 Néel 与 \(\mathbf k\) 反演精确偶：\(E_{+N}(\mathbf k)=E_{-N}(\mathbf k)=E_N(-\mathbf k)\)

数值：所有抽样与 240×240 网格上最大差 \(6.7\times10^{-15}\)。2026-09-14 更正证明如下（结论不变，原先写的 \(\tau_x X(\Delta)^*\tau_x=X(-\Delta)^T\) 一般不成立，因为 \(D\) 与 \(D^*\) 的非对角块位置不匹配）。

逐个 \(\mathbf k\)、逐个自旋把层⊗子晶格写成
\[
H_\delta=\begin{pmatrix}h+\delta I&T\\T^\dagger&h-\delta I\end{pmatrix},\qquad
h=h^\dagger\in\mathbb C^{2\times2},\qquad \delta=sN\Delta.
\]
M0 的 \(T=T_0\) 正规（\([T,T^\dagger]=(|v_{AB}|^2-|v_{BA}|^2)\sigma_z=0\)，因为实参数等幅 \(v_{AB}=v_{BA}\)）。正规性允许 \(W^\dagger TW=D\) 对角；\(h\) 是 2×2 Hermitian，再选与 \(D\) 对易的对角相位 \(S\)，把唯一非对角元的相位消去，使 \(\bar h=S^\dagger W^\dagger hWS=\bar h^*\)。层空间同样施加 \(WS\) 后
\[
\bar H_\delta=\begin{pmatrix}\bar h+\delta I&D\\D^*&\bar h-\delta I\end{pmatrix},\qquad
\tau_x\bar H_\delta^*\tau_x=\bar H_{-\delta}.
\]
因此两畴同谱。结合已验证的 \(P\)，得到 \(E_{+N}(\mathbf k)=E_{-N}(\mathbf k)=E_N(-\mathbf k)\)。这是**逐 \(k\) 的反幺正谱映射**，不是同向时间、同脉冲传播的等价关系，不推出 \(J_o=0\)。代码核验见 `same_spectrum_barred_residual`（`test_q8_m0.py`）。

等幅 \(v_{AB}=v_{BA}\) 保证本模型 \(T\) 正规；不要写成一般 Hamiltonian 的必要条件，也不要从一个不等幅负对照推断「凡非正规 \(T\) 都一定不同谱」。负对照只说明：破坏该等幅后，本构造不再适用，且该抽样点上两畴谱差变为有限。

安全的物理表述：**两畴静态色散相同，排除了畴间能带能量差作为响应差异的来源；差异须通过态投影、光学/电流矩阵元及受驱布居、相干体现。** 当前不能进一步指定它全是 Berry 曲率、全是价导交叉电流，或已证明某种几何机制。相同带速度配上不同驱动布居，仍可产生不同子空间内电流。

### 6.3 空间群清单（Cr-only 玩具几何）

理想 120° 蜂窝双层 + 沿 \(\mathbf a_2\) 的位移具有 \(C_{2h}\)：\(P\)、含 \(\mathbf a_2\) 与 \(z\) 的竖直镜面 \(M_{a_2}\)（A\(\leftrightarrow\)B，层不变，\(s_z\to-s_z\) 故 \(N\to-N\)）、\(C_2(\hat n)\)（\(\hat n\perp\mathbf a_2\) 面内，层交换，\(N\) 不变）。代码中 \(U_{C_2}=\tau_x\sigma_0(-i\hat n\cdot s)=P\circ M_{a_2}\)，其层间条件是 \(T^\dagger(\mathbf k)=T(-M\mathbf k)\)，**不是** \(P\) 的层间变换 \(\sigma_x T^\dagger\sigma_x\)。数值上 \(U_MH_N(\mathbf k)U_M^\dagger=H_{-N}(M\mathbf k)\) 与 \(U_{C_2}H_N(\mathbf k)U_{C_2}^\dagger=H_N(-M\mathbf k)\) 的残差 \(3\times10^{-5}\)，来自生产 metric 的微小畸变。沿 \(\mathbf a_2\) 偏振不会使该残差变成精确零；\(3\times10^{-5}\) 也不是弱 \(J_o\) 的相对误差界。不要为严格方向零改几何。

在理想镜面几何 \(Mq=q\)、\(Md=-d-a_2\) 下，\(v_{AB}=v_{BA}\) 确实能保证相关镜面/\(C_2\) 关系。因此「反演不强制、理想镜面可约束」两者兼容，不用重选 \(u,v\)。任务单说「\(v_{AB}=v_{BA}\) 是等幅简化，不是反演强制」仍然正确。

对 \(x\) 线偏振（\(\hat x\parallel\mathbf a_1\)，与 \(\hat n\) 成 30°）：\(M\hat x\ne\pm\hat x\)，\(C_2\hat x\ne\pm\hat x\)，二者**不**给出 \(J_{o,x}\) 或 \(J_{o,y}\) 的选择定则。唯一精确约束是 \(P\)：\(J_N[\mathbf A](t)=-J_{-N}[-\mathbf A](t)\)。若将来改为沿 \(\mathbf a_2\) 偏振，镜面会强制 \(J_o\parallel\hat n\)（横向）、\(J_e\parallel\mathbf a_2\)——这是可选的方向诊断，须作为单独协议执行；本轮未做。
