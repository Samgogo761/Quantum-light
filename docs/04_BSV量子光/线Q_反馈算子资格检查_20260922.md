# 线 Q：反馈算子 \(\mathcal L=G_{\mathrm{self}}\mathcal R^A\) 的资格检查（2026-09-22）

性质：把 Born 的控制参数从某一个经典测试 seed 的 \(\kappa_{\mathrm{self}}/\kappa_{\mathrm{P1}}\) 换成开环线性算子 \(\mathcal L\) 的最大增益。不是 48/96/192，不是增益/压缩结论，不改 M0/P1/两端口，不写生产 \(V\)。  
\(\kappa_{\mathrm{self}}/\kappa_{\mathrm{P1}}\) 只保留为固定 \(\varepsilon=3\times 10^{-5}\) 的 stress test：线性区它随 \(\varepsilon\) 缩放，不是普适无量纲参数。  
\(|A_2|\sim 0.2\) 只是一个 H2 方向上的投影，不是 \(\|\mathcal L\|\)。

## 物理问题

\[
\text{有限脉冲上 }(1-\mathcal L)^{-1}\approx 1+\mathcal L\text{ 有没有一个不受测试 seed 振幅摆布的小参数？}
\]

预先写好的出口：

- 嵌套 \(\sigma_{\max}\ll 1\) 且锁住 → Born 有真正的控制参数（仍不自动升格生产 \(V\)）。  
- 嵌套 \(\sigma_{\max}\sim 0.2\) 且锁住 → 二次反馈大约是几％，和 \(A_2^2\sim 0.04\) 同量级。  
- 嵌套 \(\sigma_{\max}\) **数值相容**且 \(\gtrsim 1\) → **人审**（H2 自己只有 \(A_2\sim 0.2\) 时，连续谱里仍有隐藏强方向）。  
- 嵌套互相矛盾 → 仍是数值，不叫人；\(\kappa\) 比不再当通行证。

第三基准：嵌套 Monkhorst–Pack \(4\times 4\)、半格点 \(4\times 4\)、\(6\times 6\)、\(8\times 8\)，只做核对，不做生产扫描。1I 的传统/AI \(k\) 集一并测量，不互相证明。

## 算子与内积（工程冻结）

\[
\mathcal L f = G_{\mathrm{self}}\,\mathcal R^A[f],\qquad
(G I)[0]=0,\quad (G I)[n]=\gamma\,\Delta t\sum_{m<n} I[m].
\]

内积 \(\langle u,v\rangle=\Delta t\sum_n u_n\cdot v_n\)（左 Riemann，与 \(G_{\mathrm{self}}\) 一致）。不显式存 \(N_t\times N_t\)。\(\sigma_{\max}\) 由 \(p=3\) 的 SVD 子空间迭代得到，与种子振幅无关。mp4 上伴随残差 \(1.7\times 10^{-15}\)，尺度残差 \(0\)。

\(\langle f_{\mathrm{H2}},\mathcal L f_{\mathrm{H2}}\rangle\) **不是** \(|A_2|\)：\(A_2\) 是 \(i\,\mathrm{pref}\int F\,\hat e\cdot I[F^*]\)（梯形、电流、复波包），\(\mathcal L\) 先把电流送进 \(G_{\mathrm{self}}\)。\(\gamma=2\pi\,\mathrm{pref}\)。

## 主奇异对的时间形状

右奇异向量 \(v\)（输入）：光滑、前中段振荡、在 \(T_p\) 处回到 0；与 H2 包络重叠只有 \(0.00\)–\(0.12\)。邻差 \(\|\Delta v\|/\|v\|\sim 0.05\)–\(0.12\)，不是白噪声。

左奇异向量 \(u=\mathcal L v/\sigma\)（输出）：前段几乎为零，\(t\gtrsim 0.6 T_p\) 以后变成**自场斜坡**；mp4/mp8 上 \(92\)–\(93\%\) 的能量在最后 \(20\%\) 脉冲里，与 H2 重叠 \(\sim 10^{-3}\) 或更小。

\(k\) 分解 \(\alpha_k=\langle u,\mathcal L_k v\rangle\)：净/毛 \(0.84\)–\(0.95\)（几乎不相消），但热图是**少数热点**对一片接近零的海。所以 \(\sigma_{\max}\) 对采样极敏感——这正是嵌套网格差到因子 3 的原因。

## 备选解释

**A1.** 真实 \(\|\mathcal L\|_2\gg 1\)。存在一条（其实是一小片）光滑的、与 H2 几乎正交的累积自场方向，\((1-\mathcal L)^{-1}\approx 1+\mathcal L\) 在这条方向上不成立；H2 矩阵元 \(\sim 0.2\) 只说明「投回 H2 波包」弱。支持：所有网格 \(\sigma_{\max}\ge 128\)、H2 的 2-范数增益 \(\ge 13\)、\(u(t)\) 都是后段斜坡、\(\alpha_k\) 几乎不相消。反对：数值从 128 跳到 729，热点采样还没钉住，\(\sigma_{\max}\) 可能被一两个 \(k\) 口袋夸大。

**A2.** 时间 L2 范数对「任意波形」过宽。物理上进来的量子场是波包/正频的；若把试探函数限制在 H2（或窄带）里，相关增益就是 Rayleigh \(\sim 0.03\) 或 \(|A_2|\sim 0.2\)，二次反馈仍是几％。支持：\(\langle f_{\mathrm{H2}},\mathcal L f_{\mathrm{H2}}\rangle\) 小；\(u\) 的能量几乎都不在 H2 里，收集核看不到这条斜坡。反对：用户要问的正是「有没有隐藏方向」；限制在 H2 里等于不让算子回答这个问题。

**A3.** 大 \(\sigma_{\max}\) 主要是少数 \(k\) 热点的采样伪增强，把网格做对之后 BZ 平均算子的 2-范数会降到 \(O(0.2)\) 或以下。支持：\(\alpha_k\) 热图极端稀疏；越「自适应盯 \(A_2\)」的 1I-AI 集 \(\sigma_{\max}\) 越小（128）。反对：连最密的均匀 \(8\times 8\) 仍是 245；三个试验奇异值都 \(\gg 1\)，不像单个野点。
