# G1 工作记录：残差矩阵元的二阶外推与分项（2026-10-14）

低频下限固定为 \(10^{-4}\)，侧翼倍数 2，共振核心 160，每周期步数 1024、2048、4096。没有改 Hamiltonian、P1、初态或探测模式，也没有重归一化 \(U,V\)。

## 1. 相邻差值，而不是残差自己的比例

正常残差 \(R_N\) 的 \((0,0)\) 元是 0.030491、0.012163、0.007439。相邻差的比值是

\[
\frac{0.030491-0.012163}{0.012163-0.007439}=3.88.
\]

四个实部元素的比值分别是 3.88、3.76、3.76、4.01。按 \(R(\Delta t)=R(0)+C\Delta t^2\)，用最后两档外推，\(R_N(0)\) 的最大元素约 **0.00586**，不是 0。因此时间步本身接近二阶；再把 4096 提到 8192，不能单独达到 \(10^{-6}\)。

反常残差没有同样地降向零。非对角实部是 0.001385、0.002021、0.002193，外推约 **0.00225**。它在三档之间几乎不下降，加密时间步留不住这个底。
