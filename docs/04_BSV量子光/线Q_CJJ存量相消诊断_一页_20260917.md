# 线 Q：CJJ 存量相消——一页（2026-09-17）

给本人读。没有新轨迹。没有 192。没有量子泵浦。

## 共同涨落可以当初步基准；非零磁畴差不是继续研究的前提

H2x（约 0.016）和 H6y（约 0.00145）的共同部分过了本轮 5%。过线不等于单调：H2x 的 Γ/移位分歧从 48 的 0.32% 增到 96 的 3.19%。磁畴差没有可信值，但这不挡住准备“源关联怎样接到收集光”的人审设计。探测模式仍由你定。

## 现在该看的是谁在抵消，不是那个最后的小数

H2x 畴差的正负贡献绝对值总和，两套 96 都约 \(5.1\times10^{-4}\)；相消后净值只有 \(-2.69\times10^{-5}\) 和 \(+4.17\times10^{-6}\)。单畴自己几乎不相消；相消发生在两畴相减之后。图在两叶内部呈红蓝斑块，换一套求积斑块就改符号。这是关联畴差的图，不是平均 H2 的细丝图。

H6y 在两套 96 上都为正；它的翻号是移位48→移位96。H2x 才是同一级 96 网格间翻号。分歧约减半，仍与信号相当，未解析。

## 同一束激光并不强迫涨落的磁畴差为零

反演把场一起翻号。平均电流一个负号；关联里两个电流，两个负号抵消。所以不能把“磁畴奇响应 = 偶次谐波”从平均电流搬过来。这也**不证明**当前同一脉冲下的畴差必须是零。近似转动/镜面还不保持沿 \(x\) 的实验室脉冲。

## 若以后再算，只做这一档分区加密，并且先停

存量足以指出：Γ96 与移位96 的分歧大约 3/4 集中在对角走廊的少数反演配对块，不是铺满整个布里渊区。建议在这些块用 192 间距、其余保持 96，再配一套半步移位；成本大约是均匀 192 的一半到一倍。块内在 96 上已是像素级棋盘，不保证 192 就够。最多跑这一对；分叉降不下来就停，不要改均匀 192。**这轮只设计，不执行。**
