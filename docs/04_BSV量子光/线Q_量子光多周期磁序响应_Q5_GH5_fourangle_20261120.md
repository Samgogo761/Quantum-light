## 因子化残差（相对 η=1 四角样本，不是 χ(2)）

严格：J(η,θ)=F(η)G(θ)，G 取 η=1 的四角向量。
弱：J(η,θ)=B(η)+F(η)G(θ)，允许独立背景。二者不得混为一谈。

**为何拒绝严格因子化：**

1. θ=0 是 B 与 A e^{iθ} 近相消。若 B(η) 与 A(η) 不按同一 F 缩放，该角相对误差必然被放大。η=0.5 的 90% 误差是这个几何后果，不是噪声。
2. 严格残差虽然低于脚本的 20% 门槛（0.105 与 0.047），但门槛过宽，会把相消点失败藏进“总体还行”。人判拒绝该自动通过。
3. 弱因子化留下独立背景后，η=1.5 残差降到 0.73%，且 arg(F_weak)=57.4° 与 arg(A) 的旋转一致。

因此：旋转项接近情形 A；严格 J=FG 不成立。四点等间隔角向 Fourier 不能认证唯一角向定律。各角绝对残差见 JSON。

## 解释边界

当前 GH5 四角数据支持

\[
J_{2,x}^{o}(\eta,\theta)\approx B(\eta)+F(\eta)\,G(\theta).
\]

\(G(\theta)\) 近似由压缩角决定，\(B(\eta)\) 与 \(F(\eta)\) 由电子体系决定。η=1.5 的 F 大约是 63 倍放大并整体旋转 57°，同时能隙从 1.135 降到 0.362；偶通道也显著变化。因此把它读作“磁性谱结构重整化后的材料系数”，而不是“压缩统计与磁序之间出现了不可因子化的新耦合”。

- 本轮只有 GH5/MTEF，没有新的精确 QED。
