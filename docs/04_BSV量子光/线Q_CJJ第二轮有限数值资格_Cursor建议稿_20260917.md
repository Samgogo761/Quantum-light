## 随下一轮合并处理的三项小修正

这些不推翻现有 0.016，也不要求重跑原八条轨迹。

1. 收尾报告的“+N 加密/移位”列混用了 +N 与两畴中较大值。统一采用明示口径并由 JSON 生成。例：H2x 的 +N 加密为 2.18%，2.56% 是两畴较大值；H6y 的 +N 加密为 3.84%，4.24% 是两畴较大值；H7x 的 +N 移位为 0.20%，1.02% 是两畴较大值。
2. `CJJ_ABS_FLOOR_RATIONALE` 不能称 10^-12 “高于 Q4/Gram 残差”：保存的 B0 最大残差约 9.92×10^-12。两时点核残差与滤波 d 的误差需要分别说明；报告阈值不等于已证明的误差上界。修正依据并记录直接作用于 d 的数值检查。不要为让某项通过而调阈值。当前主要候选远大于这个尺度，原 39 个标签不因这处说明错误而失效。
3. B0 历史缓存兼容项应限定已经审核的旧 hash、新目标 hash 和任务类型。目前只匹配旧 hash 与 B0 名称，会将尚未审核的未来代码版本也自动认作兼容。保留历史 hash 与此次只读重验记录，不改写来源、不重跑旧数据。
