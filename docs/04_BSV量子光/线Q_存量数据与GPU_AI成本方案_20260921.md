## 1. 现有计算点（不是 7 维扫描）

CJJ 实际只用了 **两个** 冻结泵浦点：实验室 \(x\) 的 P1，以及 \(\mathbf A\parallel\mathbf a_2\) 的同一 P1（\(A^*=0.8\)，8 周期，\(\hbar\omega=0.05t_h\)）。网格/移位/步长是求积检查，不是新物理工作点。旧四带 GPU 占位 **不是** 八带 M0 后端。

| 批次 | 泵浦 | 完整 \(X(t)\) | 仅 \(Y\)+快照 | 墙时（本机 CPU，单畴量级） |
|---|---|---|---|---|
| a2 B0_sixk ±N | P1 a2 | 有（2 个 npz） | — | ~1.1 s / 畴；成对 2.68 s |
| a2 V48 / V48S ±N | P1 a2 | 无 | 有 | ~139 s / 畴；成对 ~284 s / ~282 s |
| x-drive B0_sixk | P1 \(x\) | 有 | — | ~1.1 s / 畴 |
| x-drive V24/V48/V48S/V48dt | P1 \(x\) | 无 | 有 | V48 ~240 s / 畴；V48dt 一份 484 s |
| x-drive V96/V96S | P1 \(x\) | 无 | 有 | ~551–555 s / 畴；**不可转授 a2 支线** |

合计：完整 \(X\) **4** 份；有 \(Y\) 无完整 \(X\) **16** 份。大网格若存 \(X_{\mathrm{full}}\)，V48 单畴约 \((3201\times2304\times2\times4\times4)\times16\,\mathrm{B}\approx3.8\,\mathrm{GB}\)，两时 \(C(t,t')\) 不可作为默认存储。以后因果核只能在传播中做前缀积分。

**禁止：** 从少量谐波 \(Y\) 插值伪造 \(\mathcal R^A\)。

## 2. 标签政策（给任何后续 AI）

| 量 | 可否当带符号监督标签 |
|---|---|
| \(\widetilde d_{\parallel\perp}\) 奇、\(J_{o,\perp}(H_2)\) | **否**（unresolved；移位可翻号） |
| 偶数 \(\widetilde d_{\perp\perp}(H_2)\) | 只当算法基准，不是磁性发现 |
| 近似镜面禁止通道 | **否**硬编码精确零 |
| \(N\to-N\) 数据增强 | **否**（须连同泵浦/探测协议一起变） |

一个泵浦点下的很多 \(k\) ≠ 很多独立泵浦样本。现有可靠工作点数量远小于 FNO 文献的 \(5\times10^3\)–\(3\times10^4\) 条平均偶极轨迹，且那些工作验证的是平均加速度/谐波谱，不是两时量子关联。

## 3. GPU：先计时，不写生产核

当前八带 CJJ 已在每个时间步对 **全部 \(k\)** 做 numpy 批处理；墙时主要来自 **Python 时间循环**（V48 成对约 4.7 min）。旧 `tools/q_backend` 的 `gpu_stub` 面向四带 toy，状态仍是 `NOT_IMPLEMENTED_UNTIL_CPU_PROFILE`。

建议顺序（均未实施）：

1. 在现有 CPU 上拆一步的 `eigh` / 矩阵乘 / 窗累积占比（六点即可），再决定值不值得写 fused kernel。
2. 若写 GPU，只加速 **同一** `propagate_cjj` 时间步，dtype 保持 complex128，每步与 CPU 对照相消量。
3. 不以“上了 GPU”代替 V48/V48S 独立求积。

粗算：把 a2 V48 成对从 ~284 s 降到例如 30–60 s，有利于以后的在线前缀积分，但 **不** 自动授权 96/192。全时 \(X\) 的内存墙仍在。

## 4. 小数据主动选择：先离线对比，不新扫轴

外部提到的多参数 BO 需要本人先批准轴。当前冻结轴上几乎没有自由参数：\(A^*\)、\(\omega\)、周期、\(\Delta\) 都不动。

现在可以做、且尚未做的离线方法对比：

- 用已有 a2 来源图，比较「随机再抽样 \(k\)」与「按分区残差排序再抽样」在 **同一 V48 权重** 下的积分误差；AI 排序必须对传统自适应加密单独对照。
- 高斯过程若要用，输入是求积诊断（分区净/毛贡献），输出不得是未解析磁畴差的正负号。

不启动七维扫描。不训练 FNO / 有效 Hamiltonian 代理。学得的 \(H\) 会离开固定 M0，须另审。
