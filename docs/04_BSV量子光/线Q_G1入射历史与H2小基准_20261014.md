# G1 工作记录：入射历史、短驱动和 H2 投影的小基准（2026-10-14）

四项已验收的工作不在这里重做。这一轮把两 k 点、32 条电子坐标和原来那 4 个频率、两端口、两偏振接成一条链。没有改 \(\gamma\)、\(D\)、P1 或探测定义，也没有重跑 \(\Gamma 12\)。

## 1. 无泵浦稳态入射和记忆从 \(t_0\) 起算

生产的无泵浦初值是稳态散射列。\(A_0\) 与自由场 \(A_f\) 的最大差是 \(0.0494488\)。\(b,b^\dagger\) 也由这个 \(A_0\) 定出。把它放进生产中点步进，并和解析的 \(e^{-i\omega t}\) 轨道比较：

| 步长 | 轨道最大偏差 |
|---:|---:|
| 0.05 | \(3.2725\times 10^{-5}\) |
| 0.025 | \(8.1746\times 10^{-6}\) |

粗步长误差是细步长的 \(4.003\) 倍，是二阶时间误差。无泵浦框架顶点与 \(u_0 e^{i\Delta t}\) 的差约 \(10^{-15}\)。

右行输出在乘波包 \(\varphi\) 之前，与裸左端口透射最多差 \(0.74742\)。这 4 个频率上的 \(|\varphi|\) 只有 \(10^{-18}\)–\(10^{-15}\)，所以乘上 \(\varphi\) 之后两行都接近零，差 \(6\times 10^{-16}\) 不能读成 \(U_0\) 等于裸入射。\(U_0\) 仍是有材料、无泵浦的出射行。

把初值改成 \(b=b^\dagger=0\)、\(A=A_f\)，等于丢掉 \(t_0\) 之前的散射历史。脉冲中点附近 8 步的 \(H_2\) 电流积分因此改变 \(0.00777422\)。脉冲起点的收集核只有约 \(1.8\times 10^{-6}\)，同样的丢掉历史在那里只改变 \(2.57\times 10^{-6}\)。历史要在收集核不为零的时段才进入输出。

这个 \(0.00777\) 是该小窗、这 16 列上的历史差，不是 \(\Gamma 12\) 的 \(0.007439\)。

## 2. 短 P1 下显式模型和记忆核

从脉冲中点起 12 步，步长为一个光学周期的 \(1/32\)，\(A^\star=0.8\)。顶点用与生产相同的四分点框架。显式振子和同一离散谱的记忆核：

|  | 无泵浦框架 | 短 P1 |
|---|---:|---:|
| 全状态 | \(1.44\times 10^{-15}\) | \(2.24\times 10^{-15}\) |
| 片上场 | \(1.30\times 10^{-17}\) | \(1.61\times 10^{-17}\) |
| 电流 | \(3.34\times 10^{-15}\) | \(3.56\times 10^{-15}\) |
| 同一电流的 \(H_2\) 行 | \(6.78\times 10^{-15}\) | \(3.04\times 10^{-14}\) |

两边初态都是这套有限模型的裸正则坐标，不是生产稳态入射。一致只说明消元没有把这个离散系统算成两个系统。

## 3. \(H_2\) 不是末态振子

同一条电流做成的 \(H_2\) 行，和用末态右端口振子直接读出的行，无泵浦时差 \(14.82\)，短 P1 时差 \(44.19\)。末态振子不能当作远场输出。

## 4. 有限谱还不是 \(\mathrm{i}\gamma/\omega\)

离开这 4 个节点，振子浴的响应几乎是实数，生产片上定律是 \(\mathrm{i}\gamma/\omega\)。相对差是 \(O(1)\)。把节点从 8 加到 64、间距保持在各自的梳上，相对 Markov 核仍是 \(1.06\)–\(1.81\)。节点正好落在振子频率上时，相对差会到 \(10^{4}\)，那是离散极点，不是连续谱误差的大小。显式模型和记忆核的 \(10^{-15}\) 不缩小这个差别。

## 5. 残差出现在哪一层

在这条小链上，生产中点步进能够保持无泵浦稳态轨道，误差随步长二阶下降。丢掉稳态历史会改变中点附近的 \(H_2\) 积分。有限谱内部的显式传播和记忆核一致到 \(10^{-14}\) 以下，但这个谱的响应还不是生产用的 \(\mathrm{i}\gamma/\omega\)。远场行必须由电流和收集核得到。

还没有把 \(\Gamma 12\) 的 \(0.0074392606\) 归到其中一层，也没有得到正则的小系统输出。G1 未通过，不进入 G2/G3。不改 Hamiltonian。
