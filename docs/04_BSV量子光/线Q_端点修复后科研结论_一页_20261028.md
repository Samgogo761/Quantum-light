# 线 Q：Fourier 端点修复后的科研结论

2026-10-28；只读重分析现有 22 组 ±N 电流（44 份时序），无新电子传播。历史文件名中的 `20261120` 是任务标签。

**压缩角控制磁序奇 H2 邻域复电流的现象仍然存在；旧报告中的倍数、相位与畴反差必须更新。以下是冻结有限模型、有限主窗 `[2T0,4T0]` 的结果。**

## 1. 关键物理结果保留了多少？

统一采用准确窗口端点、分段线性电流的解析振荡积分。H1–H6、x/y、两畴及其半和/半差均已重算；没有人为调相或减去电流背景。

| QED 量 | 旧分析 | 修正后 |
|---|---:|---:|
| θ=π / θ=0 的 H2 奇电流二维复振幅范数比 | 约 5.80 | **4.98** |
| θ=3π/2 相对 π/2 的 H2 奇电流 Jx 相位差 | 约 106.9° | **110.6°** |
| 上述协方差反转两态的二维振幅比 | 约 1.058 | **1.045** |
| θ=π 相对 0 的 Jx 相位差（主值） | 约 −167.4° | **−174.2°** |

修正后四角 QED 的 `||J2^odd||` 依次为 **1.758、6.006、8.749、6.279 ×10⁻8**（θ=0、π/2、π、3π/2，模型电流单位）。

GH5 在 η=0.5、1、1.5 的四角拟合重新预测 π/4，复误差 `|实际−预测|/|A|` 分别为 **0.667%、0.425%、1.037%**，相位偏差 **−0.219°、+0.242°、+0.463°**。π/4 未参与拟合。这是修正估计量下的追溯性留出检验；原先传播前的冻结预测仍单独保留。

**限制：** QED 四角主窗 Jx 的线性/局部二次重构差约 **0.11%–0.59%**；抽掉一半保存点后变化约 **1.4%–4.8%**。相邻两周期窗相对主窗的复变化仍约 **16%–39%**，θ=π 的后窗缺失。因此可以保留“有限时间复响应调控”，尚不能称为稳定远场 HHG 产额。插值敏感性不是严格误差界。

## 2. A/B/C 目前解释到哪一层？

已严格写出固定动力学下 `Jq[ρph]=Tr(ρph Kq)`。在理想位移后的光子数基底，B 对应数态对角块，A/C 对应两个方向上相差两个光子的相干块；更高角谐波对应更大数态差。生产有限 PDPS 初态还须除以角度相关归一化，不能直接假设理想态。

修正后的 QED Jx：`B=(-3.301+0.954i)×10⁻8`，`A=(4.743−1.584i)×10⁻8`，`C=(0.0635−0.0434i)×10⁻8`，`|C/A|≈1.54%`。这解释了角向近圆结构，但尚未分离具体电子跃迁、SOC 或交换的微观贡献；不能把 A 直接称为 χ²，把 B 直接称为经典背景。

## 3. 接近实验的信号与协议

修正后 H2 x 分析器相干源畴反差，在四角依次约 **−21.4、+44.5、+115.9、+44.9 ppm**。压缩角仍能改变其符号；绝对反差较弱，且依赖时间窗。**相位敏感/外差读出值得优先设计，现有数据不足以给出可测光子数或信噪比。**

已准备一个 **1600 nm、25 fs、无平台 Gaussian 脉冲、0.1 TW/cm² 统计平均峰值**的计算协议初稿，主输入为有相干参考的明亮位移压缩态，纯 BSV 与同能量相干态作对照。该强度是待筛选模型工作点，不是 CrI3 适用性结论。纯 BSV 的宇称会使本协议两畴相干源强度相等；需要外部相干参考或其他读出。未启动该工作点计算。
