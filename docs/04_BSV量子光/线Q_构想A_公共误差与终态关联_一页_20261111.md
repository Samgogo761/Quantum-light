# 构想 A：公共方法误差与终态关联（归档后处理）

`20261111` 沿用工作批次标签；实际复核执行：2026-10-21。**本轮无任何新传播。**

**结论：可以结束当前冻结对象的 GH3→GH5 求积检查。公共误差对消得到支持；“只是振幅偏小”和“已找到量子机制”均不成立。**

对象仍是同一个光模式耦合的 (k,-k) 八带半填充模型、一个周期的耦合升沿。比较 (C_\alpha\) 与 (D(\alpha)S(r)|0\rangle)，不是零均值 BSV，也不是完整 HHG 脉冲。两态固定位移而未匹配平均光子数（约 0.250 / 0.343）。

## 1. 外部意见哪里成立、哪里需要收窄

GH5–GH3 的三条 x 误差为 (5.05\times10^{-10},1.86\times10^{-9},1.46\times10^{-9})；MTEF 步长对照为 (10^{-10}) 量级。已有 QED 步长/DS 截断对照也明显小于绝对奇电流的方法差异。支持停止 GH7 和重复精度检查，**范围限于当前参数、升沿、已存的 42 个共同采样时刻**。

原程序已先逐时相减再取范数，并没有“把不同时刻峰值直接相减”的错误。但 99.98% 实际定义是

\[
\frac{\|\varepsilon_{\rm common}\|_\infty}{\|\varepsilon_C\|_\infty}=0.99977464,\quad
\varepsilon_{\rm common}=(\varepsilon_C+\varepsilon_{DS})/2,
\quad\varepsilon_\Delta=\varepsilon_{DS}-\varepsilon_C.
\]

它是**峰值范数比**，不是解释了 99.98% 的物理机制或方差。以下 RMS 是共同采样点的等权 RMS，不是连续时间积分：

| 误差 | x 最大模 / RMS | y 最大模 / RMS |
|---|---:|---:|
| (\varepsilon_C) | 3.269e−7 / 1.729e−7 | 1.473e−7 / 6.196e−8 |
| (\varepsilon_{DS}) | 3.268e−7 / 1.738e−7 | 1.319e−7 / 6.062e−8 |
| 公共半和 | 3.268e−7 / 1.733e−7 | 1.396e−7 / 6.125e−8 |
| 差分误差 | 1.726e−8 / 5.360e−9 | 1.547e−8 / 4.659e−9 |

两态误差的 Pearson 相关为 **0.99901 / 0.99499（x/y）**，支持显著公共偏差。增量的 MTEF–QED 波形相关为 **0.99403 / 0.94920**，但其相对 RMS 误差仍为 **11.28% / 32.70%**，最大误差/最大 QED 信号为 **14.11% / 36.63%**。

绝对奇电流的 MTEF–QED 波形相关：Cα 的 x 为 **0.1104**，DS 的 x 为 **−0.2064**。因此 0.379 / 0.454 的峰值幅度比不能解释成同一波形简单缩小。应说：**x 增量的波形较好保留，绝对奇电流的幅度和时间形状均不准确。**

## 2. 检查点真正说明什么

20261102 原比较只存电流；20261104/05 的 dt/2 及 20261106 的 nmax10 均有完整终态 ψ。已只读提取、交叉复核：

| 输入 | (\mathrm{Tr}\rho_{ph}^2(+N)) | (\mathrm{Tr}\rho_{ph}^2(-N)) |
|---|---:|---:|
| Cα，nmax8，dt/2 | 0.9991885240 | 0.9991886136 |
| DS，nmax8，dt/2 | 0.9995700017 | 0.9995700457 |
| DS，nmax10，dt/2 | 0.9995700709 | 0.9995701149 |

整体为纯态，因此这证明**当前有限模型、耦合仍开启时存在电子—光场纠缠**；不是磁畴自由度的纠缠，也不是远场光子纠缠。DS 的终点纯度较高，但中间最低纯度较低，不能把终点一个数当作整段动力学的“关联强弱”。

已计算 (\langle J\rangle-\mathrm{Tr}[(\rho_e\otimes\rho_{ph})J]) 及有序连通矩，保存在 JSON。(J) 本身含光场 Peierls 因子；(\langle nJ\rangle_c)、(\langle JJ\rangle_c) 不能单独充当电子—光场纠缠证据。**现有 MTEF 包含自洽反馈和轨迹间统计关联，不能把上述差额直接当作 MTEF 丢失项。**

## 3. 程序复核与停止点

修正了未完成后处理中的错误测试断言（解析等于 0.9 却要求严格大于），删除了硬编码的“仅有幅度缺失”解释；增加终态完整性/时间检查、Schmidt 独立对照和旧文件保护。11 项测试通过，29 个既有归档/检查点哈希未变。归档电流与 ψ 重算相差 <1.7e−15；独立误差数组归约与报告相差 <2.7e−23。没有改 QED/MTEF 传播器。
