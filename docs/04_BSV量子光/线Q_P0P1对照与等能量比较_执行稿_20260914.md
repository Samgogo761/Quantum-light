## 3. 对外部量子光论述的必要优化

### 3.1 成对产生不等于成对吸收

“量子光的光子都成对出现”不成立；这是特定制备和模式的性质。理想单模 squeezed vacuum 含偶数光子数分量，但 a|2n⟩∝|2n−1⟩，单光子吸收仍允许。两模 squeezed vacuum 的 |n_s,n_i⟩ 表示模间数目关联，各单独模式并不只含偶数光子。实际 BSV 可以是多频模。

单模中不能给相同玻色子逐个指定可追踪的 partner；若问题是 signal 被吸收后 idler 如何变化，必须先明确两个可区分模式。

### 3.2 一次吸收不保证光—物质纠缠

假设只条件于物质到达一个确定最终态 |e⟩，简单单模吸收分支为

\[
|\Psi_{\rm abs}\rangle=\frac{a|\psi\rangle}{\sqrt{\bar n}}\otimes|e\rangle,
\]

这是乘积态。未条件的吸收/未吸收叠加，或不同电子最终态与不同剩余光态相关联时，才可能保留光—物质纠缠。

对明确的 signal/idler 两模系统，局域、未条件的 signal 操作不改变 idler 的边缘态；按“发生吸收”筛选时，idler 的条件态可以改变。后续应问“电子、剩余驱动模与 idler 的哪些条件/非条件关联改变”，而不是预先认定吸收必产生纠缠。

这一问题有研究价值，P0 可以保留作其共振对照，但本轮不因此加入 idler 模或量子传播。

### 3.3 高阶响应对统计敏感，是假说与近似层级，不是一个通用 g2 乘数

一般一光子概率涉及两时 G1(t,t′) 与物质响应核，两光子概率涉及四时场关联与物质核。只有在适当的模式/带宽/响应近似下，才压缩为 n̄ 与 ⟨a†²a²⟩。强场 HHG 不能直接乘一个输入 g2(0) 得到答案。

对理想零均值单模 Gaussian 光态，可用 Wick 得到 ⟨a†²a²⟩=2n̄²+|⟨aa⟩|²；这不能无条件推广到多模强场 HHG。区分相干位移与涨落时，更合适的异常矩是 ⟨δaδa⟩=⟨aa⟩−⟨a⟩²；coherent 态的 ⟨aa⟩ 本身也可以非零。

已有宽带 squeezed-vacuum 两光子吸收理论表明，能否用 g2(0) 描述增强取决于物质线宽与光场带宽，某些情形并不优于匹配的 coherent 脉冲。[Raymer–Landes，PRA 106, 013717](https://arxiv.org/abs/2202.01249)。这支持保留比较问题，不能预先把 P1 命名为必有量子优势的区间。

### 3.4 高于 coherent 基准，不自动证明非经典优势

经典随机强度也可满足 ⟨I²⟩>⟨I⟩²，在等平均强度下增强非线性响应。未来需区分“相对 coherent 的增强”“经典统计可解释的部分”和“需要量子关联才能解释的证据”。仅有产额增强或较大输入 g2，不足以证明纠缠或排除所有经典随机场解释。

Husimi-Q 轨迹平均保留为明确的 statistical-transfer 对照，不等同于联合量子态；它能否复现某一个平均产额，也不独自决定所有输出关联是否经典。

## 4. 采用等平均能量原则，但暂不替本人冻结量子模型

本人偏好等平均入射能量，作为以后同一驱动区间内 coherent 与指定 squeezed/BSV 态的主要比较原则，合理且本轮予以记录。

未来应以去掉零点的自由输入场能量定义

\[
U_{\rm in}=\sum_\mu\hbar\omega_\mu\langle a_\mu^\dagger a_\mu\rangle.
\]

单频单模时等 U 就是等 n̄。多模时，只有匹配归一化的平均光子频谱等条件，才能把等总能量等同于等总光子数；仅中心频率相同不够。比较时需记录空间模式、频谱、时间模式、偏振、耦合与探测口径，说明哪些固定、哪些就是待研究的统计差异。

P0/P1 改变频率与时长，是驱动区间对照；在固定 P1 内比较不同输入态，是光态对照。两者不混成一次“只改变光子统计”的实验。在相同光子谱形缩放的近单色极限，频率降低四倍、总能量固定，对应平均光子数增加四倍。

纯 squeezed vacuum 通常 ⟨E(t)⟩=0，不能把 P1 的经典 A(t) 直接当成 BSV 的平均矢势，也不能用其零平均场表示没有驱动。未来应通过明确的模式归一化把 Uin、n̄、压缩参数和涨落幅度联系起来；原始 ⟨E²⟩含真空贡献，不能未经说明直接替代入射能量。

现在不预定：单模还是多模、单模 squeezed 还是 signal/idler、压缩相位、是否保留泵浦耗尽、CJJ 的序与归一化、输出探测模。若用两模输入，还需明确计入驱动模能量还是连 idler 的能量一并计入；这属于后续真实量子设计的人审内容。
