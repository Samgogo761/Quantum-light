## 2. 数值门：通过，但口径必须收窄

| 检查 | 结果 |
|---|---|
| 有限态、\(\lVert\psi\rVert\) | 通过；\(\max|\lVert\psi\rVert-1|=1.75\times 10^{-14}\) |
| Taylor 末项 | \(5.49\times 10^{-16}\)（16 阶） |
| 顶层 Fock \(p_{n_{\max}}\) | \(\max=2.97\times 10^{-10}\)，远低于警报 0.05 |
| 历史 Cα 一周期升沿顶层 Fock | \(7.35\times 10^{-10}\) |
| 历史 DS 一周期升沿顶层 Fock | \(1.74\times 10^{-5}\) |
| 终点 \(\langle n\rangle\) | 0.250018（初值 0.250000） |
| 非相干光子数 | \(4.94\times 10^{-6}\) |
| 电子占据泄漏 | \(k\) 与 \(-k\) 均为 0 |

Q0 的 Fock 只说明：**升沿前 0.22 周期、相干态、\(N=+1\)** 没有顶层泄漏。它**不能**保证：

1. 完整四周期平台内不出现高光子数占据；
2. 位移压缩态 DS 的截断（历史一周期已经比 Cα 高四个数量级）；
3. 下降沿关断后的占据。

外审要求保留的解释边界仍然有效：耦合开关本身可以制备瞬态激发；同 α 的 Cα vs DS 还不是同 \(\langle n\rangle\) 对照。

## 3. 时间网格比方案预估更密

完整 1+4+1 的步数由 `n_steps_for(t_total, ρ)` 在 \(s=1\) 的谱半径上确定，与 Q0 前缀共用同一 \(\mathrm{d}t\)。

| 量 | 方案预估 | Q0 实测 |
|---|---:|---:|
| \(n_{\mathrm{full}}\) | \(\sim 7710\)（若 ρ 与旧升沿相同） | **11154** |
| \(\mathrm{d}t\) | 旧升沿 0.097793 | **0.067597** |
| 400 步覆盖 | \(\sim 0.31\,T_0\)（按旧 1285 步/周期） | **\(0.215\,T_0\)** |
| 每周期步数 | 1285 | \(11154/6\approx 1859\) |

更密的网格来自平台上 \(s=1\) 的谱半径 \(\rho\approx 5.92\)，不是传播器被改写。Q1a 若启动，必须用这套 \(n_{\mathrm{full}}=11154\) 的网格，不能退回旧 1285 步/周期去“省时间”。

Taylor 单步实测 0.061 s，**不用来报价**。作业墙时/步数 = 0.06184 s/step，已含采样。

## 4. 外推：单作业实测 vs 历史四路并行

Q0 是**单个作业**。历史 20261102 一周期升沿：四路总墙时 109.83 s，最慢作业 `coh_p` 108.89 s，并行因子 \(109.83/108.89=1.0086\)。不得把 Q0 单作业速度直接当成四路并发墙时。

两条独立外推（都不是运行保证）：

| 口径 | 单作业 1+4+1 | 四路 1+4+1 | 相对 10 min / 900 s |
|---|---:|---:|---|
| **Q0 实测步时** \(\times n_{\mathrm{full}}/400\) | 689.7 s（11.50 min） | **695.7 s（11.59 min）** | 超过 10 min，低于 900 s |
| 历史 `coh_p` 按步数缩放 \(n_{\mathrm{full}}/1285\) | 945.2 s（15.75 min） | 953.4 s（15.89 min） | 超过 900 s |
| 方案事前（6×108.9 s，假定旧 \(\mathrm{d}t\)） | — | \(\sim 10.9\) min | 略超 10 min |

当前机器上 Q0 每步比历史 `coh_p` 更快（0.0618 s vs 0.0847 s），因此 **Q0 口径更代表这次本机**。历史缩放更保守，因为它把更密的 11154 步乘上了更慢的旧步时。

DS 历史上不是最慢作业；四路墙时几乎等于最慢的 Cα。Q1a 仍应按四路并行、以最慢作业为墙时，并保留 DS 顶层 Fock 更高的风险。

## 5. 是否值得批准 Q1a？

脚本标签 `ask_to_approve_q1a_1_4_1_accept_about_11min`。本报告同意这一申请口径，**不代替批准**。

| 问题 | 判断 |
|---|---|
| Q0 失败或超时？ | 否 |
| 升沿早期 Fock 越界？ | 否 |
| 完整 1+4+1 能否在本机跑？ | **能跑**；Q0 外推四路 \(\approx 11.6\) min |
| 要不要缩成 1+2+1（Q1b）？ | **不要**。外审：不为省一点时间缩短平台 |
| 现在要不要服务器（Q1c）？ | **不要**。4\(k\) 精确 QED \(\sim 1.51\times 10^7\) 维，本阶段不做 |
| 900 s 预算够不够？ | Q0 口径够（696 s）；历史缩放不够（953 s）。建议批准时把硬上限留在 **900 s**，超时保留已完成作业，不自动延长 |

若批准 Q1a，正式物理交付必须从**同一次**四路传播后处理，而不是新作业：

1. 平台连续频谱（整数阶投影 \(\neq\) 已认证 HHG）；
2. 中央两周期 \([2T_0,4T_0]\) 矩形 Fourier，H1–H6 的 \(\mathcal J^{e/o}\)；
3. 平台前、后两个两周期窗的复振幅一致性；
4. 两态磁序奇复源差 \(\Delta\mathcal J^o_q=\mathcal J^{o,\mathrm{DS}}_q-\mathcal J^{o,\mathrm{C}\alpha}_q\)。

同 α 只是第一步。缺少同 \(\langle n\rangle\) 对照时，不能把差异全部归因于非经典性。耦合开关与输入统计的交叉效应列为解释边界，暂不新增真空作业。

\(A^*_{\mathrm{mean}}=0.0202044\)，经典 \(A^*=0.8\)，相差 39.6 倍。禁止与冻结的强场 Γ96 / D1 拼接。
