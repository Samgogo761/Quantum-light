# 线 Q：零驱动电子内禀电流噪声——一页交接（2026-09-24）

**本轮只查关掉激光后，电子自己的电流涨落会不会在能隙以下留下连续红外噪声。没有接光子，也没有改初态。**

规定输入下的诱导电流上一轮已经按 \(\omega^3\) 过门。完整电流二阶账本还缺电子内禀项 \(S_{I,\mathrm{int}}\)。本轮用冻结 M0 的未对称 \(C^>\) 做静态谱求和。

结果：

1. 四套网格的全部粒子—空穴跃迁都满足 \(\Delta\ge\Delta_{\min}\approx0.0927\)。严格低于最小直接隙的跃迁数是 **0**。未加展宽时，\(0<\omega<\Delta_{\min}\) 上 \(S^>=S^<=0\)。
2. 噪声和对易响应锁在同一套约定里：\(K=-R^\kappa\) 推出 \(K(\omega+i\eta)-K(\omega-i\eta)=-i(S^>_\eta-S^<_\eta)\)。小矩阵测试通过；四套 BZ 探针最大残差约 \(10^{-12}\)。等时 \(C^>\) 本身约 45，说明电流涨落存在，只是不落在隙下。
3. 有限 \(\eta=10^{-4}\) 的洛伦兹展宽会从隙上极点漏进隙内，\(0.9\Delta_{\min}\) 处 \(\operatorname{Tr}S^>_\eta\sim0.10\)。这是诊断展宽的尾巴，不是物理 \(T_2\)，不能当成隙下真有连续谱。
4. 规定、独立的输入场下，连通交叉项 \(\langle\delta I_{\mathrm{int}}\delta\kappa_{\mathrm{in}}\rangle_c=0\) 是乘积参考态的构造结果。一旦打开自洽 \(A_{\mathrm{self}}\leftrightarrow I\)，这项不再为零。

这一步支持的是：**P1=0 绝缘体在隙下没有未展宽的内禀电流连续谱。** 它没有证明联合 Maxwell 稳定，也没有批准极点分析。
