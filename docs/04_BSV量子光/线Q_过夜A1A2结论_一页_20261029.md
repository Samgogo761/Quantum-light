# 线 Q：过夜结论一页（2026-10-29）

三套光协议始终分开：Q6 是 24.8 μm、α=0.5、r=0.3 的精确/GH5 机制线；1600 nm M0 统计与 CrI₃ 相干 SBE 不是它的放大。权威 QED 数字不改写：振幅比 4.98，协方差反转 110.6°，ρ=1.456，R=1.273。

## 1. Δ=0 / SOC=0 是否关掉奇通道？

**是。** 乘积 GH5、Q6 原协议、θ=0/π：

- Δ=0：±N Hamiltonian 差为 0，H2 奇 2D 范数为 0。这是定义一致性，不是新机制。
- SOC=0：奇 2D 范数 ~10^{-16}，奇/偶 < 3×10^{-12}。最小能隙 **1.066 eV**（有能隙，不是金属化）。不能仅凭信号消失宣称 SOC 独有机制，但动力学确实继承了核的门控。

## 2. 有限时间核能否解释至少一半的 79°？

**是，73.7%。** 绝热 −117.19° → 有限时间 −175.36° → QED arg(B) 163.90°。剩余 **20.7°**。

有限时间核**没有**预测 η=1.5 的约 50° 旋转。

## 3. 剩余 21° 和 η 旋转是不是 Ehrenfest 反作用？

**是，在乘积 GH5、θ=0/π 协议下。**

| 条件 | arg(B) | 说明 |
|---|---:|---|
| kick=True，η=1 | 167.82° | 对齐冻结 GH5 167.7°（0.12°） |
| kick=False，η=1 | −175.64° | 对齐有限时间核（0.28°）；相对 QED 20.46° |
| kick on−off，η=1 | −16.54° | 剩余 21° 就是反作用 |
| kick=True，η=1.5 | −141.51° | 旋转 **+50.68°**，复现 Q4 量级 |
| kick=False，η=1.5 | 179.49° | 旋转只剩 −4.87°，关掉 kick 后旋转消失 |

机制分层现在可以写：

1. 数态块：J = Tr(ρ_ph K)，B 读 Δn=0，A/C 读 Δn=±2。
2. 输入统计窗：R=|M|/α²=1.273 使相位干涉成为 O(1)；材料只把 GH5 的 ρ 留在约 R，QED 再修正到 1.456。
3. 电子动力学：主窗相位 ≈ 有限时间二阶核 + Ehrenfest 反作用；Néel 与 SOC 是奇通道门控。

A 仍然不是 χ^{(2)}，也不是 K_N。邻窗 16%–39% 仍在，所以这是有限时间复响应，不是认证产额。

## 4. M52 相对 M88/full112：缺通道还是网格？

**H2 振幅不是缺通道；相位/偏振是模型差；不要加密 M52。**

同一 1600 nm / 25 fs / 10^{10} W/cm² / 2×2 相干光：

- 振幅同量级（M88/M52=0.82，full112/M52=0.785，M88/full112=1.05）。
- M52 相位 −26.8°、Jy/Jx=2.43；M88 +131.3°、1.31；full112 +143.9°、1.35。M88≈full112，M52 不是同一偏振族。
- H4 在 2×2 上不可用（M88 去边 Δφ=−64°）。

后续材料抽检用 **M88**。M52 的 4×4 振幅降 6.6 倍另案检查，不升格为生产网格。
