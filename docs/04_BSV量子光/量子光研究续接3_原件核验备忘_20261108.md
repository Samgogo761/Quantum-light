## 4. 现在允许说、不允许说

允许保留：

- A 线在若干明确模型内，BSV 的 GHZ fidelity 高于该协议下全部允许正 P 输入的解析或对偶上界。最完整的一个点是 A-6.4d，但模型停在二阶两能级 dispersive Hamiltonian。

- Q 线的真实 M0 低截断计算没有给出 BSV 输出优势；输入三阶矩和输出 `Dout` 都未收敛。
