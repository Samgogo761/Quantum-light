## 2. 本轮补做的独立核验

Cursor 的“对易子残差 0”实际比较 c-conj(c) 与 2i Im(c)，是同一个复数的恒等重写，并非独立算符核验。检查位置：tools/b0_small_model/q8_m0_response_verify.py 的 check_commutator_snapshots。

本轮用已有 a2 六点 ±N 数据中的 Vv(t)、Vc(t) 拼成 V(t)，重新计算

\[
j_a^{H}(t)=V^\dagger(t)j_a(t)V(t),
\]

在初始占据块直接求

\[
\sum_k w_k\operatorname{Tr}\{\Pi_0[j_a^H(t),j_b^H(t')]\},
\]

再与存量 X 所得 c_ab(t,t')-c_ba(t',t) 比较。

数据：results/q_line/cjj_m0_p1_a2_s1_20260917/B0_sixk/ 下两个 B0_sixk_N±1_A+1.npz。

两畴各有 25 个时刻，覆盖 0 至 1005.309649；全部时刻对及 x/y 方向组合，共各 2500 组。

| 磁畴 | 最大绝对差 | 除以直接对易子的全局最大模 |
|---|---:|---:|
| +N | 4.98×10^-14 | 6.78×10^-16 |
| -N | 4.27×10^-14 | 5.75×10^-16 |

X 子块重建最大差分别为 3.66×10^-15、4.53×10^-15。此检查只读取已有数据并做小矩阵运算；没有新传播，没有修改原 JSON。

现在可以说：**这条算符关联恒等式在现有六点快照上得到独立矩阵验证。** 仍不能据此证明响应时间积分收敛、接触项全时实现正确或光输出完整。

## 3. 需修正的几处表述

### 3.1 前缀积分检查的范围

当前 two_time_state_dmu 并未独立构造两时 C，而是从头重算与前缀版本相同的累积矩阵 Z，再作相同收缩。两者使用同一左矩形规则、每隔 40 步的 81 个时刻，且均不含全时接触项。

结果为零证明求和重排一致；没有证明该粗时间积分准确。下一步独立核验应比较响应预测与真实微小测试场引起的电流中心差分，并纳入接触项。此类新小样本传播仍在本人物理定义审核之后。

### 3.2 7.16×10^-5 没有包含辐射频率因子

人审文档第 2 项把该数与 1/sqrt(omega) 联系得过紧。实际 psi_on_times 只算

\[
\psi(t)=\int_0^\infty\phi(\omega)e^{i\omega t}d\omega,
\]

然后与旧 sin² 电流窗的常数缩放比较。这里**没有**乘辐射核，也没有 1/sqrt(omega)。

需分别列清：

1. 正频波包形状近似：已在六点数据核过，误差约 7.16×10^-5。
2. 辐射因子的频率依赖：尚未重投核验。
3. 全 BZ 和完整检测时间误差：上述数字均不能替代。

代码元数据已改为近似，但 q8_m0_k1_packet.py 的 reproject_d_perpperp docstring 仍写严格等号，可顺手统一。

### 3.3 四点函数不等于新近似

人审文档写“Gaussian 与四点函数都是新近似”，后半句不正确。

四点函数是更高阶统计信息；在当前独立电子、Slater 初态下，可以继续用费米 Wick 定理计算，并不必然引入新物理近似。把输出光假定为 Gaussian、用二阶矩替代高阶矩，才是另需审核的闭合。高阶计算仍需工程与观测量设计，但不能仅因阶数增加就称它是物理近似。

### 3.4 GPU 和 AI 成本尚无性能依据

“主要耗时来自 Python 时间循环”目前未有分项计时证据。循环中包含批量对角化、矩阵乘法和滤波收缩，不能把都发生在循环内解释成 Python 本身是瓶颈。

六点适合正确性检查，不足以代表 48×48 批次的 CPU/GPU 性能。应针对已有目标批量规模计时，区分矩阵构造、eigh、乘法、累积、搬运和峰值内存。284 秒降到 30–60 秒只可列为设想，不能作为测得或可靠预测的加速。

因果响应也不是“只能”在线前缀积分：完整时间数据可后处理或分块重放。当前选择在线累积是节省内存的优先方案，不是数学唯一性。

离线 AI 抽样试验须说明未采样区域如何估计以及权重如何处理，不能只挑贡献大的点沿旧权重相加。完整 V48 只能作为“重现这张旧离散网格”的参考，不能认证连续 BZ 中尚未解析的磁性小量。比较总计算、训练和验证成本，并与传统误差排序比较。

## 4. 人审应该聚焦什么

四个问题不应变成让本人选择网格和脚本的新入口。建议明确成如下研究安排：

| 内容 | 推荐方向 | 保留的边界 |
|---|---|---|
| 第一版理论范围 | 强经典背景＋较弱量子扰动 | 强纯 BSV 主驱动不自动纳入；需要小规模基准检验适用范围 |
| 空间几何 | 真空均匀薄片、法线、单侧参考通道 | 面积先符号化；周期片版本应明确 S=N_cell A_cell，不能把两者作为不相关旋钮 |
| 第一批输出 | 真空输入下最低阶平均场与正常二阶量的源贡献 | 原平均 H2 不稳定的限制继续保留；响应及异常矩的纸面推导并行，不必等全部量子输入完成 |
| 应用 | 保留相位/关联磁畴读取目标 | 暂不宣布磁性通道或判别优势成立；不立刻优化没有定义完的 SNR |

**时间范围需要单独具体化。** “电子数据只到脉冲末”是当前存量事实，不是一项已经完整定义的探测协议。不能把它与真空薄片捆绑成一个选项，让本人勾选后就当成完整输出。

理论稿应说明究竟计算有限时刻的场量、带物理时间门的检测，还是完整出射波包；有限时刻场量不自动等于远场最终光子统计。先保持全时间关系的推导，再明确现有 [0,Tp] 数据能验证的部分及缺失部分。不得自行增加退相干或假设脉冲后电流消失。

面积暂留符号不妨碍推导和阶次检查；真实空间重叠尚未确定时，也不能输出任意绝对光子数字。

### 数学稿应补齐的内容

- 从真空片辐射推导参考模式核，分别处理空间面积、正频率与频率因子。

- 分别列出正常矩与异常矩所需的同阶贡献。不要将输出高斯化或更高阶统计顺带批准。

### 审核后最小物理验证

在固定 M0/P1 和相同初态下，仅用原有六点设计 A_cl±epsilon h，记录全时接触项，与响应预测比较；h 在初始时刻为零。检查 epsilon 的线性范围及时间离散，不升级为全 BZ 新生产任务。

这个检验回答的是：“我们推的响应，能否正确预测一个微小附加场造成的实际电流变化？”它比再报一个代数残差零更接近下一阶段需要的物理证据。
