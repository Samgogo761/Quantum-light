# G1 工作记录：两点时间步收敛（2026-10-14）

固定两个 \(k\) 点、同一 526 个频率、同一初值列、同一八周期 P1 和同一个 H2 核。只改变每周期步数。不把以前另一套频率上的 \(5.8\times10^{-4}\) 放进这组外推。波包 Gram 是 \(G=U_0U_0^\dagger=(0.998110631049158)\,I\)，和 \(0.998110631049158\,I\) 的差在 \(10^{-16}\)。

## 1. 三张残差

\(R_N=UU^\dagger-VV^\dagger-I\)。\(R_N^{(G)}=UU^\dagger-VV^\dagger-G\)。\(\Delta C=UU^\dagger-VV^\dagger-U_0U_0^\dagger\)。这里 \(G=U_0U_0^\dagger\)，所以后两张相同。下表是 \((0,0)\) 实部；反常残差是最大模。

| 每周期步数 | \(R_N(0,0)\) | \(\Delta C(0,0)\) | \(\|R_A\|_{\max}\) |
|---:|---:|---:|---:|
| 128 | 0.00803806 | 0.00992742 | 0.00030585 |
| 256 | 0.00113080 | 0.00302017 | 0.00011613 |
| 512 | \(-0.00114331\) | 0.00074606 | \(3.243\times10^{-5}\) |
| 1024 | \(-0.00172364\) | 0.00016573 | \(8.423\times10^{-6}\) |

\(R_N-\Delta C=G-I\)，每一档都是 \(-0.00188937\)。静态波包缺口不随步长变化。

512 到 1024 的实部变化比是 3.92 和 3.98，非对角是 3.69。反常残差的对应比值是 3.48。这是二阶中点法的相邻差大约缩小四倍。

用 512 和 1024 做二阶外推：

| 量 | 外推后的 \((0,0)\) 或最大模 |
|---|---:|
| \(R_N\) | \(-0.00191708\) |
| \(\Delta C\) | \(-2.77\times10^{-5}\) |
| \(R_A\) | \(5.64\times10^{-7}\) |

\(R_N\) 的外推贴着 \(G-I=-0.00188937\)。强驱动带来的 \(\Delta C\) 还在按 \(h^2\) 下降，外推量级是 \(10^{-5}\)，不是 0.008 那一档。

## 2. 两种解释

在这套固定的 526 个频率上，0.008 主要是传播步长。时间连续极限里，相对单位阵留下的是波包质量缺口 \(G-I\)。相对 \(U_0\) 自己的 Gram，动态变化朝 \(10^{-5}\) 走，不是一个 \(O(10^{-3})\) 的平台。

因此这一轮不改输入谱，也不把通道删掉来压残差。1024 步时 \(\Delta C(0,0)\) 仍有 \(1.66\times10^{-4}\)；再按现在的二阶斜率，要把它降到外推的 \(10^{-5}\) 附近，大约还要再把步数提高一倍。那是精度，不是新的物理项。

\(\Gamma 12\) 的 0.007439 仍放在这组两点结果外面。G1 未通过，不进入 G2/G3。
