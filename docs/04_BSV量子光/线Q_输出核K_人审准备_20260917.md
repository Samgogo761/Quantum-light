# 线 Q：输出核 \(K_{\mu a}(t)\) 人审准备（2026-09-17）

性质：把“源核 \(d\)”和“将来某一束被收集的光”之间缺的那一层写清楚，供本人以后选模。**不冻结任何探测模，不算光子数、压缩或 \(g^{(2)}\)。**

一般结构不是创新点。Stammer 等（[arXiv:2504.13287](https://arxiv.org/abs/2504.13287)）在 Heisenberg 图像里对谐波模写出

\[
a_{q\lambda}(t)=a_{q\lambda}(0)e^{-i\omega t}+g\sqrt{q}\int^{t}\mathrm{d}t'\,e^{-i\omega(t-t')}\,\epsilon_{q\lambda}\cdot\mathbf d(t'),
\]

那是长度规范、偶极、通用发射体。Ilin 等（[arXiv:2604.20388](https://arxiv.org/abs/2604.20388)）在固体腔里用 \(D_{\mu\nu}(t,t')=\langle\delta j_\mu(t)\delta j_\nu(t')\rangle\) 接光子统计。我们若写“提出 \(b_{\mathrm{out}}=b_{\mathrm{in}}+\int K\mathcal{I}\)”本身没有新意。

还没有人替我们指定：**这块二维 PT-AFM 样品，实验收哪一个波包。** 那是基础设施。创新若存在，也只可能出现在“M0 的对称性如何约束**这个**模里的关联”，而不是核的形状。

## 1. 现在手里有的，和还缺的

已批准并算过的是每原胞源滤波（Q9/Q10）：窗函数 \(f_{na}(t)=\delta_{aa_0}(W/T_p)e^{in\omega t}\) 乘在电流上，得到 \(d_{na,mb}\)。它**不是**玻色归一化探测模，不能改名叫做光子数。

缺的是：在弱生成、指定输出真空和电磁环境这些假设获认可之后，

\[
\hat b_\mu^{\mathrm{out}}=\hat b_\mu^{\mathrm{in}}+\hat S_\mu+\text{同阶所需修正},\qquad
\hat S_\mu=\sum_a\int\mathrm{d}t\,K_{\mu a}(t)\,\hat{\mathcal I}_a(t).
\]

\(K_{\mu a}\) 必须同时装进：中心频率、带宽、偏振、传播方向、数值孔径/空间重叠、耦合常数和单位。滤波函数的内积决定 \([b_\mu,b_\nu^\dagger]\)。不能把 FFT 箱或 Hann 窗叫做 \(b_{\mathrm{out}}\)。

连通与相干仍要分开（Q11）：

\[
\langle B^\dagger B\rangle=N_{\mathrm{cell}}^2|b|^2+N_{\mathrm{cell}}d_K,
\]

其中 \(d_K\) 是用 \(K\) 而不是用 Q9 的 \(f\) 投出来的源核。没有物理 \(N_{\mathrm{cell}}\) 和收集几何，不能谈绝对光子数，也不能把 \(d/|b|^2\) 叫量子增强。

## 2. 选一个模，就是选定实验问哪句话

在二维样品、自由空间、法线附近收集的最小清单：

| 要你定的 | 它决定什么 |
|---|---|
| 传播方向 | 现在的源核是均匀 \(q=0\)。斜出射或有限光斑会要有限 \(\mathbf q\)，不能从当前 \(d\) 自动得到 |
| 偏振 | 接到 \(J_x,J_y\) 还是 \(\parallel/\perp\)。若源核按 \(\mathbf a_2\) 规则分开了，收集偏振仍沿 \(x\)，通道会再被混合 |
| 中心谐波与带宽 | “H6 的噪声”没有唯一答案，取决于窗 |
| 近/远场、是否进腔 | Ilin 的腔输入–输出不能直接搬进当前闭系统 M0 |

未选 \(\mu\) 之前，不存在一句笼统的“H6 量子噪声是多少”。

## 3. 示例家族（全部标 not_frozen）

下面只说明**选择的后果**，不是推荐，更不是已批准的生产模。

**家族 S0（尽量靠近现有源窗）。** 法线、偏振沿现在的 \(x\) 或 \(y\)、中心 \(2\omega\) 或 \(6\omega\)、带宽与 Q9 同量级。好处：和已算的 \(d_{2x,2x}\)、\(d_{6y,6y}\) 最像。坏处：不利用 \(\mathbf a_2\) 选择定则；对角核在理想镜下不分畴。

**家族 S1（对准 \(\mathbf a_2\) 规则）。** 法线、偏振沿 \(\hat n\)（横向）、中心偶次；或一个模沿 \(\hat{\mathbf a}_2\) 收奇次、另一个沿 \(\hat n\) 收偶次，看跨模协方差。好处：平均电流的 \(J_{o,\perp}\) 和 CJJ 的 \(c_{\parallel\perp}\) 有机会对上收集。坏处：要先有 \(\mathbf a_2\) 驱动协议，或至少在报告里把 \(x,y\) 投到 \(\parallel/\perp\)；生产晶格镜子只是近似。

**家族 S2（腔/压缩统计）。** 把 Ilin 那类单侧腔模搬过来。这会改掉开放边界和弱生成假设，属于另一套人审，不是“把 \(K\) 写出来”就能做的。

无论哪一族，电子 Wick 都不自动给出输出光的玻色 Gaussian 闭合；\(g^{(2)}\) 一般还要更高阶关联。
