## 3. 必须从代码回答的问题

1. \(g\) 是零点矢势耦合、Peierls 动量位移系数，还是别的？写出 \(q_g=g(\mathbf e\cdot\delta)\) 与 \(X=a+a^\dagger\) 的真空方差约定。
2. 现有单位里 \(\hbar\)、\(e\)、\(A\) 是否出现，还是 \(g\) 直接无量纲地乘键矢？
3. 线性力 \(F_{\mathrm{shared}}\propto -g\langle J\rangle\) 是否意味着反作用已经按同一 \(g\) 标定？
4. \(s(t)\) 是外加耦合开关，不是自由空间脉冲包络。标定不得把 1+4+1 写成 25 fs 高斯脉冲。
5. 同一 \(\alpha=0.5,r=0.3,R=1.273\) 在 24.8 μm 与 1600 nm **不**代表同一电场或同一脉冲能量。

若代码与 `PHYSICS_CONTRACT.md` 冲突，以代码为准，并在报告里写冲突点。不要为了公式好看去改代码。
