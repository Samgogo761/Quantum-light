# 固定输出模式的精确离散转置（2026-10-08）

本文件给出当前中点传播和探测积分的等价计算式。它不是新的物理模型，不是物理上的时间倒演，也不是高阶积分器。目的仅是：在只需 H2 两个偏振的输出行时，不再为每一个入射列保存和逐步推进整套电子状态。

所有原始输入列、暗方向、正频求积权重、接触项、背景轨迹、探测核和 canonical `U0` 保留。生产前向程序没有改动。

## 1. 原算法的离散形式

将一个列的联合坐标写为

\[
x_j=(b_j,b_j^\dagger,A_j)^{\mathsf T}.
\]

这里 `bdag` 是独立的线性系数数组，不是 `b` 的数值共轭。令电子顶点为 \(u_j\)，接触项为 \(D_j\)，时间步为 \(h\)，自场系数为 \(\gamma\)。原 CPU/CUDA 中点步进对应

\[
L_j=I+\frac{h\gamma}{2}D_j-
\frac{i h^2\gamma}{4}(u_j^*u_j^{\mathsf T}-u_ju_j^\dagger),
\]
\[
R_j=\left(\frac{h\gamma}{2}u_j^*,\frac{h\gamma}{2}u_j,I\right),\qquad
T_j=\begin{pmatrix}ih u_j^{\mathsf T}\\-ih u_j^\dagger\\2I\end{pmatrix},
\qquad D_0=\operatorname{diag}(I,I,-I).
\]

因而

\[
x_{j+1}=M_jx_j+N_jf_j,\qquad
M_j=D_0+T_jL_j^{-1}R_j,\quad N_j=\tfrac12T_jL_j^{-1}.
\]

自由光输入增量逐列为

\[
f_{j,c}=A_{\mathrm{free},0,c}\,e^{-i\nu_c(t_0+jh)}
\operatorname{expm1}(-i\nu_ch).
\]

暗列的自由光输入为零，但其初始电子坐标仍完整参与。

## 2. 将探测泛函向前时刻递推

电流行 \(J_j=(u_j^*,u_j,-D_j)\)。设偏振投影矩阵为 \(P_{\rm pol}\)，则当前探测增量是

\[
y\mathrel{+}=q_j\frac{x_j+x_{j+1}}2,
\qquad q_j=hK_jP_{\rm pol}J_j.
\]

从 \(\ell_{N_t}=0\) 开始，倒序循环时间点：

\[
s_j=\ell_{j+1}+\frac{q_j}{2},\qquad
\ell_j=\frac{q_j}{2}+s_jM_j,\qquad F_j=s_jN_j.
\]

因此每列的最终输出严格是

\[
y_c=\ell_0x_{0,c}+\sum_jF_jf_{j,c}.
\]

不形成大型 \(M_j\)：令 \(Z_j=(s_jT_j)L_j^{-1}\)，使用

\[
\ell_j=\frac{q_j}{2}+s_jD_0+Z_jR_j,\qquad F_j=Z_j/2.
\]

这是双线性的普通转置：代码使用 `solve(L.T, ST.T).T`。改成厄米共轭会改变原问题。

## 3. 两类输出与无泵参考

当前前向程序分别积累

\[
y_U=\sum_jhK_j(P_{\rm pol}I_j),\qquad
y_V=\sum_jhK_j(P_{\rm pol}I_j)^*.
\]

对 \(K\) 和 \(K^*\) 各递推两个输出行，第二组最终整体共轭，就得到 \(y_V\)。即便偏振投影是复数，也不能在第二组提前额外共轭偏振矩阵。

有泵、无泵两条路径分别计算后仍使用

\[
\Delta U=y_{U,\mathrm{driven}}-y_{U,\mathrm{undriven}},\quad
V=y_{V,\mathrm{driven}}-y_{V,\mathrm{undriven}},\quad U=U_0+\Delta U,
\]
\[
n=V^*V^{\mathsf T},\qquad m=UV^{\mathsf T}.
\]

\(U_0\) 从冻结的 `U0_canonical` 读取，绝不是把无泵源积分改名。所有输入的 \(\sqrt{d\nu}\) 等权重已在原列中，本算法不再乘第二次。

## 4. 精确性与适用范围

在相同输入、同一离散时间网格和同一探测积分下，两种求值方式在精确算术中相等。浮点累积次序不同，需逐项比较原始有泵/无泵行、\(U,V\) 及其收缩。它不强行修复对易关系，也不会减小原来的时间离散误差。

成本从逐列推进的主项 \(N_tN_{\rm el}N_{\rm col}\)，转为少数输出行递推、初始列收缩和非均匀频率的分块直接求和。当前没有使用低秩截断、NUFFT、降精度或机器学习近似。

当前的共享背景使所有输入列经历同一线性算子；若以后量子反馈改变该背景，须重新判断是否仍满足此前提。该方法也不交付全时电子占据和末态，因此不能替代 Pauli 或完整状态诊断所需的传播。
