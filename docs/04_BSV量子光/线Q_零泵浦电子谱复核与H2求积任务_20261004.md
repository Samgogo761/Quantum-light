2026-10-04。审核 R2 收尾、stage1ao 源码和 JSON；哈希一致。本轮只读复核与存量矩阵重算，没有启动电子传播或新 BZ 作业。

## 本轮可验收

1. 两点 M0 光子投影已使用占有 D 和冻结 gamma_self，原人工参数未混入这项校正。
2. 人工暗列激活满足 du* v 非零，独立中点对照约 6.7e-16。
3. 同源谱代数恒等式通过。
4. 固定 H2 源窗口的未展宽积分确有网格分歧。由 JSON 复现：
   - 128→192：迹相对差 2.3218%，完整 2×2 复矩阵 Frobenius 相对差 2.0703%；
   - 192→半步192：迹差 1.5124%，矩阵差 1.5815%。
   这没有达到原脚本 0.5% 的 H2 门槛，但不是光子数、磁畴差或量子输出结论。

“激活电流在三个时刻均为 0.18”指对初始暗列评价顶点源；真实演化电流在 JSON 中为 0.18、0.1770、0.1749。两者已分开保存，不能将前者写成演化电流严格恒定。

## 必须修正的谱形比较口径

stage1ao 的 shape_omega 依赖每套网格各自的最小能隙；_eta_l1 却直接逐数组位置比较，没有检查 omega 相同。

128 与 192 的对应频率最多错开 8.8834e-4，已接近 eta=1e-3。因此现有“22%”混合了网格变化和频率错位，不能作为纯 BZ 网格误差引用。

另：这个量是离散探针的无权样本差，不是连续频率 L1 积分。192 同一网格上 eta 改变得到的 30% 可作为同频样本敏感性，但同样不是完整谱的 L1 误差上界。当前只有 28 个频率点，不可对窄峰随意插值补救。

更正报告和状态：代数通过、固定 H2 积分未达门槛保留；旧 22% 标记为频率未对齐的旧诊断。粗直方图约 2.2% 只代表这组固定粗分箱的质量分布。

存量中仍有同一绝对频率的独立证据：omega=0.1、eta=1e-3 时，谱迹在 Gamma128/Gamma192/半步192 分别为 12.1553、16.2096、13.2231；相对变化 25.01% / 22.59%。因此细谱未稳的结论保留，只更正原来 22% 的全谱形口径。

## 下一轮执行目标

**只完成固定 H2 源窗口积分的一次有针对性 BZ 求积，以及必要的同频谱形更正。**

不改 Hamiltonian、初态、D、P1、探测波包或耗散；不运行时间传播、完整入射列、远场或 n/m/V。本任务在已有授权内，不要求用户选网格或脚本。

### 第一步：固定被积对象

继续计算源诊断矩阵
\[
M_{ab}=\sum_{kcv}w_k X_a^*X_b F(\Delta_{kcv}),
\]
其中 F 是本轮既定 H2 频率权。完整 2×2 复矩阵必须保存，不能只看迹；权重只计一次。

这是零泵浦电子涨落谱的频率积分，不是无泵浦发光，更不是最终 H2 输出。

先核对 F 的实现误差：目前在 [0,0.6] 上插值并将外部置零。用已有 window_fourier 直接评价，核对插值与正频尾对目标矩阵的影响；若已远小于目标误差，只记录证据，不另开无限精度任务。不得将这个数值截断变成物理光子截止。

### 第二步：一次局部求积

复用原始 (k,c,v) 数据，定位哪些 BZ 区域真正贡献 H2 窗积分及网格分歧。此前“靠近隙边”是合理线索，不是已证明所有误差都在那一圈。

采用覆盖全 BZ 的一次有限细化方案：

- 每个区域权重明确且总和为 1，粗细区不重计、不漏计；
- 保持适用的反演配对；不把近似镜面对称当精确替代；
- 细化区域由实际贡献/误差指示确定，不能仅凭粗网格某个节点的 gap 截断，避免漏掉单元内部隙边；
- 未细化区域仍积分；窗口尾和高能弱贡献不擅自丢弃；
- 配一个独立求积位置或另一规则的有限对照。

先给出点数与本机成本估计，然后执行一轮。无需上服务器或无界追加全局密网格。

### 第三步：验收与同频谱形

- 沿用原 H2 0.5% 作为本轮有限诊断目标，补完整矩阵差与各分量绝对误差；接近零的分量不要用不稳定相对误差。
- 检查矩阵 Hermiticity、正半定性、权重和及旧数据可重构。
- 如补固定 eta 谱形，所有网格须用完全相同的绝对频率点与评价权重；优先 H2 邻域的小范围，不重复扫描全频段。
- 固定 eta 先查 k 求积；只有 k 已分辨时才讨论缩小 eta。代数 jump 一致不等于连续极限。

如果本轮只得到稳定的窗积分，准确写“此固定频率投影有限资格通过”；不能顺带宣布点值谱或整个连续电子边界收敛。后续完整入射列还需要相应的主值与内部标签映射。
