# G1 工作记录：左右端口的奇偶分解（2026-10-15）

没有删端口，没有改 \(U,V\)，没有重跑传播。用的是已核对 sha256 的宏步 2048 伴随行。

## 1. 已批准的电流片关系

零厚度均匀片上，同一电流进入两侧（`线Q_有限kcv输入账本与辐射接口_20261005.md`）：

\[
A_{R,\mathrm{out}}=A_{L,\mathrm{in}}+A_{\mathrm{self}},\qquad
A_{L,\mathrm{out}}=A_{R,\mathrm{in}}+A_{\mathrm{self}}.
\]

奇偶组合 \(A_\pm=(A_L\pm A_R)/\sqrt{2}\) 满足

\[
A_{-, \mathrm{out}}+A_{-, \mathrm{in}}=0,
\]

\[
A_{+,\mathrm{out}}-A_{+,\mathrm{in}}-\sqrt{2}\,A_{\mathrm{self}}=0.
\]

奇通道不耦合局部电流。静止列上 \(A_L=A_R\)，所以这些列的奇场为零。这不是把右端口叫成偶、左端口叫成奇。

探测在同一侧。稳态读出因此不对称：左行入射列的出射含透射偏振和自场，右行入射列在该侧的出射只有自场。自场满足 \(A-A_f=i\gamma I/\omega\)，先前最大偏差 \(2.34\times10^{-17}\)。代码里的 \(U_0\) 对应这个读出：左侧用片上场 \(a\)，右侧用 \(a-A_f\)。两侧动力学列相同，是因为存进去的是同一份偶激发，不是因为输出公式把两侧写成了同一个数。

## 2. 基变换

\[
c_\pm=\frac{c_L\pm c_R}{\sqrt{2}}.
\]

变换是实正交的，湮灭列和产生列用同一套系数：

\[
U_\pm=\frac{U_L\pm U_R}{\sqrt{2}},\qquad
V_\pm=\frac{V_L\pm V_R}{\sqrt{2}}.
\]

\(R_N=UU^\dagger-VV^\dagger-I\) 只对每一列做外积再相加。\(U_+U_-^\dagger\) 是不同输入之间的相干，不进入 \(R_N\) 或 \(R_A\)。第一份 `port_parity_macro2048.json` 的 `total_normal_residual` 把这项加进去了，\((0,0)\) 变成 5.222，那个字段不能用。列外积的残差在 `port_parity_macro2048_column_gram.json`。

反对称通道没有动力学，它的 \(U_0\) 仍占静态恒等的一半，必须留在求和里。删掉它会拆掉已经收到 \(10^{-12}\) 的静态 \(U_0U_0^\dagger\)。偶通道承担全部 \(+20.11770\) 的交叉项和全部动态二次项。暗列抵消其中的大数。余数 \(1.61\times10^{-5}\) 在这个和里，不在反对称动力学里。

\(U_+U_-^\dagger\) 的 \((0,0)\) 是 \(+5.222\)。它说明偶、奇读出在同一个二维 H2 空间里不正交，但按定义不是 \(R_N\) 的一项。基变换因此没有、也不该把残差消掉。

## 4. 恒等式能够检查到哪一步

奇通道：\(V_-=0\)，\(\Delta U_-=0\)，输出就是直接传播 \(U_{0-}\)。这一条在现有列上成立，偏差是 \(10^{-15}\)。

偶通道耦合电流，自场两侧相同。偶通道的交叉项必须和 \(\Delta U_+\Delta U_+^\dagger-V_+V_+^\dagger\)、暗列二次项、以及 \(U_{0-}\) 一起收成 \(I\)。这就是这组基下的正则条件本身。数值上奇通道已是纯 \(U_0\)，交叉项全部在偶通道，和上一份分解的 \(+20.11770\) 与 \(-20.11769\) 是同一笔。余数仍是 \(1.61\times10^{-5}\)。没有从运动方程推出一个比这更强、又能让余数必须更小的独立恒等式。

暗列没有 \(U_0\)，但二次项是 \(-291.657\)。初始电流为零只说明它们在电流核里，不代替这一项。
