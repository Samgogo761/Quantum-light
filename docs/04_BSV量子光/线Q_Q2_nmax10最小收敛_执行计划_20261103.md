### 闸门 1：主窗 H2 对照（4 轴都过闸门 0 之后）

对 θ=0 和 θ=π：

1. 从新旧两个目录读 `p_*` / `m_*` 时间序列。
2. 调用 `windowQ1.z_channel(t, jp, jm, "main", q=2, parity="odd", axis="x"|"y", method="linear_exact")`。
3. **禁止**自己重写积分；**禁止** Hann。

主判定通道：**H2x odd**。H2y 只记录，不单独改变分类。

rel = |J10 − J8| / |J8|，Δφ = |arg(J10 conj(J8))|。

| 分类 | 预声明标准 | 行动 |
|---|---|---|
| **通过** | θ=0 与 θ=π 的 H2x 均有 rel < 2% **且** Δφ < 2° | 写报告，停。不扫 dt，不扩核 |
| **临界** | 仅允许 θ=0：2% ≤ rel < 5% 或 2° ≤ Δφ < 5°；且 θ=π 仍满足 2%/2° | 报告「θ=0 相消点对截断敏感」。停。不调 g |
| **失败** | 任一条 rel ≥ 5% 或 Δφ ≥ 5°，或 θ=π 不满足 2%/2° | 先查作业/窗/配对错误。不调 g，不升 nmax=12，不重拟合 A/B/C |

若 |J8| 与 windowQ1 表中参考值相对差 > 1%，先查读错文件，不要宣布截断不收敛。

本轮**不是** A/B/C 全角收敛证明，也不是 nmax=8 与 10 的观测量恒等式。
