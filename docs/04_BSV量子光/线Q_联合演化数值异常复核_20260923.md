# 线 Q：联合演化数值异常复核（2026-09-23）

本页复核上一份交接记录中的异常。M0、P1、规范、耦合、裸初态和两端口定义均未改。所有计算仍是两个电子动量点的算法诊断，不是全布里渊区物理结果。

## 结论先行

联合电子—光子传播仍**没有数值资格**。零经典泵浦在细时间步的巨大增长可以复现，但它既不是已经证实的物理增益，也不能归咎于电子背景轨迹或 Cayley 单步公式。旧“传播器交叉验证”与“99.95% 不稳定切片”不能作为证据。源波形的光子频带测试把 UV 截断与求积点数混在了一起；两轴拆分后，在本次最强通道上仍未通过 Maxwell 源核测试。

## 已核对的事实

1. `q8_m0_stage1w_propagator_crosscheck.py` 原 `expm_nopy` 的 Padé 多项式写错。对角矩阵 `diag(0.1,-0.1)` 原返回约 `-1.00004 I`，正确结果应为 `diag(1.10517,0.90484)`。先前由错误 Strang / 矩阵指数得出的极端分歧一律作废。现已修正公式，新增小矩阵单元测试；对角指数和二维保辛旋转误差约 `1e-16`。
2. 在零经典泵浦下，原本的电子顶点 `X(t)` 和接触项 `D(t)` 在 64/128/256 步每周期的共同采样时刻分别一致到约 `8.2e-12` 和 `6.2e-11`。因此这组爆发不是电子背景积分误差造成的。
3. 零泵浦的瞬时联合生成矩阵近似幂零。96 频率节点的四个抽样时刻 `max|K|≈0.13`，`max|K²|≤2.9e-14`；8 节点的两个时刻 `max|K²|≤1.2e-14`，但不同时间的交换子 `max|[K(t_1),K(t_2)]|≈0.117`。这解释了为何瞬时本征值计算出现 `1e-7` 级伪正实部，也解释了为什么每一步的 Cayley 和指数法几乎必然相同。不同时间的矩阵不对易，所以整体仍可能放大；必须检验时间排序和连续极限。
4. 修正后的两种单步方法在 **8 个频率节点的诊断盒**上，对零泵浦 `C_P` 给出相同数值：64、128、256、512 步每周期分别约 `0.146`、`0.280`、`9.20e9`、`2.53e18`，两种传播器的最终矩阵相对差约 `3e-14` 到 `6e-14`。这**不是独立高阶交叉验证**，因为两者使用相同的时间采样，而且 `K²≈0`。8 节点也未通过光子连续谱资格；这里只证明异常不依赖 Padé 代码。512 结果的绝对保辛残差很大，强放大下还需更适合的条件化误差检验。
5. 最强实际 `X(t)` 通道的规定源测试中，截止 `8ω₀`、96/384 节点的矢势最大相对误差分别是 `72.9%/58.6%`；截止 `64ω₀`，保持低频 96 点而使用 96/768/1536 个 UV 点时是 `343%/22.1%/22.1%`。后两者显示该 UV 截止下求积点数已稳定，但源核**仍未合格**。旧“扩大 UV 后变差”主要混入了固定节点数造成的求积失分辨。22.1% 的剩余偏差不能单凭此测试归因于截断、采样 Nyquist、脉冲端点或目标离散化中的某一个。
6. **已定位时间步突变的直接数值来源。** 原联合传播用相邻端点平均近似 `K(t)` 的中点；零驱动的 `X(t)` 本身在 64/128/256 档的共同采样时刻精确一致，但它含快速相位。用两倍电子时间网格提供真正中点，在同一个光子诊断盒、同一个粗步长下，`C_P` 从每周期 128 步的 `0.280` 变为 `1.93e8`，从 256 步的 `9.20e9` 变为 `2.04e18`。128 步时只把电子顶点 `X` 改为真实中点，就得到 `1.90e8`；只把光子波形 `F` 改为真实中点，仍是 `0.289`。因此旧“小且稳定 → 256 步突然有物理阈值”的解释被否定：**端点平均电子快速相位**严重抑制了耦合。真正中点仍没有连续极限，巨大数也未获物理资格。表在 `results/q_line/stage1ab_midpoint_sampling_n8_ntpc128_20260923.json` 和同目录的 256 档文件。

## 物理边界与下一刀

- `P1=0` 控制的 64/128 两点并不形成收敛平台；256/512 的巨大数字也没有物理资格。不能据此选择 dressed 初态、加入退相干或宣称小涨落近似失效。
- 瞬时 `Re λ>0` 和不定 Hessian 不能在此相互作用表象中作为失稳硬门槛。原 `stage1z_hamiltonian_stability.json` 的原始数值保留，但 `unstable_slice_fraction` 的物理标签撤销。
- 下一步先把真正中点采样做成受控算法输入，并对**规定源**做 UV 截止、求积密度、时间采样三轴分离，与解析或高精度因果核比较；确认真实 `X(t)` 的时间端点/频谱处理。再用独立的时间排序方法复核联合传播。不要先上 64–128 `ω₀` 的大规模联合作业。
- 全 BZ、物理面积 `S`、输出光子数、压缩度、量子泵浦继续关闭。只有数值表示和时间排序形成平台且零驱动的增长仍在时，才把“裸初态还是耦合真空”交给本人作物理审核。
