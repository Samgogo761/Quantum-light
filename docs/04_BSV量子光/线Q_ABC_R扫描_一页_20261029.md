## 判定

- a05r03 对齐 A2b：ρ=1.2685（目标 1.268），Jx π/0=8.016（目标 8.016），arg(B)=167.82°（目标 167.82°）。
- GH5 上 ρ/R 均值 0.9976，相对散度 0.27%。大相位干涉由输入统计窗 R 控制；材料在本层几乎不改 |M| 与 α² 的相对权重。
- |A+C|/|M| 与 |B|/α² 的比值均值 0.9976。若接近 1，说明异常关联与位移数态块被同一电子核读取。
- arg((A+C)/B) 偏离 180° 最多 4.7°。
- QED 的 ρ/R=1.144 不在本层。那是精确量子映射相对 Ehrenfest/GH5 的修正，不是 χ^{(2)} 选择定则。
- 低 R 点 a12r03（R=0.221）接近明亮 80%/20% 窗口：ρ=0.222，2D π/0=1.57。这解释了 1600 nm DS 为何没有 110°。

可证伪命题：在固定 Hamiltonian 与探测窗下，
\(\mathcal J_2^o(\theta)\approx K_B\alpha^2 + K_M M(\theta)\)，GH5 上 \(K_M/K_B\approx 1\)。
因此 O(1) 相位干涉要求 R≳1，而不是更大的 α。QED 把该比值修正到约 1.14。
