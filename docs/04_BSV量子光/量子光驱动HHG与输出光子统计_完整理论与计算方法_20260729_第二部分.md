## 4. 经典材料基线：从多带 Hamiltonian 到电流算符

量子输出理论不能跳过已经验收的经典材料动力学。对本课题，材料层的正确起点不是四带对称性玩具模型，而是 M88-full 或 full112 给出的多带 Wannier Hamiltonian。

### 4.1 Wannier Hamiltonian

定义：

- \(\mathbf R\)：晶格矢量；
- \(\mathbf k\)：第一 Brillouin 区中的晶体动量；
- \(\alpha,\beta\)：含原子、轨道和自旋信息的 Wannier spinor 指标；
- \(H_{\alpha\beta}^{(W)}(\mathbf R)\)：从原胞中的 Wannier 轨道 \(\beta\) 到位于 \(\mathbf R\) 原胞中的轨道 \(\alpha\) 的实空间矩阵元；
- \(N_W\)：Wannier spinor 数；full112 时 \(N_W=112\)，M88-full 时 \(N_W=88\)。

Bloch Hamiltonian 为

\[
\boxed{
H_{\alpha\beta}^{(W)}(\mathbf k)
=
\sum_{\mathbf R}
e^{i\mathbf k\cdot\mathbf R}
H_{\alpha\beta}^{(W)}(\mathbf R).
}
\tag{4.1}
\]

对每个 \(\mathbf k\) 点，用幺正矩阵 \(U(\mathbf k)\) 对角化：

\[
\boxed{
U^\dagger(\mathbf k)
H^{(W)}(\mathbf k)
U(\mathbf k)
=
\varepsilon(\mathbf k),
\qquad
\varepsilon_{mn}(\mathbf k)
=
\varepsilon_{n\mathbf k}\delta_{mn}.
}
\tag{4.2}
\]

这里 \(m,n\) 是 Hamiltonian-gauge 能带指标，\(\varepsilon_{n\mathbf k}\) 是第 \(n\) 条 Bloch 带能量。

### 4.2 长度规范 SBE

定义：

- \(\rho_{\mathbf k}(t)\)：单粒子约化密度矩阵；
- \(\mathbf E_{\rm cl}(t)\)：作为强背景完整处理的经典驱动场；
- \(\mathbf D(\mathbf k)\)：选定基底中的带间位置/偶极矩阵；
- \(\nabla_{\mathbf k}^{\rm cov}\)：对 Bloch gauge 协变的 \(\mathbf k\) 空间导数；
- \(\mathcal D_{\rm mat}\)：物质开放系统的耗散或退相干超算符。

在原子单位 \(e=\hbar=1\) 下，本项目的经典材料基线写成

\[
\boxed{
\partial_t\rho_{\mathbf k}
=
-i
\left[
H_0(\mathbf k)
+
\mathbf E_{\rm cl}(t)\cdot\mathbf D(\mathbf k),
\rho_{\mathbf k}
\right]
+
\mathbf E_{\rm cl}(t)\cdot
\nabla_{\mathbf k}^{\rm cov}\rho_{\mathbf k}
+
\mathcal D_{\rm mat}[\rho_{\mathbf k}].
}
\tag{4.3}
\]

式 (4.3) 中的两个场耦合项都来自长度规范相互作用 \(e\mathbf E_{\rm cl}\cdot\hat{\mathbf r}\)。Bloch 表象中的位置算符为

\[
\boxed{
\langle\psi_{m\mathbf k}|
\hat r_a
|\psi_{n\mathbf k'}\rangle
=
i\delta_{mn}
\partial_{k_a}\delta(\mathbf k-\mathbf k')
+
\mathcal A^a_{mn}(\mathbf k)
\delta(\mathbf k-\mathbf k'),
}
\tag{4.4}
\]

其中

\[
\boxed{
\mathcal A^a_{mn}(\mathbf k)
=
i\left\langle
u_{m\mathbf k}
\middle|
\partial_{k_a}u_{n\mathbf k}
\right\rangle
}
\tag{4.5}
\]

是 Berry connection。式 (4.4) 的导数部分产生带内加速，矩阵部分产生带间跃迁与相干。

### 4.3 经典驱动下的“零阶物质态”

这里的上标 \((0)\) 表示对**量子辐射场涨落耦合**取零阶，而不是对经典强场取零阶。

若物质是闭系统，定义经典驱动传播子

\[
\boxed{
i\hbar\partial_t
U_{\rm cl}(t,t_0)
=
H_{\rm mat}^{\rm cl}(t)
U_{\rm cl}(t,t_0),
\qquad
U_{\rm cl}(t_0,t_0)=I,
}
\tag{4.6}
\]

其中

\[
\boxed{
H_{\rm mat}^{\rm cl}(t)
=
H_0
-\hat{\mathbf d}\cdot\mathbf E_{\rm cl}(t).
}
\tag{4.7}
\]

则

\[
\boxed{
|\Psi_{\rm mat}^{(0)}(t)\rangle
=
U_{\rm cl}(t,t_0)
|\Psi_{\rm mat}(t_0)\rangle .
}
\tag{4.8}
\]

有退相干时，单一纯态通常不再足够。应改用

\[
\boxed{
\rho_{\rm mat}^{(0)}(t)
=
\mathcal U_{\rm cl}(t,t_0)
\rho_{\rm mat}(t_0),
}
\tag{4.9}
\]

其中 \(\mathcal U_{\rm cl}\) 是式 (4.3) 所定义的含耗散传播映射。

### 4.4 二次量子化电流算符

定义：

- \(\hat c_{n\mathbf k}^{\dagger}\)、\(\hat c_{n\mathbf k}\)：第 \(n\) 条 Bloch 带上电子的产生、湮灭算符；
- \(v^a_{mn}(\mathbf k)\)：沿 \(a\in\{x,y,z\}\) 方向的速度矩阵元；
- \(V_{\rm cell}\)：归一化体积或有效二维样品面积；
- \(\hat J_a\)：沿 \(a\) 方向的总电流算符。

单粒子近似中的电流算符为

\[
\boxed{
\hat J_a
=
-\frac{e}{V_{\rm cell}}
\sum_{\mathbf k}
\sum_{mn}
v^a_{mn}(\mathbf k)
\hat c_{m\mathbf k}^{\dagger}
\hat c_{n\mathbf k}.
}
\tag{4.10}
\]

在经典 SBE 中输出的是其一阶矩

\[
\boxed{
J_a^{(0)}(t)
=
\langle\hat J_a(t)\rangle_0
=
-\frac{e}{V_{\rm cell}}
\sum_{\mathbf k}
\operatorname{Tr}
\left[
v^a(\mathbf k)\rho_{\mathbf k}^{(0)}(t)
\right].
}
\tag{4.11}
\]

式 (4.11) 决定平均发射场，却不包含完整的算符涨落。

### 4.5 为什么平均电流不足以得到光子统计

定义涨落算符

\[
\boxed{
\Delta\hat J_a(t)
=
\hat J_a(t)
-
\langle\hat J_a(t)\rangle .
}
\tag{4.12}
\]

仅知道式 (4.11) 相当于只知道 \(\langle\hat J_a(t)\rangle\)，但输出光的协方差还需要

\[
\boxed{
C_{ab}(t,t')
=
\left\langle
\Delta\hat J_a(t)
\Delta\hat J_b(t')
\right\rangle .
}
\tag{4.13}
\]

而非 Gaussian 的精确四阶光子统计还需要四时刻物质关联。由此可见，现有 SBE 的平均电流是量子输出理论的必要输入，却不是充分输入。

## 5. 量子化辐射场与经典强驱动的分离

### 5.1 总 Hamiltonian

定义：

- \(\hat H_{\rm mat}\)：无外场物质 Hamiltonian；
- \(\hat H_\gamma\)：自由电磁场 Hamiltonian；
- \(\lambda\)：辐射模式的综合指标，可包含频率、偏振和传播方向；
- \(\omega_\lambda\)：模式 \(\lambda\) 的角频率；
- \(\hat a_\lambda\)：模式 \(\lambda\) 的光子湮灭算符。

自由辐射场为

\[
\boxed{
\hat H_\gamma
=
\sum_\lambda
\hbar\omega_\lambda
\left(
\hat a_\lambda^\dagger\hat a_\lambda
+\frac12
\right).
}
\tag{5.1}
\]

电偶极近似下，总 Hamiltonian 可写为

\[
\boxed{
\hat H_{\rm tot}(t)
=
\hat H_{\rm mat}
-\hat{\mathbf d}\cdot\mathbf E_{\rm cl}(t)
+
\hat H_\gamma
-\hat{\mathbf d}\cdot
\delta\hat{\mathbf E}(t).
}
\tag{5.2}
\]

其中 \(\mathbf E_{\rm cl}(t)\) 是强驱动的经典背景，\(\delta\hat{\mathbf E}(t)\) 是待量子化的场涨落和生成谐波模式。

### 5.2 位移变换

若驱动模式最初处于大振幅相干态，可用位移算符

\[
\boxed{
\hat D(\boldsymbol\alpha)
=
\exp
\left[
\sum_\lambda
\left(
\alpha_\lambda\hat a_\lambda^\dagger
-
\alpha_\lambda^*\hat a_\lambda
\right)
\right].
}
\tag{5.3}
\]

在位移表象中，

\[
\boxed{
\hat D^\dagger(\boldsymbol\alpha)
\hat a_\lambda
\hat D(\boldsymbol\alpha)
=
\hat a_\lambda+\alpha_\lambda .
}
\tag{5.4}
\]

因此 \(\alpha_\lambda\) 产生经典场 \(\mathbf E_{\rm cl}\)，剩余的 \(\hat a_\lambda\) 描述量子涨落。对 BSV 等零均值态，\(\alpha_\lambda=0\)，但不能因此删除量子驱动；此时驱动能量储存在二阶矩而不是一阶均值中。

### 5.3 经典驱动相互作用表象

定义参考 Hamiltonian

\[
\boxed{
\hat H_{\rm ref}(t)
=
\hat H_{\rm mat}
-\hat{\mathbf d}\cdot\mathbf E_{\rm cl}(t)
+
\hat H_\gamma .
}
\tag{5.5}
\]

其传播子记为 \(\hat U_{\rm ref}(t,t_0)\)。相互作用表象中的剩余耦合为

\[
\boxed{
\hat H_I(t)
=
\hat U_{\rm ref}^{\dagger}(t,t_0)
\left[
-\hat{\mathbf d}\cdot\delta\hat{\mathbf E}
\right]
\hat U_{\rm ref}(t,t_0).
}
\tag{5.6}
\]

相互作用表象态满足

\[
\boxed{
i\hbar\partial_t
|\Psi_I(t)\rangle
=
\hat H_I(t)|\Psi_I(t)\rangle .
}
\tag{5.7}
\]

形式解为 Dyson 级数

\[
\boxed{
\hat U_I(T,t_0)
=
\mathcal T
\exp
\left[
-\frac{i}{\hbar}
\int_{t_0}^{T}
dt\,\hat H_I(t)
\right],
}
\tag{5.8}
\]

其中 \(\mathcal T\) 表示时间排序。

### 5.4 Born 源近似及其边界

本项目第一阶段可采用弱生成场近似：经典强场完整驱动物质，但生成谐波场对物质的反作用忽略。其条件是

\[
\boxed{
N_{\rm emitted}
\ll
N_{\rm drive},
\qquad
E_{\rm emitted}
\ll
E_{\rm drive}.
}
\tag{5.9}
\]

其中 \(N_{\rm emitted}\) 与 \(N_{\rm drive}\) 分别为发射光子数和驱动光子数，\(E_{\rm emitted}\) 与 \(E_{\rm drive}\) 分别为相应能量。

若进入腔强耦合、显著泵浦耗尽或量子场明显反作用于电子的区域，式 (5.9) 失效，必须联合传播物质与光场。

## 6. 从 Maxwell 方程到有限带宽输出模式

![输入—物质—输出的矩与所需关联阶数](figures/量子光理论_20260729/03_输出矩与关联阶数.svg)

### 6.1 连续频率输入—输出关系

定义：

- \(\hat{\mathbf E}_{\rm in}^{(+)}(\mathbf r,\omega)\)：正频输入场；
- \(\hat{\mathbf E}_{\rm out}^{(+)}(\mathbf r,\omega)\)：正频输出场；
- \(\mathbf G(\mathbf r,\mathbf r';\omega)\)：电磁环境的 dyadic Green tensor；
- \(\hat{\mathbf J}^{(+)}(\mathbf r',\omega)\)：物质正频电流；
- \(\mu_0\)：真空磁导率。

在给定电磁环境中，频域量子 Maxwell 方程给出

\[
\boxed{
\hat{\mathbf E}_{\rm out}^{(+)}
(\mathbf r,\omega)
=
\hat{\mathbf E}_{\rm in}^{(+)}
(\mathbf r,\omega)
+
i\mu_0\omega
\int d^3r'\,
\mathbf G(\mathbf r,\mathbf r';\omega)
\hat{\mathbf J}^{(+)}
(\mathbf r',\omega).
}
\tag{6.1}
\]

式 (6.1) 比单一比例常数 \(\kappa_n\) 更一般，因为它保留传播几何、偏振、样品厚度、收集数值孔径和频率响应。

### 6.2 探测模式不能等同于单个 FFT bin

定义：

- \(F_n(\omega)\)：以 \(n\omega_0\) 为中心的归一化频谱滤波函数；
- \(\boldsymbol\epsilon_n(\omega)\)：探测偏振；
- \(\hat b_n\)：第 \(n\) 个被探测谐波波包模式的湮灭算符；
- \(\omega_0\)：驱动中心角频率。

理想化的一维模式投影为

\[
\boxed{
\hat b_n
=
\int_0^\infty d\omega\,
F_n(\omega)
\boldsymbol\epsilon_n^*(\omega)\cdot
\hat{\mathbf a}_{\rm out}(\omega).
}
\tag{6.2}
\]

滤波函数必须满足

\[
\boxed{
\int_0^\infty d\omega\,
F_n^*(\omega)F_m(\omega)
=
\delta_{nm},
}
\tag{6.3}
\]

从而保证

\[
\boxed{
[\hat b_n,\hat b_m^\dagger]
=
\delta_{nm}.
}
\tag{6.4}
\]

把探测器写成有限带宽波包模式有三点必要性：

1. 实际实验不会测量无限长时间的单频平面波；
2. 有限脉冲的一个谐波峰包含多个频率 bin；
3. \(g^{(2)}\)、压缩和纠缠都依赖模式定义。

### 6.3 模式投影后的源关系

将式 (6.1) 投影到式 (6.2)，得到一般形式

\[
\boxed{
\hat b_n^{\rm out}
=
\hat b_n^{\rm in}
+
\sum_a
\int_{t_0}^{T}
dt\,
K_{n,a}(t)
\hat J_a(t)
+
\hat b_n^{\rm env}.
}
\tag{6.5}
\]

其中：

- \(K_{n,a}(t)\)：由 Green tensor、空间模式、偏振和频谱滤波共同决定的核；
- \(a\) 是 Cartesian 电流方向；
- \(\hat b_n^{\rm env}\) 是吸收介质中为保持对易关系所需的环境噪声算符；无耗散自由空间可省略。

若使用窄带和远场近似，常可写成

\[
\boxed{
K_{n,a}(t)
\simeq
\kappa_{n,a}
W_n(t)e^{in\omega_0t},
}
\tag{6.6}
\]

其中 \(W_n(t)\) 是探测时间窗，\(\kappa_{n,a}\) 是包含单位和几何的耦合常数。

### 6.4 Heisenberg 方程的等价推导

若采用模式耦合

\[
\boxed{
\hat H_{\rm int}^{\rm rad}(t)
=
-\sum_{\lambda,a}
g_{\lambda a}
\hat J_a(t)
\left[
\hat a_\lambda e^{-i\omega_\lambda t}
+
\hat a_\lambda^\dagger e^{i\omega_\lambda t}
\right],
}
\tag{6.7}
\]

则 Heisenberg 方程

\[
\boxed{
\frac{d\hat a_\lambda}{dt}
=
-i\omega_\lambda\hat a_\lambda
+
\frac{i}{\hbar}
\sum_a g_{\lambda a}^*
\hat J_a(t)
}
\tag{6.8}
\]

给出

\[
\boxed{
\hat a_\lambda(T)
=
e^{-i\omega_\lambda(T-t_0)}
\hat a_\lambda(t_0)
+
\frac{i}{\hbar}
\sum_a g_{\lambda a}^*
\int_{t_0}^{T}dt\,
e^{-i\omega_\lambda(T-t)}
\hat J_a(t).
}
\tag{6.9}
\]

式 (6.9) 与式 (6.5) 的结构相同。它明确说明：输出场算符等于自由输入算符加上物质电流**算符**的卷积，而不是只加上平均电流函数。

### 6.5 输出场的一阶与二阶矩

定义输出模式平均振幅

\[
\boxed{
\beta_n
=
\langle\hat b_n^{\rm out}\rangle .
}
\tag{6.10}
\]

由式 (6.5) 得

\[
\boxed{
\beta_n
=
\beta_n^{\rm in}
+
\sum_a
\int dt\,
K_{n,a}(t)
\langle\hat J_a(t)\rangle
+
\beta_n^{\rm env}.
}
\tag{6.11}
\]

这就是“平均谐波复振幅主要由平均电流决定”的精确定义。

再定义中心化场算符

\[
\boxed{
\Delta\hat b_n
=
\hat b_n-\beta_n.
}
\tag{6.12}
\]

输出的正常协方差和异常协方差分别为

\[
\boxed{
N_{nm}
=
\left\langle
\Delta\hat b_n^\dagger
\Delta\hat b_m
\right\rangle ,
}
\tag{6.13}
\]

\[
\boxed{
M_{nm}
=
\left\langle
\Delta\hat b_n
\Delta\hat b_m
\right\rangle .
}
\tag{6.14}
\]

这里：

- \(N_{nn}\) 是去掉相干位移后的噪声光子数；
- \(N_{nm}\) 描述不同模式间的 phase-insensitive 关联；
- \(M_{nm}\) 描述 phase-sensitive 配对关联，是压缩和两模压缩的关键源。

### 6.6 输入—物质交叉项不能默认丢掉

由式 (6.5)，正常协方差具有结构

\[
\boxed{
N_{nm}^{\rm out}
=
N_{nm}^{\rm in}
+
N_{nm}^{JJ}
+
N_{nm}^{\rm in-J}
+
N_{nm}^{J-\rm in}
+
N_{nm}^{\rm env}.
}
\tag{6.15}
\]

其中电流源项为

\[
\boxed{
N_{nm}^{JJ}
=
\sum_{ab}
\int dt\,dt'\,
K_{n,a}^*(t)
K_{m,b}(t')
\left\langle
\Delta\hat J_a(t)
\Delta\hat J_b(t')
\right\rangle .
}
\tag{6.16}
\]

异常协方差同理：

\[
\boxed{
M_{nm}^{JJ}
=
\sum_{ab}
\int dt\,dt'\,
K_{n,a}(t)
K_{m,b}(t')
\left\langle
\Delta\hat J_a(t)
\Delta\hat J_b(t')
\right\rangle .
}
\tag{6.17}
\]

因为电流正是由输入场驱动，\(\Delta\hat b^{\rm in}\) 与 \(\Delta\hat J\) 一般相关，所以 \(N^{\rm in-J}\)、\(M^{\rm in-J}\) 不能在没有 Born 因子化证明时自动设为零。

### 6.7 二时关联和四时关联分别能算什么

式 (6.16)–(6.17) 表明二时刻电流关联足以得到：

- 平均光子数；
- 正常和异常二阶场矩；
- Gaussian 协方差矩阵；
- 在 Gaussian 闭合下重构的 \(g^{(2)}\)。

但精确的

\[
\langle
\hat b_n^\dagger
\hat b_m^\dagger
\hat b_m
\hat b_n
\rangle
\]

一般含有四个电流算符，因此需要四时刻物质关联。二时关联“足以得到全部 \(g^{(2)}\)”只有在 Gaussian/Wick 或其他明确闭合近似下才成立。

## 7. 电流关联函数：排序、费米统计与可行计算方法

### 7.1 三种两时刻关联

定义：

- \(C_{ab}^{>}(t,t')\)：greater 电流关联；
- \(C_{ab}^{<}(t,t')\)：lesser 电流关联；
- \(C_{ab}^{S}(t,t')\)：对称序电流关联。

\[
\boxed{
C_{ab}^{>}(t,t')
=
\left\langle
\Delta\hat J_a(t)
\Delta\hat J_b(t')
\right\rangle ,
}
\tag{7.1}
\]

\[
\boxed{
C_{ab}^{<}(t,t')
=
\left\langle
\Delta\hat J_b(t')
\Delta\hat J_a(t)
\right\rangle ,
}
\tag{7.2}
\]

\[
\boxed{
C_{ab}^{S}(t,t')
=
\frac12
\left[
C_{ab}^{>}(t,t')
+
C_{ab}^{<}(t,t')
\right].
}
\tag{7.3}
\]

它们不是同一个对象：

- 正常序光子计数主要关联到发射型 greater/lesser 结构；
- homodyne 正交分量协方差使用对称序；
- 只写一个未说明排序的 \(C(t,t')\) 会使真空项和符号不明确。

### 7.2 二次型费米算符的等时关联

令

\[
\boxed{
\hat J_A
=
\hat{\boldsymbol c}^{\dagger}
A
\hat{\boldsymbol c},
\qquad
\hat J_B
=
\hat{\boldsymbol c}^{\dagger}
B
\hat{\boldsymbol c},
}
\tag{7.4}
\]

其中 \(A\)、\(B\) 是单粒子空间矩阵，\(\hat{\boldsymbol c}\) 收集全部带和 \(\mathbf k\) 的费米湮灭算符。

采用约定

\[
\boxed{
\rho_{ij}
=
\langle\hat c_j^\dagger\hat c_i\rangle .
}
\tag{7.5}
\]

对无异常费米配对的 Gaussian 电子态，Wick 定理给出

\[
\boxed{
\left\langle
\Delta\hat J_A
\Delta\hat J_B
\right\rangle
=
\operatorname{Tr}
\left[
A(I-\rho)B\rho
\right].
}
\tag{7.6}
\]

式 (7.6) 中的 \(I-\rho\) 是 Pauli blocking。它说明不能把多电子电流噪声简单写成 \(\operatorname{Tr}(AB\rho)\)，也不能只把辅助初值写成 \(B\rho\) 就认为费米收缩已自动包含。

### 7.3 用 Green function 表示两时刻关联

定义单粒子 greater/lesser Green function：

\[
\boxed{
G_{ij}^{>}(t,t')
=
-i
\left\langle
\hat c_i(t)
\hat c_j^\dagger(t')
\right\rangle ,
}
\tag{7.7}
\]

\[
\boxed{
G_{ij}^{<}(t,t')
=
i
\left\langle
\hat c_j^\dagger(t')
\hat c_i(t)
\right\rangle .
}
\tag{7.8}
\]

在独立粒子或 quasifree/Wick 闭合下，连通电流关联可写为

\[
\boxed{
C_{AB}^{>}(t,t')
=
\operatorname{Tr}
\left[
A(t)G^{>}(t,t')
B(t')G^{<}(t',t)
\right],
}
\tag{7.9}
\]

总符号会随 \(G^{>,<}\) 的 convention 改变，因此实现时必须用式 (7.6) 的等时极限做单元测试。

若每个 \(\mathbf k\) 独立，式 (7.9) 变为 \(\sum_{\mathbf k}C_{\mathbf k}\)。这会默认忽略 \(\mathbf k\neq\mathbf k'\) 的电子关联；若以后研究激子、集体涨落或电子—电子关联，必须升级理论。

### 7.4 闭系统单粒子传播公式

定义：

- \(U(t,t')\)：从 \(t'\) 到 \(t\) 的单粒子传播子；
- \(\rho(t')\)：时刻 \(t'\) 的单粒子密度矩阵。

对 \(t\ge t'\) 的闭合单粒子演化，一种与式 (7.6) 一致的形式是

\[
\boxed{
C_{AB}^{>}(t,t')
=
\operatorname{Tr}
\left[
A(t)
U(t,t')
(I-\rho(t'))
B(t')
\rho(t')
U^\dagger(t,t')
\right].
}
\tag{7.10}
\]

矩阵左右次序取决于式 (7.5) 的指标 convention；代码实现前必须通过：

1. \(t=t'\) 时恢复式 (7.6)；
2. 单占据态和空态的解析极限；
3. Hermitian 关系 \(C_{AB}^{>}(t,t')=[C_{BA}^{>}(t',t)]^*\)。

### 7.5 量子回归定理的严格适用条件

设完整 Fock-space 密度算符为 \(\varrho(t)\)，并满足时间局域 Markov 主方程

\[
\boxed{
\partial_t\varrho(t)
=
\mathcal L_t[\varrho(t)].
}
\tag{7.11}
\]

若 \(\mathcal G(t,t')\) 是由同一生成元产生的 CPTP 传播映射，则量子回归定理给出

\[
\boxed{
\langle
\hat A(t)\hat B(t')
\rangle
=
\operatorname{Tr}_{\rm Fock}
\left[
\hat A\,
\mathcal G(t,t')
\bigl(
\hat B\varrho(t')
\bigr)
\right],
\qquad t\ge t'.
}
\tag{7.12}
\]

这里的关键是：

- \(\varrho\) 是 Fock-space 密度算符，不是 \(N_b\times N_b\) 的 1RDM；
- \(\hat B\varrho\) 一般非 Hermitian、非正、迹不为 1；
- 传播辅助算符时不能强制 Hermitian 化或重新归一化。

### 7.6 Lindblad 生成元与当前 \(T_2\) 项

标准 GKSL/Lindblad 形式为

\[
\boxed{
\mathcal L_t[X]
=
-\frac{i}{\hbar}
[\hat H(t),X]
+
\sum_\mu
\left(
\hat L_\mu X\hat L_\mu^\dagger
-
\frac12
\{\hat L_\mu^\dagger\hat L_\mu,X\}
\right),
}
\tag{7.13}
\]

其中 \(\hat L_\mu\) 是明确的环境跳跃算符。

当前代码中“瞬时能带基非对角元按 \(T_2\) 衰减”是一个 1RDM 级唯象规则。除非构造出 \(\hat L_\mu\) 并证明其在 1RDM 上约化为同一规则，否则不能说现有 \(T_2\) 自动满足式 (7.13)，也不能无条件套用式 (7.12)。

特别要注意：

- 简并或近简并子空间中的逐带本征矢并不唯一；
- 瞬时基变换可能引入 gauge artifact；
- 当前若在每一步执行 \(\rho\leftarrow(\rho+\rho^\dagger)/2\)，该操作不能用于 QRT 辅助算符。

### 7.7 三条可行数值路线

#### 路线 B1：quasifree/Wick + 单粒子传播

假设电子态始终可用 Gaussian 费米态近似，使用式 (7.9) 或 (7.10)。

优点：与现有多带 SBE 最接近，复杂度可控。  
缺点：忽略相互作用产生的高阶电子 cumulant；\(T_2\) 的微观一致性仍需处理。

#### 路线 B2：Keldysh/NEGF

直接传播 \(G^{<,>}(t,t')\)，再由式 (7.9) 构造电流噪声。

优点：算符排序清楚，可系统加入自能。  
缺点：双时对象计算和存储成本高；需要重新构建碰撞项。

#### 路线 B3：小有效模型的 Fock-space Lindblad/QRT

对少带有效模型构造完整 Fock 空间，显式定义 \(\hat L_\mu\)，使用式 (7.12)。

优点：QRT 逻辑最干净，可与精确演化对照。  
缺点：不能直接扩展到 M88/full112；有效模型需要单独参数化和验证。

当前最稳健的顺序是：

\[
\boxed{
\text{小模型精确基准}
\;\longrightarrow\;
\text{quasifree/Wick 实现}
\;\longrightarrow\;
\text{M88-full 材料计算}.
}
\tag{7.14}
\]

### 7.8 Markov-state approximation 不是 QRT

Lange 与 Madsen 在 Fermi–Hubbard 基准中提出的 Markov-state approximation（MSA）是一种量子 HHG 光场近似层级。在其测试参数下，MSA 能定量恢复平均 HHG 谱，并定性描述 Mandel \(Q\) 和压缩。

但 MSA：

- 不是量子回归定理；
- 不等于 Markovian master equation；
- 尚未证明能定量处理 CrI\(_3\) 的多模 \(g^{(2)}\) 与磁序关联；
- 不能因平均谱正确，就自动认定高阶光子矩正确。

因此 MSA 可作为独立近似路线和小模型 benchmark，不能未经推导直接嵌入当前 \(T_2\)-SBE。

### 7.9 2026 年全量子驱动理论给出的关键界线

Liu、Zhang、Wang 与 Yuan 的 2026 年理论指出，量子驱动下平均谐波产额可写为偶极两时关联的频率投影：

\[
\boxed{
Y(\omega_q)
\propto
\int dt_1dt_2\,
e^{-i\omega_q(t_2-t_1)}
\left\langle
\hat d(t_2)\hat d(t_1)
\right\rangle .
}
\tag{7.15}
\]

将

\[
\hat d(t)
=
\langle\hat d(t)\rangle
+
\Delta\hat d(t)
\]

代入，得到

\[
\boxed{
Y(\omega_q)
\propto
\left|
\langle\hat d(\omega_q)\rangle
\right|^2
+
\left\langle
\Delta\hat d^\dagger(\omega_q)
\Delta\hat d(\omega_q)
\right\rangle .
}
\tag{7.16}
\]

式 (7.16) 精确表达了两层区别：

- 第一项是平均偶极/电流产生的相干发射；
- 第二项是物质涨落产生的非相干或量子源项。

对零平均场的 BSV，第二项可能不可忽略。该工作以模型原子为例，不是 CrI\(_3\) 的现成算法，但它证明了只用 \(|\langle J\rangle|^2\) 会漏掉量子涨落发射。
