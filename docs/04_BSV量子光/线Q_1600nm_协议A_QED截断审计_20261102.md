## 1. 外审要先澄清的三件事

### 1.1 Weyl \(7.91\) 不是 Fock \(\langle n\rangle\)

GH5 协议 A 在 \(\theta=\pi/4\)、Néel \(=+1\) 的外层节点上给出

\[
\texttt{max\_weyl\_n}(p_q)=7.91326.
\]

公式是

\[
0.25(X_f^2+P_f^2)-0.5,
\]

作用在 GH 求积节点上，**不是** \(\langle\hat a^\dagger\hat a\rangle\)。\(\theta=\pi/2,3\pi/2\) 的 Weyl 甚至到 \(\approx 9.11\)。

clarify 记录：`weyl_is_not_qed_n.json`。第一演化角仍锁定 `n8_p_q`，**没有**用 7.91 改 \(n_{\max}\) 或 \(g\)。

本轮精确 QED 测到的才是 Fock 数：

| 量 | 精确 QED \(n_{\max}=8\)，\(\theta=\pi/4\) |
|---|---|
| \(\max_t\langle n\rangle\) | **0.34284** |
| 输入 \(\langle n\rangle\) | 0.34266 |
| 终点 \(\langle n\rangle\) | 0.34236 |
| GH5 Weyl \(p_q\) | 7.91（对照，不是本列） |

Weyl 与 Fock 差两个数量级。以后写论文必须把这两套数拆开。

### 1.2 输入尾 \(P(n>8)\) 小，不约束演化中占据

`input_fock.json`（\(\theta=\pi/4\)）：

| 量 | 值 |

| 截断 \(n_{\max}=8\) 的顶层 \(P_8\) | \(2.622\times 10^{-5}\) |
| `input_tail_small` | true |

输入态尾小，只说明 **准备态** 装得进 \(n_{\max}=8\)。电子可以把光子泵到截断边界。所以必须跑完整段联合演化。冒烟 200 步 **不是** 生产截断证明。

### 1.3 1600 nm 可能换了多光子区间，但跨阈 \(\neq\) 已共振

| 量 | 值 |
|---|---|
| \(\hbar\omega\) | **0.775 eV**（显式；`used_pf_OMEGA0=False`） |

这足以说明 1600 nm **不是** 24.8 μm 的时间缩放。它 **不足以** 声称三光子共振已经发生。本审计不提取跃迁通道，也不提取 H2。

## 4. 本结果允许说什么、不允许说什么

允许：

1. 外审点名的 Weyl \(7.91\) **不是** 精确 QED 的光子数。
2. 在 \(\theta=\pi/4\)、Néel \(=+1\)、抽象 \(g=0.005\)、1+4+1 的精确 QED 下，\(n_{\max}=8\) 顶层未触发 0.05 闸门。
3. 演化中 \(\langle n\rangle\) 没有从 0.343 涨到 \(O(1)\) 或 \(O(8)\)。
4. 因此 **不必** 为了截断失败去调 \(g\)。

不允许：

1. 提取 A/B/C，或把 GH5 的 8.778 / 1.274 / \(179.04^\circ\) 写成精确 QED。
2. 宣称“机制在 1600 nm 精确 QED 下仍然成立”。
3. 把 \(\theta=\pi/4\) 一角的通过写成四个压缩角都通过。
4. 写成实验场强、W/cm²、25 fs BSV。
5. 把 \(\rho\approx R\) 或 \(\arg(A/B)\approx\pi\) 当定理。严格 \(B\) 也不是 \(K_B\alpha^2\)。
6. 声称已证明量子优势或经典光做不到。

GH5 里值得后续（**不是本审计**）追的物理：频率从 24.8 μm 改到 1600 nm 后，\(\arg(A/B)\) 从 Q6 的 \(\sim 110.6^\circ\) 变成 GH5 的 \(\sim 179^\circ\)。相对相位对频率敏感。精确 QED 四角之前，这句话只属于 GH5。
