## 四项必须修正

### 1. 单列近零不等于暗子空间完整

源码 dark_mask 只检查每个顶点列的模，stationary_point_electron_columns 也只接受原坐标轴上的零列。这能发现显式零顶点，不能发现简并电子空间内的暗线性组合。

本次内存反例：两个相同能隙的振子，顶点列相同，
u=[[0.2,0.2],[0.1,0.1]]。
现 mask 计数为 0；在这同一简并空间内旋转成和/差基底，计数变成 1。真正解耦的差组合始终存在。

因此报告“+N 无精确暗通道、-N 有两个”的说法只能降为：**当前本征矢基底里近零顶点列数为 0/2**，不能视为暗谱维数或磁性差异。PT 简并使这个问题尤其相关。

修复要求：在自由电子生成元的不变能隙子空间内寻找电流耦合的共同零空间，并保留映回原始标签的基底。不能直接把跨不同能隙的瞬时 null(u) 全部当 stationary 暗空间。测试简并空间的幺正旋转下维数、投影算符与物理投影不变；再用不同能隙反例确认不能滥合并。近简并只能作数值诊断，不得自动作严格简并并删通道。

### 2. 0.752 不是纯粹“漏掉电子带”的误差

two_band_incoming_fixture 的 incoming_columns 没有限制谱支撑。电子带频率 omega=2.3 时，光子带只有 [0.4,1.2]，但 wrong 测试仍放入非零光子源。

所以该数值检验的是“用错误频带的光子源替代电子源”。本次直接核对：

- 正确电子列谱差：5.55e-17；
- 只遗漏电子源、不给不存在的光子源：误差 0.3185615；
- 当前错误替代：误差 0.7516316。

修复要求：自由入射列必须随谱支撑自动开闭；将“遗漏”和“错误替代”负对照分开。至少增加一个两连续谱同时存在的重叠频段，验证两族贡献相加，并分别漏掉一族；这更贴近真实自由空间光子与电子吸收带共存的情况。人工频带仍仅是数学夹具，不能变成 M0 的物理截止。

### 3. 非零响应主值不能证明谱重计数

bright_bare_electron_current_jump 实际计算的是离散电子的顺磁响应有理和，即 Pi。它不是离散电子的实频谱密度；真正的离散谱含 delta 测度，非极点上的主值不是其替代。

“Pi 非零约 0.180”只能保留为响应诊断，不能作为“重复加入电子真空已被谱测试检出”的证据。

修复要求：在同一谱测度/同一投影上做真实重复计数对照。例如重复加入一条已计入的有效谱列，再与独立谱跳跃比较；如比较离散裸谱，需在共同的频率测试函数或积分矩下比较，不能拿主值函数冒充谱权重。

### 4. 2.52e-5 是绝对误差

测试记录使用 maxabs(got-ref)，没有除以参考范数。文档及聊天中的“相对解析解 2.5e-5”应改为“最大绝对差 2.52e-5”。

如要加相对指标，明确分母、时间样本和是否包含暗列。单次该误差不能另称新的收敛证明；已有传播器收敛资格可引用原文件。

## 下一轮范围与完成标准

1. 修上述四处，保留旧 JSON，输出新的修订记录。
2. 对有简并、非坐标轴暗组合的有限例子，补原始明/暗电子投影的谱检验；只核对 A/I 不足以覆盖以后可能变亮的电子方向。
3. 对重叠连续带，验证光子＋电子两族完整谱差、各自遗漏、重复计数及基底变换不变性。
4. 若涉及点谱，保留既有留数检验，并明确连续加点谱的适用范围；不能把互不相关的几条测试合称整个 M0 谱已完整。
5. 复用原传播器做短时间接入。已有无驱动验证保留；新增暗组合受驱变亮的例子用独立方程对照，单凭“场变成非零”不证明正确，更不证明基态真实发光。
6. 修订后的夹具完成后，仅提交真实 M0 连续谱接入方案：如何保留主值与吸收谱、原始 (k,c,v) 标签、简并自由度及数值极限。先查既有 full-BZ 响应/噪声工作，不重新造重复理论。

本轮停止于上述修订与接入方案。不要并行启动真实 M0 全连续谱积分、完整 P1、H2 光子矩或服务器大作业。

后续真正进入 M0 时，要从同一原始跃迁谱构造响应与电子源，不能只给二维电流谱取平方根后宣称内部电子基底完整；也不能用有限网格非极点有理函数替代连续谱边界。数学上的正则化参数与物理耗散不同：可做有说明的极限收敛诊断，不得把数值展宽冻结为新材料耗散。
