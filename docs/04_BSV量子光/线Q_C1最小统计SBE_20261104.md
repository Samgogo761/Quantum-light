# 1600 nm C1 最小统计 SBE（理想纯 BSV，2026-11-04）

协议 v2 冻结。本轮只做 C1 方法验证：行波 25 fs 高斯包络、M0 少量 k/−k、同能量相干光对照。**不是 CrI₃，不是联合 QED，不是 C2，未改冻结拟合。**

Wigner 随机场 SBE 是近似，不等于光–电子联合量子演化。

## 冻结输入

- 波长 1600 nm，强度 FWHM 25 fs，w0 = 15 μm
- I0 = 1.000×10^11 W/cm^2（设计点 0.1 TW/cm^2，**不是** Rasputnyi ~2 TW/cm^2 比较点）
- nbar = 7.575614×10^10，相干 α = 2.752383×10^5
- 理想单模纯 BSV：α=0，n_s=nbar，|M|=√[n_s(n_s+1)]，压缩轴 θ=0（压 X）
- 稳定参数化：σ_anti=√(n_s+1)+√(n_s)，σ_sq=1/σ_anti。禁止用 2n_s+1−2|M| 生成压缩方差（该式在本 n_s 下浮点结果为 0）
- 不用 g=0.005，不用 1+4+1，不用 GH5

## 前置闸门

- Fourier 矩形窗自检：通过
- 稳定协方差与 2×10^4 样本矩：通过
- 禁止公式 2n_s+1−2|M|：返回 0，相对误差 1，判定为不可用
- 行波场映射（FWHM、相干 E_peak、BSV 平均场≪相干峰、nbar 对 v2）：通过
- 反演封闭 k 网格：nk=2，4 个 k 点，shift=0.5

## 判断

1. 方法层面：高增益纯 BSV 的稳定 Wigner 抽样、行波包络和 Néel 双畴复电流记账已经可运行。第一次 C1 的目标是数值正确、统计定义明确，这一步达到了。
2. 物理层面：在当前 M0、nk=2、0.1 TW/cm^2 下，纯 BSV 的 **Néel-odd 平均复 H2 非零**，但 **样本强度代理的磁畴对比接近 0**。这正是外审要求的区分：很大的 odd 电流并不自动给出可测的 |J₊|^2−|J₋|^2。
3. 同能量相干对照本身已有明显磁畴强度对比（单轨迹，Pcoh=Pstat）。因此“有无磁畴强度对比”首先取决于是否存在可与 odd 成分干涉的相干/偶分量，而不是 BSV 标签。
4. 这不是量子优势，不是真实 CrI₃，也不是精确 QED。输入仍是理想单模纯 BSV，不是 Rasputnyi 实验的有损多模光态。
5. 未启动 C2、额外 Fock 核、新 QED 或真实材料计算。
