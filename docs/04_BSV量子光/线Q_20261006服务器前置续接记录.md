- 不把有限 `12×12` 接入候选误称为真实 BZ 收敛；
- 不改变 `D`、初态、Hamiltonian、P1 或输出模式定义；
- 不把主 JSON 中旧测试遗留的 `false` 当作当前静态验收结论；
