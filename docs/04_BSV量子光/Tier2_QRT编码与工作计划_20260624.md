## 2. 为什么先 4 能带 Python,而不是直接改 112 带 Fortran

QRT 的成本结构:对每个源时刻 t' 和每个分量 b,要把辅助算符 χ^b(t';·)=ΔĴ^b ρ(t') 用**同一个传播子**
从 t' 演化到 T。即 **N_src × 2 次额外传播**。

```
112 带:单次前向 run ≈ 2.35 h。QRT(带状采样,只算 |t-t'|≲3T2)粗估 ~数百 CPU·小时
        → 论文 2 的生产计算,不适合用来"开发/调试流水线"。
4  带:单次前向 run ≈ 秒级(n³: 4³ vs 112³ 差 ~2×10⁴ 倍)。整条 QRT+四通道 ≈ 分钟级。
        → 适合把物理和流水线全部跑通、和解析极限/Ilin SSH 对拍。
```
下游(Williamson/Takagi/对数负性/QFI/矩问题)全是线性代数,**Python(numpy/scipy)比 Fortran 省十倍开发时间**。
所以:**4 带 Python 做引擎和物理(论文 1)→ 验证无误后把 QRT 核心(辅助算符演化)移植回 Fortran 做 112 带(论文 2)。**

> 这与主线"4 能带最小模型先行,112 能带是第二篇"完全一致。

### Phase A — 4 能带最小模型(物理引擎的地基)
- **A1 模型**(`model4band.py`):双层 massive-Dirac + AFM 交换场。每层一个有质量 Dirac(隙 m、费速 v),
  层间隧穿 t⊥,Néel 交换场在两层取 ±**N**(AFM)。这是"SSH 的 AFM 版"。
  必须满足:PT 对称(P 换层+k→-k,T 翻自旋翻 N);**N→-N 即磁畴反转**(对接 M.21)。
  输出:`H(k;N)`、速度 `v_a(k)=∂H/∂k_a`、偶极/Berry 联络。
- **A2 拟合**(`fit_from_wf.py`):把 112-WF 模型在带隙附近的最低 2 价 + 2 导带 downfold/kp 拟合,
  定出 (m, v, t⊥, |N|, λ_SOC) 等参数,让 4 带在 3200 nm 相关的低能窗口复现 112 带。
- **测试 A**:4 带经典 HHG 应复现选择定则(N→-N 下偶次变号、奇次不变,M.22/M.23);N=0 时偶次消失。
- **产物**:`fig_4band_bands.png`、选择定则对拍表。

### Phase B — QRT 双时关联(本阶段技术核心)
- **B1 前向带源**(`sbe4.py`):前向演化 ρ(t),在源时刻集合 {t'_j} 存 ρ(t'_j)。
  源时刻按 T2 带状取样:关联在 |t-t'|≳3T2 衰减,故每个 t' 只需向后演化 ~3T2(不是整段)→ 省一大截。
- **B2 辅助算符**(`qrt.py`):对每个 t'_j、每个 b∈{x,y}:
  ```
  χ^b_j(t'_j) = ΔĴ^b ρ(t'_j),   ΔĴ^b = Ĵ^b − ⟨Ĵ^b(t'_j)⟩
  χ^b_j(t)   = U(t,t'_j)[χ^b_j(t'_j)]   ← 用与 ρ 完全相同的 EOM(含同一个退相干超算符)
  C^{ab}(t,t'_j) = Tr[Ĵ^a χ^b_j(t)],  t ≥ t'_j
  ```
  **退相干一致性(对接 Thümmler 风险)**:QRT 要求同一个线性 Lindblad 超算符作用在 χ(非厄米)上。
  当前"瞬时本征基乘 exp(-Γt)"对给定时刻是线性映射,可直接套用;但要**加诊断**:近简并/带交叉处
  χ 的演化是否出现非物理跳变(4 带有隙,风险小,但必须自检后才迁移到 112 带)。
- **测试 B**:① 等时 C(t,t)=方差(自洽);② 驱动二能级解析解对拍;③ 无驱动 → 输出真空。

### Phase C — N 宇称四通道(磁性指纹)
- (`nparity.py`)跑 +N 与 -N 两套(复用 P 共轭 TB),构造 J_e/J_o(M.27/28),
  得 C_ee/C_oo/C_eo/C_oe(M.31)。
- **测试 C**:N=0 → C_oo=C_eo=C_oe=0(只剩 C_ee);|N| 增大 → C_oo 单调出现。**C_oo 就是磁性标记通道。**

### Phase D — 谐波模式协方差 Σ(Ilin 映射)
- (`covariance.py`)FFT C_conn(t,t') → C̃(ω,ω');在谐波频率 ω_q=qω0 处取谐波模式;
  按 Ilin 2026 的 current-current fluctuation → 输出光正交分量协方差的映射,组装 Σ_qq' 和均值 β_q。
  **务必先照搬 Ilin 的实现路径**(密度矩阵 + 弱光-物质关联展开,压缩不靠额外 Kerr),再换模型。
- **测试 D**:物理性 Σ + (i/2)Ω ≥ 0(M.41);把模型换成 SSH 应**复现 Ilin 的压缩谱**(金标准验证)。

### Phase E — Gaussian 可观测量
- (`gaussian.py`)Williamson → 辛本征值 ν_j → 压缩(M.43);配对核 g_qq'(N) 的 Takagi → 压缩本征模 λ_j(N)(M.46/48);
  两谐波 log-negativity(纠缠);Gaussian QFI F_Q(N)(闭式,对接 Even-Odd-QFI 2601.06513 的偶奇分块)。
- **测试 E**:纯真空 ν_j=1/2;单模压缩玩具态 QFI 对解析值。
- **产物**:压缩谱 vs 谐波阶、log-neg(q,q') 热图、F_Q(N) 曲线、λ_j(N) 配对谱。

### Phase F — 经典不可复现(L3 判据)
- (`moments.py`)构造经典强度平均基准 ∫dI P_cl(I) O_cl(I)(我们的 BSV 求积就是均值层的这个);
  对输出统计的一组矩做 Hankel 正定性检验(M.59/60),或用 Ryl-Sperling-Vogel 特征函数判据,
  找出**无法被任何 P_cl≥0 复现**的观测量(M.61),并尝试计量层 F_Q^quantum > max F_Q^cl(M.62)。
- **产物**:一张"经典可达集 vs 量子输出"的判据图(L3 的核心结论图)。

## 7. 算法优化要点（写代码时注意)

```
O1 带状源采样:只算 |t-t'|≲3T2 的块,QRT 成本从 O(Nt²) 降到 O(Nt·N_band)。
O2 频域直投:若只要谐波模式 Σ_qq',可在演化中直接累加 e^{iω_q t} 投影,不存整个 C(t,t')(省内存)。
O3 辅助传播并行:不同 t'_j 的 χ 演化彼此独立 → 天然 OpenMP/MPI/array-job 并行(对接 3 节点约束)。
O4 退相干超算符复用:把 L_deph(t) 抽成显式线性映射,ρ 和 χ 共用,保证 QRT 一致性(并便于 Thümmler 诊断)。
O5 4 带先用稠密 numpy;112 带迁移时电流/速度矩阵元预计算复用现有 Fortran Pk_eq。
```
