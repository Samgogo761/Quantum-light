## 3. 剩余两项：不要再用相邻量代替目标输出

### 3.1 输入频率端点

endpoint_estimate（活脚本约1141–1169行）确实补算了[1e-4,1e-3]和[12,24]，但只调用 electronic_measure_report，得到静态电子 bb† 迹3.37e-5。没有传播这些额外光子入射列，因此不是 P1 下输出 n,m 的频率尾误差。

静态权重小不自动给出驱动后小：必须有同一驱动传播的输出贡献，或带传播增益估计的可检查上界。full finite_nm_qualified 标志目前也没有把输出端点检查纳入。

最小执行：
- 仅 +N、原两点、原物理模型。复用已算电子背景；
- 对缺少的低/高频区间补光子连续入射列，仍按同一 dν 计权，不再加入第二套暗点列或明电子真空；
- 将额外列对 n、m、CCR 的贡献与当前基准比较，分开报告低频、高频；
- 重用 U0、ΔU、V 的同一约定，m 中不得漏 U0 V^T；
- 区间更外侧可用有依据的渐近估计或有限扩展检查。不得把数值积分边界改称物理截止。
- 若静态估计能转成输出上界，应写清转换依据；否则直接传播这少量额外列更清楚。

无需重跑已算601列或两畴整套阶梯。

### 3.2 脉冲后一周期之外

现在 ΔU 和 V 的脉冲/尾分段都已经保存；对应 n,m 的变化约1e-10，确实是实测值，不应否定。

但当前主程序仍然固定：
nstep = 8*ntpc + 1*ntpc。
所以它比较的是[0,Tp]与[0,Tp+T]，没有检查 Tp+T 以后。

最小执行：
- 仅 +N，沿同一背景继续到至少一个新的后时间终点，或推导可检查的剩余输出行尾界；
- 最好保存末态和累计输出再续算，避免重复前八周期。若旧文件没有末态，只允许为补检查做一次必要重放，并新增续算检查点；
- 两种输出系数一起续算，报告 n、m、CCR 的增量；
- 时间延长时保留相同物理探测包，核的数值频率网格须能表示延长后的时间区间；
- 不重置电子、不加T2、不扣DC、不换窗。核质量小不能单独替代 K×I 的尾界。

若只得到有限终点间的稳定性，按有限检查声明，不写“严格无限时间误差界”。

## 5. 可并行准备的 BZ / GPU 下一步

现在科学问题开始从“这套计算链能否工作”转到“结果是否代表整个晶体”。两点样本的电子隙约2.156–7.625，不能代表完整BZ接近0.093的最小隙，不能直接把其谱面板和误差表复制到真实BZ。

允许先准备以下方案及廉价成本探针，不启动大批量全脉冲生产：

1. 复用既有BZ几何/求积，选择覆盖整个BZ、正权重和为1、反演配对闭合的小规模试算点集；网格由执行AI依据成本和已有静态数据决定。不得继续用两个任意点冒充材料结果。
2. 每个新有限求积先做必要输入适用性检查，避免把已知的欠采样假不稳定再送入长传播；复用原静态检查，不另开泛化理论审计。若点集失败，调整数值求积，不改 D 或物理参数来抹平。
3. 清点电子维数、有限谱组/暗点列、共振宽度、所需输入列数；只做短前缀/profile，给出峰值内存、预计全脉冲时间及误差检查成本。
4. GPU仍采用矩阵自由/分块传播与在线收缩。不要构造巨大稠密总传播矩阵。共享光场反馈必须由所有k贡献共同求和，不能把各k当独立光场仿真再相加。
5. 若接GPU，先在已验证小基准与CPU对照；AI加速/低秩压缩暂不改变物理参考，只能在能重现参考结果后升级。
6. 先看H2两偏振的共同部分 n,m 能否随BZ采样稳定，再看两畴之差。若基准共同量尚不稳，不追逐小磁畴差。
7. 提交一份有时长/显存依据的有限BZ试运行计划；尾部收尾通过后衔接执行，不再让本人选择网格、步数或脚本。大规模服务器任务须有明确资源预算和已可用的环境。
