# G1 工作记录：全部面板的求积误差预算（2026-10-15）

343 个面板都用保存的 4096 步列做了同一种比较：节点数加倍，整张 \(2\times2\) 的正常矩阵和反常矩阵一起看。旧节点被整组换掉。频率没有互相占用，加倍后的 65808 个频率也没有重复。已知那条 H2 翼的 16→32 步被重新算到 \(10^{-12}\)，和上一份记录一致。

## 1. 两条 H2 平直翼

\(\omega\in[0.230326,\,0.263614]\)，原来 16 个节点。

| 步 | 正常矩阵最大变化 |
|---|---:|
| 16→32 | \(0.006501\)，\((0,0)=-0.006501\) |
| 32→64 | \(2.869\times10^{-5}\) |
| 64→128 | \(1.007\times10^{-9}\) |

相邻的 \([0.264349,\,0.275755]\)：16→32 的正常矩阵最大变化是 \(1.469\times10^{-4}\)，32→64 是 \(4.20\times10^{-8}\)，64→128 是 \(1.82\times10^{-12}\)。

## 3. 这九个面板的下一步

窄核心 \(0.508995\)：320→640 是 \(9.21\times10^{-5}\)，640→1280 是 \(7.23\times10^{-10}\)。

两条大尾再加倍是 \(5.7\times10^{-10}\) 和 \(3.9\times10^{-8}\)。四条较小的尾再加倍是 \(10^{-13}\) 到 \(10^{-14}\)。两条 H2 翼收到 128 个节点后，下一步是 \(10^{-9}\) 和 \(10^{-12}\)。

所以第一次加倍里较大的那些变化，再加一档就落到 \(10^{-6}\) 以下。窄核心和 \([0.230,\,0.264]\) 那条翼要加两档。只做第一次加倍会把这两笔还没走完的 \(10^{-4}\) 到 \(10^{-5}\) 留在预算外面。
