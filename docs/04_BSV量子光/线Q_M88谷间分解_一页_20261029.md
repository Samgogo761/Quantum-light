## M88 判定

- 总振幅 2×2/4×4 = **1.50**；总 Jx Δφ = **-134.4°**。
- K 自身 Δφ = -121.4°，K′ 自身 Δφ = -157.0°。
- 谷夹角 2×2 **49.0°** → 4×4 **13.4°**；
  谷相消比（1=无相消）2×2 **0.912** → 4×4 **0.993**。
- intra 份额 0.06 → 0.17；inter 1.05 → 1.03。
- intra Δφ = 86.7°，inter Δφ = -145.9°。
- 谷重构/总振幅：2×2 1.0000，4×4 1.0000。

## M52 对照（不加密）

- 振幅降 6.56；总 Δφ -10.7°。
- 谷夹角 -109.7° → -166.6°；相消比 0.595 → 0.723。

判定串：`phase_jump_is_interband_fewk_sampling`。

M88 的 134° **不是** K/K′ 相消。4×4 谷夹角更小（49°→13°），相消比更接近 1（0.912→0.993）。K 与 K′ 各自转了 −121° 和 −157°，净相位跟着带间通道走（inter Δφ=−146°，份额始终 ~1）。这是 few-k 对 interband H2-odd 相位景观的采样，不是谷间对消伪影。

M52 的 6.6 倍振幅下降才更像谷相消：2×2 夹角 −110°、相消比 0.595；4×4 夹角 −167°，K′ 份额掉到 0.22。相位只变 −11°，符号保留。

因此：2×2/4×4 都不能当材料定量；**不上 8×8**。若还做材料，应抽少数代表 k 看 interband H2-odd 相位，而不是加密网格。
