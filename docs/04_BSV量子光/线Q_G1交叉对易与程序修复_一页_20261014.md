# G1 最新状态：常数无冲突，连续消去未封板，修复一个诊断错误

日期：2026-10-14。**Γ12 输出残差仍为正常 0.007439、反常 0.002232。未通过生产物理资格。**

1. **外审的主要提醒成立。** γ=2πη²、端口和输出核的常数一致，不足以证明整个连续谱量子输入输出实现正确。没有改 γ、D、初态、P1 或探测模式。
2. **1.0→0.5 已找到原因。** 正 DFT 频箱产生周期锯齿反馈核 γ(1−2τ/Tobs)，对测试电流的误差就是 Tp/Tobs。窗口比例 1/2/4/8/16 对应 1/.5/.25/.125/.0625。固定窗口只加 UV 不能消掉这个偏差。
3. **初值没有发现所怀疑的错误。** 生产总片上场 A₀ 由稳态散射解给出，一般非零。旧测试的 A₀=0 只是没有自由输入的自场。
4. **交叉分解已完成，但不是新的独立物理证明。** U₀ 是无泵材料出射行，不是裸入射行。以 U₀ 为参考：正常交叉 +20.04214、增量自身 −20.03470；以真实自由输入为参考：+4.20909、−4.20165。两者都回到同一 0.007439。完整复矩阵已保存，大数相消仍存在。
5. **新增有限联合验证通过。** 真实两 k 电子顶点 + 相同 16 个光子振子，显式联合传播与同谱记忆核消去差约 10⁻¹⁴；反馈核与自由场对易核一致。它只证明同一有限模型的消元正确，未验证生产的连续极限、稳态入射映射或 H2 远场。
6. **发现并修复程序 bug。** 协方差检查漏掉 Im n，会把合法态误报为不合法；修复后 22 组复数 Gaussian 态对照误差小于 9×10⁻¹⁶。此 bug 不改变 U,V,n,m，也不解释 0.007。两份旧诊断脚本的静默覆盖风险也已修复。
