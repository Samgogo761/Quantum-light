# G1 工作记录：最低亮极点左尾的红外收敛（2026-10-15）

时间步保持在已经封板的四阶宏步 1024 和 2048。最终九个面板的求积不动。没有改 Hamiltonian、初态、\(\gamma\)、\(\eta\)、\(D\) 或 H2 波包，没有加新的红外屏蔽，也没有重归一化 \(U,V\)。

这条尾属于极点 \(0.092793\)，生产窗口是 \([10^{-4},\,0.02]\)，24 个节点，权重 \(0.01990\)。低于 \(10^{-4}\) 的一段单独积分，不和原面板重叠。另一种做法是把整段重构成 \([\omega_{\min},\,0.02]\)。两种都做了。

## 1. 红外积分本身

缺失带宽就是 \(\omega_{\min}\) 到 \(10^{-4}\) 的长度。\(t\) 上的 Gauss、\(\omega\) 上的 Gauss、对数频率上的 Gauss，节点从 8 加到 64。

宏步 2048 上，对数频率 64 个节点的新增正常矩阵 \((0,0)\) 是：

| \(\omega_{\min}\) | 新增 \(R_N(0,0)\) |
|---:|---:|
| \(10^{-6}\) | \(+1.95489245\times10^{-4}\) |
| \(10^{-8}\) | \(+1.95489437\times10^{-4}\) |
| \(10^{-10}\) | \(+1.95489437\times10^{-4}\) |

\(10^{-6}\) 到 \(10^{-8}\) 只动 \(1.9\times10^{-10}\)，再降到 \(10^{-10}\) 不再动。三种求积在 32 个节点之后彼此差 \(10^{-15}\)。32 到 64 的步长是 \(10^{-16}\)。

把整段尾重构成 96 个 \(t\) 节点，再减去原面板，和“只在下方加一段”的差是 \(3.7\times10^{-10}\)。这是 \([10^{-4},\,0.02]\) 被重新布点的差别，不是红外段被算了两次。

自由矢势的最大模从 \(10^{-6}\) 的 \(0.00439\) 增到 \(10^{-10}\) 的 \(0.00761\)，\(U,V\) 的最大元从 \(0.21\) 增到 \(0.27\)。新增这一段的对易矩阵停在 \(1.955\times10^{-4}\)，没有跟着 \(1/\sqrt{\omega}\) 继续变大。\(U_0\) 的最大元是 \(7\times10^{-8}\)。左右端口各约占一半，\(9.80\times10^{-5}\) 和 \(9.75\times10^{-5}\)。

## 2. 先前那个单节点

\(10^{-8}\) 的 24 点 \(t\) 面板里，有一个节点落在 \(5.42\times10^{-5}\)。它的权重是 \(1.389\times10^{-4}\)，而 \([10^{-8},\,10^{-4}]\) 的带宽只有 \(9.999\times10^{-5}\)。多出来的 \(3.89\times10^{-5}\) 是这个节点在更长区间上的 Gauss 权重，不是缺失红外段的积分。

四阶宏步 1024 上，这个节点单独的 \((0,0)\) 是 \(+2.393\times10^{-4}\)。收完的红外段是 \(+1.955\times10^{-4}\)。差 \(4.4\times10^{-5}\)，和权重偏大的方向一致。中点 4096 上整段替换的 \(+1.945\times10^{-4}\)，和四阶收完的 \(+1.955\times10^{-4}\) 差 \(1.0\times10^{-6}\)。

## 3. 加回最终求积之后

红外段在两个宏步上只差 \(1.5\times10^{-8}\)。最终矩阵仍带着原来的时间差。

| | 宏步 1024 | 宏步 2048 | \(h^4\) 外推 |
|---|---:|---:|---:|
| \(R_N(0,0)\) | \(+1.049\times10^{-6}\) | \(+1.606\times10^{-5}\) | \(+1.706\times10^{-5}\) |
| \(R_N(1,1)\) | \(-2.138\times10^{-6}\) | \(-4.688\times10^{-6}\) | \(-4.858\times10^{-6}\) |
| \(R_A\) 最大模 | \(8.94\times10^{-7}\) | \(7.09\times10^{-7}\) | \(7.00\times10^{-7}\) |

宏步 1024 的 \(+1.05\times10^{-6}\) 来自两笔还没分开的 \(10^{-5}\)：基线从 1024 到外推还要移动 \(+1.60\times10^{-5}\)，红外段比 1024 的基线多出来的部分把其中大部分抵消了。2048 和外推把这笔时间差留了下来。验收不能用 1024 这一档接近零来判断。

外推后的正常矩阵 \((0,0)\) 是 \(+1.71\times10^{-5}\)，\((1,1)\) 是 \(-4.86\times10^{-6}\)，反常矩阵是 \(7.0\times10^{-7}\)。反常矩阵过了 \(10^{-6}\)，正常矩阵没有。

## 4. 这一步说明什么

\(\omega_{\min}\to0\) 时，这一段的对易贡献停在 \(+1.955\times10^{-4}\)，不是红外发散，也不需要再引入一个物理红外机制。固定窗口上的 \(-1.784\times10^{-4}\) 加上这段之后，时间外推是 \(+1.71\times10^{-5}\)。

物理问题：时间和这条左尾的红外端都收到这一步之后，正常矩阵还剩下 \(+1.7\times10^{-5}\)。它是生产 \(W_{\rm in}\) 的动态装配，还是别的输入列仍有同量级的缺口？

证据：三种求积、两个下限、两种面板拼法，红外段本身稳定到 \(10^{-10}\)；反常矩阵是 \(7\times10^{-7}\)；两点模型在收完求积和时间后可以到 \(10^{-7}\)。
