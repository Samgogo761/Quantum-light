## 外审里哪些能验收，哪些不能照单全收

能验收：

- 电流 \(\mathcal R^A\)（含接触项）对独立传播是真预测；H2 实部波形在加密时间步后到 \(0.11\%\)。
- 理想均匀膜、模式面积等于样品面积时，连通矩的 \(S\) 可以消掉。
- \(2\mathrm{Re}A_2+\langle[s_1,s_1^\dagger]\rangle\simeq0\)（残差 \(1.2\times10^{-7}\)）只说明**二阶关系在二阶内部自洽**。
- \(\lvert A_2\rvert\approx0.705\) 已经不小，被丢掉的四阶及更高项不能默认可忽略。
- 六点 \(V_{\min}\approx0.613>1/2\) 只能说「当前二阶方法演示没有给出压缩」，不能说「这个体系没有压缩」。
- 电子对足够小的 \(\delta A\) 仍在线性区，与「一次光—物质反馈的玻色系数不小」可以同时成立。真空量子场在单胞上的 \(\delta\kappa\sim N_{\mathrm{cell}}^{-1/2}\to0\)，而 \(A_2=\mathrm{i}(\alpha_{\mathrm{fs}}/A_{\mathrm{uc}})\beta_F\) 是强度的。
- 现在不上全 BZ、不上量子输入扫描，是对的。

必须改口的：

- **\(1+\lvert A_2\rvert^2-\lvert B_2\rvert^2\simeq1.475\) 不是理论预言 \([b,b^\dagger]=1.475\)。** 它是抽了一部分 \(O(\lambda^4)\)、没有抽齐。外审这一点是对的；上一轮报告若读成“对易子等于 1.475”，应收回。
- **\(\mathcal R^A\) 是实线性的**，有 \(B_2\neq0\)。不能写成复线性标量 \((1-\chi(\omega))^{-1}\)。
- **收集核 \(K\) 不是样品上的辐射反作用 \(G_{\mathrm{self}}\)。** 薄片 \(E=-(Z_0/2)J\) 与模展开 \(a(\omega)\propto\tilde I/\sqrt{\omega}\) 还没接到同一个 \(G\)。单侧/两侧也未选。
- **其它端口只在 \(O(\lambda^4)\) 进入** \(\lvert A_{2j}\rvert^2-\lvert B_{2j}\rvert^2\)。它们修不好已经闭合的 \(O(\lambda^2)\) 恒等式，也不是自动解释 \(0.475\) 的充分理由。
- 因果 Volterra 重求和、小 Fock 基准：值得做的**候选**，还不是已批准生产闭合。把「磁序控制非平衡量子输入—输出通道」写成课题形状，是人审事项，这里不升格。

## 物理问题（必须停在这里让你选下一步）

**问题：** 电子线性响应已经对小测试场成立，但一次反馈的玻色回路增益 \(\lvert A_2\rvert\sim0.7\)。下一步应把 \(O(\lambda^2)\) Born 冻结并用全时间因果 Volterra 重求 \((1-G\mathcal R)^{-1}\)，还是先把 \(G_{\mathrm{self}}\)、两侧和正交端口的线性网络写清楚，再谈重求和？

**证据（六点、+N、本机）：**

| 量 | 数 |
|---|---:|
| \(\lvert A_2\rvert\) | 0.705 |
| \(\lvert B_2\rvert\) | 0.149 |
| 2×2 谱半径 | 0.689 \(<1\)（级数在**该 2×2 子空间**里收敛） |
| 部分四阶 \(1+\lvert A_2\rvert^2-\lvert B_2\rvert^2\) | 1.475（**不是**预言的对易子） |
| \(\hat e_\perp\) 电流里沿 \(\hat e_\perp\) 的比例（Re 驱动） | 0.632 |
| \(\hat e_\perp\) 电流相对 \(\mathrm{span}\{\mathrm{Re}F,\mathrm{Im}F\}\) 的时间残差 | 0.970 |
| 因果单模前向 vs 全窗 \(A_2+B_2\) | 相对差 0.338 |
| H3 正交端口 \(O(\lambda^4)\) | \(-0.006\) |
| H1 正交端口 \(O(\lambda^4)\) | \(-0.015\) |
| 平行偏振、同一 \(F_{H2}\) 混入 \(O(\lambda^4)\) | \(+0.015\) |
| 单模 2×2 代数重求后 \(\lvert[b,b^\dagger]-1\rvert\) | 0.357（两种样品场约定相同） |
| 2×2 重求 \(V_{\min}\) | 0.641（Born 为 0.613），仍 \(>1/2\) |

**备选解释：**

1. **同一条 H2 模的全时间反馈大于 2×2 包络。** 时间残差 97% 表示 \(\mathcal R^A[F]\) 的 L2 质量大多不在 \(\phi_{H2}\) 里（高次谐波），\(A_2\) 只是切到这个波包的矩阵元。样品上场若经 \(G_{\mathrm{self}}\) 把这些谐波再喂回去，标量/2×2 \((1-A_2)^{-1}\) 不够，需要因果 Volterra。因果单模前向已经和全窗 Born 差 34%，支持「时间结构不能丢掉」。
2. **缺的是端口和 \(G\) 的定义，不是重求和算法。** 最近的 H1/H3 正交波包和平行偏振对 \(0.475\) 几乎没有贡献。两侧真空、连续频率、横向 \(\mathbf q\neq0\) 仍未包括。\(K\) 与 \(G_{\mathrm{self}}\) 也还不是同一个核。在这些没写清以前，硬做 \((1-G\mathcal R)^{-1}\) 会把规范选进答案里。
3. **\(\lvert A_2\rvert\sim0.7\) 部分来自六点太稀或有限 \([0,T_p]\)。** 现有证据不支持用更密 \(k\) 来「算掉」\(A_2\)：它是 \(\alpha_{\mathrm{fs}}/A_{\mathrm{uc}}\) 乘上电子核重叠，强度量。全 BZ 可能改数字，但不能先当作主因。

外审主张的「线性电子 + 反馈全阶重求和」作为**候选方法**与证据 (1) 相容；不能在 (2) 未选 \(G\)、未选端口之前写成生产理论。Ilin 等是弱关联展开先例，不从腔模型拷贝公式。
