## 1. 被积对象

\[
M_{ab}=\sum_{kcv} w_k\, X_a^*(kcv)\, X_b(kcv)\, F(\Delta_{kcv}).
\]

\(F\) 是既定 H2 波包 \(|\phi|^2\)，中心 \(\omega_c=2\omega_0=0.1\)，在原 \([0,0.6]\) 网格上 \(L^2\) 归一。权重只乘一次 \(w_k\)。完整 \(2\times2\) 复矩阵必须保存。

这是零泵浦电子涨落谱的频率窗积分，不是无泵浦发光，不是最终 H2 输出，不是光子数。

## 2. \(F\) 实现：直接 `window_fourier`

stage1ao 在 \([0,0.6]\) 上插值、外部置零。本轮生产积分用直接 `window_fourier`。\(\Gamma128\) 上插值对直接：

- 迹相对差 \(3.59\times10^{-6}\)
- Frobenius \(3.63\times10^{-6}\)

\([0,2]\) 对 \([0,0.6]\) 的质量尾 \(2.06\times10^{-12}\)。远小于 0.5% 目标，不另开无限精度任务。数值截断**不是**物理光子截止。

## 6. 反演诊断：混成 \(\Gamma\) 点集未闭合

第一份 JSON 在混成 \(\Gamma\) 上写 `missing_partners=1452`。当时怀疑是浮点键假阳性。独立复核：

- 整数格（最小间距 \(1/768\)，半整数再加倍）→ 1452
- 12 位小数键 → 1452
- 半步混成两种方法都是 0
- 均匀四套都是 0

因此 **1452 是真实缺失对，不是诊断假阳性。** `shift=0` 细化子点 \(k=(i+a/r)/N\) 的反演像不必落在同一父格；一遍 `close_mask` 只补相邻父格标记，不能保证每个已细化子点的反演像也是已细化子点。半步子点的反演落在面积反演的同一父格内，所以半步混成干净。

这是 \(\Gamma\) 混成点集的配对缺口，不是第二套物理求积。门槛对照的半步一侧完全配对。未为闭合该缺口自动加第二轮细化。
