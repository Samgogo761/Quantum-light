## 4. 三个机制问题（仅本协议、仅主窗电流）

1. **近反相是否仍在？** 是。精确 QED \(\arg(A/B)=179.391^\circ\)，距 \(\pi\) \(0.609^\circ\)；修正 GH5 为 \(178.72^\circ\)。这是有限窗复电流相位，不是远场谐波光子相位。
2. **\(\rho\) 是否仍接近 \(R\)？** 是，比 24.8 μm 更近：\(1.267/1.273=0.9953\)。低频 \(\rho=1.456\)。这不是 \(K_A/K_B\) 定理，拟合 \(B,A,C\) 也不是已经独立重构的三个微观核。
3. **频率是否改变统计转导？** 在本有限时间协议下，是。\(\rho:1.456\to1.267\)；二维比 \(4.98\to8.50\)；\(\|C/A\|:1.54\%\to0.32\%\)。三项模型在主窗 \(\pi/4\) 仍能预测。不能外推成实验室 25 fs、标定场强或全 BZ / CrI₃。

留出成功 \(\neq\) 高阶 \(\Delta n\) 不存在。四点加一个留出不能排除 \(e^{\pm 2i\theta}\) 混叠。

## 5. 允许 / 不允许

允许：

- 1600 nm 精确 QED 主窗上，位移压缩角仍进入 Néel-odd H2，三项角向模型对独立 \(\pi/4\) 通过 2% 工作闸门。
- 近反相和 \(\rho\approx R\) 在精确 QED 中仍然存在，且与同口径 GH5 接近。
- 同一统计、同一周期数、改频率后，扇区相对权重发生变化。

不允许：

- 写成量子优势、出射 \(g^{(2)}\)、电子–光子纠缠、或经典光做不到。
- 把 8.534 / 8.498 写成产额增强，或拿来直接对比未分栏的 4.98。
- 写成 25 fs 实验室 BSV、宏观光子数、已标定 W/cm²、全 BZ 或真实 CrI₃。
- 因邻窗 15% 而宣布机制失败；也不得因主窗 0.09% 而宣布所有窗口都稳。
