## 3. C 段：平均 H2 相消是不是对称性强迫的

精确空间反演 **P** 把 \((N,k,A)\) 映到 \((-N,-k,-A)\)。静态 Hamiltonian 和电流在补上折叠 \(G\) 的 sewing 后，残差 \(10^{-14}\)。实验室两次畴实验用的是**同一个** \(A\)，所以这条精确映射**不能**要求本次 \(J_o(H_2)\) 为零。

镜面把 x 方向映到大约 120°，不是沿 x 的同一束光。C2 静态残差 \(\sim 3.6\times10^{-5}\)（几何畸变），也不能当本次脉冲下的严格对称。

驱动后的 nk192 逐 k H2：同一脉冲下，\(z_+(k)\) 与 \(-z_-(-k)\) 的加权相对残差约 **0.13（x）/ 0.18（y）**，不是机器零，也不是完全随机。这不能翻译成“八成贡献已经配对”。\(J_o(k)\) 对 \(k\to-k\) 既明显不是偶的、也不是严格奇的。图上红蓝相邻仍只是线索。

结论给本人判断：静态反演在同时翻转驱动时精确成立，不等于同一脉冲下必须相消；没有找到强制相消操作，也不证明相消全由动力学相位造成。本轮不改模型、不加项、不换脉冲来验证。
