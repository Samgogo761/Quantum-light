# G1 工作记录：求积绝对值预算与四阶步的小规模试验（2026-10-15）

三笔误差分开记。旧的面板加倍结果和 4096 步列没有改。

## 1. 全局求积预算

343 个面板第一次加倍的变化矩阵都还在。有符号总和是上一份记录里的

\[
\Delta R_N(0,0)=-0.005980,\qquad \Delta R_A(0,1)=-0.002243+0.000377i.
\]

把每个矩阵元的实部和虚部分别取绝对值再相加，正常矩阵 \((0,0)\) 的累计是 \(0.020001\)。有符号总和只有 \(-0.005980\)，差出来的是大面板之间的正负抵消，主要是窄核心 \(+0.006917\) 和 H2 翼 \(-0.006501\)。

334 个第一次加倍不超过 \(10^{-6}\) 的面板，单独加总是另一笔账：

| | 有符号总和 \((0,0)\) | 绝对值累计 \((0,0)\) |
|---|---:|---:|
| 这 334 个面板 | \(+2.99\times10^{-7}\) | \(3.44\times10^{-7}\) |
| 反常 \((0,1)\) 实部 | \(-6.2\times10^{-9}\) | \(8.7\times10^{-9}\) |

\(334\times10^{-6}=3.34\times10^{-4}\) 是每个面板都顶在门槛上的宽松估计。实测的绝对值累计是 \(3.44\times10^{-7}\)，比那个估计小约一千倍。这仍只是第一次加倍的实测变化，不是它们再加倍一次之后的上界。这 334 个面板没有再翻倍。

九个超过 \(10^{-6}\) 的面板，下一步已经单独量过：窄核心 640→1280 是 \(7.23\times10^{-10}\)，主 H2 翼 64→128 是 \(1.01\times10^{-9}\)，相邻翼 64→128 是 \(1.82\times10^{-12}\)，几条尾再加倍是 \(10^{-8}\) 到 \(10^{-14}\)。其中窄核心的 320→640 仍有 \(9.21\times10^{-5}\)，主翼的 32→64 仍有 \(2.87\times10^{-5}\)；再加一档才落到 \(10^{-9}\)。

窄核心在 1280 个节点上做了两种独立放置。相对同一条 \(t=\mathrm{arcsinh}((\omega-\Delta)/\Gamma)\) 的 Gauss：把 \(t\) 区间对半切开、各 640 个节点，正常矩阵差 \(1.68\times10^{-10}\)；改在 \(\omega\) 上直接放 1280 个 Gauss 节点，差 \(3.38\times10^{-11}\)。1280 的结果不是同一种节点排布的偶然一致。

整张 \(UU^\dagger-VV^\dagger\) 用 4096 列一块一块重加，和一次矩阵乘的差是 \(8.5\times10^{-11}\)。矩阵累计舍入比求积和时间误差都小。

## 2. 时间模型

在已经加上 34 条尾、主 H2 翼和窄核心的那组数上，\(R_N(0,0)\) 是 \(0.024183\)、\(0.005994\)、\(0.001309\)。只含 \(h^2\) 时，2048/4096 外推是 \(-2.53\times10^{-4}\)，1024/2048 外推差 \(1.85\times10^{-4}\)。

再用 \(R_0+C_2h^2+C_4h^4\) 把三个点插进去，得到 \(R_0=-2.66\times10^{-4}\)。它和细档的二阶外推只差 \(1.2\times10^{-5}\)。三个点正好确定三个系数，这个 \(R_0\) 是插值，不是多一个时间档验证过的连续极限。\(h^6\) 还没有约束。因此 \(10^{-4}\) 现在还不能当成已经确认的平台，也不能当成物理理论误差。

## 3. 四阶步在完整电子反馈下的小规模试验

四个输入频率、16 列，电子网格仍是生产用的 \(12\times12\)，九个周期。再生的前两步顶点和保存的生产顶点差是 0。探测器核和保存的核一致。

这 16 列在中点法 1024 步上的正常矩阵最大模是 \(0.864\)。相对这一档：

| 算法 | 正常矩阵差 | 反常矩阵差 |
|---|---:|---:|
| 中点 256 | \(0.370\) | \(0.0234\) |
| 中点 512 | \(0.112\) | \(0.00912\) |
| 四阶宏步 256 | \(0.0538\) | \(0.00497\) |
| 四阶宏步 512 | \(0.0446\) | \(0.00398\) |

宏步 256 的细步就是 512。它比中点 512 更靠近中点 1024。四阶步在这 16 列上确实减小了时间差，但没有到 \(10^{-6}\)。现有中点转置行不能拼成这个结果；这一试是重新走了这些列。全部约十三万列按同样比例做，会是一次完整重算，这一轮没有启动。
