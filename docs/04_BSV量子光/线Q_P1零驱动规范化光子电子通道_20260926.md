## 1. SI photon normalization

采用已经冻结的真空二维电流片量子化式：

\[
E^{(+)}(z,t)
=
i\int_0^\infty d\omega
\sqrt{\frac{\hbar\omega}{4\pi\epsilon_0cS}}\,
a(\omega)e^{i\omega z/c-i\omega t},
\]

\[
[a(\omega),a^\dagger(\omega')]
=\delta(\omega-\omega').
\]

对正频率部分

\[
E^{(+)}=-\partial_t A^{(+)}
\]

且时间因子为 \(e^{-i\omega t}\)，所以

\[
A^{(+)}(z,t)
=
\int_0^\infty d\omega
\sqrt{\frac{\hbar}{4\pi\epsilon_0cS\omega}}\,
a(\omega)e^{i\omega z/c-i\omega t}.
\]

将这个 \(E^{(+)}\) 与电流片的
\(E_{\rm emit}=-(Z_0/2)J_{\rm sheet}\) 逐频比较，才得到下面的
\(a_{\rm src}\) 系数；因此 \(\sqrt{\omega/\gamma_{\rm self}}\) 不是从
输出矩阵恒等式猜出的。

对于

\[
E_{\rm emit}=-\frac{Z_0}{2}J_{\rm sheet},
\qquad
I=S J_{\rm sheet},
\]

以及本项目采用的

\[
\widetilde I(\omega)=\int dt\,e^{+i\omega t}I(t)
\]

约定，得到

\[
\boxed{
a_{\rm src}(\omega)
=
i\sqrt{\frac{Z_0}{4\pi\hbar\omega S}}\,
\widetilde I(\omega)
}.
\]

这一步固定的是 SI 远场传播模的单位，不是从数值 unitarity 反推的拟合常数。

对当前 `q8_m0_gsheet.py` 的代码单位，片层反馈为

\[
A_{\rm self}(\omega)
=
\frac{i\gamma_{\rm self}}{\omega}I_{\rm cell}(\omega).
\]

把 \(I=N_{\rm cell}I_{\rm cell}\)、\(S=N_{\rm cell}A_{\rm uc}\) 代入上面的 SI
归一化，并使用冻结的 Peierls/current 转换和

\[
\gamma_{\rm self}=\frac{2\pi\alpha_{\rm fs}}{A_{\rm uc}}
\]

可得当前 \(A\)-port 与 canonical photon channel 的标量关系：

\[
\boxed{
a(\omega)=
\sqrt{\frac{\omega}{\gamma_{\rm self}}}\,A(\omega).
}
\]

因此偶通道中

\[
S_a=S,
\qquad
L_a(\omega)
=
\sqrt{\frac{\omega}{\gamma_{\rm self}}}\,
G(\omega)L(\omega).
\]

输入和输出 \(A\)-port 乘以同一个正实标量，所以 \(S\) 的数值矩阵不变；变化在
电子源的 canonical weight 中。

本轮使用

\[
\gamma_{\rm self}
=1.0807892763646022\times10^{-3}
\]

（当前冻结几何和代码单位）。\(S=N_{\rm cell}A_{\rm uc}\) 仍是理想均匀片的空间归一
条件，\(N_{\rm cell}\neq N_k\)。

## 2. 正频率源是 \(B\)，不是 \(B^\dagger\)

沿用已冻结的粒子—空穴分解：

\[
\delta\hat I_a(t)
=
\sum_p
\left[
u_{a,p}e^{+i\Delta_p t}\hat B_p^\dagger
+
u_{a,p}^*e^{-i\Delta_p t}\hat B_p
\right].
\]

在

\[
\widetilde I(\omega)=\int dt\,e^{+i\omega t}I(t)
\]

约定下，\(\omega>0\) 的频率分量是

\[
\boxed{
\delta\hat I^{(+)}(\omega)\propto\hat B_p
}
\]

因为 \(e^{-i\Delta_p t}\) 在正频率 \(\omega=\Delta_p\) 上有谱权重；而
\(u_{a,p}e^{+i\Delta_p t}\hat B_p^\dagger\) 位于负频率。

代码同时记录了两项：

```text
positive-frequency term: exp(-i Delta t) B
negative-frequency term: exp(+i Delta t) B†
```

并对代表性跃迁验证了

\[
S^>(+\Delta_p)=u_p^*u_p^{\mathsf T},
\qquad
S^<(-\Delta_p)=u_p^*u_p^{\mathsf T}
\]

（第二式采用本报告中把 lesser 矩阵指标固定为
\(\langle I_a(0)I_b(t)\rangle\) 的约定）。这与当前已经通过的
\(C_I=i(K^R-K^A)\) 谱跳跃一致。

如果错误地把正频率电子源写成 \(B^\dagger\)，则真空下会出现
\(L_a b_{\rm el,in}^\dagger\) 的 creation block。代码用它的错误控制量

\[
n_{\rm wrong}
\equiv {\rm Tr}(L_aL_a^\dagger)
\]

作对照：隙上样本 \(n_{\rm wrong}>0\)，而正确的 \(B\) 源在候选输入真空中给出
\(n_{\rm out}=0\)。

## 3. 电子 canonical channels

对 \(\omega>0\) 的电子跳跃矩阵，按

\[
C_I(\omega)=i(K^R-K^A)
=L(\omega)L^\dagger(\omega)
\]

作 Hermitian eigenfactorization。保留正特征值对应的 eigenchannels，并定义

\[
[b_{{\rm el},i}(\omega),
b_{{\rm el},j}^\dagger(\omega')]
=
\delta_{ij}\delta(\omega-\omega').
\]

因此

\[
\xi_{\rm el}(\omega)=L(\omega)b_{\rm el,in}(\omega).
\]

三个审计网格的全部样本在当前 \(\eta=10^{-4}\) 诊断展宽下均为 PSD：

| 网格 | 隙下 channel rank | 隙上 channel rank | photon-row 最大残差 |
|---|---:|---:|---:|
| \(\Gamma\ 96^2\) | 0 | 2 | \(8.9\times10^{-16}\) |
| \(\Gamma\ 192^2\) | 0 | 2 | \(8.9\times10^{-16}\) |
| half-shift \(192^2\) | 0 | 2 | \(8.9\times10^{-16}\) |

隙下 \(C_I=0\)，所以没有开放电子 channel；隙上两个面内 current eigenchannel
补回 photon 子空间失去的 canonical weight。

这里的 \(L\) 是谱矩阵的 canonical eigenchannel factor，不是原始
\((c,v,k)\) transition operator 的简单重命名。原始 \(B_{cvk}\) 先通过
\(C_I\) 的频率谱混合，再得到 \(b_{\rm el,in}\)。

## 4. Photon output row

当前得到的规范化偶通道为

\[
\boxed{
a_{+,\rm out}
=
S_a(\omega)a_{+,\rm in}
+
L_a(\omega)b_{\rm el,in}.
}
\]

奇通道保持

\[
\boxed{
a_{-,\rm out}=-a_{-,\rm in}.
}
\]

输出行验收式：

\[
\boxed{
S_aS_a^\dagger+L_aL_a^\dagger=I_2.
}
\]

在三套网格、隙下和隙上测试点上最大残差均为
\(8.9\times10^{-16}\) 量级。

严格的表述是：这证明了 photon output row 的 coisometry。尚未构造电子输出行，因此
本轮**没有**宣布完整 \(\mathbb S_{\rm ext}\) 已经 unitary：

\[
\begin{pmatrix}
a_{\rm photon,out}\\
\text{electronic out}
\end{pmatrix}
=
\mathbb S_{\rm ext}
\begin{pmatrix}
a_{\rm photon,in}\\
b_{\rm el,in}
\end{pmatrix}
\]

中的下半部分仍待后续若确有需要再定义；不能用任意数学补全替代物理电子输出。

\[

\qquad
b_{\rm el,in}|0_{\rm in}\rangle=0,
\]

\[
\boxed{

\langle a_{\rm out}a_{\rm out}\rangle=0.
}
\]

这是从 canonical source orientation 和 output row 直接得到的，不是从“零温不应发光”
反推的公式。
