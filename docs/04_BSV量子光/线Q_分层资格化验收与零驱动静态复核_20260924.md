# 线 Q：分层资格化验收与零驱动静态复核（2026-09-24）

## 给本人看的结论

**部分验收：真正的 stage 取值、CF4 实现、两点电子背景参考值得保留；“连续谱已合格、应选择裸真空还是 dressed 真空”的结论不通过。** 判断依据是代码和独立重构，不取决于执行者是不是 Cursor。

本次独立计算确认：固定 96 个光频率节点、单偏振、两个电子动量点时，零驱动的巨大增长确实是这个有限模型的解。但加密低频节点会改变其大小；两个动量点本身还产生了完整绝缘晶体不应保留的静态负曲率。因此它不能直接说明真实量子主线应更换初态。

原报告及所有原始 JSON 保留。M0、经典 P1、接触项、耦合常数、初态、规范均未改变。本次仅做复核、规定源卷积、静态积分与零驱动等价表示的矩阵指数；未启动全 BZ 动力学、量子输入或生产输出统计。

## 1. 哪些部分可以验收

### 1.1 四阶传播器的基本实现通过

独立重放 stage1ac：Cayley 拟合阶 2.0218、CF4 拟合阶 3.9600，与原报告一致。CF4 的两个指数顺序和系数正确。这里严格说是高精度 ODE 参考测试，不是已知闭式解的制造解测试；这个命名问题不影响其实现验证价值。

真正 stage 节点的电子传播也解决了旧端点平均问题。两点 P1 背景的 X(t) 显示二阶收敛；本次补核 D(t) 的 256→512→1024→2048 最大相对差为 3.16e-4、7.91e-5、1.98e-5。可把这些数据作为**两个指定 k 点**的参考，不自动推广 BZ 或最终噪声精度。旧 7e-13 冒烟比较是在零驱动下完成的，不能把该数字照搬到 P1 下。

### 1.2 固定有限模型的零驱动时间答案可由独立方法确认

零泵浦下，电子顶点满足 X_cv(t)=X_cv(0) exp[i(Ec-Ev)t]，光子波形也有已知自由相位。令 R(t) 为各自由振子的正交辛旋转，代码中的相互作用表象生成元满足

\[
K_I(t)=R^{-1}(t)K_I(0)R(t),\qquad
L=K_{\rm free}+K_I(0),\qquad
\Phi_I(T)=R^{-1}(T)e^{LT}.
\]

本次旋转恒等式数值残差 3e-17 量级，解析电子相位与实际零驱动 stage 缓存最大相对差约 5.95e-11。由一个常系数矩阵指数得到独立参考，避免继续逐步传播。

同一 8ω0 截止、96 节点、单横向偏振、两端口、两 k 点：

| 方法 | 末端 C_P |
|---|---:|
| 常系数矩阵指数参考 | 496150.97 |
| CF4，1024 步/周期 | 496058.73 |
| Cayley，1024 步/周期 | 399318.32 |

CF4 距独立参考约 0.0186%，值得验收。Cayley 距 CF4 仍约 19.5%；原文“两方法全程重合到约 1%”错误，原始轨迹最后一点就否定了这句话。不能把归一化辛残差小直接当作传播准确。

这里 C_P=Ncell×Pauli 适用性诊断系数，不是光子数或激发比例。

## 2. 连续谱资格没有按原报告关闭

### 2.1 精确截断核比较的关键数字不成立

使用原 X_ref、原最强通道、原全时间窗和脚本实际节点，独立将 Gauss 核与

\[
K_\Lambda(\tau)=\frac{2\gamma}{\pi}\mathrm{Si}(\Lambda\tau)
\]

卷积比较。卷积使用 FFT 加速，核直接用 scipy.special.sici，所有比较都针对同一离散源。

| 截止 | 低频 0–8ω0 节点 | UV 节点 | 场相对精确截断核的最大误差 |
|---|---:|---:|---:|
| 8ω0 | 96 | 0 | 34.44% |
| 64ω0 | 96 | 1152 | 15.94% |
| 64ω0 | 192 | 1152 | 6.9e-13 |
| 64ω0 | 384 | 1152 | 8.7e-13 |

原报告的“64ω0 / 1248 节点，场差 2.3e-6”在现存正式代码与产物中不能复现。固定低频 96 节点遗漏了一个求积误差方向，单独加 UV 点无法消掉它。本次补算说明：该规定源的**精确截断核表示**可以达到高精度，但原默认节点并没有达到。

精确有限截止核与无限带宽瞬时自场仍是不同对象；后者的逼近还须明确初始端点、时间采样和误差范数。不能将未消除的数值误差统称为“不可达的物理极限”，也不能自行改变原 1% 验收条件。

### 2.2 慢通道并未通过原双条件

原 stage1ae2 的两个慢通道虽有矢势误差 0.7%–0.8%，对应电场/时间导数误差仍约 17%–20%。原门槛要求两者均低于 1%；所以原文“直接合格”需要撤回。

### 2.3 延迟核收敛不能替代真空涨落的低频收敛

原波形 F(ω)∝sqrt(w/ω)。延迟核的 sin(ωτ)/ω 在零频有可去极限，但裸矢势真空二阶矩涉及 sum(w/ω)，其连续表达含低频对数积分。两种核的资格不能互相替代。

以独立常系数解固定 UV=8ω0，只改变 Gauss 节点数：

| 频率节点数 | sum(w/ω) | C_P |
|---:|---:|---:|
| 48 | 8.9176 | 394414 |
| 96 | 10.2935 | 496151 |
| 192 | 11.6746 | 598974 |
| 384 | 13.0583 | 701628 |

增长率几乎不变，但诊断系数仍随低频分辨率增长，96→192 改变约 20.7%。**低频极限尚未关闭。** 这不授权添加人为 IR 截止；应先明确哪些量是规范相关的裸粒子诊断、哪些可观测量能消去低频依赖。

## 3. 为什么现在不能让本人二选一初态

### 3.1 两 k 点测试存在静态负曲率

对当前绝缘半填充的完整 BZ，均匀静态矢势只是共同平移动量积分变量；填满价带的总能量积分不变。因此其二阶曲率应满足

\[
M_{ab}=\langle D_{ab}\rangle
-2\sum_{k,cv}w_k\frac{\mathrm{Re}[X_{a,kcv}^*X_{b,kcv}]}{E_c-E_v}
=\partial_{A_a}\partial_{A_b}E_{\rm occ}(A)\big|_{A=0},
\qquad M^{\rm BZ}_{ab}=0.
\]

这是冻结 Peierls 模型、正能隙和填满价带下的静态恒等式，不引入新项。当前两个测试 k 点给出

\[
M\approx\begin{pmatrix}7.84696&-7.74002\\-7.74002&-23.80155\end{pmatrix},
\]

本征值约 -25.5931、9.6385；横向投影为 -6.76822。直接差分已占据能量得到同一曲率，矩阵最大绝对差约 1.15e-4。

本次仅作静态 BZ 求积，未传播：12²、24²、48²、96² 网格的曲率本征值依次约 (7.06,7.46)、(0.835,0.963)、(0.161,0.535)、(-0.0119,-0.00055)。这不是宣告 96² 收敛，而是说明两点的显著负曲率不能代表完整晶体。消去正能隙电子振子后，光子静态 Hessian 的附加项正由 M 控制；两点的负方向可使软光子模式不稳定。

### 3.2 当前有限模型并没有可直接拿来替换的稳定 dressed Gaussian 真空

常系数生成元 L 在单偏振、96 节点下有正实特征值约 0.00716490，完整静态 Hessian 的最小本征值约 -0.01521。这次检查的是撤去自由旋转后的**常系数生成元**，与已作废的瞬时 K(t) 小正特征值判据不同。

一个正规、定常 Gaussian 真空需要正定协方差 V 满足 LV+VL^T=0。若 V>0，V^(-1/2) L V^(1/2) 必须为实反对称矩阵，因此其谱不能有正实部。故不能在这个不稳定的固定有限模型里简单选择一个正常的 stationary dressed vacuum 来“修好增长”。

裸真空突然开耦合可以激发穿衣动力学，但**指数增长不是仅凭初态选择就能解释或消除的**。需要先审核稀疏电子求积的静态一致性和低频表示，而不是让本人现在决定换初态。

### 3.3 单偏振的结果也不能直接升级到主模型

原资格阶梯主要是单横向偏振。保持其他离散设置不变、恢复两偏振的常系数检查得到正实特征值约 0.02635，C_P 数量级升到 8.45e21；强放大下绝对辛残差很大，该数只作应力诊断。单偏振是有用的算法简化，但没有完成全两偏振物理模型的资格。
