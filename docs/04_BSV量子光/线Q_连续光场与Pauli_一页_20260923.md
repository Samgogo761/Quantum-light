# 线 Q：今天走到哪里（一页，2026-09-23）

我们现在要让**电子电流的量子涨落**与**自由空间里能被收集的光**在同一个模型中演化。新的联合模型已经通过算符对易等结构检查；这还不能保证它算出的光子统计已经可靠。

本轮先检查了中间的桥：给二维电流片规定一段平滑电流，看量子化的两侧光场能否产生 Maxwell 方程要求的自场。旧的周期频率盒子即使把高频补全，脉冲末端仍会少 (T_p/T_{\rm obs}\)。因此原来的 8 倍观察窗恰好少 **12.5%**。直接在严格正频的开放频率轴上求积，误差降为 **0.008%**；显式光子运动方程与独立核积分相差约 (4\times10^{-15}\)。这里没有添加“零频光子”，也没有改物理耦合。

但把这些光子模式接回电子以后，**粒子—空穴占据尚未算稳**。少量频率节点连规定电流的自场也不能表示，所得巨大占据没有意义。使用已通过平滑源测试的 96 个节点后，联合演化从每周期 64、128 到 256 步的候选占据仍变化数倍到数十倍。现在不能把它换算成“需要多大光斑才安全”，更不能据此宣布出现强量子增益。

**现在真正卡住的是联合演化的数值资格**：电子随 P1 变化的电流顶点、光子的整个相关频带和两者相互作用，必须在同一个时间分辨率下稳定。接下来先改进这部分的保对易数值演化，并用更能代表电子电流的测试波形检查光子频带。节点、时间步和求解器属于工程工作，你不用选。

如果这些检查通过后，粒子—空穴占据依然很大，才轮到你审核一个物理问题：**围绕 P1 电子轨迹的小量子涨落近似是否仍适用**，以及初始光与电子的状态该如何定义。目前先不改 Hamiltonian、脉冲或退相干。
