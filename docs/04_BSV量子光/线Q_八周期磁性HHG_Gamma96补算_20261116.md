# 八周期磁性 HHG：Γ96 子网格补算

`20261116` 为任务标签；实际执行 2026-10-21。方案 1：本地补算缺失的两个 48×48 子网格，按电流平均拼成 Γ96。只算经典片电流。**没有 CJJ、光子输出、QED、G1/H2、Γ192、场强或压缩角扫描。**

**结论：没有已认证磁性通道。H2、H4 现在都不能作为非经典光驱动目标；H7-45° 只是参考窗上的网格加密候选，窗/带宽仍能把它几乎读没，因此也不批准现在就上压缩光。** Γ96 是 Monkhorst–Pack 加密证据，不是 BZ 极限。

## 1. 开算前的兼容性门槛

工作树 `q8_m0_model.py` 相对 git HEAD / 旧归档只多了坐标助手 `k_frac`；HEAD 哈希仍是归档的 `0dbcb90f…`。Hamiltonian、电流算符、Peierls、初态和 `midpoint_unitary_exponential_v1` 未改。`k_grid(geo,nk,shift)` 默认行为经 `k_grid_xy(sx=sy=shift)` 对照，分数/笛卡尔/权重完全一致。

只新增向后兼容的 `k_grid_xy(geo,nk,sx,sy)`，以及 `propagate(..., shift_xy=None)`。四个提议子网格与 Γ96 的分数偏差均为 0，互不相交，并集 9216 点，反演闭合，权重恒等式 \(w_{96}=w_{48}/4\) 成立。

协议锁定：`P1_a2_A0.8`，nk=48，ntpc=400，八周期，CEP=0，R0，\(\mu=-0.009010620372198276\)。四份旧 V48 / V48S meta 全部对齐。读写前后 8 个归档 npz/meta 哈希不变。

\[

\]

自动验收只把“\(D_B\) 翻号”记进 H7 的不稳定清单，所以机器 verdict 给 H7 空的 `unstable_quantities`。物理上不能接受：boxcar 窄带把干涉相位推到约 90°，磁畴差几乎消失。**H7 参考窗看起来稳，观测定义并不稳。**

## 5. 三个通道是否值得作为非经典光目标？

| 通道 | 已认证？ | 现在就上压缩光？ | 不稳的量 | 一句话 |
|---|---|---|---|---|
| H2-45° | 否 | **否** | \(D_B\) 符号（48 vs shift）、\(\lvert Z_B\rvert\)、窗/带宽、总强度 | 大反差是采样和分母塌缩 |
| H4-135° | 否 | **否** | \(D_B\) 符号（48→96）、\(\lvert Z_B\rvert\)、\(\phi_B\)、窗/带宽 | Γ96 推翻了“相位较稳”的偶次候选 |
| H7-45° | 否 | **否** | 窗/带宽下的 \(\phi_B\) 与 \(\lvert D_B\rvert\)；BZ 极限未证 | 唯一还值得改观测量/脉冲的经典候选 |

H7 是奇次谐波。即便以后窗设计把它稳住，也不能代替最初关心的反铁磁偶次选择定则。H4 作为偶次通道，当前更不稳定。

## 6. 停机边界

按外审：本轮是当前经典磁性谱筛选的最后一次有边界的网格加密。结果仍无稳定通道，因此

- **不启动 Γ192**
- **不启动场强 / CEP / 压缩角扫描**
- **不重开 QED–MTEF、G1/H2、多周期量子输入**

下一步若继续，应先改观测量或脉冲（分析窗、频带、包络长度），而不是加密 \(k\) 或把非经典统计加到一个尚未定义清楚的读出上。服务器现在仍不必为这条经典筛选启动。
