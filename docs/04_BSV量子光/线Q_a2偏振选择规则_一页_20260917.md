# 线 Q：\(\mathbf a_2\) 偏振选择规则——一页（2026-09-17）

对称性推导仍是设计规则。同一 P1 包络的 \(\mathbf a_2\) 工程传播已开跑（S1-v0 收集，不是光子数）。没有改 \(\Delta\)。

## 现在的 \(x\) 激光，镜面用不上

真正能保持**同一束光**、同时把 \(+N\) 映成 \(-N\) 的，是含 \(\mathbf a_2\) 的竖直镜面。它只在激光沿着 \(\mathbf a_2\) 时成立。我们一直用的 \(x\) 与 \(\mathbf a_2\) 成 120°，所以以前没有方向选择定则。

生产晶格上这面镜子是近似的（\(H\) 残差 \(3.6\times10^{-5}\)）。下面是理想镜子的设计规则；有限网格数字见 a2+S1 作业目录。

## 平均电流：磁性差应垂直于激光

两个磁畴平均起来的电流必须沿 \(\mathbf a_2\)；磁畴差必须沿垂直的 \(\hat n\)。偶次谐波如果带磁畴信息，应出现在横向，而不是沿着驱动。沿驱动的磁畴差、横向的共同电流，理想情况下都应是零。

## 涨落：对角 \(d_{nn}\) 分不开磁畴

垂直电流对磁畴是奇的，但关联里乘两次，负号抵消。所以横向自关联、平行自关联，在理想镜子下都是两个畴共有的。**能分开 \(\pm N\) 的是交叉偏振核**，例如平行的 \(H_1\) 配横向的 \(H_2\)。

这解释了为什么死盯 \(d_{2x,2x}\) 会看到大根相减：\(x\) 把两条通道混在一个分量里。若跑 \(\mathbf a_2\) 却仍只报对角 \(d_{nn}\)，对称性已经预言畴差应接近零。

## 工程上正在检验的

禁止通道（\(J_{o,\parallel}\)、\(J_{e,\perp}\)）是否明显小于允许通道；交叉核的畴半差是否还被网格相消吃掉。泄漏大就停，不自动加 192。不宣布机制。

辅助：静态 \(\Delta\)–隙已扫过。\(\Delta=0.6\) 时同一束 P1 的两光子也已经回到隙下。这只是备忘，不是改模型的授权。
