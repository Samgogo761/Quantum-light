# 线 Q：连续入射列推进，一页说明

2026-10-04。本轮计算、代码与快照已核对；详细数学推导和交接另见完整记录。

**已经推进到：让入射量子场、电子涨落和辐射反馈在同一套方程里演化，并在真实八带模型的小样本上通过独立验证。仍未开始计算可引用的光子产额、压缩或纠缠。**

之前我们解决的是“激光来之前的状态怎样进入程序”。这一次进一步检查：激光打开后，电子怎样改变光场，改变后的光场又怎样作用于电子。我们保留了原来的双层 AFM 模型、接触项和激光波形，没有靠增加耗散或删掉低频来使结果稳定。

实现中保留“无泵浦时的解析参考”，只另外传播激光引起的变化。这样两个部分共用同一组入射量子算符，避免把两个独立随机结果相减。完整输出仍需包含参考和变化之间的关联。

结果有两层：

- **数学实现：**26 项检查通过。简化后的每步求解与完整小矩阵算法相符到约 1e-15，符号和共轭错误的负对照能被检出。
- **真实八带接入：**两个磁畴、两个诊断动量点、原八周期激光的前半周期。细步下，参考加变化与独立求解器的列数据相差约 0.047%，电流约 0.0027%；时间步减半后误差约缩小四倍。这些是五个采样时刻的整体误差指标，不是小增量自身的相对精度，也不是完整 BZ 或完整脉冲的精度。

**目前真正没补齐的是：共同基态中，所有需要的量子入射通道怎样完整进入这套方程。** 本轮只传播了选定的光子入射频率。电子也有自己的连续谱，以及可能不直接被电流看见的方向；这些必须正确嵌入，不能随手另加一套“电子真空噪声”，否则可能重复计算。

因此下一步优先补这一谱分解。传播器已经有独立对照，不需要重新换算法；也暂时不值得上服务器扩大网格。补全后还要控制脉冲结束后的辐射，再投影到我们选择的二次谐波两个偏振模式。

我们的科学问题没变：**固定入射和探测，只翻转双层 AFM 的磁畴，二次谐波两个偏振之间的相位敏感光—光关联是否改变。** 当前磁畴仍是经典标签，尚不能称为“光与量子叠加磁畴的纠缠”。
