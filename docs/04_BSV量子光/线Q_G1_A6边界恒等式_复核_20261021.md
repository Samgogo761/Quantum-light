## 2. 精确恒等式（连续稳态 vs 代码对象）

要验证的不是 \(\mathrm{raw}_{[0,T]}=S\)，而是

\[
\text{有限时间积分}+\text{初始边界}+\text{遗漏时间尾}\ \stackrel{?}{=}\ \text{完整频域辐射场}
\]

的精确形式。

**连续、稳态电流** \(I_{\mathrm{stat}}(t)=I_0 e^{-i\omega t}\)：

\[
S(\omega)=\int_{-\infty}^{\infty}K(t)\,(\mathrm{pol}\cdot I_{\mathrm{stat}}(t))\,dt
=\mathrm{raw}_{[0,T]}+B_{\mathrm{past}}+B_{\mathrm{future}},
\]

其中 \(B_{\mathrm{past}}=\int_{-\infty}^{0}\)、\(B_{\mathrm{future}}=\int_{T}^{\infty}\)。片场 \(S=\phi(\sqrt{\omega}/\eta)(A-A_f)\) 在 \(A-A_f=i\gamma I/\omega\)（归档差 \(3.47\times10^{-17}\)）且 \(\eta=\sqrt{\gamma/2\pi}\) 时等于该全时重叠，因为 \(\int_{-\infty}^{\infty}K(t)e^{-i\omega t}\,dt=2\pi i\eta\phi/\sqrt{\omega}\)。

**代码离散对象（中点伴随）**

\[
\mathrm{raw}=\mathrm{row}(0)\cdot(b,b^\dagger,A)(0)+\sum_n\mathrm{force}_n\cdot\Delta A_f(t_n).
\]

这等于沿**无驱动轨道**的 \([0,T]\) 中点/梯形积分。\(\mathrm{row}(T)=0\)。没有存下来的 \(t=T\) 边界项把 raw 补成 \(S\)。因此 raw **不等于** \(B_{\mathrm{past}}\)，也不等于全时片场 \(S\)。

四个对象不得合并：

| 对象 | 数学 | 代码 | 在 raw / \(U_0\) / 片场 |
|---|---|---|---|
| 直接入射 | \(A_f(t)=A_f(0)e^{-i\omega t}\) | 初值用完整 \(A(0)\)；时间环打在 \(\Delta A_f\) | raw 含；完整 \(U_0\) 左端口 \(a_r=A\) 含透射；片场已减 |
| 辐射片场 | \(\phi(\sqrt{\omega}/\eta)(A-A_f)\) | `radiated_target` | 全时频域重叠（在片关系下） |
| \(t=0\) 伴随初值 | \(\mathrm{row}(0)\cdot(b,b^\dagger,A)(0)\) | `contract_initial` | **属于** \(\mathrm{raw}_{[0,T]}\)；**不是**物理 \(B_{\mathrm{past}}\) |
| \(t=T\) 省略尾 | \(\int_{t>T}K\cdot I\,dt\) | 不存在：从 \(\mathrm{row}(T)=0\) 起步 | 未存储 |

完整 \(U_0\) 不是 \(S\)。\(\omega=0.11\)：\(|U_0|=1.0829210928336994\)，\(|S|=0.18052090817873326\)。右端口 \(a_r=A-A_f\) 与片场差 \(9.81\times10^{-18}\)。

生产映射不变：\(U=U_0+\mathrm{raw}_{\mathrm{driven}}-\mathrm{raw}_{\mathrm{undriven}}\)。1a 仍是同一输出的时间切分；A6 只问无驱动识别。

## 3. \(R_N(T)\) 尾部恒等式（保留 \(R_N(\infty)\)）

令 \(\delta b_T=b_\infty-b(T)\)。矩阵形式

\[
R_N(T)=R_N(\infty)-2\,\mathrm{Herm}[b_\infty,\delta b_T^\dagger]+[\delta b_T,\delta b_T^\dagger],
\]

\(\mathrm{Herm}(M)=(M+M^\dagger)/2\)。上一轮文档写 \(R_N(T)=-2\mathrm{Re}[\cdots]\) 已隐含 \(R_N(\infty)=0\)。那是条件标注问题，不是旧数值错误。只有明确使用 A1–A6 时才能去掉第一项。本轮不在有限 \(T\) 公式里令其为零，也不把 \(\sim10^{-5}\) 预标为窗口切断。

## 5. 冻结核傅里叶：6e-6 能否被窗外项解释

不是新传播，不是伴随收缩。假定 \(I(t)=I_0 e^{-i\omega t}\)，则 \((S-\mathrm{raw})/S\) 与 \(I_0\) 无关，预测失配尺度 \(=\) 尾比 \(\times\lvert S\rvert\)。不含电子瞬态，不含中点离散。

协议：周期 \(125.6637\)，\(T=9\) 周期，\(t\in[-40,T+40]\)，\(dt=\) 周期\(/256\)，\(n_t=22785\)，\(n_\omega=6144\)，\(\int\lvert\phi\rvert^2=1\)。

\(\omega=0.11\)（网格最近点 \(0.10996\)）：

| 量 | 值 |
|---|---|
| 解析全时 \(\lvert 2\pi i\eta\phi/\sqrt{\omega}\rvert\) | \(0.31846\) |
| 数值完整 \([-40,T+40]\) | \(0.31124\) |
| 窗口 \([0,T]\) | \(0.31125\) |
| \(\lvert B_{\mathrm{past}}\rvert\) / \(\lvert B_{\mathrm{future}}\rvert\) | \(1.320\times10^{-5}\) / \(4.794\times10^{-6}\) |
| 块相加 vs 完整 | \(2.78\times10^{-16}\)（切分自洽） |
| 完整 vs 窗口 | \(1.057\times10^{-5}\) |
| 尾比（相对完整 / 相对解析） | \(3.395\times10^{-5}\) / \(0.02984\) |
| 预测 \(\times\lvert S\rvert\)（完整尾比） | \(6.129\times10^{-6}\) |
| 预测 \(\times\lvert S\rvert\)（解析尾比） | \(5.387\times10^{-3}\) |

完整截断尾比给出的尺度与 6.013e-6 **相符**。解析全时公式给出的尺度大两个量级，因为数值「完整」窗 \([-40,T+40]\) 与解析 \(2\pi i\eta\phi/\sqrt{\omega}\) 仍差 \(9.511\times10^{-3}\)。128 vs 256 的窗口差 \(3.48\times10^{-7}\)，一维求积不是主项。

读法：若 \(I(t)\) 真是该频率的稳态谐波，6e-6 **可以**来自 \(K\) 的窗外傅里叶，而不必是步进器 bug。本轮**没有**把真实 `generated_photon_block` 的 \(I_{\mathrm{stat}}\) 与 \(B_{\mathrm{past/future}}\) 收缩，也没有证明无驱动轨道停在 \(I_0 e^{-i\omega t}\)。因此 **不能**宣布 6e-6 已证明为窗口切断，也 **不能**宣布 A6 数值通过。

包外频率上 \(\phi\approx0\)，解析全时 \(\sim10^{-18}\)，窗口项 \(10^{-6}\)–\(10^{-7}\)：相对解析的「尾比」爆炸是 \(\phi=0\) 的除零，不是新物理。

## 6. \(K'\) 范数：标签，不重跑傅里叶，不启动 \(K'\)

来源：`io_identity.json` slice_2b。测度：包络正频网格上的 \(L^2(d\omega)\)；负频把同一网格映到 \(-\omega\)。

| 归档字段 | 值 | 实际积分 |
|---|---|---|
| `norm_phi_prime_minus_phi_sq` | \(1.3735585557819263\times10^{-10}\) | \(\int_{\omega>0}\lvert\phi'_+-\phi\rvert^2\,d\omega\)，**不是**双边 |
| `norm_phi_minus_sq` | \(1.621979970783204\times10^{-10}\) | \(\int_{\omega<0}\lvert\phi'_-\rvert^2\,d\omega\)；40 周期尾 \(1.624\times10^{-10}\) |
