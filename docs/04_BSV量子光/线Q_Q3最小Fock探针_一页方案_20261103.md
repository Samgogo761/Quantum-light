## 重构（Néel-odd 线性读出）

\[
K_{00}=J_{00},\qquad K_{22}=J_{22},
\]
\[
S=K_{02}+K_{20}=2J_{+}-J_{00}-J_{22},
\qquad
D=i(K_{02}-K_{20})=2J_{i}-J_{00}-J_{22}.

\[
K_{02}=(S-iD)/2,\qquad K_{20}=(S+iD)/2.

## 向量比较（主窗）

子空间读出：\(\mathcal J=K_{00}+\rho_{22}(K_{22}-K_{00})+\rho_{02}K_{20}+\rho_{20}K_{02}\)。

主比较（不是 \(K_{00}\) vs \(K_{02}\)）：

\[
\mathbf v_n=\mathbf K_{22}-\mathbf K_{00},\qquad
\mathbf v_c=\mathbf K_{02},\qquad
\mathbf v_{\bar c}=\mathbf K_{20},
\]
\[
\cos\phi=\frac{|\mathbf v_n^\dagger\mathbf v_c|}{\|\mathbf v_n\|\,\|\mathbf v_c\|}.
\]

通道顺序固定 \((J_{2x}^{o},J_{2y}^{o},J_{3x}^{o},J_{3y}^{o})\)。同时报告 \(\mathbf v_{\bar c}\)。三套归一化：原始 \(\mathbb C^4\)；按通道 \(\max|K|\) 缩放；H2 / H3 分开。范数接近地板 → **方向不可判定**，不得标共线。\(10^\circ\) 只是探索性阈值。前/主/后窗看方向是否一致，不用“夹角同号”。

| 主窗结果 | 预定动作 |
|---|---|
| 重构失败或范数近地板 | 方向不可判定；仍提交四个 \(K\) |
| \(\phi<10^\circ\) 且邻窗同为可判定且 \(<10^\circ\) | 标量重加权；**收口** |
| \(\phi\ge 10^\circ\) 且邻窗同为可判定且 \(\ge 10^\circ\) | 才考虑下一步；**仍需新授权** |
| 三窗不一致 | 记录窗依赖；不扩探针 |
| Fock 顶层报警 / 范数失败 / 两磁畴协议不一致 | 停止，不调 \(g\) |

成功标准：可靠重构四个复矩阵元，并判断 \(\mathbf v_c\) 与 \(\mathbf v_n\) 是否有稳定的不同方向。无方向旋转**不是失败**。四个探针只覆盖 \(2\times 2\) 子空间，不是量子优势。
