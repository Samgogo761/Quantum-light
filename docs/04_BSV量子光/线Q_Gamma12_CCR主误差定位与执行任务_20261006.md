## 2. 已定位的主病灶

当前 input_quadrature 修复了首区间倒置和H2内共振遗漏，但几何覆盖不等于谱积分准确。

活脚本：
tools/b0_small_model/q8_m0_p1_h2_finite_kcv_input_close_20261005.py

input_quadrature 的 add_fill（当前约474–494行）对H2以上的剩余区间使用：
trap_segment(x0,x1,6)。

共振核心之外的谱仍然在快速下降；它不是光滑到可以任意用6个线性节点代表的“空白区”。梯形端点有时靠近窄峰，却获得很大的区间权重，造成严重过计。

只读廉价对角积分独立重现：
- Γ12，2304电子坐标，1976暗方向，亮秩328；
- 最大对角CCR误差 = 1.6754365567423，与JSON相同；
- 最坏坐标为代码零基索引1549，能隙5.086678361098405；
- 目标亮投影对角0.5725181462，积分结果2.2479547029；
- 填充段端点ω=5.08661541605，距该极点6.29e-5；
- 此点谱密度58.1919，权重0.0270101，单节点贡献约1.57177；
- 另一填充端点还贡献约0.10932。

这已经解释了该最坏误差的主要来源。

仅加密峰内 n_panel=64→96→128→192，最大对角误差为
1.6754→1.6759→1.6761→1.6761，
几乎不改善，因为错误的大端点权重仍在。

不应继续只加 n_panel，也不应通过缩放结果、修改D或放松验收阈值令CCR看起来通过。

## 3. 临时修正验证与尚未解决的部分

只在内存中将非共振填充段梯形换为Gauss求积，未改物理或磁盘代码：
- 总对角CCR最大误差降到约0.183；
- 原最坏坐标误差随填充精度增加降至约−0.000863；
- 剩余最大误差集中到另一能隙簇2.0648643779。

因此：
- 主病灶的诊断有数值证据；
- 0.183仍未通过，不能说全部修好了；
- Gauss替换仅是定位实验，不直接指定为最终生产算法；
- 剩余簇需要检查峰内/峰间尾部、裁剪边界权重和真实耦合后的峰形。

现节点权重和11.9012832，而区间[0.001,12]长度11.999。对于常数函数也存在约0.814%的积分质量差。这不是1.675的唯一原因，但需检查 sinh_panel 裁剪节点后沿用权重、边界面板补足等细节。“区间不重叠”与“权重积分正确”应分别验证，不能把两者混成一个true。

## 4. 偶通道不是目前优先重开的理论问题

同一Γ12，在ω=.05,.10,.15,1,4核对：
- 直接计算的偶列，与实际左右入射列之和除sqrt(2)，最大差不超过3.4e-16；
- 奇列严格为0。

这是当前实现的点频一致性检查，不是完整谱资格；但它没有支持“BZ一变大，偶通道归一就失效”的判断。优先修已发现的积分过计。
