# 线 Q：连续光场核复核与 Pauli 时间资格（2026-09-23）

本轮由 Codex 接手，只沿已经人审通过的 **P1-dressed 粒子—空穴 + 双端口 canonical Gaussian** 路线做有限数值审核。Hamiltonian、P1、规范、耦合常数、初态、光场端口及算符定义均未改变；没有全 BZ、量子泵浦、退相干或生产输出统计。

## 给本人看的结论

从电子电流到真空两侧光场的 **自场系数及面积抵消**，目前有良好证据。此前 8 倍脉冲长度的周期频率盒子留下的 12.5% 误差，可以由它固有的周期尾项解析解释。改用独立的正频开放求积，同一个规定电流的自场误差降至约 0.008%；直接演化光子振子和解析延迟核彼此一致到 `3.7e-15`。

这只通过了“**规定电流 → 光子自场**”这一层。把相同光子模式与电子粒子—空穴涨落共同演化后，候选 Pauli 占据对光子求积和时间步都极敏感。它目前 **没有数值资格**，不能换算出可信的最小光斑面积，也不能开始生产 (n,m,V(\theta))。

## 1. 为什么有限频率盒子必有这项误差

令 (\tau=t-s>0\)，两侧光子消去后的延迟核是

\[
K(\tau)=\frac{2\gamma}{\pi}\int_0^{\omega_{\max}}
\frac{\sin(\omega\tau)}{\omega}\,d\omega,
\qquad
\gamma=\frac{2\pi\alpha_{\rm fs}}{A_{\rm uc}}.
\]

这里积分从 (0^+\) 开始，没有放入 (\omega=0\) 的光子振子。若再令高频上限足够大，(K(\tau)\to\gamma\)，因而 (\dot\kappa_{\rm self}=\gamma I_{\rm cell}\)，并由初值 (\kappa_{\rm self}(0)=0\) 确定因果积分。

周期盒子把频率换成 (\omega_j=2\pi j/T_{\rm obs}\)，(j\ge1\)。即使令 (j\) 的上限无穷，它在一个周期内部给出的仍是

\[
K_{\rm box}(\tau)=\gamma\left(1-\frac{2\tau}{T_{\rm obs}}\right),
\qquad 0<\tau<T_{\rm obs}.
\]

这是 (\sum_{j\ge1}\sin(jx)/j=(\pi-x)/2\) 的直接结果。它解释了先前误差随 (T_p/T_{\rm obs}\) 缩小；不能把它笼统归为“材料响应没收敛”。对本轮的 (I(t)=\sin^2(\pi t/T_p)\)，在 (t=T_p\) 正好得到 (\kappa_{\rm box}/\kappa_{\rm Maxwell}=1-T_p/T_{\rm obs}\)。因此 (T_{\rm obs}=8T_p\) 的 12.5% 是解析预期。

**对外部回复的一处修正：** 此时导数不自动比矢势更快收敛，因为

\[
\dot\kappa_{\rm box}(t)
=\gamma I(t)-\frac{2\gamma}{T_{\rm obs}}
\int_0^t I(s)\,ds .
\]

这条测试电流在脉冲末段已趋于零，导数残差仍由累积电流决定。代码的导数误差也约为 12.5%。所以“若导数已准、积分常数未准”的诊断建议有价值，但对**当前周期盒子及该测试电流**并未发生。

## 2. 两种独立表示的实测

两端口、同一 (\gamma\)、同一 (\sin^2\) 规定电流、每周期 32 个时间步，比较只在 ([0,T_p]\)。频率上限均为 (8\omega_0\)。开放表示用非均匀 Gauss 求积，所有节点严格 (\omega>0\)；最低频率由求积而非观察窗决定。

| 表示 | 正频节点/端口 | (\max|\kappa-\kappa_{\rm Mx}|/\max|\kappa_{\rm Mx}|\) | 导数相对误差 |
|---|---:|---:|---:|
| 周期盒子，(T_{\rm obs}=8T_p\) | 512 | 12.500% | 12.503% |
| 开放求积 | 96 | 0.00803% | 0.0321% |
| 开放求积 | 192 | 0.00803% | 0.0128% |
| 开放求积 | 384 | 0.00803% | 0.0128% |

开放 192 与 384 节点的 (\kappa\) 相对差为 `1.7e-12`。开放 192 的**显式光子运动方程**与同一正频积分核重建的 (\kappa\) 相对差为 `3.7e-15`。剩余约 0.008% 是当前高频截断/时间离散的量级，而非上述周期尾项。原 1R 中诊断 (N_{\rm cell}=1,4,16,64\) 的每胞核完全不变；本轮没有重新选择实际面积 (S\)。

这一验收仅覆盖给定的平滑规定电流。电子自己产生的涨落可能含更快频率，因此不能据此宣布**联合电子—光子问题**的全部频带合格。

## 3. 为什么暂不能把 continuum Pauli 数字换成面积

先用两个动量点、两偏振、双端口、每周期 32 步，直接将开放求积用于已批准的二次 Hamiltonian。结果中的 (C_P=N_{\rm cell}\varepsilon_{\rm Pauli}\) 及 (C_C=N_{\rm cell}\|\mathcal C-I\|\) 极大，但以下求积本身先没有过上节 Maxwell 核门：

| 开放频率节点 | 规定电流的矢势误差 | 导数误差 |
|---:|---:|---:|
| 8 | 137% | 227% |
| 16 | 29.7% | 94.1% |
| 32 | 1.26% | 9.69% |

因此这些少模计算的 (C_P,C_C\sim10^{70}\) **全部是无资格诊断数**。脚本已将 `Pauli_area_qualified=false` 写入结果，不再输出面积曲线。辛生成元的 Hamiltonian 恒等式仍在浮点精度内；矩阵巨大后绝对对易残差也巨大，按矩阵元素幅度平方缩放后约 (10^{-15}\)。不能由这些大数字宣称理论不保对易。

再用**已通过平滑源核测试**的 96 个正频节点，固定双端口和一个面内偏振，只作较便宜的时间步应力测试。报告的是**脉冲末端**的 (C_P\)，并非全程峰值，也不是两偏振最终系数：

| 每周期时间步 | 末端候选 (C_P\) |
|---:|---:|
| 32 | (6.67\times10^{43}\) |
| 64 | (1.57\times10^8\) |
| 128 | (8.55\times10^8\) |
| 256 | (2.02\times10^{10}\) |

它仍未随时间加密趋于稳定。电子背景电流顶点 (X(t)\) 自身的相邻时间网格相对 (L^2\) 差从 64→128 的 8.73% 降至 128→256 的 1.50%；联合占据对剩余误差明显高度敏感。到 256 步为止，本轮有限阶梯停止。

这**尚不能区分**：时间传播误差、两动量点上的真实线性增益、未充分覆盖电子电流频带的光子高频截断，以及从裸 p-h/光子真空在 (t=0\) 开始耦合的物理影响。不能因为方程保持辛结构，就宣布其准玻色占据小；也不能因为占据巨大，就在未收敛前改 Hamiltonian 或加耗散。

## 4. 下一道有限关口

1. 在原两动量点及原 P1 上，改进**联合电子—光子演化的时间资格**；任何替代积分器必须保辛，并与现有 Hamiltonian 的弱耦合 CJJ/Kubo 验证一致。先比较 (X(t)\) 与 (C_P,C_C\) 的时间网格变化，不再机械延长当前 Cayley 阶梯。
2. 为 photon basis 加入代表电子顶点频谱的规定源测试，而不只用平滑 (\sin^2\) 电流。分开检查红外加密与高频上限，提高频率求积时保持双端口及正确权重。
3. 只有源核、联合时间传播、IR/UV 都达到稳定后，才用两偏振的全程峰值给出 continuum (C_P,C_C\)，再推 (S_{\min}^{1\%,5\%,10\%}\)。之后才轮到 BZ 与输出 (n,m,V(\theta)\)。

第 1–2 项属于现有理论内的数值设计，本人无需选择时间步、求积节点或求解器。若数值资格通过后，准玻色占据仍很大，才需要本人审核：现有线性/Gaussian 物理近似是否适合 P1，以及初始真空/耦合开启方式是否应改变。
