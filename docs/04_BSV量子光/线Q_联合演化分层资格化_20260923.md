## 门禁 2：真实源光子 continuum —— 求积轴关闭，残余定性清楚

脚本 `q8_m0_stage1ae_source_qual.py`、`q8_m0_stage1ae2_channel_scan.py`，产物 `results/q_line/stage1ae_source_qual_20260923/`。用收敛的 X_ref（ntpc=2048）最强通道作规定 c-number 源（不耦回电子）。

**三轴分离结果：**

1. **源频谱截断不是残余来源。** 尾部功率：>64ω₀ 仅 1.5e-3，>128ω₀ 2e-4，>192ω₀ 1.2e-4。
2. **求积密度轴关闭。** 把 Gauss 求积核与精确截断核 \(K_{\rm exact}(\tau)=\gamma\,\frac{2}{\pi}\mathrm{Si}(\omega_{\max}\tau)\) 分别与同一源卷积：64ω₀/1248 节点下场差 **2.3e-6**。求积对截断连续谱的表示是精确的。此前"64ω₀ 下 768→1536 节点仍 22%"不是求积不足。达到谱精度所需节点：32ω₀ 需 192/octave，64ω₀ 需 384/octave（UV 扫描按此配节点）。
3. **残余 = 有限 \(\omega_{\max}\) 截断连续谱与"瞬时自场"目标之间的物理差异**，按 ~\(\Omega_{\rm src}/\omega_{\max}\) 缩放：最强通道（99% 边缘 59 ω₀）64→128→192ω₀ 时 A_rel_max 为 0.36→0.24→0.20；而慢通道（99% 边缘 ~16 ω₀）在 cutoff≥64ω₀ 时 A_rel_max≈**0.007–0.008，直接合格**。
4. **窗口端点阶跃有显著贡献。** 真实 \(X(t)\) 在 \(t=0\) 与 \(t=T\) 都非零；把源乘 sin² taper 后，低通 8ω₀ 源的误差 0.259→0.063（64ω₀）→0.026（128ω₀）。

**结论性解读：** "规定源恢复瞬时核 \(\dot\kappa=\gamma I\)"这一门对最快通道本质上是截断模型的物理极限，不是数值缺陷；逐点 <1% 的瞬时核对标对最快通道不可达。连续谱侧的正当判据应改为：(i) 求积对截断核谱精度（已 1e-6 量级满足）；(ii) 联合可观测量对 \(\omega_{\max}\) 的不敏感性（门禁 3 的 UV 扫描在测）。

## 当前判断

1. 量子主框架（P1-dressed p-h + 两端口 canonical Gaussian）仍未被推翻；辛结构在两方法下到 1e-15。
2. "64/128 步稳定平台"被**两次**否定：先被真中点、后被 CF4 独立参考。此前所有 \(C_P,C_C,N_B\) 大数与所有"稳定"小数一律继续无物理资格。
3. 电子背景（门禁 1）与光子求积（门禁 2 之求积轴）已关闭；时间排序轴在 P1=0 下已关闭（CF4 锁定，Cayley 二阶逼近同一平台）；UV 轴在 8→32ω₀ 内显示平台不敏感。
4. **P1=0 的 dressing 增长第一次获得数值资格**：在截断连续谱二次模型内，裸 product 真空 + \(t=0\) 突然开耦合确实产生单一辛方向上的指数放大（每周期 ×6.4，\(C_P\approx5\times10^5\)）。它不是步长假象、不是 UV 截断、不是求积不足。
5. 异常复核预设的人审触发条件在 P1=0 通道上已满足：**"裸初态 vs dressed Gaussian 真空"可以作为物理决定提交本人**。P1 驱动通道的时间排序已合格（8ω₀、16ω₀），但 UV 未收敛（8→16ω₀ 变化 ×20），在 UV 平台形成之前 P1 的绝对值仍标记 unqualified；不过 P1≫P1=0（×6e5，8ω₀ 各自合格值）的定性结论大概率稳固。在此决定之前，\(S_{\min}\)、光子数、\(n,m,V\)、BZ 继续全部关闭。
