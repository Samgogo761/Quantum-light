## 0. 现在真正站得住的一句话

在可控八带 PT-AFM（M0）中，位移压缩光的统计相干可以调控 Neel-odd 二次谐波的有限时间复电流；其主导角向结构是位移表象中的 \(B+Ae^{i\theta}+Ce^{-i\theta}\)。完整微观来源不能简化为实验室表象的单一 0–2 通道。在实验相关的高亮度纯 BSV 下，同一模型允许非零磁畴奇平均电流，但点反射对称的输入会禁止两畴的统计谐波强度对比。后者是对称性定理，不是 BSV 独有机制，也不是量子优势。

第一阶段（模型内机制 + C1 方法/对称性边界）可以写成连贯叙述。C1 已经是实验映射的第一步：方法通过，无条件强度读出承担不了量子辨识。下一关口不是重做 H2 或 R2，而是另找不依赖抽象强单模 \(g\) 的驱动，检验统计调控是否还在。

## 1. A/B/C：当前最应该保留的正向结果

固定电子动力学和探测窗后，

\[
\mathcal J_2^o=\operatorname{Tr}(\rho_{\mathrm{ph}}\mathsf K_2^o).
\]

位移表象 \(\widetilde\rho=D^\dagger(\alpha)\rho D(\alpha)\) 中，按光子数差分块：

- \(B=F_0\)：\(\Delta n=0\)。压缩角不变；含占据、真空块及更高阶对角过程，不恒等于 \(K_B\alpha^2\)。
- \(A=F_{+1}\)：\(\Delta n=+2\) 相干扇区。
- \(C=F_{-1}\)：\(\Delta n=-2\) 相干扇区。

因此

\[
\mathcal J_2^o(\theta)\simeq B+Ae^{i\theta}+Ce^{-i\theta}.
\]

两项限定必须保留：这里的 \(\Delta n\) 是位移表象中压缩真空的 Fock 数差，不是实验室表象少数 Fock 态；高阶 \(e^{\pm im\theta}\) 没有被证明为零。有效式 \(K_B\alpha^2+K_M M(\theta)\) 是数值验证过的近似，不是算符恒等式。

**两套协议的数字不可混栏。**

| | Q6（24.8 μm，1+4+1） | 1600 nm 协议 A QED（主窗） |
|---|---|---|
| 输入 | \(\alpha=0.5,\ r=0.3,\ R=1.273\) | 同一低占据 DS，\(g=0.005\,\mathrm{\AA}^{-1}\) 未按 \(\omega^{-1/2}\) 缩放 |
| 振幅比 | \(\theta=\pi/\theta=0\) 二维 **4.98** | \(x\) 通道 **8.534** |
| \(\rho=\|A\|/\|B\|\) | 1.456 | 1.267 |
| \(\arg(A/B)\) | 177.65° | 179.391° |
| \(\|C/A\|\) | ≈1.54% | ≈0.32% |
| 邻窗 | 16%–39% | 角向结构较稳，绝对响应随窗变 |

Q6 冻结：\(B=(-3.3006+0.9537i)\times10^{-8}\)，\(A=(+4.7434-1.5839i)\times10^{-8}\)，协方差反转约 110.6°。只称有限时间复响应，不称产额。

分层解释仍然有效：

1. 光子相干块给出角向 Fourier。
2. \(R=O(1)\) 时位移与异常关联竞争；不是 \(R\) 越大越好。
3. Néel 与 SOC 打开并缩放奇通道；绝缘窗口内 SOC 扫描不把 \(\arg(A/B)\) 拉离 \(\pi\)（跨度 4.37°）。这是负结果，不是材料相位指纹。
4. 主窗相位主要由有限时间 Peierls 核和 Ehrenfest 解释，不能写成严格相加等式。
5. 精确 QED 不增强对 \(M\) 的读取；约 15% 余量留在奇通道 \(\Delta n=0\) 核。

Q2：代表性工作点 \(n_{\max}=8\to10\)，\(\theta=0/\pi\) 复振幅相对差 0.13%/0.22%。这是截断筛查，不是全部 A/B/C 的完整收敛证明。

## 2. Q3：为什么不能用 0–2 核替代完整动力学

Q3 重构的 0–2 光子子空间核对相干项很敏感，

\[
\frac{\|K_{02}\|}{\|K_{22}-K_{00}\|}\simeq 94.5,
\]

但不足以解释完整 DS 响应。主窗 \(\theta=0\) 的 \(H2_x\)（\(\times10^{-5}\)）：完整 \(J_{\mathrm{full}}=-1.046\)，0–2 贡献 \(J_{02}=+1.383\)，其余 \(J_{\mathrm{rem}}=-2.428\)，满足 \(J_{\mathrm{full}}=J_{02}+J_{\mathrm{rem}}\)。完整响应呈负实部，是因为被排除的 Fock 块提供了更大的负贡献。\(\theta=\pi\) 时 \(J_{02}\) 仍显著，但不是全部。

这不否定 A/B/C。A/B/C 是位移表象的角向扇区；Q3 否定的是“实验室表象里一个很大的 \(|K_{02}|\) 就能解释振幅比”这一过简微观图像。统计关联通过整个电子–光子联合动力学起作用。

## 3. C1：非零奇平均电流可以与零强度对比共存

C1 是 1600 nm、25 fs、理想单模纯 BSV 的 Wigner-SBE 方法基准，不是量子优势证明。1024 条样本给出 \(\|\langle\mathbf J_2^o\rangle\|=2.163\times10^{-3}\)，bootstrap 区间约 \([2.00,2.35]\times10^{-3}\)。CEP \(=\pi/2\) 相干负控后，BSV/相干 odd-H2 范数比 0.631→0.634，载波相位错配不是主要解释。

代数上，M0 满足

\[
J_{-N}[A](t)=-J_{+N}[-A](t)
\]

（残差 \(10^{-16}\)–\(10^{-14}\)）。叠纯 BSV 的 \(W(A)=W(-A)\)，得到分布意义下 \(J_{-N}\overset{d}{=}-J_{+N}\)。因此 Néel-even 平均电流必须为 0；Néel-odd 平均电流允许非零；两畴的 \(\langle|J_2|^2\rangle\) 与 \(|\langle J_2\rangle|^2\) 对比在精确统计极限都必须为 0。

有限样本曾出现 \(C_{\mathrm{stat},x}=-0.016\)、\(C_{|\langle J\rangle|^2,x}=+0.337\)。前者与零相容；后者在偶分量理论上为零时会放大残余误差，不是相干态输入的磁畴对比，极限必须趋于 0。禁止把 BSV 的 \(C_{|\langle J\rangle|^2}\) 写成 \(C_{\mathrm{coh}}\)。

同一选择定则适用于任何点反射对称的经典随机驱动。正 Wigner 可作为经典随机场密度来模拟，不等于正 \(P\) 的经典光量子态。高亮度下 \(|M|_{\mathrm{BSV}}-n_s\) 相对极小，但压缩正交方差仍可差很多；当前强场 H2 是否分辨它是灵敏度问题，不是普适不可分辨定理。

`c1.json` SHA-256 必须保持 `6A8C3812F80898C946AC59D32EB168DC62FEB8E4DE570F5FF83B28054FD4C925`。

## 4. 哪些只属于抽象模型，哪些可能迁移

| 结论 | 定位 |
|---|---|
| A/B/C 角向结构、Néel/SOC 门控、Q3 的 0–2 不适用边界 | 模型机制，可写 |
| Q2 代表性截断筛查 | 数值资格，可写为检查而非全收敛 |
| \(g=0.005\,\mathrm{\AA}^{-1}\) 反推 \(V_{\mathrm{eff}}\sim(16.7\,\mathrm{nm})^3\)、\(\bar n\sim0.34\) | 抽象单模强耦合，不能称为实验室 1600 nm 飞秒源 |
| C1 的 Wigner-SBE 归一化与选择定则 | 可迁移的方法/对称性约束 |
| C1 的非零 odd H2 | 当前近似下的统计响应，证人不是无条件强度对比 |
| 真实 CrI3 few-k 相干光磁性 H2 | 存在性，定量未过关；M0 不是材料下折叠 |
| 低占据 \(\langle a^2\rangle\) 相对正 \(P\) 的符号分离 | 输入态事实；尚未证明材料 H2 保留该边界 |

均匀线性损耗下 \(R\) 本身可保持；真正敏感的是可观测压缩、模式匹配和信号强度。平均光子数超过 10 只说明当前直接 Fock 截断不再适用，不是必须放弃一切量子描述。

## 5. 后续只保留一个关口，且现在不算

可证伪的多谐波预测（待验证，不是本轮任务）：同一位移表象分解

\[
\mathcal J_q(\theta)=\sum_m c_{q,m}e^{im\theta},\qquad q=2,\ldots,8
\]

是否让不同谐波阶次对 \(\Delta n=0\) 与 \(\Delta n=\pm2\) 扇区有不同权重。这不是 \(\mathcal J_q\propto\langle a^q\rangle\)，也不需要新的高阶光子选择定则。原始完整时间轨迹没有保存：C1 只有逐样本 H2，协议 A 的 `ckpt_*.npz` 是 `psi`，`samples.json` 不是生产全轨迹。因此 H3–H8 不是免费 Fourier 后处理。

驱动可行性判断（候选，不是开算单）：更有希望的实验相关形式是

\[
A(t)=A_{\mathrm{pump}}(t)+\delta A_{\mathrm{quantum}}(t).
\]

强相干泵浦建立非微扰电子动力学，量子辅助场提供可调统计。这可能同时满足强场 HHG 与不必让量子光承担全部能量。它会改写 A/B/C 系数，低占据数字不能移植。C2 锁相位移可以解除 \(C_{\mathrm{stat}}=0\) 的强制要求，但相干光本身已有大对比，解除对称性不等于量子效应。

成功标准只有一句：在不依赖 \(g=0.005\,\mathrm{\AA}^{-1}\) 单模强耦合的驱动下，统计扇区对磁性复响应的调控是否仍然存在、并且能被相位/偏振/归一化比值读出。失败也应接受：平均电流和无条件强度可能天然不适合认证量子优势，那时再改观测量，而不是加样本。
