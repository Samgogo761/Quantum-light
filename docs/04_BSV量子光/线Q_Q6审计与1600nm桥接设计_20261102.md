## 2. A/B/C 数学结构与高阶相干块

固定电子 Hamiltonian、开关和探测窗后，

\[
\mathcal J_2^o=\operatorname{Tr}(\rho_{\mathrm{ph}}\mathsf K_2^o)
\]

是精确的线性读出。进入位移后 Fock 基底

\[
\widetilde\rho_\theta=D^\dagger(\alpha)\rho_\theta D(\alpha),\qquad
\widetilde K=D^\dagger(\alpha)K D(\alpha),
\]

压缩真空只含偶数光子数，密度矩阵元带 \(e^{i(p-q)\theta}\)。于是：

| 光子数差 | 密度矩阵扇区 | \(\theta\) 依赖 | 响应系数 |
|---|---|---|---|
| \(\Delta n=0\) | \(\|n\rangle\langle n\|\) | 无 | \(B\)（整块，**\(\neq K_B\alpha^2\)**） |
| \(\Delta n=+2\) | \(\|n+2\rangle\langle n\|\) | \(e^{i\theta}\) | \(A\) |
| \(\Delta n=-2\) | \(\|n\rangle\langle n+2\|\) | \(e^{-i\theta}\) | \(C\) |
| \(\Delta n=\pm 4,\pm 6,\ldots\) | 更高偶差 | \(e^{\pm iq\theta}\), \(q\ge 2\) | \(D_q,E_q\) |

完整角向展开是

\[
\mathcal J_2^o(\theta)=B+Ae^{i\theta}+Ce^{-i\theta}
+\sum_{q\ge 2}\bigl(D_q e^{iq\theta}+E_q e^{-iq\theta}\bigr).
\]

三项式是**主分量描述**，不是恒等截断。Q6 上已经做过的独立检验：

1. nmax=8 初态省略质量 \(4.06\times 10^{-6}\)，有效 \(R_M/|\langle a\rangle|^2=1.2730\)，与理想 1.2733 几乎相同。\(\rho=1.456\) **不是截断把 \(R\) 抬高**。
2. 位移后 \(a^2\) 核 \(\|N_{\ell=2}/N_{\ell=1}\|=0.0009\)。实验室 Fock 基底里 \(\|\rho_{n,n+4}\|\) 看起来不小，那是位移把偶数压缩真空混进各 \(n\)；物理扇区必须在位移后基底看。
3. \(\pi/4\) 留出 0.425% 是真正的高次扇区检验。四点残差 0.492% 不能拿来做五参数拟合证据。

因此：**Q6 工作点上，省略 \(\Delta n=\pm 4\) 是数值上站得住的。** 1600 nm 第一轮必须**重做**同一检验。近隙或多光子通道可能放大高阶块，不得把 0.0009 抄过去。

\(\Delta n\) **不是**谐波阶数，也不是传播中光子数增减。它是密度矩阵两个 Fock 指标之差。A、B、C 也**不是** H1/H2/H3，而是同一个 H2 响应对不同相干扇区的投影。

代码侧：系数由四角 \(\theta=0,\pi/2,\pi,3\pi/2\) 的奇电流 Fourier 线性解出；留出角 \(\pi/4\) 独立验证。严格 \(B\) 与有效 \(K_B\alpha^2\) 必须分列。完整 \(9\times 9\) \(K\) 矩阵未反演。

## 3. \(g\) 及模式归一化审计（转换失败）

代码定义（`PHYSICS_CONTRACT.md` + `g_normalization_note()`）：

\[
H(t)=H_{\mathrm{diag}}+\sum F_g\otimes P\exp\bigl(i q_g s(t) X\bigr)P,
\qquad
q_g=g\,(\mathbf e\cdot\delta_{\mathrm{bond}}),\qquad
X=a+a^\dagger.
\]

- 真空约定：\(\mathrm{Var}_{\mathrm{vac}}(X)=1\)。
- \(g=0.005\,\mathrm{\AA}^{-1}\)。
- 单位注释原文：**“Angstrom^-1 abstract, not experimental \(V_{\mathrm{eff}}\)”**。
- `not_macroscopic_BSV_intensity: True`。
- 固定 \(g\) 再加 \(k\) **不是**单一腔模的热力学极限。
- 线性力：\(F_{\mathrm{shared}}=\sum_\alpha -g\,\mathbf e\cdot\langle J_\alpha\rangle\)（乘积态上）。
- \(s(t)\) 是**外加耦合协议**，不是传播脉冲包络。
- Peierls 必须保持 \(P\exp(i\eta X)P\)，禁止换成 \(\exp(i\eta PXP)\)。
- `dh8` 丢掉 `neel`；奇性在 \(\rho_N\)，不在 \(j_a(N)\)。

**结论：当前 \(g\) 不能换成实际电场或 \(\mathrm{W/cm^2}\)。** 缺独立的有效模式体积 \(V_{\mathrm{eff}}\)（以及把 \(X\) 连到 SI 矢势的因子）。缺这些参数时：

- 不得写「弱场」或「强场」，只能写**低占据抽象耦合**；
- 不得假设 \(g\propto\omega^{-1/2}\) 并授权 \(g\approx 0.00127\,\mathrm{\AA}^{-1}\)；
- 同一 \(\alpha,r,R\) 在不同波长**不代表**相同电场、能量密度或强度。

若有人在草稿纸上用固定 \(V_{\mathrm{eff}}\) 的腔模公式得到 \(g_{1600}/g_{24.8}\approx 1/\sqrt{15.5}\approx 0.254\)，只允许作为**未授权的外加假设**记一笔，**本轮计算不得采用**。第一轮 1600 nm 精确 QED 继续用抽象 \(g=0.005\,\mathrm{\AA}^{-1}\)，并在方法里写明：这是频率隔离，不是实验标定。

## 4. 24.8 μm 与 1600 nm 参数对照

| 物理量 | Q6 24.8 μm | 候选 1600 nm |
|---|---|---|
| 真空波长 | 24.8 μm | 1600 nm |
| \(\hbar\omega\) | 0.05 eV | 0.775 eV |
| 光学周期 | 82.7 fs | 5.34 fs |
| \(2\hbar\omega\) | 0.10 eV | 1.55 eV |
| \(3\hbar\omega\) | 0.15 eV | 2.325 eV |
| 相对局部隙 \(E_g(k)\simeq 1.91\,\mathrm{eV}\) | 深度失谐，\(2\hbar\omega\ll E_g\) | \(2\hbar\omega\) 接近隙，\(3\hbar\omega>E_g\) |
| 1+4+1 的物理时长 | \(\approx 496\,\mathrm{fs}\) | \(\approx 32\,\mathrm{fs}\)（仍**不是** 25 fs 高斯脉冲） |
| 静态 M0 Hamiltonian | 生产点 | 第一轮**保持不变**（隔离频率） |
| \(g\) | 0.005 Å⁻¹ 抽象 | 第一轮同样抽象；不擅自缩放 |
| \(\alpha,r,R\) | 0.5, 0.3, 1.273 | 协议 A 保持；协议 B 必须重标 |
| 早期 P1 全 BZ 最小直接隙 | \(\approx 0.09255\,\mathrm{eV}\) | 不能再拿来给 Q6 的 1.91 eV 局部隙找「两光子跨隙」理由 |

24.8 μm 的历史来源是早期 P1 **亚带隙协议**，不是精确 QED 的理论要求，也不是实验室 BSV 光源。Q6 后来改到单个 \(k/-k\) 后，原先 0.05 eV 的两光子跨隙动机**不能**套到 1.91 eV 局部动力学上。保留它的正当理由只剩一条：可计算、可控制、深度失谐的精确 QED **机制测试点**。

1600 nm 不是把原计算加快 15.5 倍。三光子能量超过局部隙 \(\neq\) 三光子跃迁一定发生，还要看矩阵元、对称性和动力学。但电子响应核 \(K_A,K_B,K_C\) **允许**完全改写。这正是桥接计算要检验的。

第一轮建议：**保留静态八带 Hamiltonian，只改光场协议。** 这是方法，不是终点。目的始终是日后能推广到真实材料；材料参数（SOC、交换、层间、跃迁矩阵元、BZ）必须在机制对照之后，按 Wannier/能带重新标定，而不是把 M0 假装成 CrI₃。

必须改或重验的光场侧参数：\(\omega\)、\(dt\)、包络、Fock 截断（看**演化中**高 \(n\) 占据，不只看初态 \(\langle n\rangle=0.343\)）、动量采样敏感性。\(\alpha,r\) 仅在协议 A（相同统计）下可先保持。

## 5. 两种实验比较协议，外加独立的纯 BSV

三组**不得**合成一次参数扫描。

### 协议 A — 相同量子统计（下一轮唯一允许的最小计算）

| 参数 | 设置 |
|---|---|
| 波长 | 24.8 μm **对照已有** / 1600 nm **新算** |
| 输入 | \(D(0.5)S(0.3e^{i\theta})|0\rangle\) |
| \(R\) | 1.273 不变 |
| 静态 \(H_e\) | M0，同一 \(k/-k\) |
| \(g\) | 0.005 Å⁻¹，**标明抽象** |
| 方法 | 精确 QED + GH5 |
| 时间 | 可先保留 1+4+1 周期开关，但必须写明 1600 nm 下只有 \(\approx 32\,\mathrm{fs}\) |

要回答的问题：压缩角是否仍改 Néel-odd H2；A/B/C 是否仍成立；高阶 \(\Delta n\) 是否仍小；QED/GH5 差是否仍主要在 \(K_B\)。

**不要**把 4.98 和 110.6° 抄到 1600 nm。

### 协议 B — 相同实验物理条件（先设计，本轮不算）

参考 Rasputnyi et al., Nat. Phys. **20**, 1960 (2024)：1600 nm、约 25 fs BSV。但那是**纯 BSV**，平均光子约 \(2\times 10^{12}\)/pulse，与 Q6 每模 0.343 **不可直接比**。

协议 B 需要：真实时间包络与光谱带宽；单时空模式归一化；\(V_{\mathrm{eff}}\) 或等价场强；重标 \(\alpha,r,g\) 并观察 \(R\) 如何变；高光子数下 GH5/MTEF 的适用性。

**缺 \(V_{\mathrm{eff}}\) 时协议 B 不能数值开工。** 相同 \(\alpha,r\) \(\neq\) 相同入射能量：1600 nm 每光子能量约为 24.8 μm 的 15.5 倍。

### 协议 C — 纯 BSV（独立问题，\(\alpha=0\)）

\[
\langle a\rangle=0\qquad\Rightarrow\qquad R=\|M\|/\alpha^2\text{ 无定义。}
\]

原来依赖 \(\alpha^2\) 与 \(M\) 干涉的机制不再适用。应转向涨落、\(C_{JJ}(t,t')\)、输出 \(g^{(2)}\) 和跨谐波关联。这可能是另一篇论文，**不要**为了贴近实验 BSV 而和协议 A 混写。

三种光态也要分开：1600 nm 位移压缩态；1600 nm 纯 BSV；1600 nm 高亮度位移压缩态。Li et al., PRA **112**, 033507 (2025) 与方案一对象最近；Rasputnyi 2024 与方案二对象最近。

### 7.2 更深层次的量子力学 / 量子光学用到了哪里？

这个感觉是对的。我们已经把量子光送进电子动力学，也做了精确 QED，但主故事仍是

\[
\langle\hat J(t)\rangle
\]

而不是完整的量子光–物质理论。

**实际用到的四层：**

1. **电子能带量子力学与对称性。** \(H_e(\mathbf k)\)、PT、Néel、SOC、Peierls。仍是单粒子八带，没有库仑、激子、Keldysh。
2. **连续变量量子光学。** \([a,a^\dagger]=1\)，\(D(\alpha)\)、\(S(re^{i\theta})\)，\(\langle a\rangle=\alpha\)，\(M=\langle\delta a\delta a\rangle\)，\(\langle n\rangle=|\alpha|^2+\sinh^2 r\)。目前主要用到一阶/二阶矩和 Fock 展开，不是完整相空间层析。
3. **联合 Hilbert 空间的精确 QED。** \(H_{\mathrm{tot}}=H_e(\hat A)+H_{\mathrm{ph}}\)，电子与光子一般不可写成直积。联合传播 \(\neq\) 已经发现纠缠新物理。GH5 是 5×5 Gauss–Hermite Wigner 求积，**不得**未经比较写成 Cohen 组 MTEF。
4. **光子统计读出。** \(J=\mathrm{Tr}(\rho_{\mathrm{ph}}K)\) 与 A/B/C。这是目前最有特色的一层，但仍是平均电流的分解。

**没有作为主观测量的：** von Neumann 熵 / 电子–光子纠缠；输出 \(g^{(2)}\) 与跨谐波关联；输出态的 P 表象经典性（输入侧非负 \(P\) 界 \(\neq\) 输出非经典）；库仑/激子/非平衡格林函数。

所以会觉得「不够量子」：量子出现在**输入态和联合演化**，读出却停在经典可对照的电流期望。这不是计算错误，是问题边界。博士阶段可以逐步加层，但**下一计算仍应是 1600 nm 协议 A**，不要把尚未证明的纠缠项目插到频率桥接前面。联合态若还在，纠缠后处理可以在协议 A 之后做；现在不做。

## 附录 A. 直接回答三个原问题

**Q1. 改成 1600 nm，模型参数要变吗？**
要。第一轮只改光场协议、保留静态 M0，是为了隔离频率；这不是代表 1600 nm CrI₃。必须重验 \(dt\)、包络、Fock、\(\Delta n=\pm 4\)。\(g\) 缺 \(V_{\mathrm{eff}}\) 则保持抽象并写明。\(\alpha,r\) 仅在统计等价比较中可暂不变；实验场强比较必须重标。目的始终是推广到真实模型，材料参数以后按能带重标定。

**Q2. 光子数相干块、A/B/C、\(\Delta n\) 是什么？**

**Q3. 24.8 μm 值得写成文章吗？**
