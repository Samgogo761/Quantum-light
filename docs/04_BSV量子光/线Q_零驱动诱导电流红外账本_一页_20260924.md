# 线 Q：零驱动诱导电流红外账本——一页交接（2026-09-24）

**本轮只回答一件事：关掉激光后，规定的软真空输入经过绝缘电子响应，会不会诱导出红外发散的额外电流。没有恢复联合传播，也没有改初态。**

做法是把已经审核过的电子核接到一个冻结的输入形状 \(S_\kappa(\omega)=I_2/\omega\) 上，并**并列两条账**：

- 原始核 \(K_N(\omega)\)，含有限网格静态余量 \(M_N\)；
- 增量核 \(\Delta K(\omega)=K_N(\omega)-K_N(0)\)，只看动态部分。

结果：

1. 增量谱 \(\operatorname{Tr}S_{I,\mathrm{ind}}^\Delta\sim\omega^3\)。四套网格在 \(\omega\le0.003\omega_0\) 的拟合阶都是 **3.000000**。\(128^2\to192^2\) 的二次系数差约 **0.042%**，\(192^2\) 普通与半步移位差约 **0.0014%**。
2. 把积分下限从 \(10^{-6}\omega_0\) 抬到 \(3\times10^{-3}\omega_0\)，增量积分 \(W_I^\Delta\) 只变 **0.0105%**。红外截止可以往零推，不会把这个积分撑大。
3. 原始谱在粗网格上确实像 \(M_N^2/\omega\)。\(96^2\) 的 \(W_I^{\mathrm{raw}}\) 随下限下降增大约 4.3 倍；加密到 \(192^2\) 后，这条假红外敏感基本退到与增量积分同一量级。**不能把粗网格的 \(1/\omega\) 当成物理发散，也不能把 \(M_N\) 删掉再宣布已经安全。**

源电场只是同一电流的线性映射 \(E_{\mathrm{src}}=-\gamma I_{\mathrm{cell}}\)，幂次与电流相同。完整出射场、收集波包、电子内禀噪声、交叉项、极点、Pauli 和初态均未启动。

这一步支持的是：**在连续 BZ 的动态部分，规定软输入不会通过线性电子响应制造红外发散的诱导电流。** 它尚未证明联合光场稳定，也尚未给出光子数。
