旧的面板加倍、4096 步列和宏步 512 的原始求积矩阵都保留。这一轮没有改 Hamiltonian、初态或光学环境，没有人为正则化 \(U,V\)，也没有启动约十三万列的正向重算。

\]

反常 \((0,1)\) 是 \(-0.002243+0.000377i\)。

每个独立矩阵元的实部、虚部分别取绝对值再相加：

| 矩阵元 | 有符号总和 | 绝对值累计 |

整张 Gram 分块重加和一次矩阵乘的差是 \(8.5\times10^{-11}\)。保存的 \(U_0U_0^\dagger-I\) 最大模是 \(2.05\times10^{-12}\)。暗列的 \(U_0\) 是 0。

## 2. 十六列上的收敛阶

同一批 16 个输入列、同一套 \(12\times12\) 电子网格、九个周期。中点 1024 不是真值。比较的是这 16 列的部分 Gram，不是完整输出的 CCR。

中点法正常矩阵 \((0,0)\) 从 256 到 2048 是 \(0.49427\)、\(0.75265\)、\(0.86425\)、\(0.89680\)。相邻两档之差的比值是 \(2.32\)，然后 \(3.43\)，向二阶应有的 \(4\) 靠近。反常矩阵的对应比值是 \(1.62\)，然后 \(3.16\)。

四阶宏步 256、512、1024 的正常矩阵 \((0,0)\) 是 \(0.91809\)、\(0.90883\)、\(0.90817\)。相邻差值之比是 \(14.07\)。反常矩阵是 \(14.79\)。四阶减半步长的期望比值是 \(16\)。

用 512/1024/2048 三个中点做 \(h^2+h^4\) 插值，正常矩阵 \((0,0)\) 的极限是 \(0.908066\)。四阶宏步 512/1024 按 \(h^4\) 外推是 \(0.908122\)。两者差 \(5.7\times10^{-5}\)。反常 \((0,1)\) 的两个极限差 \(8.2\times10^{-6}\)。

宏步 1024 和中点 2048 的正常矩阵 \((0,0)\) 还差 \(0.0114\)。这是中点 2048 自己还没走完的 \(h^2\)：1024 到 2048 的变化是 \(0.03255\)，除以 3 就是 \(0.01085\)。

## 3. 四阶输出转置

现有中点转置行不能拼成四阶结果。一个宏步先从同一个入射态走一档粗步和两档细步，再把末态按 \((4F-C)/3\) 混合，下一步从这个混合态出发。均匀网格上的中点伴随行对应的是另一条轨迹。

四阶宏步的离散伴随是三次现有的中点回传，态和探测器的权重都是 \(+4/3\) 与 \(-1/3\)。在 16 列、九个周期、宏步 64 上，伴随和独立正向传播的 \(U,V\) 差是 \(5.43\times10^{-13}\)。

整段输出只要建一次伴随行，再对输入列做收缩。原始 32904 个频率加 1976 个暗列，宏步 512 的收缩是几分钟。宏步 1024 连同重新生成的细网格，大约十四分钟。这不是十三万列的正向重算。

原始求积上，四阶正常矩阵 \((0,0)\) 是：宏步 512 为 \(0.005587\)，宏步 1024 为 \(0.005836\)。按 \(h^4\) 外推是 \(0.005853\)。同一求积的中点 1024/2048/4096 三点插值是 \(0.005852\)。非对角和反常矩阵在这条未修正的求积上仍是 \(0.002\) 量级。

## 4. 修正求积上的时间极限

把已加密的面板换进上面这套四阶行。列是可加的：旧列的 Gram 减去，新列的 Gram 加上，\(U_0\) 和权重一起换。中点法的面板差值没有拿来加到四阶矩阵上。

和先前 \(-2.66\times10^{-4}\) 同一套求积（34 条尾加倍、主 H2 翼 64 个节点、窄核心 1280 个节点）：

| | \(R_N(0,0)\) |
|---|---:|
| 四阶宏步 512 | \(-5.272\times10^{-4}\) |
| 四阶宏步 1024 | \(-2.818\times10^{-4}\) |
| 四阶 \(h^4\) 外推 | \(-2.654\times10^{-4}\) |
| 先前中点两点外推 | \(-2.53\times10^{-4}\) |
| 先前中点三点插值 | \(-2.66\times10^{-4}\) |

宏步 512 自己还差约 \(2.5\times10^{-4}\)，不能拿它当极限。外推之后，它和中点三点插值落在同一个 \(-2.65\times10^{-4}\)。这一档外推离宏步 1024 还有 \(1.6\times10^{-5}\)，那是按纯 \(h^4\) 估计的下一档距离。没有第三个四阶档来约束 \(h^6\)。

这套求积没有包括相邻 H2 翼 \([0.264349,\,0.275755]\)。它的 16→128 在两个宏步上的 \(R_N(0,0)\) 变化都是 \(+8.74\times10^{-5}\)，两档只差 \(5\times10^{-8}\)。九个重点面板都收到最终节点之后：

| | 宏步 1024 | \(h^4\) 外推 |
|---|---:|---:|
| \(R_N(0,0)\) | \(-1.945\times10^{-4}\) | \(-1.781\times10^{-4}\) |
| \(R_N(0,1)\) | \(5.4\times10^{-6}-2.17\times10^{-5}i\) | \(5.2\times10^{-6}-2.11\times10^{-5}i\) |
| \(R_N(1,1)\) | \(1.89\times10^{-5}\) | \(1.58\times10^{-5}\) |
| \(R_A\) 最大模 | \(1.62\times10^{-5}\) | \(1.58\times10^{-5}\) |

先前那份记录里反常矩阵约 \(1.5\times10^{-4}\) 的外推，数量上就是这条相邻翼还停在 16 个节点时的贡献。翼加密之后，反常矩阵降到 \(1.6\times10^{-5}\)。\(R_N(0,0)\) 仍停在 \(-1.78\times10^{-4}\)。

主翼 64→128 在四阶行上是 \(1.0\times10^{-9}\)。两条大尾再加倍合计是 \(3.9\times10^{-8}\)。窄核心和主翼的符号与中点记录一致：核心约 \(+0.00686\)，主翼约 \(-0.00648\)。

## 5. 这个非零值现在说明什么

物理问题：时间和九个大面板都收到上面这一步之后，\(R_N(0,0)\) 的外推仍是 \(-1.78\times10^{-4}\)。它是生产列的组装问题，还是这套有限带宽输入在精确时间下本来就离开 \(I\)？

证据：四阶与中点在同一求积上给出同一个 \(-2.65\times10^{-4}\)；相邻翼把这个数稳定地移动 \(+8.74\times10^{-5}\)；\(U_0\) 缺陷是 \(2\times10^{-12}\)；Gram 舍入是 \(8.5\times10^{-11}\)；334 个小面板的绝对值累计是 \(3.44\times10^{-7}\)。两点模型在收完求积和时间之后，正常矩阵可以到 \(2.7\times10^{-7}\)。

备选解释有三个。第一，四阶展开里还有 \(h^6\)。现有两档按 \(h^4\) 估计的剩余是 \(1.6\times10^{-5}\)，到不了 \(1.8\times10^{-4}\)。第二，334 个小面板的第一次加倍低估了剩余求积误差。它们的实测绝对值累计只有 \(3.4\times10^{-7}\)，要解释 \(1.8\times10^{-4}\) 就得是这个低估非常严重。第三，Γ12 这套输入列在精确时间下的 \(R_N(0,0)\) 确实停在 \(10^{-4}\)。两点模型能收到 \(10^{-7}\)，所以这不像一个两点上也会以同样大小出现的共同公式错误。

这一步还不改生产列的组装。G1 未通过，不进入 G2/G3。
