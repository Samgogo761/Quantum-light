## 1. 响应对不对？

同一初态、同一 P1，测试场 \(h(0)=h(T_p)=0\) 的 \(\sin^2\) 波形，沿 \(\mathbf a_2\) 与横向各扫四个 \(\varepsilon\)。比较

\[
\frac{\mu(A_{\mathrm{cl}}+\varepsilon h)-\mu(A_{\mathrm{cl}}-\varepsilon h)}{2}
\quad\text{vs}\quad
\mathcal R^A[\varepsilon h]
=\text{前缀对易子}+\big(-\langle D\rangle\varepsilon h\big).
\]

六点、400 步/周期、本机约 22 s（含全部 \(\pm\varepsilon\)）。

接触项不是装饰：最小 \(\varepsilon\) 下，只用状态项会留下约 2% 系统偏差；加上 \(-\langle D\rangle\delta\) 后掉到 \(10^{-3}\) 量级。\(\varepsilon=10^{-3}\,\mathrm{Å}^{-1}\)（约泵浦峰值矢势的 0.5%）已明显离开线性区，相对差 14–20%。线性响应工作窗口取 \(\varepsilon\lesssim 10^{-4}\)。

这是相对真实电子传播的检验，不是 \(C\) 的自对易恒等式。

尚未做：\(\pm N\) 两畴的响应对照；全 BZ；\(A_{\mathrm{cl}}\pm\varepsilon h\) 的输出模投影（本轮比的是电流）。

## 2. 输出二阶矩是否自洽？

参考模核

\[
K_a(t)=\hat e_{\perp,a}\int_0^\infty\mathrm{d}\omega\,\frac{\phi(\omega)}{\sqrt{\omega}}e^{+i\omega t},
\]

SI 前因子 \(i\sqrt{Z_0/(4\pi\hbar S)}\) **unset**。投影的是每原胞电流、有限 \([0,T_p]\)。

| 量 | 六点、+N、核单位 |
|---|---|
| \(\beta_{\mathrm{shape}}\) | \(\lvert\beta\rvert\approx 7.70\) |
| \(n_{\mathrm{source}}=\langle\delta s^\dagger\delta s\rangle_{\mathrm{cell}}\) | \(3648\) |
| \(m_{\mathrm{source}}=\langle\delta s\,\delta s\rangle_{\mathrm{cell}}\) | \(\lvert m\rvert\approx 3134\) |
| 源项 \(n-\lvert m\rvert\) | \(\approx 514>0\)（核单位，**不是**与 \(1/2\) 比） |

分项：

- 输入真空的 \(\langle b_{\mathrm{in}}^\dagger b_{\mathrm{in}}\rangle=0\)（正常占据）。
- 电子 \(C\) 的源贡献：已投影到 \(K\)。
- 接触项：进入 \(\mathcal R^A\)，从而进入后面的 \(\alpha_\pm\) 预测。
- 响应 \(\alpha_\pm\)：用 \(K_{\mathrm{shape}}\) 充当 \(A_{\mathrm{in}}\) 波形做了实线性延拓。\(\lvert\alpha\rvert\sim 10^3\) 是 **单位混用**，不能当成玻色增益，**没有**加进 \(V(\theta)\)。

因此：源项 \(n,m\) 在核单位下闭合；与真空 \(1/2\) 可比较的完整 \(V_\mu(\theta)\) **尚未闭合**。画 \(V_{H2_\perp}(\theta)\) 相对真空、谈压缩，还差 \(S\) 与 \(K\)/\(A_{\mathrm{in}}\) 的同一套 SI 因子。

`squeezing_claim = not_evaluated`。

- 响应公式（六点、小 \(\varepsilon\)、无载波 \(\sin^2\) 输入方向）：电流层整体相对差 \(0.09\%\)（∥）、\(0.20\%\)（⊥）。
