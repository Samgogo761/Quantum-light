## 8. Gaussian 输出态的完整二阶理论

### 8.1 基本矩与平均光子数

对第 \(n\) 个有限带宽谐波模式，定义：

- \(\hat b_n\)：模式湮灭算符；
- \(\beta_n=\langle\hat b_n\rangle\)：平均复振幅；
- \(\Delta\hat b_n=\hat b_n-\beta_n\)：中心化算符；
- \(N_{nm}=\langle\Delta\hat b_n^\dagger\Delta\hat b_m\rangle\)：正常协方差；
- \(M_{nm}=\langle\Delta\hat b_n\Delta\hat b_m\rangle\)：异常协方差。

平均光子数为

\[
\boxed{
\bar n_n
=
\langle\hat b_n^\dagger\hat b_n\rangle
=
|\beta_n|^2+N_{nn}.
}
\tag{8.1}
\]

式 (8.1) 将输出能量分为：

- \(|\beta_n|^2\)：相干平均场部分；
- \(N_{nn}\)：去掉位移后的噪声或量子涨落部分。

若只由经典 SBE 计算 \(J_n\)，通常只近似得到 \(\beta_n\)，不能自动得到 \(N_{nn}\)。

### 8.2 正交分量与协方差矩阵

定义每个模式的无量纲正交分量

\[
\boxed{
\hat x_n
=
\frac{\hat b_n+\hat b_n^\dagger}{\sqrt2},
\qquad
\hat p_n
=
\frac{\hat b_n-\hat b_n^\dagger}{i\sqrt2}.
}
\tag{8.2}
\]

在该约定下，真空态满足

\[
\boxed{
\operatorname{Var}_{\rm vac}(\hat x_n)
=
\operatorname{Var}_{\rm vac}(\hat p_n)
=
\frac12.
}
\tag{8.3}
\]

构造正交分量向量

\[
\boxed{
\hat{\boldsymbol R}
=
(
\hat x_1,\hat p_1,
\hat x_2,\hat p_2,
\ldots,
\hat x_M,\hat p_M
)^T.
}
\tag{8.4}
\]

定义实对称协方差矩阵

\[
\boxed{
V_{\mu\nu}
=
\frac12
\left\langle
\{
\Delta\hat R_\mu,
\Delta\hat R_\nu
\}
\right\rangle .
}
\tag{8.5}
\]

其中 \(\{A,B\}=AB+BA\) 是反对易子。

由 \(N\) 与 \(M\) 得到各块：

\[
\boxed{
V_{x_i x_j}
=
\frac{\delta_{ij}}2
+
\operatorname{Re}
\left(
N_{ij}+M_{ij}
\right),
}
\tag{8.6}
\]

\[
\boxed{
V_{p_i p_j}
=
\frac{\delta_{ij}}2
+
\operatorname{Re}
\left(
N_{ij}-M_{ij}
\right),
}
\tag{8.7}
\]

\[
\boxed{
V_{x_i p_j}
=
\operatorname{Im}
\left(
N_{ij}+M_{ij}
\right),
}
\tag{8.8}
\]

\[
\boxed{
V_{p_i x_j}
=
\operatorname{Im}
\left(
M_{ij}-N_{ij}
\right).
}
\tag{8.9}
\]

式 (8.8) 与式 (8.9) 共同保证 \(V_{p_i x_j}=V_{x_j p_i}\)。

### 8.3 物理性条件

定义 \(M\) 模的辛形式

\[
\boxed{
\Omega
=
\bigoplus_{n=1}^{M}
\begin{pmatrix}
0&1\\
-1&0
\end{pmatrix}.
}
\tag{8.10}
\]

任意物理量子态的协方差必须满足 Robertson–Schrödinger 不确定性关系

\[
\boxed{
V+\frac{i}{2}\Omega
\succeq
0.
}
\tag{8.11}
\]

符号 \(\succeq0\) 表示 Hermitian 矩阵半正定。式 (8.11) 是代码的硬门槛：若不满足，不能通过裁剪负本征值“修好”，而应检查模式归一化、真空项、算符排序和输入—输出交叉项。

令 \(\nu_j\) 为 \(V\) 的辛本征值，则物理性等价于

\[
\boxed{
\nu_j\ge\frac12
\qquad
\text{对所有 }j.
}
\tag{8.12}
\]

要注意：普通物理协方差的 \(\nu_j<1/2\) 表示**非物理**，不是“发生压缩”。

### 8.4 单模正交分量压缩

定义相位角为 \(\theta\) 的正交分量

\[
\boxed{
\hat X_{n,\theta}
=
\frac{
\hat b_ne^{-i\theta}
+
\hat b_n^\dagger e^{i\theta}
}{\sqrt2}.
}
\tag{8.13}
\]

其方差为

\[
\boxed{
V_{n,\theta}
=
\frac12
+
N_{nn}
+
\operatorname{Re}
\left[
e^{-2i\theta}M_{nn}
\right].
}
\tag{8.14}
\]

对 \(\theta\) 最小化得到

\[
\boxed{
V_{n,\min}
=
\frac12+N_{nn}-|M_{nn}|.
}
\tag{8.15}
\]

因此，在当前真空归一化下，

\[
\boxed{
V_{n,\min}<\frac12
\quad\Longleftrightarrow\quad
|M_{nn}|>N_{nn}.
}
\tag{8.16}
\]

式 (8.16) 才是单模真空以下压缩判据。仅有 \(M_{nn}\neq0\) 不足以证明非经典性。

### 8.5 精确的二阶相干函数

定义 normally ordered 四阶矩

\[
\boxed{
G_{nm}^{(2)}
=
\left\langle
\hat b_n^\dagger
\hat b_m^\dagger
\hat b_m
\hat b_n
\right\rangle .
}
\tag{8.17}
\]

归一化二阶相干函数为

\[
\boxed{
g_{nm}^{(2)}
=
\frac{
G_{nm}^{(2)}
}{
\bar n_n\bar n_m
},
\qquad
\bar n_n\bar n_m>0.
}
\tag{8.18}
\]

对 \(n=m\)，

\[
\boxed{
g_{nn}^{(2)}
=
\frac{
\langle
\hat b_n^{\dagger2}
\hat b_n^2
\rangle
}{
\bar n_n^2
}.
}
\tag{8.19}
\]

这些定义本身不假设 Gaussian。

### 8.6 Gaussian/Wick 重构的 \(g^{(2)}\)

若输出态经过检验可近似为 Gaussian，所有四阶矩可由一、二阶矩 Wick 分解。

对单模 \(n\)，

\[
\boxed{
\begin{aligned}
G_{nn,{\rm G}}^{(2)}
={}&
|\beta_n|^4
+
4|\beta_n|^2N_{nn}
+
2\operatorname{Re}
\left(
\beta_n^{*2}M_{nn}
\right)
\\
&+
2N_{nn}^2
+
|M_{nn}|^2 .
\end{aligned}
}
\tag{8.20}
\]

对两个不同模式 \(n\neq m\)，

\[
\boxed{
\begin{aligned}
G_{nm,{\rm G}}^{(2)}
={}&
|\beta_n|^2|\beta_m|^2
+
|\beta_n|^2N_{mm}
+
|\beta_m|^2N_{nn}
\\
&+
2\operatorname{Re}
\left[
\beta_m^*\beta_nN_{nm}
+
\beta_n^*\beta_m^*M_{nm}
\right]
\\
&+
N_{nn}N_{mm}
+
|N_{nm}|^2
+
|M_{nm}|^2 .
\end{aligned}
}
\tag{8.21}
\]

式 (8.20)–(8.21) 是**Gaussian approximation**，不是一般恒等式。代码输出必须同时标记：

\[
\texttt{g2\_gaussian}
\neq
\texttt{g2\_exact}.
\]

### 8.7 Mandel \(Q\)

定义光子数算符

\[
\boxed{
\hat n_n
=
\hat b_n^\dagger\hat b_n.
}
\tag{8.22}
\]

Mandel 参数为

\[
\boxed{
Q_n^{\rm Mandel}
=
\frac{
\operatorname{Var}(\hat n_n)
-
\langle\hat n_n\rangle
}{
\langle\hat n_n\rangle
}.
}
\tag{8.23}
\]

利用式 (8.19)，有

\[
\boxed{
Q_n^{\rm Mandel}
=
\bar n_n
\left[
g_{nn}^{(2)}-1
\right].
}
\tag{8.24}
\]

因此：

- \(Q_n=0\)：泊松统计；
- \(Q_n>0\)：超泊松统计；
- \(Q_n<0\)：亚泊松统计，是非经典见证。

\(g^{(2)}>1\) 或甚至 \(g^{(2)}>2\) 只表示聚束或超聚束，不足以单独证明非经典性。

### 8.8 正常序 Cauchy–Schwarz 不等式

对具有正 Glauber–Sudarshan \(P\) 表示的经典场，强度相关满足

\[
\boxed{
\left[
g_{nm}^{(2)}
\right]^2
\le
g_{nn}^{(2)}
g_{mm}^{(2)}.
}
\tag{8.25}
\]

定义违反参数

\[
\boxed{
\mathcal R_{nm}
=
\frac{
\left[g_{nm}^{(2)}\right]^2
}{
g_{nn}^{(2)}g_{mm}^{(2)}
}.
}
\tag{8.26}
\]

若在误差条内有

\[
\boxed{
\mathcal R_{nm}>1,
}
\tag{8.27}
\]

则违反经典正常序 Cauchy–Schwarz 界，是比“\(g^{(2)}>1\)”更强的非经典证据。

### 8.9 两模 Gaussian 纠缠

从完整 \(V\) 中取出模式 \(n,m\) 的 \(4\times4\) 协方差 \(V_{nm}\)。对第二个模式做部分转置，在正交分量空间等价于

\[
\boxed{
\tilde V_{nm}
=
\Lambda
V_{nm}
\Lambda,
\qquad
\Lambda
=
\operatorname{diag}(1,1,1,-1).
}
\tag{8.28}
\]

令 \(\tilde\nu_-\) 为 \(\tilde V_{nm}\) 的最小辛本征值。Simon–Duan 判据为

\[
\boxed{
\tilde\nu_-<\frac12
\quad\Longleftrightarrow\quad
\text{该两模 Gaussian 态纠缠}.
}
\tag{8.29}
\]

对数负性定义为

\[
\boxed{
E_{\mathcal N}
=
\max
\left[
0,
-\log_2(2\tilde\nu_-)
\right].
}
\tag{8.30}
\]

式 (8.29)–(8.30) 只在两模 Gaussian 描述成立时构成完整判据；对非 Gaussian 态，它们是基于二阶矩的见证或下界。

### 8.10 Gaussian 性必须验证

定义四阶连通 cumulant

\[
\boxed{
\kappa_{nm}^{(4)}
=
G_{nm}^{(2)}
-
G_{nm,{\rm G}}^{(2)}.
}
\tag{8.31}
\]

若

\[
\boxed{
\left|
\kappa_{nm}^{(4)}
\right|
\ll
G_{nm}^{(2)},
}
\tag{8.32}
\]

则 Gaussian 重构在该模式对上可能可靠。若式 (8.32) 不成立，必须直接计算四时刻电流关联。

费米电子态是 Gaussian 并不意味着双线性电流算符或输出光自动 Gaussian；因此不能跳过式 (8.31) 的验证。

## 9. 非 Gaussian 的精确四阶理论

### 9.1 为什么精确 \(g^{(2)}\) 需要四时刻关联

忽略输入—电流混合项以展示核心结构，并令

\[
\boxed{
\hat B_n
=
\sum_a
\int dt\,
K_{n,a}(t)\hat J_a(t)
}
\tag{9.1}
\]

为物质源对第 \(n\) 个输出模式的贡献。则

\[
\boxed{
G_{nm}^{(2)}
\supset
\left\langle
\hat B_n^\dagger
\hat B_m^\dagger
\hat B_m
\hat B_n
\right\rangle .
}
\tag{9.2}
\]

展开后得到

\[
\boxed{
\begin{aligned}
G_{nm}^{(2)}
\supset
\sum_{abcd}
\int dt_1dt_2dt_3dt_4\,
&
K_{n,a}^*(t_1)
K_{m,b}^*(t_2)
K_{m,c}(t_3)
K_{n,d}(t_4)
\\
&\times
\left\langle
\hat J_a(t_1)
\hat J_b(t_2)
\hat J_c(t_3)
\hat J_d(t_4)
\right\rangle_{\rm ord}.
\end{aligned}
}
\tag{9.3}
\]

下标 “ord” 表示由光子正常序和正/负频投影决定的算符排序。实际公式还必须加入：

- 输入场四阶矩；
- 两个输入算符与两个电流算符的混合项；
- 三个电流和一个输入场的混合项；
- 环境真空噪声项。

### 9.2 四时对象不能直接存成 \(N_t^4\)

若时间点数为 \(N_t\)，直接存储式 (9.3) 的四维张量需要 \(O(N_t^4)\) 存储，不可行。正确策略是先做模式投影：

\[
\boxed{
\hat B_n
=
\int dt\,K_n(t)\hat J(t)
}
\tag{9.4}
\]

再通过以下任一方法直接累计 \(\langle B_n^\dagger B_m^\dagger B_mB_n\rangle\)：

1. nested QRT；
2. Keldysh contour contraction；
3. quantum trajectories；
4. counting-field/full-counting-statistics；
5. 小系统完整 Fock-space 演化。

生产代码不应创建 `C4(t1,t2,t3,t4)` 全张量。

### 9.3 精确路线的最低验收

必须满足：

\[
\boxed{
G_{nm}^{(2)}\ge0,
}
\tag{9.5}
\]

相干态极限必须给出

\[
\boxed{
g_{nm}^{(2)}=1,
}
\tag{9.6}
\]

热态单模必须给出

\[
\boxed{
g_{nn}^{(2)}=2,
}
\tag{9.7}
\]

单模压缩真空必须给出

\[
\boxed{
g_{nn}^{(2)}
=
3+\frac1{\bar n_n}.
}
\tag{9.8}
\]

此外必须将精确式 (9.3) 与 Gaussian 式 (8.20)–(8.21) 对比并报告 \(\kappa^{(4)}\)。

## 10. Néel 磁序如何进入输出量子统计

![磁序奇偶通道与候选谐波模式](figures/量子光理论_20260729/04_磁序奇偶与候选谐波.svg)

### 10.1 先区分“两个独立磁畴计算”和“同一 Hilbert 空间的算符分解”

对分别计算得到的 \(+\mathbf N\) 与 \(-\mathbf N\) 结果，最安全的定义是直接做磁畴偶/奇分解。

对任意标量或矩阵观测量 \(\mathcal O\)，定义

\[
\boxed{
\mathcal O_{\rm dom,e}
=
\frac{
\mathcal O(+\mathbf N)
+
\mathcal O(-\mathbf N)
}{2},
}
\tag{10.1}
\]

\[
\boxed{
\mathcal O_{\rm dom,o}
=
\frac{
\mathcal O(+\mathbf N)
-
\mathcal O(-\mathbf N)
}{2}.
}
\tag{10.2}
\]

这里下标 `dom,e/o` 指整个结果对磁畴反转的偶/奇性。式 (10.1)–(10.2) 不要求把两个磁畴的 Bloch 基底直接相加。

### 10.2 算符级 \(J_e,J_o\) 需要公共基底映射

若要定义同一 Hilbert 空间中的电流算符

\[
\boxed{
\hat J_e
=
\frac{
\hat J_+
+
\widetilde J_-
}{2},
\qquad
\hat J_o
=
\frac{
\hat J_+
-
\widetilde J_-
}{2},
}
\tag{10.3}
\]

必须先构造把 \(-\mathbf N\) 的轨道映射到 \(+\mathbf N\) 公共基底的幺正或反幺正变换 \(\mathcal U_N\)：

\[
\boxed{
\widetilde J_-
=
\mathcal U_N^{-1}
\hat J_-
\mathcal U_N.
}
\tag{10.4}
\]

\(\mathcal U_N\) 必须正确处理：

- \(\mathbf k\rightarrow-\mathbf k\)；
- 上下层交换；
- 自旋反转；
- 轨道重排；
- 反幺正变换中的复共轭。

没有式 (10.4) 时，只能对最终数值结果做式 (10.1)–(10.2)，不能逐元素相加两个不同 gauge 的矩阵算符。

### 10.3 \(C_{oo}\) 不是磁畴奇信号

若公共基底映射已经完成，可定义

\[
\boxed{
C_{\eta\eta'}(t,t')
=
\left\langle
\Delta\hat J_\eta(t)
\Delta\hat J_{\eta'}(t')
\right\rangle ,
\qquad
\eta,\eta'\in\{e,o\}.
}
\tag{10.5}
\]

对 \(+\mathbf N\) 磁畴，

\[
\boxed{
C_+
=
C_{ee}+C_{eo}+C_{oe}+C_{oo}.
}
\tag{10.6}
\]

对 \(-\mathbf N\) 磁畴，

\[
\boxed{
C_-
=
C_{ee}-C_{eo}-C_{oe}+C_{oo}.
}
\tag{10.7}
\]

因此

\[
\boxed{
\frac{C_++C_-}{2}
=
C_{ee}+C_{oo},
}
\tag{10.8}
\]

\[
\boxed{
\frac{C_+-C_-}{2}
=
C_{eo}+C_{oe}.
}
\tag{10.9}
\]

结论是：

- \(C_{oo}\) 在 \(\mathbf N\rightarrow-\mathbf N\) 下是偶的；
- 真正的磁畴奇二时关联来自 \(C_{eo}+C_{oe}\)；
- 不能把磁畴差直接称为 \(C_{oo}\)。

### 10.4 平均谐波选择与代表模式

在当前已验收的 CrI\(_3\) 参数下，建议第一轮选择：

\[
\boxed{
\mathrm{H2},\qquad
\mathrm{H5},\qquad
\mathrm{H7},\qquad
\mathrm{H9}.
}
\tag{10.10}
\]

物理分工为：

- H2：最清楚的磁序奇偶次通道，直接检验 AFM 非线性；
- H5/H7：强且已收敛的中平台通道，信噪比高；
- H9：仍在当前生产模型可信区间，又接近低中阶边界，对输入涨落更敏感。

第一轮不把 H10 作为量子统计生产模式，因为 M88-c20 的 \(J_{o,10}\) 复振幅未通过带截断验收。若研究 H10，必须回到 M88-full 并重新收敛 \(N\)、\(M\) 和 \(G^{(2)}\)，不能只沿用平均谱的结论。

### 10.5 为什么 H2–H5/H7 比单模 H2 更有体系特色

单模强度统计

\[
g_{22}^{(2)}
\]

可以受输入强度涨落、普通电子噪声和磁序共同影响。跨奇偶谐波的 phase-sensitive 协方差更直接利用磁序选择定则：

\[
\boxed{
M_{2,5}
=
\left\langle
\Delta\hat b_2
\Delta\hat b_5
\right\rangle ,
\qquad
M_{2,7}
=
\left\langle
\Delta\hat b_2
\Delta\hat b_7
\right\rangle .
}
\tag{10.11}
\]

若 H2 的复振幅在磁畴反转下变号，而 H5/H7 近似不变，则式 (10.11) 的相位和符号可能对 \(\mathbf N\) 更敏感。适合的观测包括：

- 两模联合正交分量；
- 平衡零拍的压缩角；
- 参考光干涉后的关联；
- \(M_{2,5}\)、\(M_{2,7}\) 的磁畴奇分量。

### 10.6 \(\Delta_N g^{(2)}\) 不保证非零

定义

\[
\boxed{
\Delta_Ng_{nm}^{(2)}
=
\frac{
g_{nm}^{(2)}(+\mathbf N)
-
g_{nm}^{(2)}(-\mathbf N)
}{2}.
}
\tag{10.12}
\]

即使 H2 的**复振幅**在磁畴反转下变号，归一化强度统计 \(g^{(2)}\) 也可能不变，因为其分子和分母都只含绝对值或偶次组合。因此：

\[
\boxed{
J_2(-\mathbf N)=-J_2(+\mathbf N)
\;\not\Rightarrow\;
\Delta_Ng_{22}^{(2)}\neq0.
}
\tag{10.13}
\]

所以式 (10.12) 可以计算，但不应预设为主要磁性信号。更可靠的磁性优先级是：

1. \(\Delta_N M_{2,5}\)、\(\Delta_N M_{2,7}\)；
2. 磁畴依赖的压缩角；
3. 带参考场的相位敏感交叉关联；
4. 最后才是仅由强度构成的 \(\Delta_Ng^{(2)}\)。

### 10.7 实验操作与对称性操作不是同一件事

实验中的“翻转磁畴”通常保持：

- 同一入射方向；
- 同一偏振；
- 同一 CEP；
- 同一探测方向。

而数学上的 \(P\)、\(T\) 或 \(PT\) 变换还可能同时改变传播方向、偏振、\(\mathbf k\) 和复共轭。文中必须明确比较的是：

\[
\boxed{
\text{同一光学几何下的 }
+\mathbf N
\text{ 与 }
-\mathbf N,
}
\tag{10.14}
\]

不能把实验磁畴差与对整个系统实施 \(P/T\) 后的选择定则混为一谈。
