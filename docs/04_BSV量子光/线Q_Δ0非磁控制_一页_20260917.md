## \(\Delta=0\) 是好问题，但在 M0 上不是“只关磁性”

R0 的交错交换是 \(\Delta=0.8\,t_h\)，上下层反号。把它设成 0 以后：

- \(+N\) 和 \(-N\) 变成**同一个** Hamiltonian，畴差恒为 0，不必再跑两畴；
- 直接隙从约 \(0.09\,t_h\) 变成约 \(0.86\,t_h\)（约九倍）；
- 现在这束 P1 从“单光子亚带隙、两光子刚过门槛”变成深亚带隙。

所以若 \(d_e(0.016)\) 和 \(d(\Delta=0)\) 差很多，第一句话只能是：**交换项整包拿掉以后，这个源核变了。** 不能说已经证明磁性量子几何。

同号 FM 在这一套 R0 参数下间接隙是负的，接近半金属，**不能**拿来冒充 CrI\(_3\) 的绝缘体 AFM↔FM。
