| 光源 | 实验依据 | 判断 |

| C2：同一飞秒 BSV 模上叠加相位锁定位移 | 在目前核查的文献中，**尚未发现**同类固体 HHG 输入实验 | **下一阶段候选**。待实现，不是已有驱动 |

文献边界（目前核查范围，不是穷尽性证明）：

- Rasputnyi：1600 nm / 0.77 eV；BSV **25 fs FWHM**（相干对照 **70 fs**）；样品处 \(1/e^2\) 光斑 30 μm，本协议按直径解读故 \(w_0=15\,\mu\mathrm{m}\)；比较点 \(\sim2\,\mathrm{TW/cm^2}\)；表征 \(\langle n\rangle\sim2\times10^{12}\)，尾到 \(2\times10^{13}\)；~150 nm 带宽；双通近单时空模；样品 LN / a-Si，**不是 CrI₃**。仿真是 Husimi-Q 混合相干 HHG 的**谱强度**平均。
- 2025 年 *Observation of a displaced squeezed state in high-harmonic generation* 研究的是 **HHG 出射光态**，不能当作「飞秒 DS 已作为输入驱动固体 HHG」的证据。
- 理论中的 squeezed-coherent / DS 驱动 HHG（Li, PRA **112**, 033507 (2025)；Gorlach, Nat. Phys. **19**, 1689 (2023)；Gothelf, PRA **111**, 063105 (2025)）不是光源实验。
- 论文提到宏观量子态也可以把强相干成分加到压缩真空上，但那不是他们实现了飞秒 DS-HHG 的证据。

## 2. 行波脉冲归一化（不沿用腔模 \(g=0.005\)）

\[
E^{(+)}(t)=\sqrt{\frac{\hbar\omega_0}{2\varepsilon_0 c A_{\mathrm{eff}}}}\,u_E(t)\,a,
\qquad
\int\mathrm{d}t\,|u_E(t)|^2=1,
\qquad
A_{\mathrm{eff}}=\frac{\pi w_0^2}{2}.
\]

\(A\) 由 \(E=-\partial_t A\) 再转 Peierls。\(u_E\) 取无平台高斯包络，**替换** 1+4+1 开关。

| \(I_0\)（周期平均、统计平均） | \(U\) | \(\bar n=U/\hbar\omega_0\) | 直接 Fock 截断 |
|---|---|---|---|
| \(0.1\,\mathrm{TW/cm^2}\)（研究设计点） | 9.405 nJ | \(7.58\times10^{10}\) | 不适用 |
| \(2\,\mathrm{TW/cm^2}\)（Rasputnyi 比较点量级） | 188 nJ | \(1.52\times10^{12}\) | 不适用 |

强度对纯 BSV **不能**用 \(\langle E\rangle^2\) 定义。能流来自涨落。界面透射、局域场、自洽 Maxwell 仍未计入。

## 3. 统计输入：三个独立可测量

以后所有亮态候选（含 C1、C2）的理论输入写成

\[
\boxed{\alpha=\langle a\rangle,\qquad n_s=\langle\delta a^\dagger\delta a\rangle,\qquad M=\langle\delta a\,\delta a\rangle}
\]

其中 \(\delta a=a-\alpha\)。总平均光子数

\[
\bar n=|\alpha|^2+n_s.
\]

**理想纯单模位移压缩态** \(D(\alpha)S(re^{i\theta})|0\rangle\) 才有

\[
n_s=\sinh^2 r,\qquad |M|=\sqrt{n_s(n_s+1)}.
\]
若再指定相干能量份额 \(f_\alpha=|\alpha|^2/\bar n\)，则 \(r\) **不再独立**：

\[
r=\operatorname{arsinh}\sqrt{(1-f_\alpha)\bar n}.
\]
在 \(0.1\,\mathrm{TW/cm^2}\) 行波模 \(\bar n\simeq7.58\times10^{10}\) 上：

| \(f_\alpha\) | 理想纯 DS 的 \(r\) | 对应 \(R=\lvert M\rvert/\lvert\alpha\rvert^2\) |
|---|---|---|
| 1% | 13.2135 | 99 |
| 10% | 13.1659 | 9 |
| \(R=1\)（对照，不列为候选） | 12.8720 | 1 |

这就是 v1 的矛盾：排除 \(R=1\) 是因为它需要很大的内部 \(r\)，但 1% / 10% 设计在同一理想纯态模型下需要**更大**的 \(r\)。

**有损混合态不得未经认证套用** \(\lvert M\rvert=\sqrt{n_s(n_s+1)}\)。一般只满足相应不等式。高增益 BSV 的内部参数增益可以很大；实验室可测正交压缩受损耗、相位噪声和模匹配限制，二者不能等同，也不能用「多少 dB」判断高增益 BSV 是否可做输入。

均匀线性损耗：\(\alpha\to\sqrt{\eta}\alpha\)、\(M\to\eta M\)，故理想定义下的 \(R\) 不变。敏感的是可观测压缩、非经典性、信号强度和模式匹配。

## 4. 三个候选

### C1 — 已实现飞秒纯 BSV（第一实验基准）

| 量 | 取值 |
|---|---|
| \(\lambda,\tau,w_0\) | 1600 nm，25 fs，15 μm |
| \(I_0\) | 比较用 \(\sim2\,\mathrm{TW/cm^2}\) |
| \(\alpha\) | \(0\) |
| \(n_s\) | 由脉冲能量 / 表征光子数给出，不是实验室求积 \(r\) |
| \(M\) | 理想纯压缩真空 \(\lvert M\rvert=\sqrt{n_s(n_s+1)}\)，相位相对参量泵浦；实验混合态需另测，不得直接假定饱和 |
| \(R\) | \(\alpha=0\)，无定义 |
| 样品 | LN / a-Si，不是 CrI₃ |

C1 **不能**自动承接协议 A 的 \(A/B/C\)（那套机制依赖非零 \(\alpha^2\) 与 \(M\) 干涉）。
但 C1 仍是独立物理问题：理想压缩真空没有一阶位移，却有异常关联相位。磁性 H2 的复相位是否对压缩轴敏感，要由对称性和计算回答，不能事先判零。

### C2 — 待实现：同一时空模上的锁相位移

操作定义改为：在 C1 的行波模上，加入相对压缩轴锁定的位移，输入用 \((\alpha,n_s,M)\) 而不是 \((f_\alpha,\) 未知 \(r)\)。

| 量 | 本版 |
|---|---|
| 包络 | 同 C1；位移臂必须自己做时间模清洗（文献相干臂 70 fs ≠ BSV 25 fs） |
| \(I_0\) | 先 0.1，再视损伤与信号到 2 TW/cm² |
| \(f_\alpha\) | 只是可选的能量分割**标签**，不是与 \(r\) 并列的独立纯态参数 |
| 若把标签当成理想纯 DS | 1% → \(r=13.2135,\,R=99\)；10% → \(r=13.1659,\,R=9\)。\(\alpha=\sqrt{f_\alpha\bar n}\) 仍为 27524 与 87038（相对 \(0.1\,\mathrm{TW/cm^2}\) 的 \(\bar n\)），只作设计换算 |
| 实际理论输入 | 独立的 \(\alpha,n_s,M\)；有损时 \(\lvert M\rvert\le\sqrt{n_s(n_s+1)}\) |
| 实现条件 | **相位锁定**与**模匹配**。否则 \(\theta\) 平均，\(A/B/C\) 被洗掉 |
| 状态 | 待实现。在目前核查的文献中尚未发现飞秒 DS 输入驱动固体 HHG |

C2 下一步要确认的，不是硬填一个 \(r\)，而是：高增益 BSV 的异常关联 \(M\) 及其相位，能在多大程度上与外加相干位移保持稳定关系。这才决定协议 A 的机制能否实验延伸。

不把 2026-10-28 的 \(\alpha\sim2.5\times10^5\)、80/20、\(R\to0.25\) 升级为光源。

### C3 — CW 1550 nm

窄带 DS / 压缩真空可以存在（例如约 12.6 dB 多为压缩真空，位移需另混频）。峰值场不是固体 HHG 体制。不进入统计 SBE。

## 5. 两类观测量，不得互换

Rasputnyi 理论对照用 Husimi-Q：

\[
S_{\mathrm{HHG}}=\int\mathrm{d}\gamma\,Q(\gamma)\,S_{\mathrm{HHG}}(\gamma).
\]
这是不同场幅下谱**强度**的非相干平均。

协议 A / Q6 用的是平均电流的复 Fourier 分量

\[
\mathcal J_2=\int\mathrm{d}t\,e^{2i\omega t}\langle J(t)\rangle.
\]

一般情况下

\[
\lvert\langle\mathcal J_2\rangle\rvert^2\neq\langle\lvert\mathcal J_2\rvert^2\rangle.
\]

因此，**若之后授权 C1 最小测试**，必须同时记录：

1. 每条样本的复 H2（及 H2x/H2y），再对样本做平均，保留相位参考；
2. 按样本平均的 H2 强度代理 \(\langle\lvert\mathcal J_2\rvert^2\rangle\)，以便和文献谱强度口径对照。

不能把 Husimi 谱强度增强解释成 Néel-odd 平均复振幅增强。
高增益 BSV 的 Wigner 抽样可以作候选近似，但要先检验输入光子数矩、异常关联 \(M\) 和抽样收敛。不能沿用低占据 GH5 五点求积。

## 6. 可测协议（不追 8.5 倍）

1. **相位**：\(\arg(J_{2x}^o)\) 相对位移或外差本振。C1 相对压缩轴；C2 相对锁相位移。翻转 Néel 或翻转位移相位 \(\pi\)，看是否按对称性翻转。
2. **偏振**：同一时间序列读 \(H2_x,H2_y\)。
3. **磁畴对比**：\(\mathcal C=(S_{+}-S_{-})/(S_{+}+S_{-})\)。\(S\) 必须声明是 \(\lvert\langle\mathcal J\rangle\rvert^2\) 还是 \(\langle\lvert\mathcal J\rvert^2\rangle\)。
4. **对照**：同能量相干态、同能量纯 BSV、位移相位正交的两组。

这些仍是有限时间电流代理，不是已标定的出射 \(g^{(2)}\)。
