## 2. \(p_x,p_y,p_z\) 各干什么

层间 hopping（已有 Phase B + 本轮口径）：界面 I–I 比裸 Cr–Cr 大约 \(700\times\)；层间通道的 SVD 主分量是全局 \(p_z\)（Kramers-2 捕获 \(\sim 70\%\)）。

层内 d–p：传输权重 d–p \(67\%\)、p–p \(32\%\)、d–d \(0.46\%\)。每个 I 只留一个 \(p\) 不够；M88（\(p_x+p_y\)）保住约 81% 层内权重，M64（全 \(p_z\)）约 30%，M52（界面 \(p_z\)）约 16%，纯 \(d\) 约 6%。

所以：\(p_z\) 主要走层间/界面；\(p_x/p_y\) 主要走层内杂化与面内光学。二者都出现在隙附近，不是「可以随便积分掉的同一配体尾」。

## 4. 两种读法（请你选问题，不要现在选参数）

**读法 A。** 近隙价带 \(\gtrsim 90\%\) I-\(p\)，且 \(p_z\) 与 \(p_x/p_y\) 分成不同带；少带 HHG 也显示丢掉哪一组 \(p\) 都会改普通谱或层间通道。若 8-band 要承担 **CrI\(_3\) 定量光学 / HHG**，一个 Cr 心轨道很难同时吸收这些独立组合。那是「8-band 是否太小」的材料理由。

**读法 B。** 线 Q 的目标若是 **可控的 PT-AFM 机制玩具**，不必复现 VBM 的 I-\(p\) 载体。有效轨道可以口头写成 Cr 心、配体杂化进参数；那是现象学，**不是**「已证明 I-\(p\) 可被一个 Wannier 吸收」。40-WF 已经试过把 I-\(p\) 硬塞进 Cr 心，spread 变差、HHG 失败。

两层共用 \(h_0\)、\(H_R=0\) 的交接前提，与材料投影「可能改层内块 / 自旋项 / 能量依赖」可以并存：后者是警告，不是本轮要改 Hamiltonian。
