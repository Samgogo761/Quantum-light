## 1. Laplace 与 \(Y\) 的符号（不抄外层）

已冻结 \(F(z)=I+i\gamma K(z)/z\)。取 \(s=-iz\)。则 \(z=is\)，\(i/z=1/s\)，故

\[
F_s(s)=I+\gamma Y(s),\qquad Y(s)=\frac{K(is)}{s}.
\]

增量账用 \(\Delta K=K-K(0)\)：

\[
Y_\Delta(s)=\frac{\Delta K(is)}{s}=i\left.\frac{\Delta K}{z}\right|_{z=is}.
\]

连续 BZ 的 \(K(0)=0\)，故物理目标是 \(Y_\Delta\)。原始账多一项 \(M_N/s\)，不要求正实。

## 2. 完整张量，不是标量振子

冻结

\[
K(z)=D+\sum_p\left[\frac{C_p}{z-\Delta_p}-\frac{C_p^*}{z+\Delta_p}\right],
\qquad C_{ab}=X_a^*X_b.
\]

相减后

\[
Y_\Delta(s)=i\sum_p\frac{1}{\Delta_p}\left[\frac{C_p}{is-\Delta_p}+\frac{C_p^*}{is+\Delta_p}\right].
\]

令 \(\alpha_p=v^\dagger C_p v=|\sum_a X_a v_a|^2\ge0\)，\(\beta_p=v^\dagger C_p^* v=|\sum_a X_a^* v_a|^2\ge0\)。两者对复电流矩阵元仍是非负实数。\(s=x+iy\) 时

\[
\boxed{
\operatorname{Re}\,v^\dagger Y_\Delta(s)v
=\sum_p\frac{x}{\Delta_p}\left(
\frac{\alpha_p}{(\Delta_p+y)^2+x^2}
+\frac{\beta_p}{(\Delta_p-y)^2+x^2}
\right).
}
\]

\(\Delta_p>0\)、\(x>0\) ⇒ 右端 \(\ge0\)。因此 \(H_{Y_\Delta}=(Y_\Delta+Y_\Delta^\dagger)/2\succeq0\)。再加 \(\gamma>0\)：

\[
\operatorname{Re}\,v^\dagger F_s(s)v=\|v\|^2+\gamma\operatorname{Re}\,v^\dagger Y_\Delta v>0
\quad(v\neq0,\;\operatorname{Re}s>0).
\]

故增量账

\[
\boxed{\det F(z)\neq0\qquad\forall\operatorname{Im}z>0.}
\]

这覆盖上一轮故意留空的 \(0<\operatorname{Im}z<0.05\) 粒子—空穴贴面，也覆盖 \(|z|\to\infty\)。割线上的 p-h 极点仍在实轴，不在开 UHP。

外层的标量 \(\operatorname{Re}[s/(s^2+\Delta^2)]>0\) 是 \(\alpha=\beta\) 的特例。完整证明必须同时留下 \(C\) 与 \(C^*\)；两者的二次型都非负，结论不变。
