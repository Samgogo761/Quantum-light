## 2. 候选是 \(M\) 不是 \(\mathcal{P}\)

- \(\mathcal{P}\)：有限 \(A_\parallel\) 对同号 \(A\) 的 \(-N\) 残差 2.4699138300926466；对反转 \(\kappa\) 的 \(-N\) 残差 \(2.943923360032078\times10^{-17}\)。同驱动 \(\pm N\) **不是** \(\mathcal{P}\) 恒等（与 2026-10-23 反演字典一致）。
- \(M\)：`op_mirror_a2`，期望 \(U_M H_N(k)U_M^\dagger=H_{-N}(Mk)\)。\(U_M\) 酉残差 \(5.20\times10^{-17}\)。\(M\hat e_\parallel=\hat e_\parallel\) 残差 \(5.55\times10^{-17}\)。
- 几何 Peierls 恒等成立。障碍在电子块，不在驱动方向。

## 4. 量子约束

不能从 \(\beta\) 翻号推出协方差翻号。条件推导见一页。\(U_0\) 含直接透射；不变换入射则 \(b_\perp\) 算符映射不成立。完整 \(M\) 作用在光子场上时真空仍不变，但电子 \(M\) 已失败，整条链不是定理。

若将来量子 \(m_{01}\) 只随 \(N\) 反号，必须与本页 Stokes / \(I_{45}\) 比，不能只比两偏振各自强度。
