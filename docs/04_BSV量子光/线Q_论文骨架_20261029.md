# 线 Q：论文骨架（2026-10-29）

不是投稿稿。目的：把已经闭合的机制写成一篇普通理论物理论文的结构，避免再把课题拖去证明量子优势或加密 M52。

建议体裁：一篇 **八带机制 + 有限材料存在性检验** 的理论文。主结果是位移压缩光控制的磁性二次谐波有限时间复响应，以及 A/B/C 的分层解释，不是谐波增强倍数，也不是量子优势。

## 暂定题目

中文：位移压缩光调控 PT 反铁磁二次谐波复响应

英文：
Quantum-light-controlled magnetic second-harmonic response in a PT antiferromagnet

不要用 cutoff HHG、量子优势或普适磁性选择定则作标题。研究边界写进方法/讨论：有限时间窗、few-k、无经典 \(P\) 输出对照。

## 摘要草稿

我们研究位移压缩真空 \(D(\alpha)S(re^{i\theta})|0\rangle\) 如何改变一个八带 PT 反铁磁模型的 Néel-odd 二次谐波复电流。固定电子动力学后，该电流是入射光子密度矩阵的线性泛函。严格数态块给出

\(\mathcal J_2^o(\theta)\approx B+Ae^{i\theta}+Ce^{-i\theta}\)，

其中 \(B\) 读取 Δn=0，\(A,C\) 读取 Δn=±2。这与有效近似 \(\mathcal J_2^o\approx K_B\alpha^2+K_M M(\theta)\) 不是恒等式。

在 α=0.5、r=0.3 的精确 QED 中，Fourier 端点修复后 θ=π/θ=0 的二维振幅比为 4.98，协方差反转相位差 110.6°。\(R=|M|/|\alpha|^2=O(1)\) 时干涉显著，\(R\approx 1\) 附近位移与异常关联相消最强；生产态 \(R=1.273\)。同一电子核在 Wigner/GH5 层面对 α² 与 M 的读取几乎相同。Néel 交换与自旋轨道耦合打开并缩放奇通道，但不把绝缘窗口内的 \(\arg(A/B)\) 拉离 π。生产窗相位主要由有限时间 Peierls 二阶核和 Ehrenfest 反作用解释，而不是平衡 \(\chi^{(2)}\)；二者不能写成严格相加等式。精确量子映射并不增强对异常关联的读取；约 15% 的稳定余量留在奇通道的光子数对角核上。真实 CrI₃ 类 Wannier 模型在 1600 nm 相干光下存在同名磁性 H2，但 few-k 相位尚未定量，不能把八带 M0 当作材料下折叠。

## 章节

### 1. 引言：要回答的问题

不是“压缩光是否比相干光更强”，也不是“反铁磁有没有 SHG”。
要回答：

入射光的位移与异常关联，如何通过 Néel 序和 SOC 控制的电子通道，变成可预测的 H2 复振幅与相位？

文献边界写清楚：2019 Sun 等已有双层 CrI₃ 磁序 SHG；2024 Rasputnyi 等有固体 BSV-HHG；2026 Prabhu-Dixit 有压缩相位与谐波偏振。本文差异化在 **磁性电子核如何把光子的 Δn=0 与 Δn=±2 块转成 A/B/C**。

### 3. 主结果：A/B/C

冻结数字：

- R=1.273，ρ=1.456，arg(A/B)=177.65°
- B=(−3.3006+0.9537i)×10⁻⁸，A=(+4.7434−1.5839i)×10⁻⁸，\|C/A\|≈1.54%
- 振幅比 4.98；协方差反转 110.6°
- 邻窗 16%–39%，故只称有限时间复响应

图：压缩角轨迹、θ=0/π 复平面、Q5→Q6 留出预测。

### 4. 机制分层

1. 光子相干块：J=Tr(ρ_ph K)。
2. 输入统计窗：GH5 上 ρ 跟踪 R（0.9976，相对散度 0.27%）。\(R=O(1)\) 时干涉显著，\(R\approx 1\) 附近相消最强，不是 \(R\) 越大越好。a12r03 解释为何 80%/20% 亮态看不到 110°。
3. 电子门控：Δ=0 与 SOC=0 关掉奇通道；绝缘窗口内 SOC 扫描不把 \(\arg(A/B)\) 拉离 π（跨度 4.37°）。这是负结果，不是材料相位指纹。
4. 相位：有限时间核解释原 79° 差的 73.7%；Ehrenfest kick on/off 约 −16.5°，覆盖大部分剩余。仍有约 4° GH5–QED 残差。不要写成 \(\phi_{\mathrm{QED}}=\phi_{\mathrm{finite}}+\phi_{\mathrm{Ehrenfest}}\)。
5. 量子映射余量：主窗 \(K_M=1.003\)，\(K_B=0.868\)。平台内 \(K_B\) 均值 0.853，来自 4 个**重叠**的 2 周期窗，散度 1.3%，不是独立误差。前窗写成开关相关瞬态，不是已分解的唯一成因。

可证伪句：固定 Hamiltonian 与生产主窗，GH5 的 \(K_M/K_B\approx 1\)；精确 QED 把 \(K_M\) 留下、把奇通道 \(K_B\) 压低 O(10%)。

### 5. 材料检验（短）

1600 nm、25 fs、10¹⁰ W/cm² 相干光：

- M52/M88/full112 的 2×2 都有 Néel-odd H2，振幅同量级。
- M88 4×4 振幅只降 1.50，但相位转 −134°。谷间分解表明这是 **interband few-k 采样**，不是 K/K′ 相消。
- M52 的 6.6 倍下降更像谷相消，相位符号保留。
- 结论：存在性成立，定量不成立。不上 8×8。M0 不是 CrI₃ 下折叠。full112/WINDOW144 的空间完备性未决，本文不依赖它。

### 6. 讨论

- 控制实验相关协议时应扫 R，而不是固定 80%/20%。
- 不宣称量子优势；具有相同二阶矩的经典随机光仍可能复现平均电流。
- 平均电流不是输出光子统计。C_JJ、g²、纯 BSV 非经典性留待另文。
- H2 足够成为主文；H4 只作附录。

### 7. 现在不要写进论文的句子

- 4.98 倍是谐波产额或实验可测增强。
- 材料优先读取异常关联 M。
- 1600 nm 已复现 110°。
- GH5 的 ρ 就是 QED 的 \|A\|/\|B\|。
- \(B\equiv K_B\alpha^2\)。数态块 \(B\) 与有效模型 \(K_B\alpha^2\) 必须分开。
- \(\phi_{\mathrm{QED}}=\phi_{\mathrm{finite}}+\phi_{\mathrm{Ehrenfest}}\)。
- 把 0.853±1.3% 当成独立统计误差或严格收敛界。
- K_B 窗口变号是新选择定则；前窗已严格分解为升沿唯一成因。
- full112 已完备；WINDOW144 是生产模型。
- 非负 \(P\) 界 \(|M_{\mathrm{cl}}|\le n_{\mathrm{fl}}\) 证明了 H2 输出非经典性。
