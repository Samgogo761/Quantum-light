## 1. 改成 1600 nm，参数必须变

不是只改一个频率。第一轮**保留静态 M0**、只改光场，是为了隔离波长，**不是**已经代表实验室 CrI₃。

| 必须动 | 第一轮可不动 | 不能假装不动 |
|---|---|---|
| \(\omega\)、\(dt\)、包络物理时长、演化中 \(n_{\max}\)、\(\Delta n=\pm 4\) 重测 | 静态八带 \(H_e\)、同一 \(k/-k\) | 把 \(g=0.005\) 当成 W/cm²；把 1+4+1 当成 25 fs 高斯脉冲 |

\(g\) 在代码里是抽象 Peierls 动量位移（Å⁻¹），**转不成**电场。缺 \(V_{\mathrm{eff}}\) 时禁止 \(g\propto\omega^{-1/2}\)。协议 A 保持 \(\alpha=0.5,r=0.3,R=1.273\)；协议 B 比场强/能量时必须重标。纯 BSV 是第三套问题（\(\alpha=0\)，\(R\) 无定义）。

1600 nm 下 \(3\hbar\omega=2.325\,\mathrm{eV}>E_g(k)\simeq 1.91\,\mathrm{eV}\)。可能换机制。不要把 4.98 / 110.6° 抄过去。

## 2. \(\Delta n\) 和 A/B/C

光场密度矩阵有对角（各 \(n\) 的概率）和非对角（不同光子数之间的相干）。\(\Delta n=n-m\) 就是那两块差了几个光子，**不是**谐波阶数。

位移压缩态在位移后的偶数 Fock 基底里：

- \(\Delta n=0\) → \(B\)（整块，\(\neq K_B\alpha^2\)）
- \(\Delta n=+2\) → \(A\sim e^{i\theta}\)
- \(\Delta n=-2\) → \(C\sim e^{-i\theta}\)

所以同一个 Néel-odd H2 写成 \(B+Ae^{i\theta}+Ce^{-i\theta}\)。还有 \(\pm 4,\ldots\)。Q6 上 \(\|N_{\ell=2}/N_{\ell=1}\|=0.0009\)，三项够用；1600 nm 必须重测。
