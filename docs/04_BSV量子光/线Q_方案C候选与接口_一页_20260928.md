# 线 Q：方案 C 候选与接口——一页

2026-09-28，Codex 完成。**本轮是推导与小型接口验证；没有新的 P1 传播或真实光子结果。**

## 现在走到了哪里

我们已经有电子电流、它的量子涨落、到光场的辐射桥，以及关掉泵浦时正确的光子归一化。方案 C 也已确定：**同一束激光、同一套探测器、同一把相位尺子，只翻磁畴。**

这一轮把“该观察什么”变成了两个具体候选，并接好了“给定一般初始涨落，怎样从联合演化读出光的二阶关联”的数学接口。下一步缺的是实际脉冲前的准备态与脉冲后自由光场如何接进这个接口。

## 本轮完成什么

- 保留沿 a2、A*=0.8、8 周期的 P1。查明前一轮 A*=0.1、x 偏振只是代数测试参数，不能当研究工作点。
- 推完 P、T、PT 对电流、两侧光场、波包、平均场和二阶关联的变换。时间反演会交换入射/出射、改变状态边界，不能直接拿来宣布同场两畴的关联翻号。
- 新接口要求明确给出初始协方差，避免旧函数默认的“电子与光分别处于裸真空”被静默用作物理初态。
- 8 个小型测试通过。两条玻色对易关系与独立协方差计算的残差约 10^-15；这验证公式和程序，不证明材料产生了磁性量子光。

## 建议先审的两个候选

两者都在薄膜 +z 侧收光，并且两个磁畴保持同一探测器和相位参考。“平行/垂直”指样品平面内相对 a2 晶轴。

| 候选 | 关联哪两束光 | 想看什么 |
|---|---|---|
| A | 二次谐波的平行、垂直偏振 | 同频段两种偏振的相位联系能否读出磁畴 |
| B | 三次谐波的平行偏振、二次谐波的垂直偏振 | 不同谐波间的相位联系能否读出磁畴 |

它们是**提案，未开生产计算**。主候选为异常关联 m 的复数磁畴半差，同时保留平均场、正常关联 n、同偏振对照和总强度。m 不是单独一个直接测量值；实际正交分量相关还含 n。

为什么先提出交叉偏振？在理想镜面对称的参照模型里，交叉偏振关联可以翻号而同偏振项不翻号。但实际 M0 只有近似镜面，所以只是寻找方向，不能强制结果。这也不证明压缩或纠缠。

## 现在真正需要理解、审核的事情

**第一，是否把这两种“收光方式”作为首批候选。** 我建议先从 A 建立读出，再用 B 接到跨谐波问题；不是按哪张谱更漂亮选点。

**第二，激光到来以前，光和电子处于什么联合状态。** 建议研究“耦合已经存在、入射通道为真空”的准备方式，然后推导它在有限时间计算坐标里的协方差。这不是直接在旧裸坐标里填一个真空矩阵。

同样，脉冲结束时程序中的振子还需匹配到自由传播的输出光。关泵浦时通过的光子散射行，并没有自动完成这两端的匹配。我们已有的辐射桥仍然成立；缺的是怎样把它用于一次真实强脉冲演化的完整边界条件。

这是目前需要你参与的物理内容。网格、缓存和脚本不需要你选择。也不需要重新选择方案 C 或重做零驱动审计。

## 执行边界与交付

选择两个探测模式，不等于只让两个光子振子参与演化。完整反馈仍需保留足够的其他光场通道。初态/输出匹配与成本明确以前，不上服务器、不启动真实 P1 联合传播。
