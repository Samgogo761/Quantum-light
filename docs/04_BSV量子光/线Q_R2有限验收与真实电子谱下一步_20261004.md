### A. 真实 M0 标签与人工光场参数混在同一个诊断里

test_q8_m0_incoming_completeness_r2_20261004.py 的 m0_finite_label_diagnostics：

- assemble_incoming_bundle 使用 D_test=Pi(0)+0.03 I；
- 实际传入 GAMMA=0.22；
- JSON 却在外层记录 gamma_self(geo)=0.001080789276...。

因此，暗核维数与零电流检查（A=0）可保留，因为它们不依赖 D/gamma；photon_dark_projection 应标作“真实 M0 顶点＋人工场参数夹具”，不能称冻结 M0 的光场接入。

下一次小检查改用既有 d_ops/mean_d_from_bases 装配原始 D，并传入 gamma_self(geo)，将实际使用的参数写进 JSON；不要将人工 D 替换作为物理修正。旧结果不改写，补一份有来源的校正结果即可。

### B. 暗通道激活例子实际上没有激活

complex_propagation_and_projection 中新增顶点正比 outer(pol,v.conj())。当前暗向量满足 v^T v=0，所以新增实际电流正比 v^T v，仍为零。独立检查 t=0、0.5、1.8 的电流均为零。

故 driven_dark_vs_independent_midpoint=0 只证明两边在这个例子里都不响应，不能证明受驱暗源的非平凡接入。

改一个人工顶点变化，使实际 current/RHS 在指定时刻明确非零；例如在已确认的系数约定下从 du* v 非零反推变化，而非凭外观指定共轭。增加激活幅度非零断言，再与独立密集中点对照。该夹具不是修改 M0，也不需用户选择。

原有无驱动、复杂基底、弱耦合和谱支撑结果继续保留。

## 下一步：真实 M0 的零泵浦电子谱诊断

完成上面秒级收尾后可继续，不需再问初态或网格。目标是：

**弄清真实 M0 的电子跃迁在频率上的权重，是否在数值加密后稳定，并与响应的吸收部分来自同一谱。**

1. 先读取 stage1ai/ak 的现有数据及缓存。旧 JSON 的少量频率探针只够核对定义，不能插值重构完整谱；若缺原始数据，按原模型重建必要的静态 (k,c,v) 数据，不启动时间传播。
2. 明确权重只计一次：可以选择未加权顶点配 BZ 测度，或 sqrt(w_k) 加权顶点配普通离散和。写出与现有 u、C 的映射，不能既在列中乘 sqrt(w) 又在谱中重复乘 w。
3. 保留原始 D、正负频率两项和复顶点。同一数据给出主值、跳跃与原始标签的电子源。不要把二维电流谱平方根当完整内部电子基底。
4. 分开两种检查：
   - 代数一致性：K^R-K^A 与 S^>-S^< 相符；
   - 数值连续极限：固定正则化宽度先查 BZ 加密/移位，再在足够分辨的网格上考察宽度减小；不可在固定粗网格上直接令 eta→0。
   代数恒等式通过不证明谱已经收敛；有限 eta 只是解析边界诊断，不是新 T2。
5. 优先给出固定平滑频率权下的谱积分，可参考已有 H2 波包频宽，并用不依赖展宽的原始跃迁加权和作独立对照。该量只是电子源谱诊断，不是光子数。不要改物理探测定义，也不要只因核里有 H2 中心频率就称光子模式已接通。
6. 使用已有网格层级，最多做一轮事先列明的有限比较；先估算成本，能本机完成则不上服务器。不无边界加密，也不重做已通过的静态规范或积分器审计。
