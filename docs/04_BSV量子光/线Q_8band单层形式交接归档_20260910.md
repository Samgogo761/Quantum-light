# 线 Q：8-band 单层形式交接归档（2026-09-10）

仓库此前没有独立的「单层已审核」条目。按任务单，**不因缺失记录而推翻用户已给出的前提**；把前提写在这里，供后续静态审核引用。

用户给出的单层（\(H_R=0\)）与 8 维自然 A/B 基底：

\[
h_\ell(\mathbf k)
=
t\bigl[\mathrm{Re}f(\mathbf k)\,\sigma_x-\mathrm{Im}f(\mathbf k)\,\sigma_y\bigr]s_0
+\lambda_{\mathrm{SO}}g(\mathbf k)\,\sigma_z s_z
+\eta_\ell\Delta\,\sigma_0 s_z,
\]

\[
\mathrm{basis}=
(tA\uparrow,tA\downarrow,tB\uparrow,tB\downarrow,
bA\uparrow,bA\downarrow,bB\uparrow,bB\downarrow),
\]

\[
H_8(\mathbf k)
=
\begin{pmatrix}
h_t(\mathbf k)&T_\perp(\mathbf k)\\
T_\perp^\dagger(\mathbf k)&h_b(\mathbf k)
\end{pmatrix},
\qquad
T_\perp=T_{AB}\otimes s_0.
\]

本归档**不**批准任意 \(f/g\) 的数值实现。\(f\)、\(g\) 必须来自同一套实空间 NN/NNN 键表；实现与核对见 `q8_tperp_static_audit.py` 与《线Q_C3静态候选一致性与对称补审_20260910.md》。
