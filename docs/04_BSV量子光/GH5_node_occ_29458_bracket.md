## 结论（按门）

**1. 经典主基线 \(2\times10^{11}\) 的绝对顶部缓冲已经 FAIL。**  
这是相对 29452 的新事实。以前只能说「不能从 \(10^{12}\) 反推 \(2\times10^{11}\)」；现在直接测到 `global_edge_max=2.19\times10^{-3}`，约为门的 2.2 倍。论文里「固定场 3200 nm / \(2\times10^{11}\) 材料空间可信」**不能**再靠 occupation 的绝对顶部缓冲来背书。旧的 M88 vs full112 HHG 对照仍然存在，但那是可观测量对照，不是这套门。

**2. 本轮抽到的中环主轴反节点全部 ABS FAIL；这不是整层 44.42% 权重的穷尽认证。**  
一条 GH5 求积（权重和=1）里，\(I\sim 3.65\)–\(3.76\times10^{11}\) 的**整个强度层**合计约 **44.42%**。本轮直接检查的是两条压缩轴上 \(I=3.65\times10^{11}\) 的主轴反节点（th0 id12/id14 与 th180 id8/id18），每条求积约 **23.69%**，外加中环最高 \(I\) 的 th0 id2（约 0.25%）。对角节点 id7/9/17/19（同层、另四相位）未直接跑 occupation。θ=0 的 90°/270° 与 θ=180 的 0°/180° 的 `edge_max` 都在 \(4.1\)–\(4.5\times10^{-3}\)。**不要**写成 97.75% 或全部 44.42% 权重已认证。

**3. 本轮唯一被测且 ABS PASS 的案例是 th0 id3。**  
\(I=1.09\times10^{10}\)、CEP=180°：`edge_max=1.50\times10^{-4}`。REL 仍 FAIL（3.22%），因为激发总人口本身很小（边缘人口峰值仅 0.25）。这是小分母，不是「顶部被填满」。**不能**推广为「全部内环 ABS PASS」。112/105=0.68，比高场的 0.85–0.97 **更有**衰减包络。ABS PASS 与 overall FAIL 的 CEP 还不一致，**不能**写成同一 CEP 下的 \([I_P,I_F]\)。

**4. dt/2 不支持「正定性是 \(O(dt^2)\)」。**  
对照 29453：\(\min f\) 从 \(-1.34\times10^{-5}\) 变为 \(-2.09\times10^{-5}\)（比值 1.56，不是 1/4）。最差点仍在 band 92、同一 \((k_x,k_y)=(7,15)\) 附近。顶部人口不变。正定性与顶部缓冲继续分开；\(10^{-8}\) 先不放宽。内环的负占据反而最深（\(-1.15\times10^{-4}\)），更不像强场截断。

**5. 仍无 overall \(I_P\)。** 安全边界若存在，已不在「GH5 中环 vs \(10^{12}\)」之间，而是要回答：在绝对顶部缓冲下，\(2\times10^{11}\) 已经失败；本轮近零场唯一 ABS PASS 是 th0 id3，不是「全部内环」。

## 分层物理

这些跨 CEP/节点案例的 `edge_max` **上包络**随强度上升，未见逆转：\(1.5\times10^{-4}\to 2.2\times10^{-3}\to 4.4\times10^{-3}\to 1.4\times10^{-2}\to 2.8\times10^{-2}\)（29452）\(\to 0.065\)（29403）。这不是同一 CEP 的受控 \(I\) 扫描。高阶谐波对尾节点敏感、平均主体占中环——现在抽到的中环主轴自己也过不了绝对顶部缓冲。full112 的适用域比「只在 GH7 尾撞顶」窄得多。
