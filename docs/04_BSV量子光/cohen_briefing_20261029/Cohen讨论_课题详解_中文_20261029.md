 # 课题详解：位移压缩光对 PT 反铁磁 Néel-odd 二次谐波复响应的调控

 日期：2026-10-29
 用途：把自己的课题讲清楚，并作为与 Cohen 教授讨论的底稿。不是投稿稿。关键数字全部来自 Fourier 端点修复之后的冻结结果。

 **一句话定位**

 我们没有做出接近 1600 nm 亮压缩真空实验的磁性高次谐波预测。我们做成的是：在可控八带 PT 反铁磁模型里，用精确 QED 证明低占据位移压缩态的压缩角可以调控 Néel-odd 的有限时间 H2 复电流，并把现象分解成输入统计干涉、磁序/SOC 门控、有限时间电子动力学和量子映射修正。

 10 月 24 日那份 30 页汇报仍可作内部历史记录，但其中的 **5.80 倍** 和 **106.9°** 已经作废。现行数字是 **4.98** 和 **110.6°**。不要把旧 PPT 发给教授。

 ## 1. 真正要问的科学问题

 不要把课题说成：压缩光是否比相干光更强、反铁磁有没有 SHG、或能否证明输出光的量子优势。

 真正的问题是：入射光的相干位移 alpha^2 与异常关联 M(theta)，怎样通过 Néel 序和自旋轨道耦合控制的电子通道，变成可预测的磁序奇二次谐波复振幅与相位？

 因果链：

 输入量子统计 (alpha, M, theta) -> 磁序/SOC 控制的电子响应核 -> Néel-odd H2 复电流

 磁性材料提供对磁畴奇偶敏感的读取通道。输入光提供可以旋转的二阶关联，而不只是平均电场。

 ---

 ## 2. 为什么先做八带模型

 长期目标仍是双层反铁磁 CrI3。Sun et al., Nature 572, 497 (2019) 已经实验证明：双层 CrI3 的晶格中心对称，巨大非互易 SHG 来自层状反铁磁序，同时打破空间反演和时间反演。所以“AFM 可以产生 SHG”不是新结果。

 我们需要一个小到能做电子-光子联合演化、又保留 Néel 序、层间耦合和 SOC 的 Hamiltonian，才能问量子统计怎样进入这条磁性通道。

 八带 M0：两层 x 两个子晶格 x 两个自旋。层内最近邻跃迁 t_h = 1 eV，层间同类/异类耦合 u,v，Kane-Mele 型次近邻 SOC，上下层符号相反的交换场。动量只取 k = (0.173, 0.271) 及其反演配对，并共享同一个光模。

 **必须讲清的限制：** M0 是现象学 PT-AFM 模型，不是由 CrI3 full112 Wannier 严格下折叠得到的八带。不能把带隙、交换、SOC 填成 CrI3 的数，就声称这是真实材料的量子 HHG。

 真实 Wannier 线（M52 / M88 / full112 / WINDOW144）只承担材料检验。目前 1600 nm 相干光 few-k 只证明磁性 H2 存在。M52 从 2x2 到 4x4 振幅下降约 6.6 倍。full112 的空间完备性仍有 WINDOW144 诊断留下的疑问。这些都不支持把 M0 写成 CrI3 预测。

 ## 3. 为什么选 24.8 μm、alpha=0.5、r=0.3

 这是教授几乎一定会问的问题。

 ### 3.1 三套光协议不能混

 | | 八带 Q6（主结果） | 1600 nm M0 统计探查 | 已发表 BSV-HHG 实验 |
 |---|---|---|---|
 | 波长 | 24.8 μm | 1600 nm | 1600 nm |
 | 单光子能量 | 0.05 eV | 0.775 eV | 约 0.775 eV |
 | 光学周期 | 82.71 fs | 5.337 fs | 飞秒 |
 | 光态 | D(0.5) S(0.3 e^{i theta}) |0> | 理想化高增益 DS / BSV / 相干 | 纯 BSV，相干对照 |
 | 平均光子数 | 0.343 / 模 | 宏观 | 约 2e12 / 脉冲量级 |
 | 压缩 | r=0.3（理想约 2.61 dB） | 形式参数 r ~ 11 | 高增益单时空模 BSV |
 | 时间协议 | 1+4+1 周期耦合开关，约 496 fs | 25 fs Gaussian | 25 fs BSV |
 | 强度 | 未完成 W/cm^2 标定 | 1e10 W/cm^2 理论筛选 | 实验强场，不可照搬到 CrI3 |
 | 方法 | 截断 QED + GH5 | Wigner 统计 SBE，求积未充分认证 | 实验 |
 | 动量 | 一个 k/-k 对 | BZ 网格探查 | 真实晶体 |

 Q6 耦合常数 g = 0.005 Å^{-1}，omega_0 = 0.05 t_h。协议名 Qin_a2_141 里的 a2 是晶格偏振方向，不是 alpha ≈ 1.41。

 ### 3.2 当初为什么选这套参数

 四个互相约束的理由，不是因为我们认为它已经接近实验。

 1. 精确 QED 的维数。电子扇区 36 维，光子截断 n_max=8（9 个数态），联合空间 11664 维。这是还能做多周期精确传播的上限附近。宏观光子数的 Fock 空间进不去。
 2. 要让压缩角真正起作用。|M| = (1/2) sinh(2r) = 0.318，alpha^2 = 0.25，于是 R = |M|/alpha^2 = 1.273。R = O(1) 时位移与异常关联可以竞争。后来 1600 nm 方案若按 80% 位移 / 20% 压缩分配能量，则 R ≈ 0.25，压缩角几乎只是微扰。这不是 Q6 没放大，而是统计窗口不同。
 3. 深度失谐，先避开共振载流子动力学。2 omega_0 = 0.10 eV，生产点局部能隙约 1.91 eV。Q6 研究的是远离带间共振的有限时间非线性复响应，不是 1600 nm 下 H2 落在 1.55 eV 可能碰到的真实跃迁窗口。
 4. 需要非零平均场，才能看到 alpha^2 与 M 的相位竞争。纯 BSV 满足 <a>=0。Q6 是位移压缩态：平均位移不动，只旋转涨落椭圆。这样才能做“相同平均场和平均光子数、只改涨落方向”的干净对照。

 ### 3.3 这套光有没有人制备过

 位移压缩态是量子光学教科书中的标准高斯态。r=0.3 对应的理想压缩也不算苛刻。但是：量子测量或连续变量实验里的压缩光，不等于可以聚焦到磁性样品上驱动 SHG 的飞秒光源。我没有独立核实“已经有人用 1550 nm、约 5 dB 的位移压缩光做过与 Q6 同类的固体 SHG”。不要对教授转述这条未核验对应。24.8 μm（约 12.1 THz）也不是当前固体 BSV-HHG 的工作波长。

 对教授应说：Q6 是机制显微镜，不是实验协议的缩小版。

 ## 4. 文献地图

 若教授来自量子光 HHG 方向，不要把前半部分讲成科普。

 ### 4.1 磁性 SHG

 Sun et al., Nature 572, 497 (2019)。双层 AFM CrI3 的巨大非互易 SHG 来自层状磁序。我们借鉴：磁序奇信号可以用 SHG 读出。这不构成新意。

 第一性原理工作表明，有些双层 CrI3 构型在无 SOC 时仍可有非零 SHG，SOC 往往增强而不是唯一来源。因此“SOC=0 关掉 M0 奇通道”只属于当前八带模型，不能推广成所有 CrI3 磁性 SHG 都必须依赖 SOC。

 ### 4.2 量子光驱动的固体 HHG

 Gorlach et al., Nature Physics 19, 1689 (2023)。把驱动光的量子态引入极端非线性光学。作者包括 Cohen、Kaminer 等。借鉴：HHG 可以依赖光的量子统计，而不只是平均场。

 Rasputnyi et al., Nature Physics 20, 1960 (2024)。1600 nm、25 fs 亮压缩真空驱动 LiNbO3 与非晶硅的非微扰 HHG，并与相同平均强度的相干光比较。作者同样包括 Cohen 等。借鉴：实验已经证明宏观量子光可以驱动固体 HHG。关键差别：那是高增益纯 BSV，不是我们的低占据位移压缩态；样品不是磁性二维材料。

 Li et al., Physical Review A 112, 033507 (2025)。压缩相干态驱动固体 HHG 的量子光学特征。这是最接近的理论先例之一。“压缩相干态改变固体谐波”不是我们独有的命题。

 Prabhu and Dixit, Physical Review B 114, L140301 (2026)。石墨烯中用禁戒谐波感知压缩涨落，并讨论偏振与光子统计。说明：用谐波读量子涨落、用压缩相位改偏振，2026 年已经有人做了。

 ### 4.3 方法背景

 de-la-Peña et al., J. Chem. Theory Comput. 21, 283 (2025)。多轨迹 Ehrenfest 与精确 QED 的对照思路。本地反馈实现并不相同。
 Kane and Mele, Phys. Rev. Lett. 95, 226801 (2005)。只借用次近邻 SOC 的结构形式。
 Walls and Milburn, Quantum Optics (2008)。位移/压缩算符与二阶矩恒等式。

 ### 4.4 可能还剩下的位置

 如果还有新意，它不在“量子光能改 HHG”，而在：把位移压缩光的 Delta n=0 与 Delta n=±2 相干块，映射到 Néel-odd 的有限时间复响应系数 A,B,C 上，并说明哪些部分来自输入统计几何 R，哪些来自磁序/SOC 通道，哪些来自有限时间电子动力学。

 截至目前的文献检索，尚未看到直接把可控位移压缩光或 BSV 用到双层 AFM CrI3、并研究这一套 A/B/C 分解的实验或同等理论。这只是检索判断，不是全球不存在的证明。

 ## 5. 模型、协议和观测量

 同一输入光、同一偏振、同一时间参考，只整体翻转上下层交换场，得到 +N 与 -N。电流之和/之差分别是磁序偶/奇分量。这里的奇偶针对 Néel 矢量，与谐波阶数 q 的奇偶无关，所以 H2 也可以有磁序奇分量。N 是静态标签，没有让光与磁畴形成叠加态。

 Peierls 代换把晶格动量平移 g s(t) e X_hat，其中 X_hat 是光场算符。只有一个光模，同时连到 k 与 -k。初态是耦合关闭时的电子基态直积输入光态。

 s(t) 是 1 周期升沿、4 周期平台、1 周期下降沿的耦合开关，不是实验自由传播脉冲的电场包络。不能把 Q6 说成一束 496 fs、某个已知 W/cm^2 的实际激光。

 在主窗 [2 T_0, 4 T_0] 对奇电流做正频 Fourier 投影，q=2 称为 H2 邻域。结果是复数。二维振幅用 sqrt(|Jx|^2+|Jy|^2)。邻窗仍变化 16%–39%，所以这是有限时间复响应，不是已收敛的远场谐波产额，更不是光子计数。

 ---

 ## 6. 计算方法

 同一 Hamiltonian、同一输入、同一窗口，用两种方法。

 1. 截断 QED：电子-光子联合态直接演化，包含反作用。
 2. GH5：把输入 Wigner 函数写成相关二维高斯，5x5 Gauss-Hermite 节点，每个节点做带电流反馈的平均场演化，再加权。GH5 是求积阶数，不是 5 条轨迹。

 GH5 用于预测和参数扫描，QED 用于检验。两者偏差只说明近似精度，不自动等于量子优势。Fourier 端点修复后，六项解析测试通过。旧 PPT 里的 5.80 / 106.9° 来自修复前的主窗定义，已经作废。

 ## 7. 冻结的主要结果

 生产输入：|psi_theta> = D(0.5) S(0.3 e^{i theta}) |0>。

 | 量 | 值 | 正确读法 |
 |---|---:|---|
 | theta=pi / theta=0 奇电流二维振幅比 | 4.98 | 有限窗复振幅，不是产额 |
 | 协方差反转的 Jx 相位差 | 110.6° | theta=pi/2 与 3pi/2，初始方差相同，只反协方差 |
 | R = |M|/alpha^2 | 1.273 | 位移与异常关联已经能竞争 |
 | rho = |A|/|B| | 1.456 | QED，不是 GH5 的 rho |
 | arg(A/B) | 177.65° | 近对径干涉，主要是输入几何 |
 | B | (-3.3006+0.9537i) x 10^{-8} | Delta n=0 块 |
 | A | (+4.7434-1.5839i) x 10^{-8} | Delta n=+2 块 |
 | |C/A| | 1.54% | 反向项很小 |
 | 邻窗复变化 | 16%–39% | 不能称稳定谐波 |
 | SOC 扫描 arg((A+C)/B) 跨度 | 4.37° | 绝缘窗口负结果 |
 | K_M / K_B | 0.975–1.008 | GH5 上同一核读 alpha^2 与 M |
 | 有限时间核 | 73.7% | 占绝热核与 QED 之间原 79° 差 |
 | Ehrenfest kick on/off | -16.54° | 覆盖大部分剩余，不是全部 |
 | 主窗 QED/GH5 K_B | 0.868 | 奇通道压低约 13% |
 | 主窗 QED/GH5 K_M | 1.003 | 并不增强读 M |

 交换强度 eta 会大幅缩放 |A| 并转动 arg(B)，但近 pi 的 arg(A/B) 仍然钉在输入几何上。pi/4 留出预测误差 0.667%、0.425%、1.037%（分母是 |A|）。

 ## 8. A/B/C 解释到哪一层

 J_2^o(theta) ~ B + A e^{i theta} + C e^{-i theta}

 第一层，严格光子数块。固定电子动力学和探测窗后，J = Tr(rho_ph K)。B 读 Delta n=0，A 读 +2，C 读 -2。B 可以含正常占据、真空块和更高阶对角过程，不恒等于 K_B alpha^2。

 第二层，有效二阶读取，已验证但非恒等：J ~ K_B alpha^2 + K_M M(theta)。GH5 上 K_M/K_B ~ 1，所以 rho ~ R。QED 把 rho/R 从 1.00 修到 1.144，原因是奇通道 K_B 被压低，不是 K_M 被抬高。约 15% 余量住在 Delta n=0 块。

 第三层，R 窗口。R = O(1) 时干涉显著；R ~ 1 附近相消最强；R << 1 时压缩角几乎只是微扰。理想单模高增益时 R ~ n_s / n_d。因此在输入统计上，保持 R ~ 1 并不要求每模不到一个光子。这只是数学可行性，不是已经认证的实验光源，更不是 1600 nm 材料核与 Q6 相同的证明。

 第四层，电子门控。Néel 与 SOC 同时打开奇通道并缩放 ||K||。Delta=0 是定义性归零。SOC=0 是动力学门控，但能隙变成 1.066 eV。绝缘窗口内 SOC 扫描不把 arg(A/B) 拉离 pi（跨度 4.37°）。这是负结果，不是磁性相位指纹。

 第五层，绝对相位。平衡 chi^(2) 不能预测 Q6 的 arg(B)。同协议有限时间 Peierls 核解释原 79° 差的 73.7%。Ehrenfest 覆盖大部分剩余。仍有约 4° 的 GH5-QED 残差。不要写成相位严格相加等式。

 还没有闭合的一层：还不能从具体电子跃迁矩阵元出发，第一性预测 A,C 的完整复数值。目前能独立预测的是角向形式、R 窗口、通道开关，以及 arg(B) 的主要来源。

 ## 9. 明确不主张什么

 面对教授时，主动划边界比事后被问倒更有利。

 - 4.98 不是谐波产额，不是实验可测增强倍数。
 - 没有证明量子优势。相同二阶矩的经典随机光仍可能复现平均电流。
 - 非负 P 表示的 |M_cl| <= n_fl 只约束输入统计，不证明输出 H2 非经典。
 - arg(A/B) ~ pi 主要是输入几何，不是磁性指纹。
 - 材料没有优先读取 M。
 - 1600 nm 没有复现 110°。
 - M0 不是 CrI3 下折叠。full112 未证明完备。
 - SOC=0 不能写成所有磁性 SHG 的普遍选择定则。
 - 平均电流不是输出光子统计。C_JJ、g^(2)、纯 BSV 非经典性是另一篇文章的问题。

 ---

 ## 10. 与实验相关 BSV 还有多远

 距离分成四段，不要混成一句“还差参数扫描”。

 1. 光源统计：从 R=O(1) 的低占据 DS，到高增益、可锁相的位移压缩或纯 BSV。数学上 R 可以在高亮度下保持，实验上要解决锁相、损耗、多模和标定。
 2. 场的归一化：Q6 的 g 还没有对应到实验模式体积和 W/cm^2。
 3. 电子动力学：24.8 μm 深度失谐不等于 1600 nm 下 1.55 eV 的 H2。即使 R 相同，K_B、K_M 和高阶过程都可以变。
 4. 材料模型：需要经审计的 Wannier/SBE，而不是把 M0 参数改一改。

 当前论文若要写，题目应限定为 quantum-light-controlled magnetic second-harmonic response in a PT antiferromagnet。研究边界写进方法：有限时间窗、few-k、低占据位移压缩态、无经典 P 输出对照。

 ## 11. 建议向 Cohen 教授请教的问题

 不要问“我们能不能发 Nature Physics”。问他能用专业判断直接回答的问题。

 1. 在已经有 Gorlach 2023、Rasputnyi 2024、压缩相干态固体 HHG 和 2026 年石墨烯禁戒谐波工作的背景下，Néel-odd 通道上的 A/B/C 分解是否仍构成一个清楚的理论问题，还是只会被看成已知量子光 HHG 的一次模型演示？
