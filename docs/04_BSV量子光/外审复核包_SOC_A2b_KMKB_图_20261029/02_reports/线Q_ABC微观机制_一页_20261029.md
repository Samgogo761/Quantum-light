# 线 Q：A/B/C 微观机制一页结论（2026-10-29）

无新 QED。只读重分析 + 八带 k/-k 完整 Peierls 因果核。生产态是 alpha=0.5、r=0.3，不是 alpha 约 1.41。

## 1. 修复 Fourier 以后，压缩角改变 H2 复响应是否仍成立？

**成立，但是有限时间复响应，不是认证产额。** 主窗 [2T0,4T0] 冻结值：

| 指标 | 更新值 |
|---|---|
| theta=pi / theta=0 的 H2 奇电流二维振幅比 | **4.98**（旧约 5.80） |
| 协方差反转对应的 Jx 相位差 | **110.6°**（旧约 106.9°） |
| Q6 三个交换强度的留出预测误差 | **0.667%、0.425%、1.037%** |
| 邻窗复变化 | 仍约 **16%–39%** |

QED eta=1 奇 Jx：B=(-3.301+0.954i)×10^{-8}，A=(4.743-1.584i)×10^{-8}，|C/A|约 1.54%，rho=|A|/|B|=**1.456**。

## 2. A/B/C 目前解释到什么物理层次？

三层，不要混：

1. **严格：** 固定动力学下 J=Tr(rho_ph K)。B 读 Delta n=0，A/C 读 Delta n=±2。
2. **本轮可独立预测：** 若 J 约等于 K(alpha^2+M)，则 rho 应由 |M|/alpha^2=**1.273** 给出，arg(A/B) 约 **180°**，协方差反转角约 2 arctan(rho)。实测 arg(A/B)=**177.7°**；用实测 rho 得到 111.0°，对上 110.6°。材料只把场比修正约 **14%**。偶通道 rho=0.015，同一相干被位移本底淹没。
3. **尚未闭合：** 绝热 chi^(2)(omega,omega) 相位与 QED 窗相位差约 **79°**。净奇核是 t0（0.518）与接触项 t1（0.525）近相消后的 0.017。Delta=0 时奇核精确为 0；SOC=0 时该 k 对二阶奇/偶核都约 10^{-13}。**A 不是 chi^(2)，也不是 K_N。**

Q6 能出约 110° 的主因是输入统计窗口 |M|>alpha^2，不是材料把 Delta n=±2 放到 Delta n=0 之上。

## 3. 有没有值得继续研究、能够接近实验的磁性信号？

有线索，还没有实验口径下的同一效应。

- 八带 Q6：Néel-odd H2 没有大位移本底，压缩角可以 O(1) 地改复相位/振幅。这是理论主线。
- 1600 nm 明亮位移压缩：|M|/alpha^2=0.25，只剩约 5/3 强度比和 **0.925°** 相位差。机制没死，是宏观位移淹没了 M。
- 真实 Wannier M52 相干光：2×2/4×4 已证明实验波长下存在 Néel-odd H2，但网格一加密振幅降约 6.6 倍。存在性过关，定量未过关。相干光磁性 H2 本身不是本课题终点。

接近实验时，应寻找可控小位移、外差/偏振/归一化比值，而不是复制 4.98 倍。

## 4. 下一轮最必要的一次新计算是什么？

**不要加密 M52，也不要先做 nmax=10 全套 QED。**

最小必要计算：Q6 协议下，用现有 GH5 做 **Delta=0 与 SOC=0** 两路对照（theta=0/pi 即可），检验动力学是否继承核的对称性门控。
预算：本机或现有 CPU，大约数十分钟量级，远小于 nmax=10。
并行、仍可本机完成：把因果核改成与 Q6 相同的有限时间窗，解释 79° 相位差。
