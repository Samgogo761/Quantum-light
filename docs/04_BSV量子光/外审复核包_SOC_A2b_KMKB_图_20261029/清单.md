## 2. 两角代理：必须写在复核前面

SOC GH5 只用 \(\theta=0,\pi\)：

\[
B_{\mathrm{proxy}}=\frac{J_0+J_\pi}{2},\qquad (A+C)_{\mathrm{proxy}}=\frac{J_0-J_\pi}{2}.
\]

**不能拆开 \(A\) 与 \(C\)。** 已有判定是 \(\arg((A+C)/B)\) 钉在 \(\pi\) 附近，不是“SOC 永远不能把 \(\arg(A/B)\) 拉离 \(\pi\)”的定理。四角 QED 只在冻结工作点给出独立 \(A,B,C\)。不要为了拆开代理去升级 nmax 或全角 QED。

## 4. 明确不要从本包推出的主张

- 量子优势，或非负 \(P\) 经典界已被输出观测量打破。
- 4.98 是谐波产额增强。
- 材料优先读取 \(M\)（\(K_M/K_B\approx 1\)）。
- 1600 nm 复现 110° 相位旋转。
- M0 等于 CrI₃；full112 空间完备。
- \(K_B\) 前窗变号是第二条磁性选择定则。
- SOC 把 \(\arg(A/B)\) 拉离 \(\pi\)（本扫描未发生；两角代理也证明不了“永远不能”）。
- \(\phi_{\mathrm{QED}}=\phi_{\mathrm{finite}}+\phi_{\mathrm{Ehrenfest}}\) 严格等式。
- \(B\equiv K_B\alpha^2\) 作为算符恒等式。有效模型 \(K_B\alpha^2+K_M M\) 已经过数值验证，但不是 Hamiltonian 恒等。

## 5. 建议论文定位（给外审对照）

位移压缩态的 \(\alpha^2\) 与 \(M\) 在同一 Néel-odd、SOC 门控的 H2 通道上干涉。O(1) 对比度由 \(R\gtrsim 1\) 控制。SOC/Néel 开门并缩放 \(\|K\|\)，在已扫描的绝缘窗口内不把 \(\arg(A/B)\) 拉离 \(\pi\)。主窗相位 ≈ 有限时间核 + Ehrenfest，外加约 4° 的 QED 残差。QED 相对 GH5 的 ~15% 余量住在奇通道 \(K_B\)，不是增强的 \(K_M\)。CrI₃ few-k 只支持磁性 H2 存在性，不支持定量收敛。

定位建议：quantum-light-controlled magnetic SHG / finite-time complex response。不要包装成非微扰 cutoff HHG，也不要包装成必须击败一切资源匹配经典光的量子优势论文。
