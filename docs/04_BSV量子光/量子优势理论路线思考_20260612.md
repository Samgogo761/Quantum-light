## 0. 战略定位:三层阶梯(先想清楚自己站在哪一层)

```text
R1 半经典强度平均(现在)
   Gorlach 路线:BSV → 经典场系综 {E(t;I,φ)},对 P(I)=e^{-I/I₀}/I₀ 平均。
   属"无量子优势"区,但 双层 CrI3 HHG + 量子光驱动本身是空白 → 论文 1 站得住。
   确定性求积(本目录另一文档)就是把这层做干净。

R2 输出光的非经典性(下一篇的核心,风险低、增量大)
   不声称"输入有优势",改问:CrI3 发出的谐波光场本身是什么量子态?
   压缩了吗?谐波之间纠缠吗?亚泊松吗?磁序 N 在光子统计上留下什么指纹?
   只需 QRT 二阶电流关联 + 高斯态工具,与 González-Monge/Feist 不冲突
   (他们说的是"驱动统计可被经典混合复现",没说"输出光是经典的")。

R3 严格量子优势(高风险长线)
   构造一个任何经典强度分布 P_cl(I) 都无法复现的可观测量/估计精度。
   需要 R2 的全部机器 + 凸分析(矩问题)形式化。建议放最后。
```

**思考滤网**(评估任何候选"量子签名"时连问三个问题):
```text
(i)   它是否只通过强度分布 P(I) 进入? 是 → 必被经典复现,放弃(Feist 定理覆盖区)。
(ii)  它是否依赖场的相位结构 / 反常关联 ⟨aa⟩ / 光子数离散性(配对、偶数性)?
      是 → 候选量子签名。
(iii) 在 T2≈10 fs 与可实现样本量下数值可分辨吗? 先估量级再谈叙事。
```

## 1. 必备理论模块(按用途分组)

### A. 相空间表示与"经典性"的精确定义
- **Glauber–Sudarshan P 表示** 与光学等价定理:正常序观测量
  ⟨:f(a,a†):⟩ = ∫d²α P(α) f(α,α*)。"经典态" ⟺ P 是合法概率密度。
- 关键事实 1:**BSV(压缩真空)的 P 非正定** → 输入态本身非经典。
- 关键事实 2:**相位平均也杀不死 BSV 的非经典性**:其光子数分布只有偶数占据
  (SU(1,1) 光子配对)。任何相干态的经典混合都有 P(n)>0 ∀n,
  而 BSV 的 P(odd n)=0 —— 这是经典混合不可能复现的指纹。
  (你笔记里的 Δn=2 选择性、崩塌复苏 T_R 减半,都是同一代数事实的不同表现。)
- González-Monge/Feist 论证的精髓:强场半经典极限下,物质响应只通过
  **强度包络** 进入 ⟹ 有效信息退化为 P(I) ⟹ 可经典复现。
  **突破口必然在"不只通过强度进入"的耦合或观测量**(见 §2 Step 2)。

### B. 高斯量子信息(输出光的母语)
- 协方差矩阵 σ、辛变换、Williamson 分解;两模压缩态。
- 纠缠判据:Simon 判据 / Duan 判据(高斯态充要);
  **对数负性 E_N**(高斯双模有闭式,Vidal–Werner)。
- 为什么高斯够用:位移表象中谐波模式由电流线性源驱动(一阶 Dyson),
  输出 ≈ 位移热/压缩态;非高斯性来自高阶 Dyson 项,先放后面。

### C. 量子估计理论(R3 的语言)
- Cramér–Rao 界、SLD、量子 Fisher 信息 QFI;Bures 度规。
- **高斯态 QFI 有闭式**(只需均值矢量与协方差矩阵对参数的导数)。
- R3 判据:F_Q^(quantum drive)(θ) > sup_{P_cl} F^(classical mixture)(θ)。
  右边是对强度分布的优化 —— 数学上是**矩锥/凸分析**问题(见 E)。

### D. 开放系统与多时关联
- **量子回归定理**(Lax):⟨J(t)J(t')⟩ = Tr[v U(t,t')(v ρ(t'))]。
  适用条件 = 马尔可夫退相干;我们的 T2 模型(瞬时基纯退相)正是 Lindblad 型,适用。
- **压缩库主方程**(教科书模板:Gardiner & Zoller《Quantum Noise》):
  二能级/谐振子浸在压缩真空里,Bloch 方程的横向弛豫各向异性
  (T_x ≠ T_y,随压缩角旋转)。这是 §2 Step 2 修正主方程的原型 —— 把"库"换成
  "驱动模式的量子涨落"即可。

### E. 非经典性见证与凸界(可数值检验的不等式)
- Mandel Q_q < 0、g²(0) < 1:单模见证。
- **Shchukin–Vogel 矩判据层级**(2005):用有限阶矩判定非经典性/纠缠,
  正是"算得出的关联函数 → 严格非经典证书"的桥梁。
- **Hausdorff/Stieltjes 矩问题**:给定 ⟨I^p⟩ 可达观测值的集合是矩锥 —
  把"任何 P_cl(I) 都无法复现"变成可计算的凸可行性问题。R3 的数学核心。

## 2. 框架怎么改(从现有 SBE 出发的两步升级)

现有方程:`dρ/dt = -i[H₀ + E_cl·D, ρ] + E_cl·∇_k ρ + L_deph[ρ]`,E_cl 是 c 数。

### Step 1(QRT 二阶关联 → R2 全部观测量)
不改运动方程,只增加演化对象:在源时刻 t' 构造辅助算符 χ_b(k,t') = v̂_b(k)ρ(k,t'),
用**同一个传播子**演化到 t,得
```text
C^{ab}(t,t') = Σ_k Tr[ v̂_a(k) U(t,t')[ v̂_b(k) ρ(k,t') ] ]
```
频域 C^{ab}(ω_q, ω_q') 直接给出输出多模高斯态:
```text
β_q   ∝ ∫dt e^{iω_q t}⟨J(t)⟩          (均值,已有)
σ_qq' ∝ C^{ab}(ω_q, ω_q')              (协方差 → 压缩谱、E_N、Mandel Q、QFI)
```
注意点:χ 非厄米,退相干对它的作用要重新推一遍(QRT 下仍是同一 Lindblad 超算符,
但代码里"瞬时基对非对角衰减"的实现要验证对非厄米算符的正确性)。

### Step 2(输入量子统计的二阶进入 → 超出强度平均的第一个效应)
对 δÊ 做二阶微扰(Redfield 型),修正主方程多出双对易子项:
```text
dρ/dt = …经典项… - (1/ħ²)∫₀^t dτ { C_N(τ) [d(t),[d(t-τ),ρ]] + C_A(τ) [d(t),[d(t-τ),ρ]]_anom + h.c. }
其中  C_N(τ) = ⟨δa†δa⟩ 型(正常关联,经典噪声也能给)
      C_A(τ) = ⟨δa δa⟩ 型(反常关联)= e^{iθ} sinh r cosh r × 相位因子
```
**物理判别**:经典随机场只能给 C_N ≥ 0 的加性噪声;C_A 是压缩特有的
**相位敏感**通道,其亚真空部分原则上不可经典复现。
直接预言:谐波谱/偏振对**压缩角 θ** 的依赖 —— c 数强度采样里根本没有 θ 这个参数。
这是第一个具体的、可计算的、超出 R1 的观测量。

### Step 3(R3 形式化)
定义观测量 O 的经典可达集 C = {∫dI P_cl(I) O_cl(I) : P_cl 任意分布}(矩锥)。
证明/数值演示某个 O*∉C。最有希望的候选:
θ-依赖观测量(Step 2)、谐波两模纠缠 E_N>0(R2 输出)、C_oo 磁性通道的相位敏感部分。

## 3. 推导作业清单(带依赖顺序)

```text
1. 位移表象二阶 Dyson → 输出高斯态 (β_q, σ_qq') 用 C^{ab}(ω_q,ω_q') 表达。
   [Stammer 框架适配到旋量 SBE;R2 的总纲]
2. QRT 表达式 + 退相干下非厄米辅助算符的演化一致性。 [Step 1 的代码前提]
3. BSV 二阶修正主方程(含 C_N/C_A),并显式标出:
   只保留 C_N 的对角部分 ⟺ 强度平均(R1) —— 看清量子残差到底是哪几项。 [Step 2 核心]
4. 谐波两模 E_N 高斯闭式 ← σ。  [R2 产出]
5. Mandel Q_q、g²(q,q')。       [R2 产出,Shchukin–Vogel 证书]
6. Gaussian QFI(N, J_ex) + 经典混合上界的矩锥表述。 [R3]
7. (独立支线)k 分辨两带 JC 崩塌复苏:T_R = π√n̄/g(k),BSV 减半。
   诚实评估:自由空间宏观模式体积下 g 极小 → T_R 天文数字;
   此线只能作为"腔增强方案/概念论证",不是材料预言。
8. C^{ab} 的 Néel 宇称分解 C_ee + |N|²C_oo + 磁点群对二时关联张量的选择定则
   (Neumann 原理推广到双时响应)。 [CrI3 独有卖点:磁性标记的光子关联]
```

## 5. 诚实的风险与边界

```text
1. T2 ≈ 10 fs 会强烈压制光-物纠缠/压缩的积累:R2 的所有量必须带着 T2 算,
   预期量级偏小;先算数量级再决定叙事强度。
2. 输出高斯近似在强发射/级联区失效(高阶 Dyson);先在弱-中驱动区建立结论。
3. 崩塌复苏:固体+自由空间不可观测(模式体积),只能作腔方案概念。
4. R3 的"超经典上界"证明是凸优化+矩问题,难度高;建议作为长线,
   R2(输出非经典性 + 磁性标记)已经是独立可发表的增量。
```

## 6. 一句话路线
