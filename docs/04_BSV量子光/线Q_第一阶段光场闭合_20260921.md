## 2. 同模式两端与面积

约定 \(b=\int\phi(\omega)a(\omega)\,d\omega\)，\(\int\lvert\phi\rvert^2=1\)。真空、法线、横截面积 \(S\)：

\[
u(t)=\sqrt{\frac{\hbar Z_0}{4\pi S}}F^*(t),\qquad
K(t)=\frac{i}{\hbar}u^*(t)=i\sqrt{\frac{Z_0}{4\pi\hbar S}}F(t).
\]

理想均匀膜且模式面积等于样品面积时，\(S=N_{\mathrm{cell}}A_{\mathrm{uc}}\)。连通涨落组合 \(N_{\mathrm{cell}}/S=1/A_{\mathrm{uc}}\)。程序数值

\[
\eta^2 N_{\mathrm{cell}}=\alpha_{\mathrm{fs}}\frac{L_0^2}{A_{\mathrm{uc}}}=1.72013\times10^{-4},
\]

\(A_{\mathrm{uc}}=42.423\,\mathrm{\AA}^2\)，\(L_0=1\,\mathrm{\AA}\)。**没有**把六点 \(k\) 当成 \(N_{\mathrm{cell}}\)。平均相干场仍带 \(\sqrt{N_{\mathrm{cell}}}\)，本轮只报 \(\beta/\sqrt{N_{\mathrm{cell}}}\)。

源正常矩乘 \(+\eta^2 N_{\mathrm{cell}}\)；源异常矩乘 \(-\eta^2 N_{\mathrm{cell}}\)（来自 \(i^2\)）。

## 3. 同阶项

\[
\delta b_{\mathrm{out}}=b_{\mathrm{in}}+\lambda s_1+\lambda^2(A_2 b_{\mathrm{in}}+B_2 b_{\mathrm{in}}^\dagger+\text{其它端口})+\cdots
\]

真空输入、电子与光初始独立时，保留 \(O(\lambda^2)\)：

\[
n=\langle s_1^\dagger s_1\rangle,\qquad
m=\langle s_1 s_1\rangle+B_2.

\(B_2\) 是裸输入与辐射响应的干涉，与源项同阶。旧 \(\lvert\alpha_-\rvert^2\)、\(\alpha_+\alpha_-\) 未使用。接触项在 \(\mathcal R^A\) 里，因而进入 \(A_2,B_2\)。

## 5. 对易关系与未闭合项

保留阶次要求 \(2\mathrm{Re}A_2+\langle[s_1,s_1^\dagger]\rangle=0\)。+N 残差 \(1.19\times10^{-7}\)。接触项对 \(\mathrm{Re}A_2\) 的贡献为 0（数值 \(10^{-19}\)）。

这只固定了 \(O(\lambda^2)\)。单模截断的完整

\[
\lvert 1+A_2\rvert^2-\lvert B_2\rvert^2+\langle[s_1,s_1^\dagger]\rangle=1+\lvert A_2\rvert^2-\lvert B_2\rvert^2\approx1.475
\]

不是 1。原因：\(\lvert A_2\rvert\sim0.7\) 在此六点样本上并不是小量（核重叠 \(\sim10^3\) 乘上 \(\eta^2 N_{\mathrm{cell}}\)）。其它真空端口与 \(O(\lambda^4)\) 未计入。生产 \(V(\theta)\) 仍只用 \(O(\lambda^2)\) 分项，协方差未裁剪。后续把该截断明确冻结为 Born / 一次反馈，见 [1C 回路关口](C:/Users/26507/Documents/New_SBEs/Quantum-light/docs/04_BSV量子光/线Q_第一阶段1C回路关口_20260921.md)。

**问题**：在已闭合的 \(O(\lambda^2)\) 之外，单模 \([b,b^\dagger]\) 还缺哪一块？  
**证据**：\(\lvert A_2\rvert=0.705\)，\(1+\lvert A_2\rvert^2-\lvert B_2\rvert^2=1.475\)。  
**备选解释**：(1) 其它正交真空端口应抵消 \(\lvert A_2\rvert^2-\lvert B_2\rvert^2\)；(2) 此六点上耦合并不弱，截断本身不足。不是授权把响应整段换成 c-number 通道，也不是把旧 \(\lvert\alpha\rvert^2\) 加进 \(V\)。

## 6. 两畴 \(V(\theta)\)（方法展示）

真空基准 \(V=1/2\)。零耦合极限：\(n=m=0\Rightarrow V=1/2\)。

|  | \(+N\) | \(-N\) |
|---|---:|---:|
| \(n\) | 0.6275 | 0.6312 |
| \(\lvert m\rvert\) | 0.5146 | 0.5177 |
| \(V_{\min}\) | 0.6129 | 0.6135 |
| \(V_{\max}\) | 1.642 | 1.649 |
| \(n-\lvert m\rvert\) | 0.113 | 0.113 |

相对真空，此六点在所有相位上 \(V>1/2\)。源项单独时 \(0.5+n-\lvert m_{\mathrm{source}}\rvert\approx0.588\)；加上 \(B_2\) 后 \(V_{\min}\) 升到 0.613（\(\lvert m\rvert\) 变小）。**不能**据此宣布压缩，也**不能**据此宣布连续 BZ 中两畴相同或不同。

物理问题仍是：电子涨落与响应对真空噪声是增加还是在某个相位压低。六点给出的是方法曲线，不是材料结论。
