# 线 Q：本轮验收与下一步，一页说明

2026-10-04，恢复额度中断后的记录。代码与四份结果已核对，源码哈希一致。

**这一轮有实际进展：连续光场接口已实现，正确初态进入八带电子程序的写法也通过了小样本验证。还没有得到磁畴相关的光子产额、压缩或纠缠结果。**

我们仍在解决同一件事：激光到来之前，电子和光场已经相互耦合；计算要从这样的基态出发，再得到远处收集的二次谐波光。不能在初始时刻把它们当成互不相关，然后把突然接通产生的信号误认为激光效应。

本轮完成了什么：

1. **连续光场有了可运行接口。** 光子频率从零到无穷直接解析积分，不再用有限光子振子替代外界光场。真实八带模型保留原始电子通道和接触项，独立检查最大残差约 3.6×10^-14。这仍是复频接口的验证，完整实频入射基态尚未构造完成。
2. **明确了应在哪些量上判断基态是否可计算。** 某些未经频率筛选的裸坐标，其基态方差可能发散。我们选定的二次谐波波包能抑制相应端点；解析条件和人工例子已经核对。这不是靠新增频率截止处理，也不是已经算出了光子数。
3. **正确初态修正已经接到真实八带电子演化。** 两个磁畴、两个动量点、原激光波形的前半周期，26 项检查通过；时间步减半，传播误差约降为四分之一。初态投影的接入误差约 2.8×10^-9。故意遗漏这一初态修正，就出现明显错误。这里检验的是程序中的局域映射，不代表全脉冲或整个布里渊区已经合格。

下一步应当做：

**把这套正确的初态列，放进同一组连续入射算符下的电子—光场增量传播。** 先核对极低频的静态规范部分如何与态响应、电流显式变化及电磁反馈配合，再控制真正探测波包需要的时间尾。目标是实现既定物理，不是重新挑 Hamiltonian、基态或激光参数。

仍有两个明确未完成处：

- 复频接口不等于完整实频基态；原始电子通道、可能的暗/点谱贡献要完整接入。
- 脉冲结束后，电子不一定立即停止辐射；不能把有限时刻的内部光子坐标直接当作远场输出。

本轮没有新的物理选择需要你重复批准，也不需要服务器大作业。若数学分析确实要求改变初态、规范、场的有效频率范围或 Gaussian 近似，会带着具体冲突来与你讨论。

近期科学目标仍是：固定实验装置，翻转双层 AFM 磁畴，二次谐波两个偏振之间的相位敏感光—光关联是否改变。当前 N=±1 是经典磁畴标签，还不能称为光与“量子叠加磁畴”的纠缠。
