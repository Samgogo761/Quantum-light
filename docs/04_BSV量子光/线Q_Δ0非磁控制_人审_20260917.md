## 1. 本模型里 \(\Delta\) 是什么（不要和 Néel 符号混用）

代码里交换场大小是参数 `M0Params.delta = 0.8`（R0，单位 \(t_h\)）。Néel 标签 `neel = ±1` 只改变上下层的符号：

\[
h_{\mathrm{top}}=+\texttt{neel}\cdot\Delta\,\sigma_0 s_z,\qquad
h_{\mathrm{bot}}=-\texttt{neel}\cdot\Delta\,\sigma_0 s_z.
\]

所以：

| 写法 | 实际对象 |
|---|---|
| \(d(+N)\)、\(d(-N)\) | 同一 \(\Delta=0.8\)，两套相反交错磁化 |
| \(\Delta=0\) | 交错交换场整项去掉；此时 `neel=+1` 与 `neel=-1` 的 \(H\) **完全相同**（本机残差 \(0\)） |
| FM 同号交换 | 上下层都是 \(+\Delta\) 或都是 \(-\Delta\)；**不是** 现成的 `h8(neel)` 路径 |

外面写的 \(d(+\Delta)\)、\(d(-\Delta)\) 应读成 \(d(+N)\)、\(d(-N)\)。\(\Delta=0\) 不是第三种 Néel 方向，是把交错磁化幅度关掉。

因此 \(\Delta=0\) 上的“磁畴差”是恒等式：

\[
d_{\mathrm{domain}}(\Delta=0)\equiv 0,
\]

不是测出来的。真正新的数只有 \(d(\Delta=0)\)，拿来和已经有的 \(d_e(\Delta=0.8)\) 比。

## 2. 静态事实：关掉 \(\Delta\) 会把能隙放大约九倍

nk=48、仍占 4 个带：

| 模型 | 直接隙 \(E_g^{\mathrm{dir}}\) | \(E_g^{\mathrm{ind}}\) | P1 \(\hbar\omega_1/E_g^{\mathrm{dir}}\) | 两畴 \(H\) 是否相同 |
|---|---:|---:|---:|---|
| R0 AFM \(\Delta=0.8\)，\(\pm N\) | \(0.093\,t_h\) | \(0.093\,t_h\) | \(0.54\)（单光子亚带隙，两光子过门槛） | 否（差 \(2\Delta=1.6\)） |
| \(\Delta=0\) | \(0.862\,t_h\) | \(0.861\,t_h\) | \(0.058\)（深亚带隙） | 是 |
| 同号 FM（两层都 \(+\Delta\)） | \(0.001\) | **负**（间接重叠） | 不再是同一绝缘体 | — |

R0 的低能结构是：无层间耦合时，上下层带子在 \(\sqrt{t_h^2|f|^2+\lambda^2 g^2}=\Delta\) 的**环**上交叉，\(T_0\) 再把环打开成 \(\sim 0.09\,t_h\) 的反交叉隙。\(\Delta=0\) 以后这条环不存在，隙变成 \(\sim 0.86\,t_h\)，主要由层内带宽/SOC/层间耦合决定。

经典平均电流已经用过 \(\Delta=0\)：\(J_o\equiv 0\)（严格）。那是代码路径检查，**不是** CJJ，也不是“磁性对涨落没影响”的证据。

同号 FM 在 R0 参数下接近半金属（间接隙为负）。**不能**把 M0 的 AFM↔FM 直接说成双层 CrI\(_3\) 那种绝缘体磁相切换。CrI\(_3\) 电控 AFM/FM（Huang 等, Nat. Nanotechnol. 2018）和 SHG（Sun 等, Nature 2019）说明真实材料里磁序能进经典非线性光学；它们不给 M0 的 FM 对照颁发绝缘许可证。

## 3. 建议的两个量：定义可以留，解释必须加限制

若只比较**同一个源窗口**（建议先仍用已稳定的 \(d_{2x,2x}\) 共同部分，不要用未解析的 \(d_o\)）：

\[
d_{\mathrm{domain}}=\tfrac12\bigl(d(+N)-d(-N)\bigr)=d_o,
\]

\[
d_{\mathrm{mag}}=d_e(\Delta=0.8)-d(\Delta=0).
\]

- \(d_{\mathrm{domain}}\)：问题 A。现在未解析。
- \(d_{\mathrm{mag}}\)：问题 B 的**第一层**。若非零，只能说“把交错交换场整项去掉以后，这个源核变了”。

不能把 \(d_{\mathrm{mag}}\neq 0\) 写成“差异来自磁性量子几何”。因为它同时包含：磁序去掉、环状小隙变成大隙、P1 从“两光子刚过门槛”变成“十几个光子才到隙”。这与外面那篇“第一步只问总体影响”一致，但幅度比“隙可能变一点”大得多。

## 4. 若批准，三种公平口径（请选一种，不要三种一起跑）

**口径 1（最小、不公平但干净）。** 脉冲、窗口、占据数、CJJ 定义全部与现在的 P1 相同，只把 `delta` 设为 0，跑**一条**畴即可（\(\pm N\) 重复）。得到 \(d(\Delta=0)\)，再算 \(d_{\mathrm{mag}}\)。  
解释：这是“同一束实验室光打在 AFM M0 与无交错交换的兄弟姐妹上”。不解释成等共振条件对照。

**口径 2（先看隙，再决定要不要 CJJ）。** 只做静态：\(\Delta=0.8,0.4,0.2,0\) 的 \(E_g\)、占据与 \(\hbar\omega_1/E_g\)。若你看到隙几乎单调决定共振条件，可以决定 CJJ 不值得在口径 1 上烧。仍不改 P1，除非你另批改驱动。

**口径 3（更像“只关磁性”）。** 另造一个非磁参考，把隙调回 \(\sim 0.09\,t_h\)（例如动 \(u,v\) 或 \(\lambda_{\mathrm{SO}}\)）。这是**另一套模型**，比 \(\Delta=0\) 更重，不是最小控制。

不建议把 R0 参数下的同号 FM 当作第一对照。若目标是磁相探测，需要先单独审一套仍绝缘的 FM 参数，不能借用 CrI\(_3\) 实验默认 M0 的 FM 可用。

## 5. 并行、仍停在人审上的两件事（本轮也不自动开算）
