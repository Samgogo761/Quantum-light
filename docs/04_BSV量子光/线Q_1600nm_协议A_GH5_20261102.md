## 0. 一句话结论

在 **GH5、单 \(k/-k\)、抽象 \(g=0.005\,\mathrm{\AA}^{-1}\)、1+4+1 约 32 fs 耦合开关** 下，压缩角仍然进入 Néel-odd H2；四角 A/B/C 拟合的独立 \(\theta=\pi/4\) 留出相对误差为 **0.0115%**，未触发 \(\Delta n=\pm 4\) 闸门。

verdict：`mechanism_survives_frequency_bridge_gh5_only`

这只说明：**同一 \(R\) 下，频率从远红外改到 1600 nm 之后，GH5 平均电流里的统计干涉没有消失。** 它不是精确 QED，不是远场产额，不是 25 fs 高斯脉冲，也不是实验室 BSV。

禁止把 Q6 的 4.98 或 110.6° 抄到 1600 nm。本工作点的振幅比是 **8.778**，\(\arg(A/B)\) 是 **179.04°**。

## 2. 四角主窗（\(\theta=0,\pi/2,\pi,3\pi/2\)）

观测量：矩形窗 Fourier

\[
J_q=\frac{1}{t_1-t_0}\int_{t_0}^{t_1} e^{+iq\omega_0 t}\,J(t)\,dt
\]

主窗 `plateau_center_2T`：\(t\in[2T_0,4T_0]\)。这是有限时间复电流，**不是**辐射产额。

| 量 | 1600 nm GH5 | 说明 |
|---|---|---|
| H2 奇振幅比 \(\theta=\pi/0\) | **8.778** | 有限窗 \(\|J_2^o(\pi)\|/\|J_2^o(0)\|\) |
| \(\|J_2^o(\theta=0)\|\) | \(9.934\times 10^{-6}\) | 主窗 \(J_x\) |
| \(\|J_2^o(\theta=\pi)\|\) | \(8.720\times 10^{-5}\) | 主窗 \(J_x\) |
| \(\rho=\|A\|/\|B\|\) | **1.274** | 几乎等于本点 \(R=1.273\) |
| \(\arg(A/B)\) | **179.04°** | 近反相 |
| \(\|C/A\|\) | **1.61%** | \(\Delta n=-2\) 通道仍小 |
| 四点相对残差 | \(4.29\times 10^{-5}\) | 四点**不能**排除 \(e^{\pm 2i\theta}\) |

负结果闸门（压缩角不再进奇 H2 → 收口，不调 SOC/\(g\)）**未触发**。`amp_ratio=8.778 > 1.20`。

\(\rho\approx R\) **只是当前工作点的数值巧合/有效关系，不是定理。** 不得推广成“材料总是把 \(R\) 原样读成 \(\|A\|/\|B\|\)”。

## 3. \(\theta=\pi/4\) 独立留出（本轮完成）

四角拟合得到 \(B,A,C\) 后，用从未进入拟合的 \(\theta=\pi/4\) 检验

\[
J_2^o(\theta)\stackrel{?}{=} B+A e^{i\theta}+C e^{-i\theta}.
\]

| 量 | 值 |
|---|---|
| 实际 \(J_2^o(\pi/4)\) | \(6.497\times 10^{-6}-i\,3.413\times 10^{-5}\) |
| A/B/C 预测 | \(6.494\times 10^{-6}-i\,3.413\times 10^{-5}\) |
| \(\|J_2^o(\pi/4)\|\) | \(3.474\times 10^{-5}\) |
| 相对误差 | **\(1.15\times 10^{-4}\)** = 0.0115% |
| 相位差 | \(0.006^\circ\) |
| 闸门 \(\lesssim 2\%\) | **通过** |
| `needs_delta_n_pm4` | **false** |

在 GH5、本工作点、本探测窗下，三项 A/B/C 足以描述角向响应；**没有**被迫承认 \(\Delta n=\pm 4\)。

这仍不能证明更高阶 Fock 相干块在精确 QED 里一定可忽略。GH5 是 Wigner 求积平均电流，不是 Fock 空间完备展开。

外层 GH 节点上 Weyl \(\langle n\rangle\) 已经顶到 \(\approx 7.91\)。Q6 精确 QED 用的 \(n_{\max}=8\) **不能**因为平均光子数只有 0.343 就直接沿用。当前 **不调 \(g\)**。

GH5 的节点传播 **不是** Fock 空间维数。不要把 GH5 的 25 个节点和 QED 的 \(n_{\max}\) 混为一谈。

## 6. 本结果允许说什么、不允许说什么

允许：

1. 在协议 A 的 GH5 定义下，压缩角仍调控 Néel-odd H2 复电流。
2. 同一 \(R\) 的 A/B/C 三项形式，在本点被独立 \(\pi/4\) 留出支持。
3. 负结果闸门未触发，因此 **不** 以“1600 nm 杀死机制”收口。

不允许：

1. 写成精确 QED 或 Cohen 组 MTEF。
2. 写成 1600 nm 实验、25 fs BSV、或宏观光子数。
3. 把 8.778 写成产额增强 8.778 倍。
4. 把 \(\rho\approx R\) 写成普适材料定律。
5. 把单 \(k/-k\) 写成全 BZ 或 CrI₃ 定量预测。
6. 启动协议 B、纯 BSV、SOC/\(\Delta\) 扫描来“做大数字”。
