## 允许保留的物理判断

1. **M0 在该协议下存在 Néel-odd H2。** 相干光、BSV、位移压缩态都给出非零磁序奇 H2。
2. **位移压缩 \(\theta=\pi/\theta=0\) 的主差来自场 \(\langle E^2\rangle\) 的 \(5/3\)，不是磁性核的特色读取。**
   - 电子 DS 二维比 **1.56160**，\(J_x\) 比 **1.56587**，相位差仅 **0.925°**。
   - 纯场级 \(\langle E^2\rangle\) 的 DS \(\pi/0\) 比是 **1.66666666557 \(\approx 5/3\)**，相位差 0。
   - 电子材料只把 \(5/3\) 修正约 **6.3%**。
3. **没有复现 Q6 的 \(\sim110^\circ\) 相位旋转。** 1600 nm 两压缩角几乎同相。
4. **纯 BSV 的 even/odd \(\sim10^{-12}\) 是反演对称性，不是发现。** 两畴相干源强度在该协议下必须相同。
5. **Q6 低占据位移压缩机制可以保留为理论基准，但不能当作本轮实验相关主发现。**

## 数值尚未过关的部分

- 畴反差未收敛：相干光 nk=6/12/21 的 x-contrast \(\approx +0.047 / -0.303 / -0.148\)。
- GH5/7/9 在 nk=6 的 BSV odd 约 4% 摆动。
- 现用 GH 是**只沿反压缩轴的 1D GH**，压缩轴真空被丢掉；高增益求积未认证。
- \(I=10^{11}\,\mathrm{W/cm^2}\) 窗口变化 23%–53%，DS 比降到约 1.116，**不得作主结论**。
- Q-MATH 仓库内最新完成报告是 **16.30**；16.31 不是已完成工作。
