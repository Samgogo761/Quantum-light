# 线Q 方案C输出变换（一页）

用户已确认方案 C。本轮只做定义、变换表和小型代数验证，不运行 P1。

## 固定装置

两畴使用同一个 P1 波形、入射端口、偏振、CEP、时间零点、初态规则和收集波包。只改 \(N\to-N\)。

\(A\to-A\) 是场波形反号，不是 \(+z\to-z\)。端口交换只出现在数学 \(P/T\) 解释层。

## 已验证

- 现有 P1 的 `sign=-1` 精确等于 \(-A(t)\)。
- \(P H_N(k+A)P^\dagger=H_{-N}(-(k+A))\)，残差 \(3.93\times10^{-17}\)。
- 电流负号约定残差 \(2.78\times10^{-16}\)。
- 相同面电流给出相同的左右出射辐射，残差 0。
- 单独改输出模式相位会改变 \(\beta,m\)，但不改变 \(|\beta|\)。

## 候选，不是结论

固定装置下，\(P,T,PT\) 都不给出 \(n(+N)=n(-N)\) 或 \(m(+N)=-m(-N)\)。

第一个值得算的候选是同侧、同偏振、固定相位参考的 \(m_{\mu\nu}\)；同时记录 \(|\beta|^2+n\) 作为强度对照。允许非零不等于已经非零。
