## 1. 电流约定（本项目，不是文献通用记号）

代码：\(\hbar=e=1\)，\(\boldsymbol\kappa=\mathbf k+\mathbf A\)，

\[
\hat I_a=-\frac{\partial\hat H}{\partial A_a}= -\frac{\partial\hat H}{\partial k_a}.
\]

每原胞核 \(c\) 是总源关联除以真实原胞数。**数值 \(k\) 点数不是 \(N_{\mathrm{cell}}\)。**

二阶导数（接触项）

\[
\hat D_{ab}=\frac{\partial^2\hat H}{\partial A_a\partial A_b},
\qquad
\hat I_a[A_{\mathrm{cl}}+\delta A]=\hat I_a^0-\hat D_{ab}^0\delta A_b+\cdots.
\]

解析 \(D\) 与 `current_ops` 中心差分在六点 \(k\) 上相对差 \(3.2\times10^{-8}\)。

## 2. 完整 \(C^>\) 已含对易子（公式层面）

\[
C^>_{ab}(t,t')=\langle\delta\hat I_a(t)\delta\hat I_b(t')\rangle,
\qquad
\langle[\hat I_a(t),\hat I_b(t')]\rangle
=C^>_{ab}(t,t')-C^>_{ba}(t',t).
\]

在每原胞 \(X\) 语言里，后者等于 \(c-c^*\)。存量六点快照上该恒等的数值残差为 **0**。

外部常用

\[
R^{\mathrm{std}}_{ab}=-\frac{i}{\hbar}\theta(t-t')\big(C^>_{ab}(t,t')-C^>_{ba}(t',t)\big).
\]

本约定下对经典测试场

\[
\boxed{
\mathcal R^A_{ab}(t,t')
=\frac{i}{\hbar}\theta(t-t')
\langle[\hat I_a^0(t),\hat I_b^0(t')]\rangle
-\langle\hat D_{ab}^0(t)\rangle\delta(t-t')
=-R^{\mathrm{std}}_{ab}-\langle D_{ab}\rangle\delta(t-t').
}
\]

**不能**写成 \(\delta I=+R^{\mathrm{std}}\delta A\) 并直接接到当前 \(I=-\partial_A H\)。这是约定与瞬时项，不是新材料参数。

把 \(D\) 和对易子换成数值期望值，是约化步骤，不是精确算符恒等式。

## 3. 磁盘数据 ≠ 公式信息

| 数据 | 有什么 | 能否还原任意因果 \(\mathcal R^A\) |
|---|---|---|
| a2 / 旧 x 的 **B0_sixk** | 完整 \(X(t)\)、\(Y\)、25 个快照 | 状态项可以（已做前缀积分核验） |
| V48 / V48S / V96 | \(Y_{1\ldots9}\) + 25 个 \(X\) 快照 | **不能**。禁止用 \(Y\) 插值伪造响应 |
| 快照上的 \(\langle D\rangle\) | 六点有 \(V_v(t_{\mathrm{snap}})\) | 大网格没有全时 \(V_v(t)\)，接触项不能从 \(Y\) 重建 |

在线形式（避免存整张两时表）：

\[
Z_k(t)=\sum_b\int^{t-}dt'\,X_{b,k}(t')h_b(t'),
\qquad
\delta\mu_a^{\mathrm{state}}(t)
=-\frac{2}{\hbar}\mathrm{Im}\sum_k w_k\mathrm{Tr}\big[X_{a,k}^\dagger(t)Z_k(t)\big].
\]

复测试场必须拆成实部、虚部。存量六点上，子采样前缀积分与显式两时求和相对差 **0**（同一因果矩形规则）。接触项 \(-\langle D\rangle h\) 只在 25 个快照上有数。

**未做** \(A_{\mathrm{cl}}\pm\varepsilon h\) 的新传播。那一步仍等人审物理定义之后。

## 4. 辐射候选（仍不求值）

真空均匀薄片、法线、两侧真空（9 月 18 日说明稿）：

\[
\mathbf E_{\mathrm{emit}}(z,t)=-\frac{Z_0}{2}\mathbf J_{\mathrm{sheet}}(t-|z|/c),
\qquad
a_{\mathrm{src}}(\omega)=i\sqrt{\frac{Z_0}{4\pi\hbar\omega S}}\,\widetilde I(\omega).
\]

\(I=S J_{\mathrm{sheet}}\)。投影到已批准 \(\phi\) 后 \(K(t)\) 含 \(1/\sqrt{\omega}\)，**不能**再当成与 Q9 窗严格差一个与频率无关的常数。

仍 unset：\(S\)、\(N_{\mathrm{cell}}\)、单侧收集对完整模空间、脉冲结束后的出射时间、代入的是零阶经典泵电流还是全耦合电流。

代码拒绝把该候选变成 \(\langle n\rangle\)。

## 5. 哪些输出可能只需 \(C\)，哪些同阶就要 \(\mathcal R^A\)

记号 \(b_{\mathrm{out}}=b_{\mathrm{in}}+\lambda B_1+\lambda^2 B_2+\cdots\)，\(B_1\) 为经典泵下的电子源。

| 目标 | 最低阶 |
|---|---|
| 独立输入真空、弱辐射下的正常二阶矩（如平均光子数的源贡献） | \(O(\lambda^2)\) 可用 \(B_1^\dagger B_1\)（均值 + \(C\)）；平均磁性 H2 未稳，不能宣布完整 H2 光子数合格 |
| 相位敏感异常矩 \(\langle\delta b_\mu\delta b_\nu\rangle\) | 同阶可能有 \(\langle b_{\mathrm{in}}B_2\rangle\)，要响应与接触项 |
| 非真空输入的正常矩 | 通常不能删输入—响应 |
| \(g^{(2)}\) / 一般非 Gaussian | 更高阶或另审闭合 |

Gaussian closure、强纯 BSV、完整量子泵浦：均 **not_chosen / not_run**。
