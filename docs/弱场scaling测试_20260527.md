# 弱场 scaling 测试记录（2026-05-27）

## 1. 测试目的

这轮测试用于检查低阶响应是否满足微扰极限：

```text
电流振幅：J(ω)   ∝ E0
电流振幅：J(2ω) ∝ E0^2
电流振幅：J(3ω) ∝ E0^3
```

由于当前 `HHG.dat` 输出的是：

```text
HHG(nω) = |J(nω)|^2
```

所以对 `HHG.dat` 的强度峰值应检查：

```text
H1 ∝ E0^2
H2 ∝ E0^4
H3 ∝ E0^6
```

三组运行都给出干净初始电流：

```text

```

说明 `nb1-104` 的全价带截断仍保持基态电流为机器零。

新增 TB 质量诊断输出：

```text
H(k) Hermiticity:  max = 8.11e-16, rms = 7.04e-16
r(k) Hermiticity:  max = 7.31e-03, rms = 3.64e-03
v(k) Hermiticity:  max = 9.87e-04, rms = 5.36e-04
```

其中 `H(k)` 很干净；`r(k)` 和 `v(k)` 的绝对最大非厄米元不是 `1e-10` 量级，需要后续进一步检查。当前代码在实际使用前会 Hermitize `D_full`、`dH_full`、`P_full`，所以这不是已经证明会污染谱的错误；但按审查标准，它是一个未完全闭合的矩阵元质量问题。

下一步建议把 TB 诊断改成：

```text
按 x/y/z 分量输出；
输出相对 Frobenius 误差；
比较 Hermitize 前后对 P=dH/dk-i[D,H] 的影响；
重点关注 x/y 分量，因为当前外场为面内线偏振。
```

## 6. 结论

这轮测试不能说明代码错误；更合理的解释是：

```text
2.0e11 -> 1.25e10 W/cm^2 这一组强度仍不够“弱场”，尤其对 H3 来说还没有进入纯三阶微扰区。
```

当前可确认：

```text
1. H1 线性响应通过。
2. 初始电流保持机器零，通过。
3. lg_cov / nb1-104 路径在弱场降低强度时没有出现数值爆炸。
4. H2/H3 的严格弱场 scaling 还没有被这组数据证明。
```

当前不能据此说：

```text
H2/H3 低阶非线性 scaling 已完全通过。
```

```text
E0    : |J(0)| = 4.3862e-18
E0/2  : |J(0)| = 4.4265e-18
E0/4  : |J(0)| = 4.3935e-18
```

逐分量 TB 质量诊断：

```text
H(k)   max|H-H+| = 8.11e-16, avg rel_frob = 6.33e-16
r_x(k) max|r-r+| = 7.31e-03, avg rel_frob = 1.02e-03
r_y(k) max|r-r+| = 6.61e-03, avg rel_frob = 9.88e-04
r_z(k) max|r-r+| = 2.12e-11, avg rel_frob = 3.69e-13
v_x(k) max|v-v+| = 9.87e-04, avg rel_frob = 3.29e-03
v_y(k) max|v-v+| = 9.40e-04, avg rel_frob = 3.14e-03
v_z(k) max|v-v+| = 3.31e-12, avg rel_frob = 7.17e-13
```

解释：

```text
H(k) 的厄米性为机器精度。
r_z/v_z 非厄米误差为机器精度附近。
r_x/r_y 的相对 Frobenius 误差约 1e-3，v_x/v_y 约 3e-3。
```

这说明 Wannier 矩阵元的面内分量存在小但可见的非厄米数值误差。当前传播前会对实际使用的矩阵做 Hermitize，而且弱场 scaling 与 |J(0)| 检查均正常，所以这不是阻塞性错误；但它应作为矩阵元质量系统误差项记录，后续可在论文或补充材料中说明矩阵元经过厄米化处理。

## 10. 当前弱场审查结论

当前可以认为：

```text
1. lg_cov / nb1-104 / 40x40 / T2_cycles=0.5 通过了 H1 线性响应检查。
2. 更低强度 I_full=2e10 下，H2/H3 的直接电流投影已经接近二阶/三阶微扰规律。
3. 初始电流始终为机器零，说明全价带 + 截高导带窗口没有破坏基态。
4. 弱场 scaling 没有暴露出 RK4、协变导数、电流算符或 T2_cycles 实现的系统性错误。
```

暂时不必继续跑 `I_full=2e9 W/cm^2`。只有在需要给审稿人展示非常严格的三阶微扰极限，或者外部审查坚持 `HHG.dat` 峰值指数必须更接近理想值时，再补这一组。
